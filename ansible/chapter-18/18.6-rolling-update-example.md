# 18.6 Πρακτικό παράδειγμα — Rolling Update με Zero Downtime 🚀

## Τι θα φτιάξουμε

Ένα **production-grade rolling update playbook** που χρησιμοποιεί **όλα** τα εργαλεία performance:

```
rolling-update.yml
│
├── Pre-checks (assert)
│   └── Επαλήθευση νέας έκδοσης
│
├── Rolling deployment (serial: "25%")
│   ├── pre_tasks:  Drain από load balancer
│   ├── block:      Stop → Deploy → Start
│   ├── rescue:     Rollback αν αποτύχει
│   ├── post_tasks: Health check + Restore σε LB
│   └── always:     Logging
│
└── Post-deployment (run_once)
    ├── Τελικό health check όλων
    └── Αναφορά αποτελεσμάτων
```

```
Παράδειγμα υποδομής:
                                                       
  ┌─────────────────────────────────────────────────┐

```

## Το Playbook

```yaml
---
# rolling-update.yml
# Zero-Downtime Rolling Update

# ══════════════════════════════════════════════════════
# PLAY 1: PRE-DEPLOYMENT CHECKS (run_once)
# ══════════════════════════════════════════════════════
- name: Pre-deployment Checks
  hosts: webservers
  gather_facts: false

  vars:
    app_name:        myapp
    app_version:     "{{ new_version | mandatory }}"
    app_dir:         /opt/myapp
    app_port:        8080
    backup_dir:      /opt/myapp-backup
    deploy_src:      "files/{{ app_name }}-{{ app_version }}"
    lb_socket:       /var/run/haproxy/haproxy.sock
    lb_backend:      webservers_backend
    max_fail_pct:    25

  tasks:

    - name: "🔍 Επαλήθευση new_version variable"
      ansible.builtin.assert:
        that:
          - new_version is defined
          - new_version | length > 0
        fail_msg: "❌ Δεν ορίστηκε new_version! Χρήση: -e new_version=2.5.0"
      run_once: true

    - name: "🔍 Έλεγχος αρχείου deployment"
      ansible.builtin.stat:
        path: "{{ deploy_src }}"
      register:    deploy_src_stat
      delegate_to: localhost
      run_once:    true

    - name: "🔍 Επαλήθευση deploy source"
      ansible.builtin.assert:
        that:
          - deploy_src_stat.stat.exists
        fail_msg: >
          ❌ Δεν βρέθηκε: {{ deploy_src }}
          Βεβαιώσου ότι το deployment package υπάρχει!
      run_once: true

    - name: "🔍 Έλεγχος load balancer"
      ansible.builtin.command:
        cmd: "haproxy -f /etc/haproxy/haproxy.cfg -c"
      register:     lb_check
      changed_when: false
      ignore_errors: true
      delegate_to:   "{{ groups['loadbalancers'][0] }}"
      run_once:      true

    - name: "✅ Pre-checks OK — Ξεκινά deployment v{{ app_version }}"
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "  🚀 ROLLING UPDATE — v{{ app_version }}"
          - "  Hosts  : {{ ansible_play_hosts | join(', ') }}"
          - "  Serial : 25% ανά batch"
          - "  LB     : {{ groups['loadbalancers'][0] }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      run_once: true

# ══════════════════════════════════════════════════════
# PLAY 2: ROLLING DEPLOYMENT
# ══════════════════════════════════════════════════════
- name: Rolling Deployment
  hosts: webservers
  become: true
  gather_facts: true
  strategy:            linear    # ← linear για προβλέψιμη σειρά
  serial:              "25%"     # ← 25% hosts ανά batch
  max_fail_percentage: "{{ max_fail_pct | default(25) }}"

  vars:
    app_name:    myapp
    app_version: "{{ new_version }}"
    app_dir:     /opt/myapp
    app_port:    8080
    backup_dir:  /opt/myapp-backup
    deploy_src:  "files/{{ app_name }}-{{ app_version }}"
    lb_socket:   /var/run/haproxy/haproxy.sock
    lb_backend:  webservers_backend

  pre_tasks:

    # ── Ανακοίνωση batch ──────────────────────
    - name: "📦 Batch: {{ inventory_hostname }}"
      ansible.builtin.debug:
        msg: "Έναρξη deployment σε {{ inventory_hostname }}..."

    # ── Αφαίρεση από load balancer ────────────
    - name: "🔌 Αφαίρεση {{ inventory_hostname }} από LB"
      community.general.haproxy:
        state:   disabled
        host:    "{{ inventory_hostname }}"
        backend: "{{ lb_backend }}"
        socket:  "{{ lb_socket }}"
        wait:    true
        wait_retries: 10
        wait_interval: 1
      delegate_to:   "{{ groups['loadbalancers'][0] }}"
      ignore_errors: true    # ← σε case που LB δεν είναι HAProxy

    # ── Drain — αναμονή για υπάρχοντα connections ──
    - name: "⏳ Drain connections (10s)"
      ansible.builtin.pause:
        seconds: 10

    # ── Backup τρέχουσας έκδοσης ─────────────
    - name: "💾 Backup τρέχουσας έκδοσης"
      ansible.builtin.copy:
        src:        "{{ app_dir }}/"
        dest:       "{{ backup_dir }}/"
        remote_src: true
      ignore_errors: true

  tasks:

    # ── Deployment ────────────────────────────
    - name: "Deployment v{{ app_version }} σε {{ inventory_hostname }}"
      block:

        - name: "⏹ Σταμάτα {{ app_name }}"
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: stopped

        - name: "📁 Deploy v{{ app_version }}"
          ansible.builtin.copy:
            src:   "{{ deploy_src }}/"
            dest:  "{{ app_dir }}/"
            mode:  '0755'
            owner: "{{ app_name }}"
            group: "{{ app_name }}"

        - name: "⚙️ Εκτέλεση migrations"
          ansible.builtin.command:
            cmd:   "{{ app_dir }}/manage.py migrate --no-input"
            chdir: "{{ app_dir }}"
          become:       true
          become_user:  "{{ app_name }}"
          changed_when: true
          run_once:     true    # ← migrations ΜΟΝΟ μία φορά!

        - name: "▶️ Εκκίνηση {{ app_name }}"
          ansible.builtin.service:
            name:    "{{ app_name }}"
            state:   started
            enabled: true

        - name: "🔍 Health check (αναμονή)"
          ansible.builtin.uri:
            url:         "http://localhost:{{ app_port }}/health"
            status_code: 200
            return_content: true
          register: health
          retries:  10
          delay:    5
          until:    health.status == 200

        - name: "🔍 Επαλήθευση νέας έκδοσης"
          ansible.builtin.assert:
            that:
              - "app_version in health.content"
            fail_msg: >
              ❌ Λάθος έκδοση στο health endpoint!
              Αναμενόταν: {{ app_version }}
              Βρέθηκε:    {{ health.content }}

      rescue:

        - name: "❌ Deployment απέτυχε! Rollback..."
          ansible.builtin.debug:
            msg:
              - "Σφάλμα στο: {{ ansible_failed_task.name }}"
              - "Ξεκινά rollback για {{ inventory_hostname }}"

        - name: "⏹ Σταμάτα σπασμένη έκδοση"
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: stopped
          ignore_errors: true

        - name: "🔄 Επαναφορά από backup"
          ansible.builtin.copy:
            src:        "{{ backup_dir }}/"
            dest:       "{{ app_dir }}/"
            remote_src: true

        - name: "▶️ Εκκίνηση παλιάς έκδοσης"
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: started

        - name: "❌ Αποτυχία deployment"
          ansible.builtin.fail:
            msg: >
              Rollback ολοκληρώθηκε για {{ inventory_hostname }}.
              Ελέγξτε τα logs: journalctl -u {{ app_name }}

      always:

        # ── Log ΠΑΝΤΑ ─────────────────────────
        - name: "📝 Log deployment"
          ansible.builtin.lineinfile:
            path:   /var/log/deployments.log
            line: >
              {{ ansible_date_time.iso8601 }}
              | {{ inventory_hostname }}
              | {{ app_name }}
              | v{{ app_version }}
              | {{ 'SUCCESS' if ansible_failed_task is not defined
                             else 'FAILED' }}
            create: true
            mode:   '0644'

  post_tasks:

    # ── Επαναφορά στον load balancer ──────────
    - name: "🔌 Επαναφορά {{ inventory_hostname }} στο LB"
      community.general.haproxy:
        state:   enabled
        host:    "{{ inventory_hostname }}"
        backend: "{{ lb_backend }}"
        socket:  "{{ lb_socket }}"
      delegate_to:   "{{ groups['loadbalancers'][0] }}"
      ignore_errors: true

    - name: "✅ {{ inventory_hostname }} — Deployment ολοκληρώθηκε"
      ansible.builtin.debug:
        msg: >
          {{ inventory_hostname }}:
          v{{ app_version }} ✅ (servicing traffic)

# ══════════════════════════════════════════════════════
# PLAY 3: POST-DEPLOYMENT VERIFICATION
# ══════════════════════════════════════════════════════
- name: Post-deployment Verification
  hosts: webservers
  gather_facts: false

  vars:
    app_version: "{{ new_version }}"
    app_port:    8080

  tasks:

    - name: "🔍 Final health check — όλοι οι hosts"
      ansible.builtin.uri:
        url:            "http://{{ inventory_hostname }}:{{ app_port }}/health"
        status_code:    200
        return_content: true
      register:     final_health
      changed_when: false
      delegate_to:  localhost

    - name: "📊 Τελική αναφορά"
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "  ✅ ROLLING UPDATE COMPLETE"
          - "  Version : v{{ app_version }}"
          - "  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - >
            {{
              ansible_play_hosts
              | map('extract', hostvars,
                    ['final_health', 'status'])
              | list
              | zip(ansible_play_hosts)
              | map('reverse') | map('list')
              | map('join', ': ')
              | list
            }}
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      run_once: true
```

## Εκτέλεση

```bash
# ── Βασική εκτέλεση ─────────────────────────────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0"

# ── Με verbose (δες κάθε βήμα) ──────────────────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0" -v

# ── Dry run (τι θα κάνει χωρίς να το κάνει) ─────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0" --check --diff

# ── Μόνο σε συγκεκριμένο host (για test) ─────────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0" \
    --limit web-01

# ── Αυστηρότερο max_fail ─────────────────────────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0 max_fail_pct=0"

# ── Λίστα tasks πριν εκτέλεση ────────────────────────
ansible-playbook playbooks/rolling-update.yml \
    -e "new_version=2.5.0" --list-tasks
```

## Σύνοψη 18.6

```
Τι χρησιμοποιήσαμε:
│
├── serial: "25%"
│   └── Rolling — 1 host ανά batch (25% of 4)
│
├── max_fail_percentage
│   └── Ασφαλιστική δικλίδα
│
├── strategy: linear
│   └── Προβλέψιμη σειρά tasks
│
├── pre_tasks / post_tasks
│   ├── Drain από load balancer
│   └── Επαναφορά στο load balancer
│
├── block / rescue / always
│   ├── block:  Deployment
│   ├── rescue: Rollback
│   └── always: Logging
│
├── run_once
│   └── Migrations: μία φορά μόνο
│
└── delegate_to
    └── LB operations: εκτέλεση στο lb-01
```
