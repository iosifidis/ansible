# 6.5 Host Verification 🔍

## Τι είναι το Host Verification;

Το Host Verification είναι η διαδικασία **επαλήθευσης** του inventory — να βεβαιωθείς ότι:

```
✅ Το inventory διαβάζεται σωστά
✅ Οι hosts είναι στα σωστά groups
✅ Οι μεταβλητές έχουν τις σωστές τιμές
✅ Η Ansible μπορεί να συνδεθεί στους servers
```

---

## Εργαλείο 1: `ansible-inventory`

Το κύριο εργαλείο για επαλήθευση inventory:

### `--list` — Πλήρης λίστα
```bash
# Δες όλο το inventory σε JSON format
ansible-inventory --list

# Αναμενόμενο output:
# {
#     "_meta": {
#         "hostvars": {
#             "localhost": {...},
#             "nextcloud": {
#                 "ansible_host": "83.212.104.27",
#                 "ansible_port": 2022,
#                 "ansible_user": "ansible",
#                 ...
#             }
#         }
#     },
#     "all": {
#         "children": ["all_managed", "controller", "ungrouped"]
#     },
#     ...
# }
```

### `--graph` — Δενδρική δομή
```bash
# Δες την ιεραρχία του inventory
ansible-inventory --graph

# Αναμενόμενο output:
# @all:
# |--@ungrouped:
# |--@controller:
# |  |--localhost
# |--@all_managed:
# |  |--@debian_based:
# |  |  |--nextcloud
# |  |--@redhat_based:
# |  |--@opensuse_based:

# Με μεταβλητές
ansible-inventory --graph --vars

# Αναμενόμενο output:
# @all:
# |--@debian_based:
# |  |--nextcloud
# |  |  |--{ansible_host = 83.212.104.27}
# |  |  |--{ansible_port = 2022}
# |  |  |--{ansible_user = ansible}
```

### `--host` — Πληροφορίες συγκεκριμένου Host
```bash
# Δες όλες τις μεταβλητές ενός host
ansible-inventory --host nextcloud

# Αναμενόμενο output:
# {
#     "ansible_become": true,
#     "ansible_become_method": "sudo",
#     "ansible_host": "83.212.104.27",
#     "ansible_port": 2022,
#     "ansible_ssh_private_key_file": "/home/ansible/.ssh/id_ed25519",
#     "ansible_user": "ansible",
#     "common_packages": ["curl", "wget", "nano", "git", "htop"],
#     "server_env": "production",
#     "system_timezone": "Europe/Athens"
# }
```

## Εργαλείο 2: `ansible` — Ad-hoc Verification

### Ping Test
```bash
# Έλεγχος σύνδεσης σε όλους
ansible all -m ansible.builtin.ping

# Έλεγχος σε συγκεκριμένο group
ansible debian_based -m ansible.builtin.ping

# Έλεγχος σε συγκεκριμένο host
ansible nextcloud -m ansible.builtin.ping

# Αναμενόμενο output:
# nextcloud | SUCCESS => {
#     "changed": false,
#     "ping": "pong"
# }
```

### Gathering Facts Test
```bash
# Συλλογή ΟΛΩΝ των facts
ansible nextcloud -m ansible.builtin.setup

# Φιλτράρισμα facts
ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_distribution*"

# Αναμενόμενο:
# nextcloud | SUCCESS => {
#     "ansible_facts": {
#         "ansible_distribution": "Debian",
#         "ansible_distribution_major_version": "12",
#         "ansible_distribution_release": "bookworm",
#         "ansible_distribution_version": "12.13"
#     }
# }

# Άλλα χρήσιμα filters
ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_memory_mb"      # μνήμη

ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_processor*"     # CPU

ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_network*"       # δίκτυο

ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_mounts"         # δίσκοι
```

### Variable Test
```bash
# Επαλήθευση μεταβλητών
ansible nextcloud -m ansible.builtin.debug \
    -a "msg='Host: {{ inventory_hostname }}, TZ: {{ system_timezone }}'"

# Επαλήθευση group membership
ansible nextcloud -m ansible.builtin.debug \
    -a "msg='Groups: {{ group_names }}'"

# Αναμενόμενο:
# nextcloud | SUCCESS => {
#     "msg": "Groups: ['debian_based', 'all_managed']"
# }
```

## Patterns για στοχευμένο έλεγχο

```bash
# Έλεγχος με patterns

# Ένα group
ansible webservers -m ping

# Πολλά groups
ansible webservers,dbservers -m ping

# Όλοι εκτός από ένα group
ansible all,!controller -m ping

# Wildcard
ansible web* -m ping

# Intersection (hosts που ανήκουν ΚΑΙ στα δύο groups)
ansible debian_based:&webservers -m ping

# Συγκεκριμένος host
ansible nextcloud -m ping

# Έλεγχος αν host ανήκει σε group
ansible-inventory --graph | grep nextcloud
```

## Playbook για πλήρη επαλήθευση

```yaml
---
# verify-inventory.yml
# Τρέξε: ansible-playbook playbooks/verify-inventory.yml

- name: Επαλήθευση Inventory
  hosts: all
  gather_facts: true

  tasks:

    - name: Βασικές πληροφορίες host
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host     : {{ inventory_hostname }}"
          - "IP       : {{ ansible_facts['default_ipv4']['address'] }}"
          - "OS       : {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}"
          - "Kernel   : {{ ansible_facts['kernel'] }}"
          - "Groups   : {{ group_names | join(', ') }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

    - name: Έλεγχος μνήμης
      ansible.builtin.debug:
        msg:
          - "RAM Total: {{ ansible_facts['memtotal_mb'] }} MB"
          - "RAM Free : {{ ansible_facts['memfree_mb'] }} MB"

    - name: Έλεγχος δίσκου
      ansible.builtin.debug:
        msg: "Disk {{ item.mount }}: {{ item.size_available | human_readable }}"
      loop: "{{ ansible_facts['mounts'] }}"
      when: item.mount == '/'

    - name: Έλεγχος SSH connectivity
      ansible.builtin.ping:

    - name: Έλεγχος sudo
      ansible.builtin.command: whoami
      become: true
      register: whoami_result

    - name: Εμφάνιση sudo αποτελέσματος
      ansible.builtin.debug:
        msg: "Sudo whoami: {{ whoami_result.stdout }}"

    - name: Έλεγχος Python version
      ansible.builtin.command: python3 --version
      register: python_result

    - name: Εμφάνιση Python version
      ansible.builtin.debug:
        msg: "Python: {{ python_result.stdout }}"
```

```bash
# Εκτέλεση verification playbook
ansible-playbook playbooks/verify-inventory.yml

# Μόνο σε συγκεκριμένο host
ansible-playbook playbooks/verify-inventory.yml \
    --limit nextcloud
```

## Troubleshooting — Συνηθισμένα προβλήματα

```bash
# Πρόβλημα 1: Host not found
ansible wronghost -m ping
# ERROR! No hosts matched

# Λύση: έλεγξε το όνομα στο inventory
ansible-inventory --graph | grep wronghost

# ────────────────────────────────────────────

# Πρόβλημα 2: Connection refused
# nextcloud | FAILED! => {"msg": "Connection refused"}

# Λύση: έλεγξε port και SSH service
ansible nextcloud -m ping -vvv   # verbose για debugging

# ────────────────────────────────────────────

# Πρόβλημα 3: Permission denied
# nextcloud | FAILED! => {"msg": "Permission denied"}

# Λύση: έλεγξε SSH key και ansible user
ssh -i ~/.ssh/id_ed25519 -p 2022 ansible@83.212.104.27

# ────────────────────────────────────────────

# Πρόβλημα 4: Μεταβλητή δεν βρίσκεται
# ERROR! 'my_var' is undefined

# Λύση: έλεγξε αν η μεταβλητή υπάρχει
ansible-inventory --host nextcloud | grep my_var
```

## Quick Reference — Οι πιο χρήσιμες εντολές

```bash
# Δομή inventory
ansible-inventory --graph

# Δομή με μεταβλητές
ansible-inventory --graph --vars

# Μεταβλητές host
ansible-inventory --host nextcloud

# Πλήρης λίστα σε JSON
ansible-inventory --list

# Ping σε όλους
ansible all -m ping

# Ping σε group
ansible debian_based -m ping

# Facts από host
ansible nextcloud -m setup -a "filter=ansible_distribution*"

# Debug μεταβλητής
ansible nextcloud -m debug -a "msg={{ system_timezone }}"
```

## Σύνοψη 6.5

```
Host Verification
├── ansible-inventory
│   ├── --graph       → δενδρική δομή
│   ├── --graph --vars→ δομή + μεταβλητές
│   ├── --host NAME   → μεταβλητές host
│   └── --list        → πλήρης JSON λίστα
│
├── ansible (ad-hoc)
│   ├── -m ping       → έλεγχος σύνδεσης
│   ├── -m setup      → facts
│   └── -m debug      → εμφάνιση μεταβλητών
│
└── Troubleshooting
    ├── -vvv          → verbose debugging
    └── ssh manual    → έλεγχος σύνδεσης
```
