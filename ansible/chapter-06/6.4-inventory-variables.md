# 6.4 Μεταβλητές στο Inventory 📊

## Γιατί μεταβλητές στο Inventory;

Οι μεταβλητές στο inventory μας επιτρέπουν να **παραμετροποιούμε** την συμπεριφορά της Ansible **ανά host ή group** — χωρίς να αλλάζουμε τα playbooks.

```
┌─────────────────────────────────────────────────────────┐
│  Χωρίς μεταβλητές:                                      │
│  → Ένα playbook για κάθε server ❌                      │
│                                                         │
│  Με μεταβλητές:                                         │
│  → Ένα playbook, διαφορετικές τιμές ανά server ✅       │
└─────────────────────────────────────────────────────────┘
```

---

## Οι 3 τρόποι ορισμού μεταβλητών

```
Τρόπος 1: Inline στο inventory file
          → Απλό, αλλά γίνεται ακατάστατο

Τρόπος 2: group_vars/ directory
          → Βέλτιστη πρακτική για groups ✅

Τρόπος 3: host_vars/ directory
          → Βέλτιστη πρακτική για hosts ✅
```

---

## Τρόπος 1: Inline Μεταβλητές

### Στο INI:
```ini
[webservers]
# Host variables inline
web01 ansible_host=192.168.1.10 ansible_port=2022 http_port=80
web02 ansible_host=192.168.1.11 ansible_port=2022 http_port=8080

# Group variables
[webservers:vars]
app_env=production
ssl_enabled=true

[all:vars]
ansible_user=ansible
ansible_ssh_private_key_file=/home/ansible/.ssh/id_ed25519
```

### Στο YAML:
```yaml
---
all:
  vars:
    ansible_user: ansible
  children:
    webservers:
      vars:
        app_env: production
        ssl_enabled: true
      hosts:
        web01:
          ansible_host: 192.168.1.10
          ansible_port: 2022
          http_port: 80          # ← host variable
        web02:
          ansible_host: 192.168.1.11
          ansible_port: 2022
          http_port: 8080        # ← διαφορετική τιμή!
```

> ⚠️ **Πρόβλημα με Inline:** Όταν έχεις πολλές μεταβλητές, το inventory γίνεται **δυσανάγνωστο**. Γι' αυτό υπάρχουν τα `group_vars/` και `host_vars/`.

---

## Τρόπος 2: group_vars/ Directory

Αντί να γράφεις τις μεταβλητές inline, τις βάζεις σε **ξεχωριστά αρχεία**:

### Δομή:
```
ansible/
├── inventory/
│   ├── hosts.ini
│   └── group_vars/           ← φάκελος για group variables
│       ├── all.yml           ← μεταβλητές για ΟΛΟΥΣ
│       ├── webservers.yml    ← μεταβλητές για webservers
│       ├── dbservers.yml     ← μεταβλητές για dbservers
│       └── debian_based.yml  ← μεταβλητές για debian hosts
```

### `group_vars/all.yml`:
```yaml
---
# Μεταβλητές για ΟΛΟΥΣ τους servers
ansible_user:                 ansible
ansible_ssh_private_key_file: /home/ansible/.ssh/id_ed25519
ansible_become:               true
ansible_become_method:        sudo

# Κοινές ρυθμίσεις
system_timezone:    "Europe/Athens"
system_locale:      "el_GR.UTF-8"
ntp_server:         "ntp.grnet.gr"

# Κοινά packages
common_packages:
  - curl
  - wget
  - nano
  - git
  - htop
```

### `group_vars/webservers.yml`:
```yaml
---
# Μεταβλητές μόνο για webservers
http_port:               80
https_port:              443
app_env:                 production
ssl_enabled:             true
nginx_worker_processes:  4
nginx_worker_connections: 1024

# Directories
web_root:    /var/www/html
log_dir:     /var/log/nginx
```

### `group_vars/dbservers.yml`:
```yaml
---
# Μεταβλητές μόνο για dbservers
db_port:         5432
db_name:         myapp
db_user:         appuser
max_connections: 100
shared_buffers:  "256MB"
```

### `group_vars/debian_based.yml`:
```yaml
---
# Μεταβλητές για Debian/Ubuntu hosts
ansible_python_interpreter: /usr/bin/python3
package_manager:            apt
service_manager:            systemd
```

## Τρόπος 3: host_vars/ Directory

Για μεταβλητές που αφορούν **συγκεκριμένο host**:

### Δομή:
```
ansible/
├── inventory/
│   ├── hosts.ini
│   ├── group_vars/
│   │   └── all.yml
│   └── host_vars/            ← φάκελος για host variables
│       ├── web01.yml         ← μεταβλητές μόνο για web01
│       ├── web02.yml         ← μεταβλητές μόνο για web02
│       └── nextcloud.yml     ← μεταβλητές για nextcloud
```

### `host_vars/web01.yml`:
```yaml
---
# Μεταβλητές μόνο για τον web01
ansible_host: 192.168.1.10
ansible_port: 2022

# Server-specific ρυθμίσεις
server_role:             primary
nginx_worker_processes:  8        # ← πιο δυνατό μηχάνημα
max_upload_size:         "100M"

# Monitoring
enable_monitoring: true
alert_email:       "admin@example.com"
```

### `host_vars/web02.yml`:
```yaml
---
# Μεταβλητές μόνο για τον web02
ansible_host: 192.168.1.11
ansible_port: 2022

server_role:             secondary
nginx_worker_processes:  4        # ← λιγότερο δυνατό
max_upload_size:         "50M"

enable_monitoring: true
alert_email:       "admin@example.com"
```

### `host_vars/nextcloud.yml`:
```yaml
---
# Μεταβλητές για τον nextcloud
ansible_host: 192.212.104.27
ansible_port: 2022

# Server info
server_role:    nextcloud
server_env:     production

# Nextcloud specific
nextcloud_domain: "cloud.example.com"
nextcloud_admin:  "admin"
```

## Σειρά προτεραιότητας μεταβλητών

```
┌─────────────────────────────────────────────────────────┐
│  Υψηλότερη προτεραιότητα                                │
│                                                         │
│  1. Extra vars (-e flag)                                │
│     ansible-playbook -e "http_port=9090"                │
│                                                         │
│  2. Task vars (set_fact, register)                      │
│                                                         │
│  3. host_vars/hostname.yml                              │
│     → συγκεκριμένος host                                │
│                                                         │
│  4. group_vars/groupname.yml                            │
│     → συγκεκριμένο group                                │
│                                                         │
│  5. group_vars/all.yml                                  │
│     → όλοι οι hosts                                     │
│                                                         │
│  6. Inline inventory variables                          │
│                                                         │
│  7. Default role variables                              │
│                                                         │
│  Χαμηλότερη προτεραιότητα                               │
└─────────────────────────────────────────────────────────┘
```

## Χρήση μεταβλητών στα Playbooks

```yaml
---
- name: Web server configuration
  hosts: webservers
  tasks:

    - name: Ρύθμιση nginx port
      ansible.builtin.lineinfile:
        path: /etc/nginx/nginx.conf
        regexp: '^listen'
        line: "listen {{ http_port }};"  # ← από group_vars/webservers.yml

    - name: Δημιουργία web root
      ansible.builtin.file:
        path: "{{ web_root }}"           # ← από group_vars/webservers.yml
        state: directory
        mode: '0755'

    - name: Εγκατάσταση κοινών packages
      ansible.builtin.package:
        name: "{{ common_packages }}"    # ← από group_vars/all.yml
        state: present

    - name: Εμφάνιση server role
      ansible.builtin.debug:
        msg: "Server {{ inventory_hostname }} is {{ server_role }}"
        # ← server_role από host_vars/
```

## Βέλτιστη δομή για το Project μας

```bash
# Δημιουργία host_vars directory
mkdir -p ~/ansible/inventory/host_vars

# Δημιουργία αρχείου για nextcloud
cat > ~/ansible/inventory/host_vars/nextcloud.yml << 'EOF'
---
# Host variables για nextcloud
ansible_host: 192.212.104.27
ansible_port: 2022

# Server info
server_role: managed_server
server_env:  production
server_os:   debian
EOF

# Ενημέρωση group_vars/all.yml
cat > ~/ansible/inventory/group_vars/all.yml << 'EOF'
---
# Global variables για όλους τους servers

# Σύνδεση
ansible_user:                 ansible
ansible_ssh_private_key_file: /home/ansible/.ssh/id_ed25519
ansible_become:               true
ansible_become_method:        sudo

# Σύστημα
system_timezone: "Europe/Athens"
system_locale:   "el_GR.UTF-8"

# Κοινά packages
common_packages:
  - curl
  - wget
  - nano
  - git
  - htop
  - tree
EOF
```

## Επαλήθευση Μεταβλητών

```bash
# Δες όλες τις μεταβλητές ενός host
ansible-inventory --host nextcloud

# Αναμενόμενο output:
# {
#     "ansible_become": true,
#     "ansible_become_method": "sudo",
#     "ansible_host": "192.212.104.27",
#     "ansible_port": 2022,
#     "ansible_ssh_private_key_file": "/home/ansible/.ssh/id_ed25519",
#     "ansible_user": "ansible",
#     "common_packages": ["curl", "wget", "nano", "git", "htop", "tree"],
#     "server_env": "production",
#     "server_role": "managed_server",
#     "system_timezone": "Europe/Athens"
# }

# Test χρήσης μεταβλητής
ansible nextcloud -m ansible.builtin.debug \
    -a "msg='Role: {{ server_role }}, TZ: {{ system_timezone }}'"
```

## Σύνοψη 6.4

```
Μεταβλητές Inventory
├── Τρόπος 1: Inline → απλό, δυσανάγνωστο
├── Τρόπος 2: group_vars/ → βέλτιστη πρακτική για groups ✅
├── Τρόπος 3: host_vars/  → βέλτιστη πρακτική για hosts ✅
│
├── Προτεραιότητα (υψηλή → χαμηλή):
│   -e flag > host_vars > group_vars > all vars > defaults
│
└── Χρήση στα playbooks:
    └── {{ variable_name }}
```
