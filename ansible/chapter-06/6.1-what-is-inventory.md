# 6.1 Τι είναι το Inventory (εις βάθος) 📋

## Ο ρόλος του Inventory

Το Inventory είναι η **απάντηση** της Ansible στο ερώτημα:

> *«Σε ΠΟΙΟΥΣ servers θα εκτελέσω τις εργασίες μου;»*

Χωρίς inventory, η Ansible **δεν ξέρει** πού να συνδεθεί. Είναι το **θεμέλιο** κάθε αυτοματοποίησης.

```
┌─────────────────────────────────────────────────────────┐
│                    Ansible                              │
│                                                         │
│  Playbook    +    Inventory   → Εκτέλεση                │
│ (τι να κάνω)      (σε ποιους)                           │
└─────────────────────────────────────────────────────────┘
```

---

## Τι περιέχει το Inventory

```
Inventory
├── Hosts     → οι servers (IP ή hostname)
├── Groups    → ομαδοποίηση servers
├── Variables → παράμετροι ανά host ή group
└── Hierarchy → groups μέσα σε groups
```

---

## Static vs Dynamic Inventory

```
┌─────────────────────────────────────────────────────────┐
│  STATIC INVENTORY                                       │
│  ├── Αρχείο που γράφεις εσύ χειροκίνητα                 │
│  ├── INI ή YAML format                                  │
│  ├── Αλλάζει μόνο αν το επεξεργαστείς                   │
│  └── Ιδανικό για: σταθερή υποδομή, εκμάθηση ✅          │
├─────────────────────────────────────────────────────────┤
│  DYNAMIC INVENTORY                                      │
│  ├── Script ή plugin που γεννά το inventory αυτόματα    │
│  ├── Συνδέεται με AWS, Azure, VMware κλπ                │
│  ├── Ανακαλύπτει servers αυτόματα                       │
│  └── Ιδανικό για: cloud, dynamic infrastructure         │
└─────────────────────────────────────────────────────────┘
```

> 📝 **Σημείωση για τον Μαθητή:** Ξεκινάμε με **Static Inventory** γιατί είναι απλούστερο και κατανοητό. Το Dynamic θα το δούμε στο 6.6.

---

## Πού βρίσκει το Inventory η Ansible

Η Ansible ψάχνει για inventory με αυτή τη **σειρά προτεραιότητας**:

```
1. Command line flag: -i
   ansible-playbook -i /path/to/hosts.ini playbook.yml
   → Υψηλότερη προτεραιότητα

2. ansible.cfg:
   [defaults]
   inventory = ./inventory/hosts.ini
   → Αυτό χρησιμοποιούμε εμείς ✅

3. ANSIBLE_INVENTORY environment variable:
   export ANSIBLE_INVENTORY=/path/to/hosts.ini

4. Default locations:
   /etc/ansible/hosts
   → Χαμηλότερη προτεραιότητα
```

## Inventory ως φάκελος

Αντί για ένα αρχείο, μπορείς να έχεις **φάκελο** με πολλά αρχεία inventory:

```
inventory/
├── hosts.ini          ← static hosts
├── production.yml     ← production servers
├── staging.yml        ← staging servers
└── group_vars/
    ├── all.yml
    ├── webservers.yml
    └── dbservers.yml
```

```bash
# Χρήση φακέλου ως inventory
ansible-playbook -i inventory/ playbook.yml

# Η Ansible διαβάζει ΟΛΑ τα αρχεία του φακέλου
# και τα συνδυάζει αυτόματα!
```

> 💡 **Πότε να χρησιμοποιήσεις φάκελο:**
> ```
> Ένα αρχείο   → απλές υποδομές, εκμάθηση ✅
> Φάκελος      → πολύπλοκες υποδομές με πολλά environments
> ```

## Τα ειδικά Groups

Η Ansible έχει **δύο ειδικά groups** που υπάρχουν πάντα αυτόματα:

```ini
# [all] → περιέχει ΟΛΟΥΣ τους hosts
ansible all -m ping          # ping σε όλους

# [ungrouped] → hosts που δεν ανήκουν σε κανένα group
ansible ungrouped -m ping    # ping σε ungrouped hosts
```

```
@all
├── @ungrouped     ← hosts χωρίς group
├── @webservers    ← custom group
├── @dbservers     ← custom group
└── @monitoring    ← custom group
```

## Inventory & Facts — Η σύνδεση

Το inventory δεν είναι μόνο λίστα servers — συνδέεται άμεσα με τα **facts** που συλλέγει η Ansible:

```yaml
# Η Ansible συλλέγει facts από κάθε host του inventory
- name: Show inventory info
  hosts: all
  tasks:
    - name: Εμφάνιση inventory hostname
      ansible.builtin.debug:
        msg:
          - "Inventory name : {{ inventory_hostname }}"
          - "Short hostname : {{ inventory_hostname_short }}"
          - "Group names    : {{ group_names }}"
          - "All groups     : {{ groups.keys() | list }}"
```

```
# Αναμενόμενο output:
# inventory_hostname      → nextcloudpi (όπως στο inventory)
# inventory_hostname_short→ nextcloudpi
# group_names             → ['debian_based', 'all_managed']
# groups.keys()           → ['all', 'controller', 'debian_based'...]
```

## Σύνοψη 6.1

```
Inventory
├── Απαντά: "σε ΠΟΙΟΥΣ servers;"
├── Περιέχει: hosts, groups, variables, hierarchy
├── Τύποι:
│   ├── Static  → αρχείο χειροκίνητο (INI ή YAML)
│   └── Dynamic → script/plugin (AWS, Azure κλπ)
├── Μορφές αρχείου: ένα αρχείο ή φάκελος
├── Ειδικά groups: [all] και [ungrouped]
└── Προτεραιότητα:
    1. -i flag
    2. ansible.cfg
    3. ANSIBLE_INVENTORY
    4. /etc/ansible/hosts
```
