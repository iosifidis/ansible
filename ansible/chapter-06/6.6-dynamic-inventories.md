# 6.6 Dynamic Inventories 🔄

## Τι είναι το Dynamic Inventory;

Μέχρι τώρα το inventory μας ήταν **static** — ένα αρχείο που γράφουμε χειροκίνητα. Το **Dynamic Inventory** είναι διαφορετικό:

```
┌─────────────────────────────────────────────────────────┐
│  STATIC INVENTORY                                       │
│  Εσύ γράφεις → hosts.ini → Ansible διαβάζει             │
│                                                         │
│  web01 ansible_host=192.168.1.10  ← γράφτηκε χειροκίνητα│
│  web02 ansible_host=192.168.1.11  ← γράφτηκε χειροκίνητα│
├─────────────────────────────────────────────────────────┤
│  DYNAMIC INVENTORY                                      │
│  Plugin/Script → Cloud API → Ansible                    │
│                                                         │
│  AWS EC2 → 47 instances → Ansible τα ανακαλύπτει ✅     │
│  (αυτόματα, χωρίς χειροκίνητη γραφή)                    │
└─────────────────────────────────────────────────────────┘
```

---

## Πότε χρειάζεσαι Dynamic Inventory

```
✅ Cloud infrastructure (AWS, Azure, GCP)
   → Servers δημιουργούνται/καταστρέφονται συνεχώς

✅ VMware/Proxmox περιβάλλοντα
   → Πολλά VMs που αλλάζουν συχνά

✅ Kubernetes clusters
   → Nodes που scale up/down

✅ Large scale infrastructure (100+ servers)
   → Αδύνατο να συντηρήσεις χειροκίνητα

❌ Μικρή σταθερή υποδομή (< 20 servers)
   → Static inventory αρκεί
```

## Τύποι Dynamic Inventory

### 1. Inventory Plugins (Σύγχρονη προσέγγιση ✅)

```yaml
# aws_ec2.yml — Dynamic inventory από AWS
plugin: amazon.aws.aws_ec2
regions:
  - eu-west-1
  - eu-central-1
filters:
  instance-state-name: running    # μόνο running instances
  tag:Environment: production     # μόνο production servers
keyed_groups:
  - key: tags.Role                # grouping βάσει tag
    prefix: role
  - key: placement.region         # grouping βάσει region
    prefix: region
hostnames:
  - private-ip-address            # χρησιμοποίησε private IP
```

```yaml
# azure_rm.yml — Dynamic inventory από Azure
plugin: azure.azcollection.azure_rm
include_vm_resource_groups:
  - myResourceGroup
auth_source: auto
keyed_groups:
  - key: tags.environment
    prefix: env
  - key: location
    prefix: location
```

```yaml
# gcp_compute.yml — Dynamic inventory από GCP
plugin: google.cloud.gcp_compute
projects:
  - my-gcp-project
regions:
  - europe-west1
filters:
  - status = RUNNING
keyed_groups:
  - key: labels.role
    prefix: role
```

### 2. Inventory Scripts (Παλιά προσέγγιση)

```python
#!/usr/bin/env python3
# custom_inventory.py — Custom dynamic inventory script

import json
import sys

def get_inventory():
    """
    Επιστρέφει inventory σε JSON format
    που καταλαβαίνει η Ansible
    """
    inventory = {
        "webservers": {
            "hosts": ["web01.example.com", "web02.example.com"],
            "vars": {
                "http_port": 80
            }
        },
        "dbservers": {
            "hosts": ["db01.example.com"],
            "vars": {
                "db_port": 5432
            }
        },
        "_meta": {
            "hostvars": {
                "web01.example.com": {
                    "ansible_host": "192.168.1.10"
                },
                "web02.example.com": {
                    "ansible_host": "192.168.1.11"
                }
            }
        }
    }
    return inventory

if __name__ == "__main__":
    if "--list" in sys.argv:
        print(json.dumps(get_inventory()))
    elif "--host" in sys.argv:
        print(json.dumps({}))
```

```bash
# Χρήση custom script
chmod +x custom_inventory.py
ansible-playbook -i custom_inventory.py playbook.yml
```

> 📝 **Plugins vs Scripts:**
> ```
> Scripts → παλιά μέθοδος, εξακολουθεί να δουλεύει
> Plugins → σύγχρονη μέθοδος, προτιμάται ✅
> ```

## Χρήση Dynamic + Static Inventory μαζί

Μπορείς να **συνδυάσεις** static και dynamic inventory:

```
inventory/
├── hosts.ini          ← static (τοπικοί servers)
├── aws_ec2.yml        ← dynamic (AWS servers)
└── group_vars/
    ├── all.yml
    └── aws_ec2.yml    ← vars για AWS hosts
```

```bash
# Η Ansible διαβάζει ΟΛΑ τα αρχεία του φακέλου
ansible-playbook -i inventory/ playbook.yml

# Αποτέλεσμα:
# → Static hosts από hosts.ini
# → Dynamic hosts από AWS
# → Όλοι μαζί σε ένα inventory!
```

## Practical Example — Proxmox Dynamic Inventory

Αφού χρησιμοποιείς Armbian (πιθανώς σε SBC), ίσως σε ενδιαφέρει το **Proxmox**:

```yaml
# proxmox.yml
plugin: community.general.proxmox
url: https://proxmox.example.com:8006
user: ansible@pam
password: "{{ lookup('env', 'PROXMOX_PASSWORD') }}"
validate_certs: false
want_facts: true
keyed_groups:
  - key: proxmox_tags_parsed
    prefix: tag
  - key: proxmox_status
    prefix: status
groups:
  running: proxmox_status == 'running'
```

```bash
# Test
export PROXMOX_PASSWORD="mypassword"
ansible-inventory -i proxmox.yml --graph
```

## Dynamic Inventory με φάκελο

```bash
# Ενεργοποίηση plugins στο ansible.cfg
nano ~/ansible/ansible.cfg
```

```ini
[inventory]
enable_plugins = host_list, script, auto, yaml, ini, toml,
                 amazon.aws.aws_ec2,
                 azure.azcollection.azure_rm,
                 community.general.proxmox
```

```bash
# Test dynamic inventory
ansible-inventory -i inventory/ --graph
ansible-inventory -i inventory/ --list
```

## Filtering & Grouping στα Plugins

```yaml
# aws_ec2.yml — Advanced example
plugin: amazon.aws.aws_ec2
regions:
  - eu-west-1

# Φιλτράρισμα
filters:
  instance-state-name: running
  tag:Project: myapp

# Αυτόματο grouping βάσει tags
keyed_groups:
  - key: tags.Role
    prefix: role
    separator: "_"
  - key: tags.Environment
    prefix: env
    separator: "_"

# Custom groups με conditions
groups:
  webservers: "'web' in tags.Role"
  dbservers:  "'db' in tags.Role"
  production: "tags.Environment == 'production'"

# Μεταβλητές από tags
compose:
  ansible_host: private_ip_address
  server_env:   tags.Environment
  server_role:  tags.Role
```

## Σύνοψη 6.6

```
Dynamic Inventory
├── Τι είναι: αυτόματη ανακάλυψη servers
├── Πότε: cloud, VMware, large scale (100+ servers)
├── Τύποι:
│   ├── Plugins → σύγχρονο ✅ (aws_ec2, azure_rm, proxmox)
│   └── Scripts → παλιό (custom Python scripts)
├── Συνδυασμός: static + dynamic μαζί
└── Ρύθμιση: enable_plugins στο ansible.cfg
```

> 📝 **Για τον Μαθητή:** Το Dynamic Inventory είναι **advanced θέμα**. Για τώρα αρκεί να ξέρεις ότι υπάρχει και πότε χρειάζεται. Θα το εφαρμόσουμε πρακτικά όταν φτάσουμε στο **Docker** και το **cloud** κομμάτι!
