# 6.7 Ανάλυση & Βελτίωση του Inventory μας 🔍

## Το τρέχον Inventory μας

```bash
# Δες τι έχουμε τώρα
cat ~/ansible/inventory/hosts.ini
```

```ini
[controller]
localhost ansible_connection=local

[debian_based]
nextcloud ansible_host=83.212.104.27 ansible_port=2022

[redhat_based]
# server01 ansible_host=192.168.1.X

[opensuse_based]
# server01 ansible_host=192.168.1.X

[all_managed:children]
debian_based
redhat_based
opensuse_based

[all:vars]
ansible_user                 = ansible
ansible_ssh_private_key_file = /home/ansible/.ssh/id_ed25519
ansible_become               = true
ansible_become_method        = sudo
```

---

## Ανάλυση — Τι έχουμε ✅

```
✅ controller group    → localhost με local connection
✅ debian_based group  → nextcloud με σωστό port
✅ redhat_based group  → έτοιμο (σχολιασμένο)
✅ opensuse_based group→ έτοιμο (σχολιασμένο)
✅ all_managed group   → nested group σωστά
✅ ansible_user        → σωστός χρήστης
✅ private_key_file    → σωστό key path
✅ become              → ενεργό
```

---

## Τι να βελτιώσουμε ⚠️

### 1. Inline vars στο `[all:vars]`
Οι μεταβλητές του `[all:vars]` καλύτερα να πάνε στο `group_vars/all.yml` για καλύτερη οργάνωση.

### 2. Λείπουν Group-specific vars
Δεν έχουμε ξεχωριστά `group_vars` για κάθε distro group.

### 3. Λείπει το `host_vars/`
Δεν έχουμε ξεχωριστό αρχείο για τον `nextcloud`.

### 4. Λείπει το `ansible_become_user`
Δεν ορίζεται ρητά ποιος είναι ο target user του sudo.

## Βήμα 1: Καθαρισμός hosts.ini

```bash
nano ~/ansible/inventory/hosts.ini
```

```ini
# ============================================================
# Ansible Inventory
# Controller: ansible@ansible-controller
# ============================================================

# ── Controller ────────────────────────────────
[controller]
localhost ansible_connection=local

# ── Debian based (Ubuntu, Debian, Armbian) ────
[debian_based]
nextcloud

# ── RedHat based (Rocky, AlmaLinux, Fedora) ───
[redhat_based]
# rocky01 (προσθέσε όταν έτοιμο)

# ── openSUSE based ────────────────────────────
[opensuse_based]
# suse01 (προσθέσε όταν έτοιμο)

# ── Nested Groups ─────────────────────────────
[all_managed:children]
debian_based
redhat_based
opensuse_based
```

> 💡 **Παρατήρησε:** Αφαιρέσαμε το `[all:vars]` — οι μεταβλητές πάνε στο `group_vars/all.yml`. Επίσης ο `nextcloud` δεν έχει πλέον inline vars — πάνε στο `host_vars/nextcloud.yml`.

## Βήμα 2: Ενημέρωση group_vars/all.yml

```bash
nano ~/ansible/inventory/group_vars/all.yml
```

```yaml
---
# ============================================================
# Global Variables — Ισχύουν για ΟΛΟΥΣ τους servers
# ============================================================

# ── Σύνδεση ───────────────────────────────────
ansible_user:                 ansible
ansible_ssh_private_key_file: /home/ansible/.ssh/id_ed25519
ansible_become:               true
ansible_become_method:        sudo
ansible_become_user:          root

# ── Σύστημα ───────────────────────────────────
system_timezone: "Europe/Athens"
system_locale:   "el_GR.UTF-8"
ntp_server:      "ntp.grnet.gr"

# ── Κοινά Packages ────────────────────────────
common_packages:
  - curl
  - wget
  - vim
  - git
  - htop
  - tree
```

## Βήμα 3: Δημιουργία Group-specific vars

### Debian based:
```bash
cat > ~/ansible/inventory/group_vars/debian_based.yml << 'EOF'
---
# ── Debian/Ubuntu/Armbian specific ────────────
package_manager:            apt
service_ssh:                ssh       # (όχι sshd)
ansible_python_interpreter: /usr/bin/python3
EOF
```

### RedHat based:
```bash
cat > ~/ansible/inventory/group_vars/redhat_based.yml << 'EOF'
---
# ── RedHat/Fedora/Rocky specific ──────────────
package_manager:            dnf
service_ssh:                sshd      # (όχι ssh)
ansible_python_interpreter: /usr/bin/python3
EOF
```

### openSUSE based:
```bash
cat > ~/ansible/inventory/group_vars/opensuse_based.yml << 'EOF'
---
# ── openSUSE specific ─────────────────────────
package_manager:            zypper
service_ssh:                sshd
ansible_python_interpreter: /usr/bin/python3
EOF
```

> 💡 **Γιατί `service_ssh`;** Θυμάσαι στο security playbook είχαμε:
```yaml
name: "{{ 'ssh' if ansible_facts['os_family'] == 'Debian' else 'sshd' }}"
```

> Τώρα μπορούμε να γράφουμε απλά:
```yaml
name: "{{ service_ssh }}"
```

> Πολύ πιο καθαρό! ✅

## Βήμα 4: Δημιουργία host_vars/nextcloud.yml

```bash
mkdir -p ~/ansible/inventory/host_vars

cat > ~/ansible/inventory/host_vars/nextcloud.yml << 'EOF'
---
# ============================================================
# Host Variables — nextcloud
# OS: Debian 12 (Bookworm)
# IP: 83.212.104.27
# Provider: Okeanos
# ============================================================

# ── Σύνδεση ───────────────────────────────────
ansible_host: 83.212.104.27
ansible_port: 2022

# ── Server Info ───────────────────────────────
server_role:     managed_server
server_env:      production
server_provider: okeanos

# ── Resources ─────────────────────────────────
server_cpu:  4
server_ram:  "2GB"
server_disk: "20GB"
EOF
```

## Βήμα 5: Επαλήθευση

```bash
# Δες την νέα δομή
tree ~/ansible/inventory/

# Αναμενόμενο:
# inventory/
# ├── group_vars/
# │   ├── all.yml
# │   ├── debian_based.yml
# │   ├── opensuse_based.yml
# │   └── redhat_based.yml
# ├── host_vars/
# │   └── nextcloud.yml
# └── hosts.ini

# Έλεγχος δομής inventory
ansible-inventory --graph

# Έλεγχος μεταβλητών nextcloud
ansible-inventory --host nextcloud

# Ping test
ansible all -m ansible.builtin.ping

# Έλεγχος νέων μεταβλητών
ansible nextcloud -m ansible.builtin.debug \
    -a "msg='TZ: {{ system_timezone }}, SSH: {{ service_ssh }}, Role: {{ server_role }}'"
```

## Βήμα 6: Ενημέρωση security-bootstrap.yml

Τώρα που έχουμε το `service_ssh` variable, μπορούμε να απλοποιήσουμε τον handler:

```bash
nano ~/ansible/playbooks/security-bootstrap.yml
```

```yaml
# Βρες τον handler "Restart SSH" και άλλαξέ τον:

  handlers:
    - name: Restart SSH
      ansible.builtin.service:
        name: "{{ service_ssh }}"    # ← πολύ πιο καθαρό!
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"
```

## Το Τελικό Αποτέλεσμα

```
ΠΡΙΝ                          ΜΕΤΑ
──────────────────────────    ──────────────────────────
hosts.ini με inline vars  →  hosts.ini καθαρό
[all:vars] στο hosts.ini  →  group_vars/all.yml
Χωρίς group-specific vars →  group_vars/debian_based.yml
                              group_vars/redhat_based.yml
                              group_vars/opensuse_based.yml
Χωρίς host_vars           →  host_vars/nextcloud.yml
Handler με if/else        →  {{ service_ssh }} ✅
```
