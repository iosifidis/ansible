# 17.6 Πρακτικό παράδειγμα Error Handling 🛠️

## Τι θα φτιάξουμε

Ένα **production-grade playbook** που εγκαθιστά και ρυθμίζει έναν web server, χρησιμοποιώντας **όλα** τα εργαλεία error handling:

```
error-handling-demo.yml
│
├── Pre-flight checks (assert)
│   ├── OS check
│   ├── RAM check
│   └── Disk check
│
├── Installation (block/rescue)
│   ├── block: Εγκατάσταση nginx + config
│   ├── rescue: Cleanup αν αποτύχει
│   └── always: Αποθήκευση log
│
├── Verification (assert + debug)
│   ├── Service running check
│   ├── Port listening check
│   └── HTTP response check
│
└── Report (debug)
    └── Σύνοψη αποτελεσμάτων
```

---

## Το Playbook

```yaml
---
# error-handling-demo.yml
# Πλήρες παράδειγμα Error Handling

- name: Web Server Setup με Error Handling
  hosts: all
  become: true
  gather_facts: true

  vars:
    web_package:
      Debian: nginx
      RedHat: nginx
      Suse:   nginx
    web_service:  nginx
    web_port:     80
    web_root:     /var/www/html
    min_ram_mb:   256
    max_disk_pct: 90
    log_file:     /var/log/ansible-webserver-setup.log

  # ══════════════════════════════════════════════════════
  # PRE-FLIGHT CHECKS
  # ══════════════════════════════════════════════════════
  tasks:

    - name: "════ PRE-FLIGHT CHECKS ════"
      ansible.builtin.debug:
        msg: "Ξεκινούν οι pre-flight checks..."

    # ── OS Check ──────────────────────────────────────
    - name: "🔍 Έλεγχος υποστηριζόμενου OS"
      ansible.builtin.assert:
        that:
          - ansible_facts['os_family'] in ['Debian', 'RedHat', 'Suse']
        fail_msg: >
          ❌ Μη υποστηριζόμενο OS:
          {{ ansible_facts['os_family'] }}
          (υποστηρίζονται: Debian, RedHat, Suse)
        success_msg: >
          ✅ OS: {{ ansible_facts['distribution'] }}
          {{ ansible_facts['distribution_version'] }}

    # ── RAM Check ─────────────────────────────────────
    - name: "🔍 Έλεγχος RAM"
      ansible.builtin.assert:
        that:
          - ansible_facts['memtotal_mb'] >= min_ram_mb
        fail_msg: >
          ❌ Ανεπαρκής RAM:
          {{ ansible_facts['memtotal_mb'] }}MB
          (απαιτείται >= {{ min_ram_mb }}MB)
        success_msg: >
          ✅ RAM: {{ ansible_facts['memtotal_mb'] }}MB

    # ── Disk Check ────────────────────────────────────
    - name: "🔍 Έλεγχος ελεύθερου disk"
      ansible.builtin.shell:
        cmd: "df / | tail -1 | awk '{print $5}' | tr -d '%'"
      register:     disk_usage
      changed_when: false

    - name: "🔍 Επαλήθευση disk usage"
      ansible.builtin.assert:
        that:
          - disk_usage.stdout | int < max_disk_pct
        fail_msg: >
          ❌ Disk σχεδόν γεμάτος:
          {{ disk_usage.stdout }}% used
          (όριο: {{ max_disk_pct }}%)
        success_msg: >
          ✅ Disk: {{ disk_usage.stdout }}% used

    # ── Port Check ────────────────────────────────────
    - name: "🔍 Έλεγχος port {{ web_port }}"
      ansible.builtin.shell:
        cmd: "ss -tlnp | grep ':{{ web_port }}'"
      register:      port_check
      ignore_errors: true
      changed_when:  false

    - name: "⚠️  Προειδοποίηση port {{ web_port }}"
      ansible.builtin.debug:
        msg: >
          ⚠️  Port {{ web_port }} ήδη σε χρήση!
          Το nginx θα πάρει τον έλεγχο.
      when: port_check.rc == 0

    - name: "✅ Pre-flight checks ΟΚ"
      ansible.builtin.debug:
        msg:
          - "OS   : {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}"
          - "RAM  : {{ ansible_facts['memtotal_mb'] }}MB"
          - "Disk : {{ disk_usage.stdout }}% used"
          - "Port : {{ web_port }} {{ 'IN USE' if port_check.rc == 0 else 'free' }}"

  # ══════════════════════════════════════════════════════
  # INSTALLATION
  # ══════════════════════════════════════════════════════

    - name: "════ INSTALLATION ════"
      ansible.builtin.debug:
        msg: "Ξεκινά η εγκατάσταση..."

    - name: "Εγκατάσταση & ρύθμιση nginx"
      block:

        # ── Install ─────────────────────────────────
        - name: "📦 Εγκατάσταση nginx (Debian)"
          ansible.builtin.apt:
            name:         "{{ web_package['Debian'] }}"
            state:        present
            update_cache: true
          when: ansible_facts['os_family'] == "Debian"

        - name: "📦 Εγκατάσταση nginx (RedHat)"
          ansible.builtin.dnf:
            name:  "{{ web_package['RedHat'] }}"
            state: present
          when: ansible_facts['os_family'] == "RedHat"

        - name: "📦 Εγκατάσταση nginx (openSUSE)"
          community.general.zypper:
            name:  "{{ web_package['Suse'] }}"
            state: present
          when: ansible_facts['os_family'] == "Suse"

        # ── Configure ───────────────────────────────
        - name: "⚙️  Δημιουργία web root"
          ansible.builtin.file:
            path:  "{{ web_root }}"
            state: directory
            owner: www-data
            group: www-data
            mode:  '0755'

        - name: "⚙️  Δημιουργία index.html"
          ansible.builtin.copy:
            dest:    "{{ web_root }}/index.html"
            content: |
              <!DOCTYPE html>
              <html>
              <head><title>Ansible Setup Complete</title></head>
              <body>
                <h1>✅ Ansible Error Handling Demo</h1>
                <p>Server: {{ inventory_hostname }}</p>
                <p>Setup: {{ ansible_date_time.iso8601 }}</p>
              </body>
              </html>
            owner: www-data
            group: www-data
            mode:  '0644'
          notify: Restart nginx

        # ── Syntax check πριν εκκίνηση ──────────────
        - name: "🔍 Έλεγχος nginx syntax"
          ansible.builtin.command:
            cmd: nginx -t
          register:     nginx_syntax
          changed_when: false
          failed_when:  nginx_syntax.rc != 0

        # ── Start ────────────────────────────────────
        - name: "🚀 Εκκίνηση nginx"
          ansible.builtin.service:
            name:    "{{ web_service }}"
            state:   started
            enabled: true

      rescue:

        - name: "❌ Αποτυχία εγκατάστασης!"
          ansible.builtin.debug:
            msg:
              - "Σφάλμα κατά την εγκατάσταση nginx."
              - "Task: {{ ansible_failed_task.name }}"
              - "Error: {{ ansible_failed_result.msg | default('N/A') }}"

        - name: "🧹 Cleanup μετά από αποτυχία"
          ansible.builtin.package:
            name:  nginx
            state: absent
          ignore_errors: true

        - name: "❌ Αποτυχία — Τερματισμός"
          ansible.builtin.fail:
            msg: >
              Η εγκατάσταση του nginx απέτυχε.
              Ελέγξτε τα logs: {{ log_file }}

      always:

        - name: "📝 Καταγραφή αποτελέσματος"
          ansible.builtin.lineinfile:
            path:   "{{ log_file }}"
            line: >
              {{ ansible_date_time.iso8601 }}
              | {{ inventory_hostname }}
              | nginx setup
              | {{ 'SUCCESS' if ansible_failed_task is not defined
                             else 'FAILED: ' + ansible_failed_task.name }}
            create: true
            mode:   '0644'
          ignore_errors: true

  # ══════════════════════════════════════════════════════
  # VERIFICATION
  # ══════════════════════════════════════════════════════

    - name: "════ VERIFICATION ════"
      ansible.builtin.debug:
        msg: "Ξεκινά η επαλήθευση..."

    # ── Service check ─────────────────────────────
    - name: "🔍 Έλεγχος service nginx"
      ansible.builtin.command:
        cmd: "systemctl is-active {{ web_service }}"
      register:     svc_status
      changed_when: false
      failed_when:  svc_status.rc != 0

    - name: "🔍 Κατάσταση nginx"
      ansible.builtin.debug:
        msg: "nginx: {{ svc_status.stdout }}"
        verbosity: 1    # ← εμφανίζεται μόνο με -v

    # ── Port check ────────────────────────────────
    - name: "🔍 Έλεγχος port {{ web_port }}"
      ansible.builtin.wait_for:
        port:    "{{ web_port }}"
        timeout: 10
        state:   started

    # ── HTTP check ────────────────────────────────
    - name: "🔍 Έλεγχος HTTP response"
      ansible.builtin.uri:
        url:            "http://localhost:{{ web_port }}"
        return_content: true
        status_code:    200
      register:  http_response
      retries:   3
      delay:     2
      until:     http_response.status == 200

    - name: "🔍 Επαλήθευση HTTP content"
      ansible.builtin.assert:
        that:
          - "'Ansible Error Handling Demo' in http_response.content"
        fail_msg:    "❌ Λάθος περιεχόμενο στο HTTP response!"
        success_msg: "✅ HTTP response OK"

  # ══════════════════════════════════════════════════════
  # FINAL REPORT
  # ══════════════════════════════════════════════════════

    - name: "════ FINAL REPORT ════"
      ansible.builtin.debug:
        msg:
          - "╔══════════════════════════════════════════╗"
          - "║  ✅ WEB SERVER SETUP COMPLETE!           ║"
          - "╠══════════════════════════════════════════╣"
          - "║  Server  : {{ inventory_hostname }}"
          - "║  OS      : {{ ansible_facts['distribution'] }}"
          - "║  Service : nginx (active)"
          - "║  Port    : {{ web_port }}"
          - "║  URL     : http://{{ ansible_facts['default_ipv4']['address'] }}"
          - "╚══════════════════════════════════════════╝"

  # ══════════════════════════════════════════════════════
  # HANDLERS
  # ══════════════════════════════════════════════════════
  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name:  "{{ web_service }}"
        state: restarted
```

## Εκτέλεση

```bash
# Βασική εκτέλεση
ansible-playbook playbooks/error-handling-demo.yml \
    --limit nextcloud

# Με verbose output (δες debug verbosity: 1)
ansible-playbook playbooks/error-handling-demo.yml \
    --limit nextcloud -v

# Dry run — δες τι θα κάνει
ansible-playbook playbooks/error-handling-demo.yml \
    --limit nextcloud --check --diff

# Syntax check
ansible-playbook playbooks/error-handling-demo.yml \
    --syntax-check

# Εκκίνηση από verification step
ansible-playbook playbooks/error-handling-demo.yml \
    --limit nextcloud \
    --start-at-task "════ VERIFICATION ════"
```

## Σύνοψη 17.6

```
Τι χρησιμοποιήσαμε:
│
├── assert
│   ├── Pre-flight OS/RAM/Disk checks
│   └── Post-deployment HTTP verification
│
├── block / rescue / always
│   ├── block:  Εγκατάσταση + ρύθμιση
│   ├── rescue: Cleanup + αποτυχία gracefully
│   └── always: Logging (ΠΑΝΤΑ)
│
├── ignore_errors
│   └── Port check (προαιρετικό warning)
│
├── failed_when
│   └── nginx -t syntax check
│
├── changed_when: false
│   └── Όλα τα read-only checks
│
├── debug + verbosity
│   ├── verbosity: 0 → πάντα (reports)
│   └── verbosity: 1 → με -v (details)
│
└── register + conditionals
    └── Αποτελέσματα checks → αποφάσεις
```
