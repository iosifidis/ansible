# 17.3 changed_when 🔄

## Τι είναι το changed_when

Το `changed_when` σου επιτρέπει να **ορίσεις εσύ** πότε ένα task θεωρείται ότι «άλλαξε» κάτι στο σύστημα.

> 📝 **Γιατί σημαίνει;** Η Ansible έχει μια αρχή: κάθε task αναφέρει αν έκανε αλλαγή (changed) ή όχι (ok). Αν κάτι είναι `changed`, ενεργοποιούνται οι handlers. Τα builtin modules (apt, copy, service) το κάνουν αυτόματα. Τα `command` και `shell` **όχι** — θεωρούν ΠΑΝΤΑ ότι έκαναν αλλαγή.

```bash
# Πρόβλημα: το command ΠΑΝΤΑ εμφανίζεται ως "changed"
TASK [Έλεγχος uptime] *****
changed: [nextcloud]    ← λάθος! Δεν άλλαξε τίποτα!

# Λύση: changed_when: false
TASK [Έλεγχος uptime] *****
ok: [nextcloud]         ← σωστό ✅
```

---

## changed_when: false — «Δεν αλλάζει ποτέ τίποτα»

Η πιο συνηθισμένη χρήση: εντολές που **μόνο διαβάζουν** (read-only).

```yaml
tasks:

  # ── Εντολές που μόνο διαβάζουν ──────────────
  - name: Εμφάνιση uptime
    ansible.builtin.command:
      cmd: uptime
    changed_when: false     # ← μόνο διαβάζει, δεν αλλάζει!

  - name: Λίστα processes
    ansible.builtin.command:
      cmd: ps aux
    register:     processes
    changed_when: false

  - name: Έλεγχος disk usage
    ansible.builtin.shell:
      cmd: "df -h /"
    register:     disk_info
    changed_when: false

  - name: Κατάσταση service
    ansible.builtin.command:
      cmd: "systemctl status nginx"
    register:     nginx_status
    changed_when: false
    ignore_errors: true     # ← αν δεν τρέχει, δεν σταματά
```

## changed_when με condition — Custom λογική

Μπορείς να ορίσεις **πότε ακριβώς** θεωρείται αλλαγή:

```yaml
tasks:

  # ── Αλλαγή βάσει output ───────────────────
  - name: Εκτέλεση migration script
    ansible.builtin.command:
      cmd: /opt/myapp/manage.py migrate
    register:     migration_result
    changed_when: "'No migrations to apply' not in migration_result.stdout"
    #              ↑ Αλλαγή ΜΟΝΟ αν έγιναν migrations

  # ── Αλλαγή βάσει return code ──────────────
  - name: Συγχρονισμός αρχείων (rsync)
    ansible.builtin.command:
      cmd: "rsync -av /src/ /dst/"
    register:     rsync_result
    changed_when: rsync_result.rc == 1
    #              ↑ rsync: 0=no changes, 1=changes made

  # ── Αλλαγή βάσει πολλαπλών συνθηκών ──────
  - name: Ενημέρωση config database
    ansible.builtin.command:
      cmd: /opt/cfgtool/update-config
    register: cfg_result
    changed_when:
      - cfg_result.rc == 0
      - "'updated' in cfg_result.stdout"
    # ↑ Αλλαγή ΜΟΝΟ αν: επιτυχία ΚΑΙ "updated" στο output
```

## Συνδυασμός changed_when + handlers

Το `changed_when` **ελέγχει αν θα ενεργοποιηθεί ο handler**:

```yaml
tasks:

  - name: Ανανέωση nginx config
    ansible.builtin.command:
      cmd: /opt/nginx-refresh.sh
    register:     refresh_result
    changed_when: "'UPDATED' in refresh_result.stdout"
    notify:       Restart nginx
    # ↑ Handler εκτελείται ΜΟΝΟ αν έγινε αλλαγή!

  - name: Έλεγχος nginx syntax
    ansible.builtin.command:
      cmd: nginx -t
    changed_when: false     # ← validation, δεν αλλάζει τίποτα
    # ↑ Handler ΔΕΝ ενεργοποιείται από αυτό

handlers:

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
```

## changed_when vs failed_when — Σύγκριση

```
┌─────────────────────────────────────────────────────────┐
│  changed_when              │  failed_when                │
├─────────────────────────────────────────────────────────┤
│  Ελέγχει αν το task        │  Ελέγχει αν το task         │
│  «άλλαξε» κάτι             │  «απέτυχε»                  │
├─────────────────────────────────────────────────────────┤
│  Επηρεάζει handlers        │  Επηρεάζει ροή εκτέλεσης    │
│  (notify)                  │  (συνεχίζει ή σταματά)      │
├─────────────────────────────────────────────────────────┤
│  false → task είναι ok     │  false → task ΠΟΤΕ αποτυχία │
│  true  → task είναι changed│  true  → task ΠΑΝΤΑ αποτυχία│
├─────────────────────────────────────────────────────────┤
│  Χρήση: command/shell που  │  Χρήση: command με           │
│  δεν αλλάζουν τίποτα       │  ιδιαίτερα exit codes        │
└─────────────────────────────────────────────────────────┘
```

## Κλασικό pattern: command/shell + register + changed_when + failed_when

Αυτός είναι ο **σωστός τρόπος** χρήσης των `command` και `shell` modules:

```yaml
tasks:

  # ─── Pattern 1: Read-only check ──────────────
  - name: Έλεγχος έκδοσης app
    ansible.builtin.command:
      cmd: /opt/myapp/bin/myapp --version
    register:     app_version
    changed_when: false           # ← read-only
    failed_when:  app_version.rc != 0

  # ─── Pattern 2: Action με custom logic ───────
  - name: Εκκαθάριση παλιών sessions
    ansible.builtin.command:
      cmd: /opt/myapp/bin/cleanup-sessions --older-than 7d
    register:     cleanup_result
    changed_when: cleanup_result.stdout | trim != "0 sessions removed"
    failed_when:  cleanup_result.rc not in [0, 2]
    #             ↑ 0=OK, 2=no sessions to clean (αποδεκτό)

  # ─── Pattern 3: Idempotent shell script ──────
  - name: Αρχικοποίηση βάσης (αν δεν γίνηκε ήδη)
    ansible.builtin.shell:
      cmd: |
        if psql -lqt | grep -q mydb; then
          echo "ALREADY_EXISTS"
        else
          createdb mydb && echo "CREATED"
        fi
    register:     db_init
    changed_when: "'CREATED' in db_init.stdout"
    failed_when:  db_init.rc != 0
```

## Ειδική περίπτωση: Idempotency check

Ο στόχος είναι το playbook να φαίνεται **ok** όταν δεν αλλάζει τίποτα:

```yaml
tasks:

  - name: Προσθήκη cron job
    ansible.builtin.command:
      cmd: >
        bash -c '
        crontab -l 2>/dev/null | grep -q "myapp-backup" &&
        echo "EXISTS" ||
        (crontab -l 2>/dev/null; echo "0 2 * * * /opt/myapp/backup.sh") |
        crontab - && echo "ADDED"'
    register:     cron_result
    changed_when: "'ADDED' in cron_result.stdout"
    failed_when:  cron_result.rc != 0
```

> 💡 **Tip:** Για cron jobs χρησιμοποίησε πάντα το `ansible.builtin.cron` module — είναι idempotent από μόνο του. Το παραπάνω είναι για εκπαιδευτικούς σκοπούς.

## Σύνοψη 17.3

```
changed_when
│
├── Πρόβλημα: command/shell ΠΑΝΤΑ = "changed"
│   ακόμα κι αν δεν άλλαξε τίποτα
│
├── Λύση:
│   ├── changed_when: false
│   │   └── Read-only tasks (stat, check, verify)
│   │
│   └── changed_when: <condition>
│       ├── Βάσει .stdout
│       ├── Βάσει .rc
│       └── Συνδυασμός συνθηκών
│
├── Επίδραση στους handlers:
│   ├── changed → handler εκτελείται
│   └── ok      → handler ΔΕΝ εκτελείται
│
└── Best practice:
    command/shell tasks = πάντα
    register + changed_when + failed_when
```
