# 17.4 Block / Rescue / Always 🏗️

## Τι είναι το Block

Το `block` ομαδοποιεί tasks και σου επιτρέπει να χειριστείς σφάλματα σαν **try-catch** της Python ή της Java.

> 📝 **Αναλογία με Python:**
> ```python
> # Python
> try:
>     deploy_new_version()
> except Exception as e:
>     rollback()
>     notify_team(e)
> finally:
>     cleanup_temp_files()
> ```
> ```yaml
> # Ansible
> block:
>   - deploy new version tasks
> rescue:
>   - rollback tasks
>   - notify team tasks
> always:
>   - cleanup temp files tasks
> ```

---

## Βασική δομή

```yaml
tasks:

  - name: Deployment με error handling
    block:

      # ── Τα κανονικά tasks ──────────────────
      - name: Task 1
        # ...

      - name: Task 2
        # ...

      - name: Task 3
        # ...

    rescue:

      # ── Εκτελείται ΜΟΝΟ αν αποτύχει το block ─
      - name: Cleanup μετά από αποτυχία
        # ...

      - name: Ειδοποίηση ομάδας
        # ...

    always:

      # ── Εκτελείται ΠΑΝΤΑ (επιτυχία ή αποτυχία) ─
      - name: Αφαίρεση temp files
        # ...
```

---

## Πώς λειτουργεί

```
block: tasks εκτελούνται κανονικά
       │
       ▼
  Όλα πήγαν καλά;
       │
  ─────┼───────────────────────
  ΝΑΙ  │  ΟΧΙ (κάποιο task απέτυχε)
  ─────┼───────────────────────
       │             │
       ▼             ▼
  always:      rescue: tasks
  εκτελείται   εκτελούνται
       │             │
       │             ▼
       │          always: tasks
       │          εκτελούνται
       │
       ▼
  Συνέχεια playbook

Σημείωση:
- Αν το rescue: επιτύχει → playbook συνεχίζει ✅
- Αν το rescue: αποτύχει → playbook αποτυγχάνει ❌
```

## Παράδειγμα 1: Απλό try-catch

```yaml
tasks:

  - name: Εγκατάσταση εφαρμογής
    block:

      - name: Download application
        ansible.builtin.get_url:
          url:  https://example.com/myapp-v2.tar.gz
          dest: /tmp/myapp-v2.tar.gz

      - name: Αποσυμπίεση
        ansible.builtin.unarchive:
          src:        /tmp/myapp-v2.tar.gz
          dest:       /opt/myapp/
          remote_src: true

      - name: Εκκίνηση service
        ansible.builtin.service:
          name:  myapp
          state: restarted

    rescue:

      - name: "❌ Deployment απέτυχε!"
        ansible.builtin.debug:
          msg: "Σφάλμα κατά το deployment. Ξεκινώ rollback..."

      - name: Επαναφορά σε προηγούμενη έκδοση
        ansible.builtin.service:
          name:  myapp
          state: restarted
        # (στο πραγματικό σενάριο: επαναφορά από backup)

    always:

      - name: Αφαίρεση temp αρχείων
        ansible.builtin.file:
          path:  /tmp/myapp-v2.tar.gz
          state: absent
```

## Παράδειγμα 2: Deployment με rollback

```yaml
---
# deployment-with-rollback.yml

- name: Deployment με Rollback
  hosts: all
  become: true
  gather_facts: true

  vars:
    app_name:    myapp
    app_version: "2.5.0"
    app_dir:     /opt/myapp
    backup_dir:  /opt/myapp-backup

  tasks:

    # ── Backup πριν το deployment ──────────────
    - name: Backup τρέχουσας έκδοσης
      ansible.builtin.copy:
        src:        "{{ app_dir }}/"
        dest:       "{{ backup_dir }}/"
        remote_src: true
      ignore_errors: true     # ← μπορεί να μην υπάρχει ακόμα

    # ── Deployment με error handling ──────────
    - name: Deployment v{{ app_version }}
      block:

        - name: "🚀 Έναρξη deployment v{{ app_version }}"
          ansible.builtin.debug:
            msg: "Deployment ξεκινάει..."

        - name: Σταμάτα service
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: stopped

        - name: Deploy νέα έκδοση
          ansible.builtin.copy:
            src:  "files/{{ app_name }}-{{ app_version }}/"
            dest: "{{ app_dir }}/"
            mode: '0755'

        - name: Εκτέλεση migrations
          ansible.builtin.command:
            cmd:  "{{ app_dir }}/manage.py migrate"
            chdir: "{{ app_dir }}"
          changed_when: true

        - name: Εκκίνηση service
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: started

        - name: Health check
          ansible.builtin.uri:
            url:         "http://localhost:8080/health"
            status_code: 200
          register:     health
          retries:      5
          delay:        3
          until:        health.status == 200

        - name: "✅ Deployment επιτυχές!"
          ansible.builtin.debug:
            msg: "v{{ app_version }} τρέχει κανονικά."

      rescue:

        - name: "❌ Deployment απέτυχε — Rollback!"
          ansible.builtin.debug:
            msg: "Σφάλμα! Επαναφορά στην προηγούμενη έκδοση..."

        - name: Σταμάτα το σπασμένο service
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: stopped
          ignore_errors: true

        - name: Επαναφορά από backup
          ansible.builtin.copy:
            src:        "{{ backup_dir }}/"
            dest:       "{{ app_dir }}/"
            remote_src: true

        - name: Εκκίνηση παλιάς έκδοσης
          ansible.builtin.service:
            name:  "{{ app_name }}"
            state: started

        - name: Αναφορά αποτυχίας
          ansible.builtin.debug:
            msg: "⚠️ Rollback ολοκληρώθηκε. Ελέγξτε τα logs!"

      always:

        - name: Αφαίρεση temp αρχείων
          ansible.builtin.file:
            path:  "/tmp/{{ app_name }}-{{ app_version }}.tar.gz"
            state: absent
          ignore_errors: true

        - name: Αποθήκευση deployment log
          ansible.builtin.lineinfile:
            path:   /var/log/ansible-deployments.log
            line: >
              {{ ansible_date_time.iso8601 }}
              {{ app_name }} v{{ app_version }}
              {{ ansible_facts['hostname'] }}
            create: true
            mode:   '0644'
```

```bash
# Εκτέλεση
ansible-playbook playbooks/deployment-with-rollback.yml \
    --limit nextcloud -v
```

## block + when — Conditionals σε ομάδα tasks

```yaml
tasks:

  # ── To when εφαρμόζεται σε ΟΛΟΚΛΗΡΟ το block ──
  - name: Debian-specific deployment
    when: ansible_facts['os_family'] == "Debian"
    block:

      - name: Update apt cache
        ansible.builtin.apt:
          update_cache: true

      - name: Install dependencies (Debian)
        ansible.builtin.apt:
          name:
            - nginx
            - postgresql-client
          state: present

      - name: Ρύθμιση ufw
        community.general.ufw:
          rule:  allow
          port:  "443"
          proto: tcp

    rescue:

      - name: Αποτυχία Debian setup
        ansible.builtin.debug:
          msg: "Αποτυχία κατά την εγκατάσταση σε Debian!"
```

## Μεταβλητή ansible_failed_task

Μέσα στο `rescue:`, η Ansible παρέχει πληροφορίες για το task που απέτυχε:

```yaml
tasks:

  - name: Block με πληροφορίες αποτυχίας
    block:

      - name: Task που θα αποτύχει
        ansible.builtin.command:
          cmd: /nonexistent/command

    rescue:

      - name: Εμφάνιση λεπτομερειών αποτυχίας
        ansible.builtin.debug:
          msg:
            - "Task που απέτυχε : {{ ansible_failed_task.name }}"
            - "Σφάλμα          : {{ ansible_failed_result.msg }}"
```

## Nested blocks — Block μέσα σε block

```yaml
tasks:

  - name: Outer block
    block:

      - name: Εγκατάσταση
        block:

          - name: Install dependencies
            ansible.builtin.apt:
              name: "{{ dependencies }}"

        rescue:
          - name: Dependencies αποτυχία
            ansible.builtin.debug:
              msg: "Δεν μπόρεσα να εγκαταστήσω dependencies"

      - name: Configuration
        block:

          - name: Deploy configs
            ansible.builtin.template:
              src:  "{{ item }}.j2"
              dest: "/etc/myapp/{{ item }}"
            loop: "{{ config_files }}"

        rescue:
          - name: Config αποτυχία
            ansible.builtin.debug:
              msg: "Αποτυχία ρύθμισης config"

    rescue:
      - name: Outer αποτυχία
        ansible.builtin.debug:
          msg: "Γενική αποτυχία!"

    always:
      - name: Πάντα cleanup
        ansible.builtin.debug:
          msg: "Cleanup ολοκληρώθηκε"
```

## Σύνοψη 17.4

```
Block / Rescue / Always
│
├── block:
│   ├── Ομαδοποιεί tasks
│   ├── Υποστηρίζει when: (εφαρμόζεται σε όλα)
│   └── Αν αποτύχει → rescue:
│
├── rescue:
│   ├── Εκτελείται ΜΟΝΟ αν αποτύχει το block
│   ├── Χρήση: rollback, cleanup, notifications
│   ├── ansible_failed_task → info για το task που απέτυχε
│   └── Αν rescue επιτύχει → playbook συνεχίζει ✅
│
└── always:
    ├── Εκτελείται ΠΑΝΤΑ
    ├── Χρήση: temp files, logs, αποδέσμευση πόρων
    └── Ακόμα κι αν block ΚΑΙ rescue αποτύχουν!

Best practices:
✅ Χρήση για deployments
✅ Χρήση για database operations
✅ Χρήση για operations που χρειάζονται cleanup
❌ Μην κάνεις over-engineer με nested blocks
```
