# 23.6 Πρακτικό παράδειγμα — Πλήρης GitOps Workflow 🚀

## Το Πλήρες Σύστημα

```
                    GitHub Repository
                    ┌───────────────────────────────┐
                    │  main (protected)              │
                    │  develop (auto-staging)        │
                    │  feature/* (developer work)   │
                    └───────────────────────────────┘
                              │
               ┌──────────────┼──────────────┐
               │              │              │
          Push to         Push to       Push to
         feature/*        develop        main
               │              │              │
               ▼              ▼              ▼
           CI: lint        CI: lint       CI: lint
         + molecule      + molecule     + molecule
               │              │              │
           (no deploy)    Auto-deploy    Approval gate
                          → STAGING    ──────────────►
                               │        Human review
                               │              │
                          Verify OK          ▼
                               │       Deploy →
                               │       PRODUCTION
                               │
                    (Open PR → main)
```

---

## Βήμα-βήμα: Νέο feature

### 1. Αρχικοποίηση

```bash
# Clone (μία φορά)
git clone git@github.com:myorg/ansible-configs.git
cd ansible-configs

# Εγκατάσταση dependencies
pip install ansible ansible-lint molecule molecule-plugins[docker]
ansible-galaxy install -r requirements.yml

# Setup vault password (τοπικά, ΔΕΝ στο git!)
echo "my-vault-password" > .vault_pass
chmod 600 .vault_pass
echo ".vault_pass" >> .gitignore
```

### 2. Δουλειά σε νέο feature

```bash
# Ξεκίνα πάντα από develop
git checkout develop
git pull origin develop

# Νέο feature branch
git checkout -b feature/add-redis-role

# Δημιουργία role
ansible-galaxy role init roles/redis

# Γράψε tasks, handlers, defaults, molecule tests...
vim roles/redis/tasks/main.yml
vim roles/redis/molecule/default/converge.yml

# Τοπικό testing
ansible-lint
cd roles/redis && molecule test
cd ../..

# Commit
git add roles/redis/
git commit -m "feat(redis): add Redis installation and configuration role"

# Push
git push origin feature/add-redis-role
```

### 3. Pull Request → develop

```
GitHub: Open PR
  From: feature/add-redis-role
  To:   develop
  Title: feat(redis): Add Redis role
  
  Description:
  ## Τι αλλάζει
  - Νέο role για εγκατάσταση Redis
  - Υποστηρίζει Ubuntu, Rocky, openSUSE
  - Molecule tests για όλες τις distros

  ## Testing
  - [x] ansible-lint: OK
  - [x] molecule test: OK (Ubuntu, Rocky)
  - [x] Idempotency check: OK

  ## Rollback plan
  ansible-playbook playbooks/remove-redis.yml --limit staging
```

**CI/CD checks:**
- ✅ ansible-lint → pass
- ✅ molecule/redis → pass
- ✅ Review approved

**Merge → develop**

---

### 4. Auto-deploy σε Staging

```
Merge στο develop trigger:
  GitHub Actions: deploy-staging job
    → ansible-playbook playbooks/deploy.yml
         -i inventory/staging/
         -e "app_version=abc1234"
    → Slack: "✅ Staging deploy OK (abc1234)"
```

```bash
# Verify staging manually
ssh staging-01 "redis-cli ping"  # → PONG

# Τρέξε playbook ξανά → πρέπει 0 changes!
ansible-playbook playbooks/deploy.yml \
    -i inventory/staging/ \
    --vault-password-file .vault_pass \
    --check
# ok=12  changed=0  failed=0  ← ΤΕΛΕΙΟ!
```

### 5. PR: develop → main (Production)

```bash
# Βεβαιώσου ότι develop είναι ενημερωμένο
git checkout develop
git pull origin develop

# Open PR: develop → main
# Required: Senior SRE approval
# Required: CI checks green
```

```
GitHub:
  PR: develop → main
  Status: Waiting for review
  
  Checks:
  ✅ ansible-lint
  ✅ molecule/redis
  ✅ molecule/nginx
  
  Reviewers:
  ⏳ @senior-sysadmin (required)
  
  [senior-sysadmin approves after reviewing diff]
  
  Status: ✅ Approved — Ready to merge
```

---

### 6. Deploy → Production (με approval gate)

```
Merge main → GitHub Actions: deploy-production
  Environment: production (requires approval)
  
  Approval request email → sre-team:
  "Deploy to production ready. Approve?"
  
  [SRE approves]
  
  → ansible-playbook playbooks/deploy.yml
       -i inventory/production/
       -e "app_version=abc1234"
       --diff
       -v
  → Slack: "✅ Production deploy OK (abc1234)"
```

---

### 7. Emergency Hotfix (παράκαμψη develop)

```bash
# Κρίσιμο bug στο production!
git checkout main
git pull origin main

# Hotfix branch από main
git checkout -b hotfix/nginx-crash-fix

# Διόρθωση
vim roles/nginx/tasks/main.yml
git commit -m "fix(nginx): resolve crash on high connection load"

# PR → main (expedited review)
git push origin hotfix/nginx-crash-fix

# Μετά το merge στο main:
# → deploy production (με approval, αλλά expedited!)

# ΣΗΜΑΝΤΙΚΟ: Back-merge στο develop!
git checkout develop
git merge main
git push origin develop
# Αν υπάρχουν conflicts → resolve!
```

## Full lifecycle summary

```
Developer:
  git checkout develop && git pull
  git checkout -b feature/my-change
  [κάνει αλλαγές]
  ansible-lint && molecule test
  git push → PR → develop
         │
         ▼
CI: lint + molecule (αυτόματα)
         │
         ▼ (merge)
STAGING: auto-deploy (αυτόματα)
         │
         ▼ (verify OK)
PR: develop → main (code review)
         │
         ▼ (approve)
PRODUCTION: deploy (manual approval)
         │
         ▼
Monitoring: Prometheus/Grafana alerts
```
