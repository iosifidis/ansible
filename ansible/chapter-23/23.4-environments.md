# 23.4 Environments: Testing → Staging → Production 🏗️

## Τα 3 Environments

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  Testing (local / CI)                                    │
│  ├── Molecule tests (Docker containers)                  │
│  ├── ansible-lint                                        │
│  └── Τρέχει: αυτόματα σε κάθε push                      │
│                         │                               │
│                         ▼                               │
│  Staging                                                 │
│  ├── Real servers (clone production)                     │
│  ├── Ίδια configuration με production                    │
│  ├── Χαμηλότερα resources (1 server vs 3)               │
│  └── Τρέχει: αυτόματα στο develop branch                │
│                         │                               │
│                         ▼                               │
│  Production                                              │
│  ├── Real servers, real data                             │
│  ├── Πλήρη resources                                     │
│  ├── Monitoring & alerts                                 │
│  └── Τρέχει: ΜΟΝΟ με manual approval (main branch)      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

---

## Χωριστά inventories ανά environment

```
inventory/
├── production/
│   ├── hosts.yml
│   └── group_vars/
│       └── all/
│           ├── vars.yml     ← production values
│           └── vault.yml    ← production secrets (encrypted)
└── staging/
    ├── hosts.yml
    └── group_vars/
        └── all/
            ├── vars.yml     ← staging values
            └── vault.yml    ← staging secrets (encrypted)
```

```yaml
# inventory/production/group_vars/all/vars.yml
---
environment:     production
app_replicas:    3
nginx_workers:   4
log_level:       warn
db_pool_size:    20
monitoring:      true

# inventory/staging/group_vars/all/vars.yml
---
environment:     staging
app_replicas:    1
nginx_workers:   2
log_level:       info
db_pool_size:    5
monitoring:      true     # ← ΝΑΙ! Πάντα test monitoring
```

```yaml
# inventory/production/hosts.yml
---
all:
  children:
    webservers:
      hosts:
        web-01: { ansible_host: 192.168.1.10 }
        web-02: { ansible_host: 192.168.1.11 }
        web-03: { ansible_host: 192.168.1.12 }
    databases:
      hosts:
        db-01:  { ansible_host: 192.168.1.20 }
    monitoring:
      hosts:
        mon-01: { ansible_host: 192.168.1.30 }

# inventory/staging/hosts.yml
---
all:
  children:
    webservers:
      hosts:
        staging-01: { ansible_host: 192.168.2.10 }
    databases:
      hosts:
        staging-01: { ansible_host: 192.168.2.10 }  # ← same server!
    monitoring:
      hosts:
        staging-01: { ansible_host: 192.168.2.10 }
```

## Εκτέλεση ανά environment

```bash
# Testing (molecule — τοπικά):
cd roles/nginx && molecule test

# Staging (develop branch → auto από CI/CD):
ansible-playbook playbooks/deploy.yml \
    -i inventory/staging/ \
    --vault-password-file .vault_pass \
    -e "environment=staging"

# Production (main branch → μετά από approval):
ansible-playbook playbooks/deploy.yml \
    -i inventory/production/ \
    --vault-password-file .vault_pass \
    -e "environment=production" \
    --diff \
    -v

# Dry-run production (check mode):
ansible-playbook playbooks/deploy.yml \
    -i inventory/production/ \
    --vault-password-file .vault_pass \
    --check \
    --diff
```

## Διαφορετικά Vault passwords ανά environment

```bash
# Δύο vault passwords:
ansible-vault encrypt_string 'staging_secret' \
    --vault-id staging@.vault_pass_staging

ansible-vault encrypt_string 'prod_secret_real' \
    --vault-id production@.vault_pass_production

# ansible.cfg:
# [defaults]
# vault_identity_list = staging@.vault_pass_staging, production@.vault_pass_production
```

## Σύνοψη 23.4

```
3 Environments:
│
├── Testing:    molecule (local/CI, Docker)
├── Staging:    real servers, auto-deploy (develop)
└── Production: real servers, approval required (main)

Χωριστά inventories:
├── inventory/staging/   → staging values + secrets
└── inventory/production/ → production values + secrets

Key principle:
  Αν δουλεύει στο staging → ασφαλές για production
```
