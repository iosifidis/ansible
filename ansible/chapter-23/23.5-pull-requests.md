# 23.5 Pull Requests & Code Review 👥

## Branch Protection Rules (GitHub)

```
GitHub → Repository → Settings → Branches → main:

☑ Require a pull request before merging
    ☑ Required number of approvals: 1
    ☑ Dismiss stale reviews when new commits are pushed

☑ Require status checks to pass before merging
    Required checks:
    ├── ansible-lint        (CI job)
    └── molecule / nginx    (CI job)

☑ Require branches to be up to date before merging

☑ Do not allow bypassing the above settings
    (ακόμα και οι admins πρέπει να κάνουν PR!)
```

---

## PR Checklist — Ti ελέγχεις

```markdown
## PR Checklist

### Code Quality
- [ ] Τρέχει `ansible-lint` χωρίς errors
- [ ] Τρέχει `molecule test` για τα επηρεαζόμενα roles
- [ ] Δεν υπάρχουν hardcoded passwords/secrets
- [ ] Χρησιμοποιούνται `no_log: true` σε tasks με secrets

### Idempotency
- [ ] Τρέξε το playbook 2 φορές → 0 changes τη 2η φορά
- [ ] `--check --diff` επιστρέφει λογικές αλλαγές

### Documentation
- [ ] Ενημερώθηκε το CHANGELOG.md
- [ ] Νέες μεταβλητές τεκμηριώνονται στο defaults/main.yml

### Testing
- [ ] Tested στο staging πριν merge
- [ ] Rollback plan υπάρχει αν χρειαστεί
```

## Πρακτικός workflow review

```bash
# Reviewer: κάνε checkout το branch τοπικά
git fetch origin
git checkout feature/add-docker-role

# Dry-run σε staging
ansible-playbook playbooks/deploy.yml \
    -i inventory/staging/ \
    --check \
    --diff \
    --limit staging-01

# Αν ok → Approve PR στο GitHub/GitLab
```

## CODEOWNERS — Αυτόματος reviewer

```
# .github/CODEOWNERS
# Αυτόματα assigns reviewer για συγκεκριμένα paths:

roles/nginx/      @sre-team          # SRE team review για nginx
roles/postgres/   @db-team           # DB team για database roles
inventory/        @sre-team          # SRE review για inventory changes
playbooks/        @senior-sysadmin   # Senior approval για playbooks
.github/          @devops-lead       # DevOps lead για CI/CD changes
```
