# 23.2 Repository Structure 📁

## Mono-repo vs Multi-repo

```
Mono-repo (ΠΡΟΤΕΙΝΕΤΑΙ για αρχή):
  ansible-configs/          ← ΈΝΑ repo για τα πάντα
  ├── playbooks/
  ├── roles/
  ├── inventory/
  └── .github/

  Πλεονεκτήματα:
  ✅ Απλή διαχείριση
  ✅ Ένα CI/CD pipeline
  ✅ Εύκολο cross-role refactoring

Multi-repo:
  ansible-base/    ← base roles (nginx, postgres)
  ansible-myapp/   ← app-specific playbooks
  ansible-infra/   ← infrastructure setup

  Πότε:
  → Πολλές ομάδες, διαφορετικά access levels
  → Roles που μοιράζονται σε πολλά projects
```

## Προτεινόμενη δομή mono-repo

```
ansible-configs/                   ← root
│
├── .github/
│   └── workflows/
│       └── ansible-cd.yml         ← CI/CD pipeline
│
├── .ansible-lint                  ← lint config
├── ansible.cfg                    ← Ansible configuration
├── requirements.yml               ← Galaxy collections/roles
│
├── inventory/
│   ├── production/
│   │   ├── hosts.yml              ← production hosts
│   │   └── group_vars/
│   │       ├── all/
│   │       │   ├── vars.yml       ← κοινές μεταβλητές
│   │       │   └── vault.yml      ← encrypted secrets
│   │       ├── webservers.yml
│   │       └── databases.yml
│   └── staging/
│       ├── hosts.yml              ← staging hosts
│       └── group_vars/
│           └── all/
│               ├── vars.yml
│               └── vault.yml
│
├── playbooks/
│   ├── site.yml                   ← master playbook
│   ├── deploy.yml                 ← deploy application
│   ├── patching.yml               ← OS patching
│   └── monitoring-stack.yml       ← monitoring
│
├── roles/
│   ├── base/                      ← SSH, firewall, users
│   │   ├── tasks/main.yml
│   │   ├── handlers/main.yml
│   │   ├── defaults/main.yml
│   │   └── molecule/default/      ← tests
│   ├── nginx/
│   ├── docker/
│   └── monitoring/
│
└── files/
    ├── nginx/nginx.conf
    └── prometheus/rules/alerts.yml
```

## ansible.cfg για Git workflow

```ini
# ansible.cfg
[defaults]
inventory          = inventory/production/hosts.yml
roles_path         = roles
collections_path   = ~/.ansible/collections
host_key_checking  = True
retry_files_enabled = False
stdout_callback    = yaml
stderr_callback    = yaml

# Logging (χρήσιμο για CI/CD)
log_path           = /tmp/ansible.log

[ssh_connection]
ssh_args           = -o ControlMaster=auto -o ControlPersist=60s
pipelining         = True
```

## Σύνοψη 23.2

```
Repository Structure
│
├── Mono-repo: ιδανικό για αρχή
├── inventory/production/ + inventory/staging/
│   └── Χωριστό hosts.yml ανά environment
├── playbooks/: κεντρικά playbooks
├── roles/: reusable components (με molecule tests)
└── .github/workflows/: CI/CD pipeline
```
