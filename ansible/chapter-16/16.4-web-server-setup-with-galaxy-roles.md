# 16.4 Web Server Setup με Galaxy Roles 🌐

## Τι θα φτιάξουμε

```
Ένα πλήρες web server setup χρησιμοποιώντας
Galaxy roles + δικά μας roles:

├── geerlingguy.nginx    → web server
├── geerlingguy.php      → PHP (optional)
└── Δικό μας nginx role  → custom config
```

---

## Βήμα 1: Εγκατάσταση Galaxy Roles

```bash
# Δημιουργία requirements.yml
cat > ~/ansible/requirements.yml << 'EOF'
---
roles:
  - name:    geerlingguy.nginx
    version: "3.2.0"

collections:
  - name:    community.general
    version: ">=7.0.0"
  - name:    ansible.posix
    version: ">=1.5.0"
  - name:    community.docker
    version: ">=3.0.0"
EOF

# Εγκατάσταση
ansible-galaxy install -r requirements.yml -p ~/ansible/roles/
ansible-galaxy collection install -r requirements.yml

# Επαλήθευση
ansible-galaxy role list
ansible-galaxy collection list
```

## Βήμα 3: group_vars για Web Servers

```bash
# Δημιουργία group_vars για webservers
mkdir -p ~/ansible/inventory/group_vars/debian_based

cat > ~/ansible/inventory/group_vars/debian_based/nginx.yml << 'EOF'
---
# ============================================================
# Nginx Variables για Debian-based servers
# Χρήση με geerlingguy.nginx Galaxy role
# ============================================================

# ── Performance ───────────────────────────────
nginx_worker_processes:     "{{ ansible_facts['processor_vcpus'] | default(1) }}"
nginx_worker_connections:   "1024"
nginx_keepalive_timeout:    "65"
nginx_client_max_body_size: "64m"
nginx_server_tokens:        "off"

# ── Gzip ──────────────────────────────────────
nginx_extra_http_options: |
  gzip on;
  gzip_vary on;
  gzip_proxied any;
  gzip_comp_level 6;
  gzip_types text/plain text/css application/json
             application/javascript text/xml;

# ── Remove default vhost ──────────────────────
nginx_remove_default_vhost: true

# ── Virtual Hosts ─────────────────────────────
nginx_vhosts:
  - listen:      "80"
    server_name: "{{ inventory_hostname }}"
    root:        "/var/www/{{ inventory_hostname }}"
    index:       "index.html index.htm"
    access_log:  "/var/log/nginx/{{ inventory_hostname }}_access.log"
    error_log:   "/var/log/nginx/{{ inventory_hostname }}_error.log"
    extra_parameters: |
      location / {
          try_files $uri $uri/ =404;
      }

      location ~* \.(js|css|png|jpg|jpeg|gif|ico)$ {
          expires 1y;
          add_header Cache-Control "public, immutable";
      }

      location = /favicon.ico {
          log_not_found off;
          access_log off;
      }

      location = /robots.txt {
          allow all;
          log_not_found off;
          access_log off;
      }
EOF
```

## Βήμα 4: Web Server Playbook

```bash
cat > ~/ansible/playbooks/webserver-galaxy.yml << 'EOF'
---
# ============================================================
# Web Server Setup με Galaxy Role
# ============================================================

- name: Web Server Setup
  hosts: "{{ target | default('all_managed') }}"
  become: true
  gather_facts: true

  pre_tasks:

    # ── Εμφάνιση info ─────────────────────────
    - name: Deployment info
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host : {{ inventory_hostname }}"
          - "OS   : {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}"
          - "IP   : {{ ansible_facts['default_ipv4']['address'] }}"
          - "CPUs : {{ ansible_facts['processor_vcpus'] }}"
          - "RAM  : {{ (ansible_facts['memtotal_mb'] / 1024) | round(1) }}GB"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      tags: always

    # ── System update ─────────────────────────
    - name: Update apt cache (Debian)
      ansible.builtin.apt:
        update_cache:     true
        cache_valid_time: 3600
      when: ansible_facts['os_family'] == "Debian"
      tags: [update, packages]

    # ── Web root ──────────────────────────────
    - name: Create web root
      ansible.builtin.file:
        path:  "/var/www/{{ inventory_hostname }}"
        state: directory
        owner: www-data
        group: www-data
        mode:  '0755'
      tags: [setup, directories]

    # ── Default page ──────────────────────────
    - name: Deploy default index.html
      ansible.builtin.copy:
        dest:  "/var/www/{{ inventory_hostname }}/index.html"
        owner: www-data
        group: www-data
        mode:  '0644'
        content: |
          <!DOCTYPE html>
          <html>
          <head>
              <title>{{ inventory_hostname }}</title>
              <style>
                  body { font-family: Arial, sans-serif;
                         max-width: 600px; margin: 50px auto;
                         text-align: center; }
                  h1   { color: #333; }
                  .ok  { color: #4CAF50; font-size: 2em; }
              </style>
          </head>
          <body>
              <div class="ok">✅</div>
              <h1>{{ inventory_hostname }}</h1>
              <p>{{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}</p>
              <p>Managed by Ansible {{ ansible_version.full }}</p>
              <p>Deployed: {{ ansible_facts['date_time']['date'] }}</p>
          </body>
          </html>
      tags: [setup, content]

  # ── Galaxy Role ───────────────────────────────
  roles:

    - role: geerlingguy.nginx
      tags: nginx
      # ← Variables από group_vars/debian_based/nginx.yml

  # ── Post-install tasks ────────────────────────
  tasks:

    # ── Custom security headers ───────────────
    - name: Add security headers config
      ansible.builtin.copy:
        dest:  /etc/nginx/conf.d/security-headers.conf
        mode:  '0644'
        content: |
          # Security Headers
          # Managed by Ansible

          add_header X-Frame-Options       "SAMEORIGIN"    always;
          add_header X-Content-Type-Options "nosniff"      always;
          add_header X-XSS-Protection      "1; mode=block" always;
          add_header Referrer-Policy       "strict-origin-when-cross-origin" always;
      notify: reload nginx
      tags: [config, security, nginx]

    # ── Logrotate config ─────────────────────
    - name: Configure nginx log rotation
      ansible.builtin.copy:
        dest:  /etc/logrotate.d/nginx-custom
        mode:  '0644'
        content: |
          /var/log/nginx/*.log {
              daily
              missingok
              rotate 14
              compress
              delaycompress
              notifempty
              create 0640 www-data adm
              sharedscripts
              prerotate
                  if [ -d /etc/logrotate.d/httpd-prerotate ]; then
                      run-parts /etc/logrotate.d/httpd-prerotate;
                  fi
              endscript
              postrotate
                  invoke-rc.d nginx rotate >/dev/null 2>&1
              endscript
          }
      tags: [config, logging]

    # ── Monitoring endpoint ───────────────────
    - name: Create nginx status endpoint
      ansible.builtin.copy:
        dest:  /etc/nginx/conf.d/status.conf
        mode:  '0644'
        content: |
          # Nginx Status Endpoint
          server {
              listen 127.0.0.1:8080;
              location /nginx_status {
                  stub_status on;
                  access_log  off;
                  allow       127.0.0.1;
                  deny        all;
              }
          }
      notify: reload nginx
      tags: [config, monitoring]

  # ── Post-tasks ────────────────────────────────
  post_tasks:

    # ── Flush handlers ────────────────────────
    - name: Flush handlers
      ansible.builtin.meta: flush_handlers
      tags: always

    # ── Verify HTTP ───────────────────────────
    - name: Verify HTTP response
      ansible.builtin.uri:
        url:         "http://localhost"
        status_code: 200
      register:      http_check
      retries:       3
      delay:         5
      ignore_errors: true
      tags: [verify, nginx]

    # ── Verify nginx status ───────────────────
    - name: Verify nginx status endpoint
      ansible.builtin.uri:
        url:         "http://127.0.0.1:8080/nginx_status"
        status_code: 200
      register:      status_check
      ignore_errors: true
      tags: [verify, monitoring]

    # ── Final report ──────────────────────────
    - name: Web Server Report
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "✅ WEB SERVER SETUP COMPLETE"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host    : {{ inventory_hostname }}"
          - "IP      : {{ ansible_facts['default_ipv4']['address'] }}"
          - "HTTP    : {{ '✅ OK' if not http_check.failed else '❌ FAILED' }}"
          - "Status  : {{ '✅ OK' if not status_check.failed else '❌ FAILED' }}"
          - "Web root: /var/www/{{ inventory_hostname }}"
          - "Logs    : /var/log/nginx/"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      tags: always

  # ── Handlers ──────────────────────────────────
  handlers:

    - name: reload nginx
      ansible.builtin.service:
        name:  nginx
        state: reloaded
      ignore_errors: "{{ ansible_check_mode }}"
EOF
```

## Βήμα 5: Εκτέλεση

```bash
# ── Syntax check ──────────────────────────────
ansible-playbook playbooks/webserver-galaxy.yml \
    --syntax-check

# ── List tasks ────────────────────────────────

    --list-tasks

# ── Dry run ───────────────────────────────────

    --check --diff \
    --limit nextcloud

# ── Full deployment ───────────────────────────
ansible-playbook playbooks/webserver-galaxy.yml \
    --limit nextcloud \
    -v

    --tags nginx \
    --limit nextcloud
```

## Βήμα 6: Επαλήθευση

```bash
# ── HTTP check ────────────────────────────────
ansible nextcloud -m ansible.builtin.uri \
    -a "url=http://localhost status_code=200"

ansible nextcloud -m ansible.builtin.command \
    -a "nginx -t" --become

    -a "systemctl status nginx" --become

ansible nextcloud -m ansible.builtin.command \
    -a "ls -la /var/www/{{ inventory_hostname }}" \
```

## Συνδυασμός Galaxy + Δικό μας Role

```yaml
---
# Χρήση ΑΜΦΟΤΕΡΩΝ — Galaxy και δικό μας role
- name: Advanced Web Setup
  hosts: all
  become: true

  roles:
    # ── Galaxy role για βασική εγκατάσταση ────
    - role: geerlingguy.nginx
      tags: nginx
      vars:
        nginx_remove_default_vhost: true

    # ── Δικό μας role για custom config ───────
    - role: nginx                  # ← ~/ansible/roles/nginx/
      tags: [nginx, custom]
      vars:
        nginx_vhosts:
          - name:    myapp
            domains: ["{{ inventory_hostname }}"]
            port:    80
            root:    /var/www/myapp
```

```
Web Server Setup με Galaxy
├── Βήματα:
│   ├── requirements.yml → roles + collections
│   ├── ansible-galaxy install -r requirements.yml
│   ├── group_vars → nginx configuration
│   └── playbook → Galaxy role + custom tasks
│
├── geerlingguy.nginx variables:
│   ├── nginx_vhosts        → virtual hosts
│   ├── nginx_worker_*      → performance
│   ├── nginx_extra_http_options → custom config
│   └── nginx_remove_default_vhost → cleanup
│
├── Custom additions:
│   ├── Security headers
│   ├── Log rotation
│   └── Status endpoint
│
└── Verify:
    ├── ansible ... uri → HTTP check
    └── ansible ... command → nginx -t
```
