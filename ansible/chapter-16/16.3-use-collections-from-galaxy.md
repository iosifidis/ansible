# 16.3 Χρήση Collections από Galaxy 📦

## Τι είναι τα Collections (εις βάθος)

```
Collection = πακέτο που περιέχει:
├── modules      → νέα modules για tasks
├── plugins      → connection, lookup, filter plugins
├── roles        → έτοιμα roles
├── playbooks    → έτοιμα playbooks
└── docs         → τεκμηρίωση
```

> 📝 **Παράδειγμα:** Το `community.docker` collection περιέχει:
> ```
> modules:  docker_container, docker_image, docker_network...
> roles:    docker_swarm_manager, docker_swarm_worker
> plugins:  docker connection plugin
> ```

## Εγκατάσταση Collections

```bash
# ── Βασική εγκατάσταση ────────────────────────
ansible-galaxy collection install community.docker

# Output:
# Starting galaxy collection install process
# Installing 'community.docker:3.4.0' to
# '/home/ansible/.ansible/collections/ansible_collections/community/docker'
# community.docker:3.4.0 was installed successfully

# ── Συγκεκριμένη έκδοση ───────────────────────
ansible-galaxy collection install community.docker:3.4.0

# ── Ελάχιστη έκδοση ───────────────────────────
ansible-galaxy collection install 'community.docker:>=3.0.0'

# ── Πολλαπλές collections ─────────────────────
ansible-galaxy collection install \
    community.docker \
    community.general \
    ansible.posix \
    amazon.aws

# ── Σε συγκεκριμένο path ──────────────────────
ansible-galaxy collection install \
    community.docker \
    -p ~/ansible/collections/

# ── Force reinstall ───────────────────────────
ansible-galaxy collection install \
    community.docker \
    --force

# ── Upgrade ───────────────────────────────────
ansible-galaxy collection install \
    community.docker \
    --upgrade
```

## Πού αποθηκεύονται

```bash
# Default τοποθεσία
ls ~/.ansible/collections/ansible_collections/

# Output:
# amazon/      → amazon.aws
# ansible/     → ansible.posix, ansible.windows
# community/   → community.docker, community.general

# Δομή φακέλου:
~/.ansible/collections/
└── ansible_collections/
    └── community/
        └── docker/
            ├── MANIFEST.json
            ├── plugins/
            │   └── modules/
            │       ├── docker_container.py
            │       ├── docker_image.py
            │       └── ...
            └── roles/
```

```ini
# ansible.cfg — custom collections path
[defaults]
collections_path = ~/ansible/collections:~/.ansible/collections
```

## Επαλήθευση & Πληροφορίες

```bash
# ── Λίστα εγκατεστημένων collections ─────────
ansible-galaxy collection list

# Output:

ansible-galaxy collection verify community.docker

ansible-doc community.docker.docker_image | head -50

# ── Λίστα modules collection ──────────────────
ansible-doc -l | grep community.docker
```

## requirements.yml με Collections

```yaml
# requirements.yml
---
roles:
  - name:    geerlingguy.nginx
    version: "3.2.0"
  - name:    geerlingguy.docker
    version: ">=6.0.0"

collections:

  # ── Core collections ──────────────────────
  - name:    ansible.posix
    version: ">=1.5.0"
    source:  https://galaxy.ansible.com   # ← custom source

  - name:    community.general
    version: ">=7.0.0"

  # ── Docker ────────────────────────────────
  - name:    community.docker
    version: ">=3.0.0"

  # ── Cloud providers ───────────────────────
  - name:    amazon.aws
    version: ">=6.0.0"

  - name:    azure.azcollection
    version: "*"

  # ── Από private Galaxy ────────────────────
  - name:    myorg.internal_collection
    source:  https://my-galaxy.mycompany.com
```

```bash
# Εγκατάσταση όλων
ansible-galaxy install -r requirements.yml

# Μόνο collections
ansible-galaxy collection install -r requirements.yml

# Με upgrade
ansible-galaxy collection install \
    -r requirements.yml \
    --upgrade
```

## Χρήση Collections σε Playbook

### Τρόπος 1: FQCN (Fully Qualified Collection Name)
```yaml
# Πάντα δουλεύει — συνιστάται ✅
tasks:

  - name: Docker container
    community.docker.docker_container:
      name:  myapp
      image: nginx:latest
      state: started

  - name: Docker image
    community.docker.docker_image:
      name:   myapp
      source: pull

  - name: Firewalld rule
    ansible.posix.firewalld:
      port:      80/tcp
      permanent: true
      state:     enabled
```

### Τρόπος 2: collections keyword
```yaml
# Ορισμός collections στο play level
- name: Docker Setup
  hosts: all
  become: true
  collections:
    - community.docker    # ← δεν χρειάζεσαι FQCN!

  tasks:
    - name: Docker container
      docker_container:    # ← χωρίς community.docker prefix
        name:  myapp
        image: nginx:latest
        state: started

    - name: Docker image
      docker_image:        # ← χωρίς prefix
        name:   myapp
        source: pull
```

> ⚠️ **Σύσταση:** Χρησιμοποίησε **πάντα FQCN** (Τρόπος 1) — είναι σαφέστερο και αποφεύγεις conflicts.

## Πρακτικά παραδείγματα Collections

### community.docker:
```yaml
tasks:

  # ── Pull image ────────────────────────────
  - name: Pull nginx image
    community.docker.docker_image:
      name:   nginx
      tag:    latest
      source: pull

  # ── Run container ─────────────────────────
  - name: Start nginx container
    community.docker.docker_container:
      name:    nginx_web
      image:   nginx:latest
      state:   started
      restart_policy: always
      ports:
        - "80:80"
        - "443:443"
      volumes:
        - /var/www/html:/usr/share/nginx/html:ro

  # ── Docker network ────────────────────────
  - name: Create app network
    community.docker.docker_network:
      name:  app_network
      state: present
```

### ansible.posix:
```yaml
tasks:

  # ── SSH authorized key ────────────────────
  - name: Add SSH key
    ansible.posix.authorized_key:
      user:  ansible
      key:   "{{ lookup('file', '~/.ssh/id_ed25519.pub') }}"
      state: present

  # ── Firewalld ─────────────────────────────
  - name: Open HTTP port
    ansible.posix.firewalld:
      port:      80/tcp
      permanent: true
      state:     enabled
      immediate: true

  # ── Sysctl ────────────────────────────────
  - name: Enable IP forwarding
    ansible.posix.sysctl:
      name:       net.ipv4.ip_forward
      value:      "1"
      sysctl_set: true
      state:      present
      reload:     true
```

### community.general:
```yaml
tasks:

  # ── Timezone ──────────────────────────────
  - name: Set timezone
    community.general.timezone:
      name: Europe/Athens

  # ── UFW firewall ──────────────────────────
  - name: Allow SSH
    community.general.ufw:
      rule:  allow
      port:  "2022"
      proto: tcp

  - name: Enable UFW
    community.general.ufw:
      state: enabled

  # ── zypper (openSUSE) ─────────────────────
  - name: Install package (openSUSE)
    community.general.zypper:
      name:  nginx
      state: present
```

## Collections στο ansible.cfg

```ini
# ansible.cfg
[defaults]
# Paths για collections
collections_path = ~/ansible/collections:~/.ansible/collections

[galaxy]
# Custom Galaxy server
server_list = automation_hub, release_galaxy

[galaxy_server.automation_hub]
url = https://cloud.redhat.com/api/automation-hub/
auth_url = https://sso.redhat.com/auth/...
token = mytoken123

[galaxy_server.release_galaxy]
url = https://galaxy.ansible.com/
```

## Ενημέρωση & Συντήρηση Collections

```bash
# ── Έλεγχος για updates ───────────────────────
ansible-galaxy collection list | while read col ver; do
    echo "Checking ${col}..."
done

# ── Update συγκεκριμένης collection ───────────
ansible-galaxy collection install \
    community.docker \
    --upgrade

# ── Update όλων από requirements.yml ──────────
ansible-galaxy collection install \
    -r requirements.yml \
    --upgrade

# ── Verify integrity ──────────────────────────
ansible-galaxy collection verify community.docker
# Output:
# Collection community.docker contains modified content
# in the following files:
# (nothing = OK! ✅)
```

## Σύνοψη 16.3

```
Collections από Galaxy
├── Τι είναι: πακέτο modules/plugins/roles/playbooks
│
├── Εγκατάσταση:
│   ├── ansible-galaxy collection install namespace.name
│   ├── Με version: namespace.name:>=3.0.0
│   └── requirements.yml → collection install -r
│
├── Τοποθεσία:
│   └── ~/.ansible/collections/ansible_collections/
│
├── Χρήση:
│   ├── FQCN: community.docker.docker_container ✅
│   └── collections: keyword (λιγότερο explicit)
│
├── Σημαντικά:
│   ├── ansible.posix    → authorized_key, firewalld, sysctl
│   ├── community.docker → docker_container, docker_image
│   ├── community.general→ timezone, ufw, zypper
│   └── amazon.aws       → EC2, S3, RDS...
│
└── Συντήρηση:
    ├── --upgrade → ενημέρωση
    └── verify   → έλεγχος integrity
```
