# 16.1 Τι είναι το Ansible Galaxy 🌌

## Ο ορισμός

Το **Ansible Galaxy** είναι το **κεντρικό αποθετήριο** της κοινότητας Ansible — ένα "app store" για roles και collections που μπορείς να κατεβάσεις και να χρησιμοποιήσεις αμέσως.

> 📝 **Αναλογία:**
> ```
> Ansible Galaxy = PyPI για Python
>                = npm για JavaScript
>                = apt για Debian
>
> Αντί να γράφεις τα πάντα από την αρχή,
> κατεβάζεις έτοιμα roles/collections!
> ```

---

## Roles vs Collections

```
┌─────────────────────────────────────────────────────────┐
│  ROLES                                                  │
│  ├── Παλαιότερο σύστημα (Ansible 1.x+)                  │
│  ├── Αυτόνομες μονάδες για ένα component                │
│  │   (nginx, mysql, docker κλπ)                         │
│  ├── Εγκατάσταση: ansible-galaxy role install           │
│  └── Τοποθεσία: ~/ansible/roles/ ή /etc/ansible/roles   │
├─────────────────────────────────────────────────────────┤
│  COLLECTIONS                                            │
│  ├── Νεότερο σύστημα (Ansible 2.9+)                     │
│  ├── Πακέτα με modules, plugins, roles, playbooks       │
│  ├── Εγκατάσταση: ansible-galaxy collection install     │
│  └── Τοποθεσία: ~/.ansible/collections/                 │
└─────────────────────────────────────────────────────────┘
```

> 💡 **Τάση:** Η Ansible κινείται προς **Collections** — είναι το μέλλον. Τα roles παραμένουν σημαντικά αλλά η νέα ανάπτυξη γίνεται ως collections.

## ansible-galaxy CLI

```bash
# ── Role commands ──────────────────────────────
ansible-galaxy role install   geerlingguy.nginx
ansible-galaxy role remove    geerlingguy.nginx
ansible-galaxy role list
ansible-galaxy role search    nginx
ansible-galaxy role info      geerlingguy.nginx
ansible-galaxy role init      my_new_role

# ── Collection commands ────────────────────────
ansible-galaxy collection install  community.docker
ansible-galaxy collection list
ansible-galaxy collection verify   community.docker

# ── Requirements ───────────────────────────────
ansible-galaxy install -r requirements.yml
ansible-galaxy collection install -r requirements.yml
```

## Galaxy Namespace — Ονοματολογία

```
geerlingguy.nginx
│           │
│           └── role name
└──────────────── namespace (GitHub username)

community.general
│          │
│          └── collection name
└──────────────── namespace (community)

amazon.aws
│      │
│      └── collection name
└──────────── namespace (amazon)
```

## Ποιοτικοί δείκτες στο Galaxy

```bash
# Πριν εγκαταστήσεις ένα role, έλεγξε:
ansible-galaxy role info geerlingguy.nginx

# Κοίτα:
# ├── Download count    → πόσοι το χρησιμοποιούν
# ├── Stars             → community rating
# ├── GitHub            → ενεργό repo;
# ├── Last commit       → πότε ενημερώθηκε τελευταία
# └── Platforms         → υποστηρίζει τη distro σου;
```

## Δημοφιλή Roles & Collections

```
Δημοφιλή Roles:
├── geerlingguy.nginx         → Nginx web server
├── geerlingguy.mysql         → MySQL/MariaDB
├── geerlingguy.docker        → Docker
├── geerlingguy.php           → PHP
├── geerlingguy.postgresql    → PostgreSQL
├── geerlingguy.redis         → Redis
└── geerlingguy.security      → Security hardening

Δημοφιλή Collections:
├── community.general         → general purpose modules
├── community.docker          → Docker management
├── amazon.aws                → AWS cloud
├── azure.azcollection        → Azure cloud
├── google.cloud              → Google Cloud
├── ansible.posix             → POSIX/Linux modules
└── kubernetes.core           → Kubernetes
```

## Σύνοψη 16.1

```
Ansible Galaxy
├── Κεντρικό αποθετήριο roles & collections
├── https://galaxy.ansible.com
├── CLI: ansible-galaxy role/collection
│
├── Roles:
│   ├── Παλαιότερο, αυτόνομο component
│   └── ansible-galaxy role install
│
├── Collections:
│   ├── Νεότερο, πακέτο modules/plugins/roles
│   └── ansible-galaxy collection install
│
└── Ποιότητα:
    ├── Έλεγξε: downloads, stars, last commit
    └── Προτίμησε: certified ή community collections
```
