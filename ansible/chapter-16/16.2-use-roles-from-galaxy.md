# 16.2 Χρήση Roles από Galaxy 📦

## Αναζήτηση Roles

```bash
# ── Αναζήτηση από command line ────────────────
ansible-galaxy role search nginx

# Output:
#  Name                    Description
#  ----------------------- ----------------------------------
#  geerlingguy.nginx       Nginx for Linux
#  nginxinc.nginx          Official NGINX role
#  jdauphant.nginx         Nginx role for Debian/Ubuntu

# ── Αναζήτηση με φίλτρα ───────────────────────
ansible-galaxy role search nginx \
    --platforms EL          # ← μόνο RedHat-based

ansible-galaxy role search nginx \
    --author geerlingguy   # ← μόνο από συγκεκριμένο author

# ── Πληροφορίες role ──────────────────────────
ansible-galaxy role info geerlingguy.nginx

# Output:
# Role: geerlingguy.nginx
# Description: Nginx for Linux
# Downloads:   25,000,000+
# Stars:       1,400+
# Platforms:   EL, Debian, Ubuntu, Fedora, opensuse
```

---

## Εγκατάσταση Role

```bash
# ── Βασική εγκατάσταση ────────────────────────
ansible-galaxy role install geerlingguy.nginx

# Output:
# - downloading role 'nginx', owned by geerlingguy
# - downloading role from https://github.com/geerlingguy/...
# - extracting geerlingguy.nginx to ~/.ansible/roles/geerlingguy.nginx
# - geerlingguy.nginx was installed successfully

# ── Συγκεκριμένη έκδοση ───────────────────────
ansible-galaxy role install geerlingguy.nginx,3.2.0

# ── Σε συγκεκριμένο path ──────────────────────
ansible-galaxy role install \
    geerlingguy.nginx \
    -p ~/ansible/roles/
# → εγκαθίσταται στο ~/ansible/roles/geerlingguy.nginx

# ── Πολλαπλά roles ────────────────────────────
ansible-galaxy role install \
    geerlingguy.nginx \
    geerlingguy.mysql \
    geerlingguy.php

# ── Force reinstall ───────────────────────────
ansible-galaxy role install geerlingguy.nginx --force
```

## Πού εγκαθίσταται

```bash
# Default τοποθεσίες (με σειρά προτεραιότητας):
# 1. roles_path στο ansible.cfg
# 2. ~/.ansible/roles
# 3. /etc/ansible/roles

# Δες τρέχουσες τοποθεσίες
ansible-galaxy role list

# Output:
# # /home/ansible/ansible/roles
# - nginx, (unknown version)
# # /home/ansible/.ansible/roles
# - geerlingguy.nginx, 3.2.0
```

```ini
# ansible.cfg — ορισμός custom roles path
[defaults]
roles_path = ~/ansible/roles:~/.ansible/roles
#            ↑ πρώτα ψάχνει εδώ, μετά εκεί
```

## requirements.yml — Βέλτιστη πρακτική

Αντί να εγκαθιστάς manually, ορίζεις τα roles σε αρχείο:

```bash
cat > ~/ansible/requirements.yml << 'EOF'
---
# ============================================================
# Ansible Requirements
# Εγκατάσταση: ansible-galaxy install -r requirements.yml
# ============================================================

roles:

  # ── Από Galaxy ────────────────────────────
  - name:    geerlingguy.nginx
    version: "3.2.0"           # ← συγκεκριμένη έκδοση

  - name:    geerlingguy.mysql
    version: ">=4.0.0"         # ← ελάχιστη έκδοση

  - name:    geerlingguy.php
    version: "*"               # ← οποιαδήποτε

  # ── Από GitHub ────────────────────────────
  - name:    my_nginx
    src:     https://github.com/myuser/ansible-nginx
    version: main              # ← branch ή tag

  # ── Από GitHub με συγκεκριμένο tag ────────
  - name:    custom_security
    src:     https://github.com/myuser/ansible-security
    version: "v1.2.0"

  # ── Local role (για testing) ───────────────
  - name:    local_common
    src:     file:///home/ansible/ansible/roles/common

collections:

  # ── Από Galaxy ────────────────────────────
  - name:    community.general
    version: ">=7.0.0"

  - name:    community.docker
    version: ">=3.0.0"

  - name:    ansible.posix
    version: ">=1.5.0"
EOF
```

```bash
# ── Εγκατάσταση από requirements.yml ─────────
ansible-galaxy install -r requirements.yml

# Ή με explicit paths:
ansible-galaxy role install \
    -r requirements.yml \
    -p ~/ansible/roles/

# ── Update (force reinstall) ──────────────────
ansible-galaxy install \
    -r requirements.yml \
    --force

# ── Μόνο roles ────────────────────────────────
ansible-galaxy role install -r requirements.yml

# ── Μόνο collections ──────────────────────────
ansible-galaxy collection install -r requirements.yml
```

## Χρήση Galaxy Role σε Playbook

```yaml
---
# Χρήση geerlingguy.nginx

- name: Web Server με Galaxy Role
  hosts: all
  become: true
  gather_facts: true

  vars:
    # ── geerlingguy.nginx variables ───────────
    nginx_vhosts:
      - listen:           "80"
        server_name:      "{{ inventory_hostname }}"
        root:             "/var/www/html"
        index:            "index.html"
        access_log:       "/var/log/nginx/access.log"
        error_log:        "/var/log/nginx/error.log"

    nginx_remove_default_vhost: true

    nginx_worker_processes: >-
      "{{ ansible_facts['processor_vcpus'] }}"

  roles:
    - role: geerlingguy.nginx    # ← Galaxy role!
      tags: nginx
```

## Εξερεύνηση εγκατεστημένου Role

```bash
# Δες τη δομή του Galaxy role
tree ~/.ansible/roles/geerlingguy.nginx/

# Output:
# geerlingguy.nginx/
# ├── README.md           ← ΠΑΝΤΑ διάβαζε αυτό!
# ├── defaults/
# │   └── main.yml        ← διαθέσιμες μεταβλητές
# ├── handlers/
# │   └── main.yml
# ├── meta/
# │   └── main.yml
# ├── tasks/
# │   └── main.yml
# └── templates/
#     └── ...

# Διάβασε τα defaults — αυτές είναι οι μεταβλητές!
cat ~/.ansible/roles/geerlingguy.nginx/defaults/main.yml
```

## Σύγκριση — Galaxy Role vs δικό μας Role

```
┌───────────────────────┬──────────────┬──────────────────┐
│                       │ Galaxy Role  │ Δικό μας Role    │
├───────────────────────┼──────────────┼──────────────────┤
│ Χρόνος ανάπτυξης      │ 0 λεπτά!     │ Ώρες/μέρες       │
│ Battle-tested         │ ✅ Millions  │ ⚠️ Νέο           │
│ Multi-distro          │ ✅           │ Εσύ φτιάχνεις    │
│ Customization         │ ⚠️ Μόνο vars │ ✅ Πλήρης        │
│ Εξάρτηση από 3rd party│ ❌ Ναι       │ ✅ Όχι           │
│ Κατανόηση κώδικα      │ ⚠️ Μελέτη    │ ✅ Πλήρης        │
└───────────────────────┴──────────────┴──────────────────┘

Χρησιμοποίησε Galaxy role όταν:
✅ Θέλεις γρήγορη λύση
✅ Το role είναι well-maintained
✅ Χρειάζεσαι multi-distro support
✅ Δεν έχεις custom requirements

Φτιάξε δικό σου role όταν:
✅ Έχεις πολύ specific requirements
✅ Θέλεις πλήρη έλεγχο
✅ Η υποδομή σου είναι ιδιαίτερη
```

    ├── Δες defaults/main.yml
