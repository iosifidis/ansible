## Βήμα 1: Προετοιμασία Role

### meta/main.yml — Πλήρες
```yaml
# roles/nginx/meta/main.yml
---
galaxy_info:
  # ── Βασικές πληροφορίες ───────────────────
  role_name:   nginx
  author:      your_github_username
  description: >
    Production-ready nginx installation and configuration.
    Supports Debian/Ubuntu, RedHat/Fedora, openSUSE.
    Multi-distro, idempotent, fully tested.

  # ── License ───────────────────────────────
  license: MIT    # MIT, GPL-2.0, Apache-2.0, BSD

  # ── Ansible version ───────────────────────
  min_ansible_version: "2.15"

  # ── Platforms ─────────────────────────────
  platforms:
    - name: Debian
      versions:
        - bookworm
        - trixie
    - name: Ubuntu
      versions:
        - jammy      # 22.04
        - noble      # 24.04
    - name: EL       # Enterprise Linux (RHEL/Rocky/Alma)
      versions:
        - "8"
        - "9"
    - name: Fedora
      versions:
        - "39"
        - "40"
    - name: opensuse
      versions:
        - "15.5"
        - "15.6"

  # ── Galaxy Tags ───────────────────────────
  galaxy_tags:
    - web
    - nginx
    - http
    - webserver
    - reverse_proxy

dependencies: []
```

### README.md — Πλήρες
```markdown
# Nginx Role

Production-ready nginx installation and configuration for Linux.

## Πλατφόρμες

- Debian 12 (Bookworm), 13 (Trixie)
- Ubuntu 22.04, 24.04
- Rocky Linux / AlmaLinux 8, 9
- Fedora 39, 40
- openSUSE Leap 15.5, 15.6

## Εγκατάσταση

```bash
ansible-galaxy role install your_username.nginx
```

## Απαιτήσεις

- Ansible >= 2.15
- community.general collection

## Μεταβλητές

| Variable | Default | Description |
|---|---|---|
| `nginx_worker_processes` | auto | Worker processes |
| `nginx_worker_connections` | 768 | Max connections |
| `nginx_ssl_enabled` | false | Enable SSL |
| `nginx_gzip_enabled` | true | Enable gzip |
| `nginx_vhosts` | [] | Virtual hosts |

## Βήμα 3: Galaxy Token

```bash
# Βήμα 1: Πήγαινε στο https://galaxy.ansible.com
# Βήμα 2: Login με GitHub
# Βήμα 3: Πήγαινε στο: Preferences → API Key
# Βήμα 4: Copy το API token

# Αποθήκευση token
mkdir -p ~/.ansible
cat > ~/.ansible/galaxy_token << 'EOF'
YOUR_GALAXY_TOKEN_HERE
EOF
chmod 600 ~/.ansible/galaxy_token
```

```ini
# ansible.cfg — χρήση token
[galaxy]
server_list = release_galaxy

[galaxy_server.release_galaxy]
url   = https://galaxy.ansible.com/
token = YOUR_GALAXY_TOKEN_HERE
# ← ή χρησιμοποίησε environment variable:
# ANSIBLE_GALAXY_SERVER_RELEASE_GALAXY_TOKEN
```

## Βήμα 4: Import Role στο Galaxy

```bash
# ── Μέθοδος 1: Web UI ─────────────────────────
# 1. Πήγαινε στο https://galaxy.ansible.com
# 2. My Content → Add Content
# 3. Import Role from GitHub
# 4. Επίλεξε: your_username/ansible-role-nginx
# 5. Click Import

# ── Μέθοδος 2: Command Line ───────────────────
ansible-galaxy role import \
    your_github_username \
    ansible-role-nginx

# ── Μέθοδος 3: με token ───────────────────────
ansible-galaxy role import \
    --token YOUR_GALAXY_TOKEN \
    your_github_username \
    ansible-role-nginx

# Output:
# successfully imported role your_username.nginx
```

## Βήμα 5: Αυτόματο Import με GitHub Actions

```bash
mkdir -p ~/ansible/roles/nginx/.github/workflows

cat > ~/ansible/roles/nginx/.github/workflows/galaxy.yml << 'EOF'
---
# .github/workflows/galaxy.yml
# Αυτόματο import στο Galaxy σε κάθε release

name: Release to Ansible Galaxy

on:
  release:
    types: [published]    # ← τρέχει όταν δημοσιεύεις release

jobs:
  release:
    runs-on: ubuntu-latest
    steps:

      - name: Checkout code
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install Ansible
        run: pip install ansible

      - name: Import role to Galaxy
        run: >
          ansible-galaxy role import
          --token ${{ secrets.GALAXY_API_KEY }}
          ${{ github.repository_owner }}
          ${{ github.event.repository.name }}

      - name: Notify success
        run: |
          echo "✅ Role imported to Galaxy successfully!"
          echo "Version: ${{ github.event.release.tag_name }}"
EOF
```

```bash
# Στο GitHub repo:
# Settings → Secrets → Actions → New secret
# Name: GALAXY_API_KEY
# Value: your_galaxy_token

# Δημιουργία νέου release:
git tag -a v1.1.0 -m "Release v1.1.0 - Added PHP support"
git push origin v1.1.0

# Στο GitHub: Releases → Create Release από tag v1.1.0
# → Αυτόματα import στο Galaxy! ✅
```

## Βήμα 7: Testing πριν τη δημοσίευση

```bash
# ── Εγκατάσταση Molecule (testing framework) ──
pip install molecule molecule-docker

# ── Δημιουργία test scenario ──────────────────
cd ~/ansible/roles/nginx
molecule init scenario --driver-name docker

# ── molecule/default/molecule.yml ─────────────
cat > molecule/default/molecule.yml << 'EOF'
---
dependency:
  name: galaxy
driver:
  name: docker
platforms:
  - name:  debian12
    image: geerlingguy/docker-debian12-ansible
    pre_build_image: true
  - name:  ubuntu2204
    image: geerlingguy/docker-ubuntu2204-ansible
    pre_build_image: true
provisioner:
  name: ansible
verifier:
  name: ansible
EOF

# ── molecule/default/converge.yml ─────────────
cat > molecule/default/converge.yml << 'EOF'
---
- name: Converge
  hosts: all
  become: true
  roles:
    - role: nginx
EOF

# ── molecule/default/verify.yml ───────────────
cat > molecule/default/verify.yml << 'EOF'
---
- name: Verify
  hosts: all
  tasks:
    - name: Check nginx is running
      ansible.builtin.service_facts:

    - name: Assert nginx is active
      ansible.builtin.assert:
        that:
          - ansible_facts.services['nginx.service'].state == 'running'

    - name: Check HTTP response
      ansible.builtin.uri:
        url:         http://localhost
        status_code: 200
EOF

# ── Τρέξε tests ───────────────────────────────
molecule test

# Output:
# PLAY [Converge] ****
# TASK [nginx : Install nginx] → changed
# TASK [nginx : Configure nginx] → changed
# ...
# PLAY [Verify] ****
# TASK [Assert nginx is active] → ok ✅
# TASK [Check HTTP response] → ok ✅
```
