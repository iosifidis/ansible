# 20.1 Τι είναι τα Lookups 🔍

## Ορισμός

Τα **Lookups** είναι plugins που επιτρέπουν στην Ansible να **διαβάζει δεδομένα από εξωτερικές πηγές** — αρχεία, environment variables, databases, password stores, κ.ά. — κατά τη διάρκεια εκτέλεσης.

> 📝 **Αναλογία:**
> ```
> Module:  Εκτελείται στον MANAGED HOST
>          ansible.builtin.copy → αντιγράφει αρχείο στον host
>
> Lookup:  Εκτελείται στον ANSIBLE CONTROLLER (τοπικά!)
>          lookup('file', '/path/to/local/file') → διαβάζει τοπικό αρχείο
> ```

> ⚠️ **Κρίσιμο:** Τα lookups τρέχουν πάντα **στον controller**, όχι στον managed host. Αυτό είναι εσκεμμένο — ανεβάζεις/διαβάζεις δεδομένα τοπικά για να τα παραδώσεις στον host.

---

## Σύνταξη

```yaml
# Βασική σύνταξη
{{ lookup('plugin_name', 'argument') }}

# Με options
{{ lookup('plugin_name', 'argument', kwarg=value) }}

# Σε μεταβλητή
vars:
  my_file_content: "{{ lookup('file', '/etc/ssl/cert.pem') }}"
  my_env_var:      "{{ lookup('env', 'HOME') }}"

# Σε task
tasks:
  - name: Χρήση lookup
    ansible.builtin.debug:
      msg: "{{ lookup('file', '/etc/hostname') }}"
```

---

## query() vs lookup()

```yaml
# lookup() → επιστρέφει string (ή λίστα ως string)
- ansible.builtin.debug:
    msg: "{{ lookup('fileglob', '/etc/nginx/conf.d/*.conf') }}"
    # → "/etc/nginx/conf.d/default.conf,/etc/nginx/conf.d/ssl.conf"
    # (string με κόμμα!)

# query() → επιστρέφει ΠΑΝΤΑ λίστα ✅
- ansible.builtin.debug:
    msg: "{{ query('fileglob', '/etc/nginx/conf.d/*.conf') }}"
    # → ["/etc/nginx/conf.d/default.conf", "/etc/nginx/conf.d/ssl.conf"]
    # (λίστα!)

# Ισοδύναμο: lookup(..., wantlist=True)
- ansible.builtin.debug:
    msg: "{{ lookup('fileglob', '/etc/nginx/conf.d/*.conf', wantlist=True) }}"
```

> 💡 **Κανόνας:** Όταν χρησιμοποιείς lookup σε `loop:`, χρησιμοποίησε `query()` για να εξασφαλίσεις λίστα.

## Κατηγορίες Lookups

```
Ansible Lookup Plugins
│
├── File & Path
│   ├── file      → περιεχόμενο αρχείου
│   ├── fileglob  → glob pattern → λίστα αρχείων
│   ├── find      → εύρεση αρχείων
│   └── url       → HTTP content
│
├── System
│   ├── env       → environment variables
│   ├── pipe      → output εντολής
│   └── ini       → INI file values
│
├── Credentials
│   ├── password  → auto-generate & cache password
│   └── template  → render Jinja2 template
│
└── Data Structures
    ├── items     → λίστα
    ├── dict      → dictionary items
    └── subelements → nested lists
```

```

├── Εκτελούνται: στον CONTROLLER (τοπικά)
```
