# 20.3 System Lookups 🖥️

## lookup('env') — Environment variables

```yaml
vars:
  home_dir:    "{{ lookup('env', 'HOME') }}"
  user_name:   "{{ lookup('env', 'USER') }}"
  ci_token:    "{{ lookup('env', 'CI_TOKEN') }}"
  deploy_env:  "{{ lookup('env', 'DEPLOY_ENV') | default('production') }}"

tasks:

  # ── Χρήση env vars ──────────────────────────
  - name: Deploy config
    ansible.builtin.template:
      src:  app.conf.j2
      dest: /etc/myapp/app.conf
    vars:
      database_url: "{{ lookup('env', 'DATABASE_URL') }}"
      redis_url:    "{{ lookup('env', 'REDIS_URL') }}"

  # ── Έλεγχος αν υπάρχει env var ──────────────
  - name: Έλεγχος CI_TOKEN
    ansible.builtin.fail:
      msg: "CI_TOKEN δεν έχει οριστεί!"
    when: lookup('env', 'CI_TOKEN') == ''

  # ── CI/CD integration ────────────────────────
  - name: Slack notification
    ansible.builtin.uri:
      url:    "{{ lookup('env', 'SLACK_WEBHOOK') }}"
      method: POST
      body_format: json
      body:
        text: "Deploy {{ app_version }} ολοκληρώθηκε!"
    when: lookup('env', 'SLACK_WEBHOOK') != ''
```

> 💡 **CI/CD χρήση:** Στο GitHub Actions / GitLab CI, ορίζεις secrets ως environment variables. Η Ansible τα διαβάζει με `lookup('env', 'SECRET_NAME')` — ασφαλέστερο από `-e`!

## lookup('pipe') — Output εντολής

```yaml
vars:
  # Τοπική εντολή → μεταβλητή
  git_commit: "{{ lookup('pipe', 'git rev-parse --short HEAD') }}"
  hostname:   "{{ lookup('pipe', 'hostname -f') }}"
  date_str:   "{{ lookup('pipe', 'date +%Y%m%d') }}"

tasks:

  - name: Deploy info με git commit
    ansible.builtin.debug:
      msg:
        - "Deploying commit: {{ lookup('pipe', 'git rev-parse --short HEAD') }}"
        - "Branch: {{ lookup('pipe', 'git branch --show-current') }}"
        - "Date:   {{ lookup('pipe', 'date +%Y-%m-%d') }}"

  - name: Tag Docker image με git hash
    community.docker.docker_image:
      name:   "myapp"
      tag:    "{{ lookup('pipe', 'git rev-parse --short HEAD') }}"
      source: local
      push:   true
```

> ⚠️ **Προσοχή:** `lookup('pipe', ...)` τρέχει στον **controller**. Αν η εντολή αποτύχει, το playbook αποτυγχάνει.

## lookup('ini') — INI file values

```yaml
# files/config.ini
# [section]
# key = value

vars:
  db_host: "{{ lookup('ini', 'host section=database file=files/config.ini') }}"
  db_port: "{{ lookup('ini', 'port section=database file=files/config.ini') }}"
  app_key: "{{ lookup('ini', 'secret_key section=app file=files/config.ini') }}"

tasks:

  - name: INI lookup
    ansible.builtin.debug:
      msg:
        - "DB Host: {{ lookup('ini', 'host section=database file=files/config.ini') }}"
        - "DB Port: {{ lookup('ini', 'port section=database file=files/config.ini') }}"
```

## Σύνοψη 20.3

```
System Lookups
│
├── lookup('env', 'VAR_NAME')
│   ├── Environment variables του controller
│   ├── Χρήση: CI/CD secrets, config από env
│   └── | default('value') αν δεν υπάρχει
│
├── lookup('pipe', 'command')
│   ├── Εκτέλεση τοπικής εντολής
│   ├── Χρήση: git hash, date, local system info
│   └── ⚠️ Τρέχει στον controller!
│
└── lookup('ini', 'key section=X file=Y')
    ├── Ανάγνωση INI αρχείων
    └── Χρήση: legacy config files
```
