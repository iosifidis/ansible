# 20.4 Credential Lookups 🔐

## lookup('password') — Auto-generate passwords

Το `lookup('password', ...)` **δημιουργεί** password αυτόματα και το **αποθηκεύει τοπικά** ώστε να είναι idempotent:

```yaml
vars:
  # ── Δημιουργία password (ή επαναχρησιμοποίηση αν υπάρχει) ──
  db_password: >-
    {{ lookup('password',
              'credentials/db_pass
               length=20
               chars=ascii_letters,digits,punctuation') }}
  #              ↑ path (τοπικό αρχείο cache)
  #                        ↑ μήκος
  #                                  ↑ χαρακτήρες

  # ── Simple password ──────────────────────────
  app_secret: >-
    {{ lookup('password', 'credentials/app_secret length=32') }}

  # ── Μόνο alphanumeric (χωρίς σύμβολα) ───────
  api_key: >-
    {{ lookup('password',
              'credentials/api_key
               length=40
               chars=ascii_letters,digits') }}
```

```
Πώς λειτουργεί:
│
├── 1η εκτέλεση:
│   └── Δημιουργεί random password
│       → Αποθηκεύει σε credentials/db_pass
│       → Επιστρέφει το password
│
└── 2η+ εκτέλεση:
    └── Βρίσκει credentials/db_pass
        → Επιστρέφει ΙΔΙΟ password (idempotent!) ✅
```

> ⚠️ **Σημαντικό:** Το αρχείο `credentials/` πρέπει να είναι στο `.gitignore`! Ή κρυπτογράφησέ το με Ansible Vault.

## lookup('password') σε πρακτική χρήση

```yaml
---
# Αρχικοποίηση infrastructure με auto-generated secrets
- name: Initialize secrets
  hosts: localhost
  gather_facts: false

  tasks:

    - name: Generate secrets
      ansible.builtin.set_fact:
        db_pass:       "{{ lookup('password', 'credentials/db_pass length=24') }}"
        redis_pass:    "{{ lookup('password', 'credentials/redis_pass length=24') }}"
        app_secret:    "{{ lookup('password', 'credentials/app_secret length=48') }}"
        admin_pass:    "{{ lookup('password', 'credentials/admin_pass length=16 chars=ascii_letters,digits') }}"

    - name: Αποθήκευση secrets σε vault
      ansible.builtin.template:
        src:  templates/vault.yml.j2
        dest: group_vars/all/vault.yml
        mode: '0600'

    - name: Encrypt vault
      ansible.builtin.command:
        cmd: ansible-vault encrypt group_vars/all/vault.yml
      changed_when: true

    - name: Εμφάνιση (για πρώτη φορά)
      ansible.builtin.debug:
        msg:
          - "DB Pass    : {{ db_pass }}"
          - "Admin Pass : {{ admin_pass }}"
          - "⚠️  Αποθήκευσε αυτά τα credentials!"
```

## lookup('template') — Render Jinja2 τοπικά

```yaml
# templates/app.conf.j2 (τοπικό αρχείο)
# [database]
# host = {{ db_host }}
# port = {{ db_port }}
# pass = {{ db_pass }}

vars:
  rendered_config: >-
    {{ lookup('template', 'templates/app.conf.j2') }}
  # ↑ render γίνεται στον controller
  # ↑ αποτέλεσμα = string με rendered content

tasks:

  - name: Deploy rendered config
    ansible.builtin.copy:
      content: "{{ lookup('template', 'templates/app.conf.j2') }}"
      dest:    /etc/myapp/app.conf
      mode:    '0640'
    # ← ισοδύναμο με ansible.builtin.template module
    # αλλά μπορείς να χρησιμοποιήσεις σε vars!
```

## Σύνοψη 20.4

```
Credential Lookups
│
├── lookup('password', 'path length=N chars=...')
│   ├── Auto-generate & cache password
│   ├── Idempotent: ίδιο password σε κάθε run
│   ├── Path: τοπικό αρχείο (gitignore!)
│   └── Χρήση: DB pass, API keys, secrets init
│
└── lookup('template', 'template.j2')
    ├── Render Jinja2 τοπικά (controller)
    ├── Αποτέλεσμα ως string
    └── Χρήση: dynamic content σε vars
```
