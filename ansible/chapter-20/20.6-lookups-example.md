# 20.6 Πρακτικό παράδειγμα — Dynamic Config 🛠️

## Τι θα φτιάξουμε

Playbook που χρησιμοποιεί **πολλά lookups** για να δημιουργήσει δυναμική ρύθμιση:

```yaml
---
# dynamic-config.yml

- name: Dynamic Config με Lookups
  hosts: webservers
  gather_facts: true

  vars:
    # ── Από environment (CI/CD) ─────────────────
    deploy_version: "{{ lookup('env', 'APP_VERSION') | default('latest') }}"
    slack_webhook:  "{{ lookup('env', 'SLACK_WEBHOOK') | default('') }}"

    # ── Από git (τοπικά) ─────────────────────────
    git_commit: "{{ lookup('pipe', 'git rev-parse --short HEAD') }}"
    git_branch: "{{ lookup('pipe', 'git branch --show-current') }}"

    # ── Auto-generated passwords ─────────────────
    db_pass:    "{{ lookup('password', 'credentials/db_pass length=24') }}"
    app_secret: "{{ lookup('password', 'credentials/app_secret length=48') }}"

    # ── SSL cert από local file ───────────────────
    ssl_cert: "{{ lookup('file', 'files/ssl/' + inventory_hostname + '.crt') }}"
    ssl_key:  "{{ lookup('file', 'files/ssl/' + inventory_hostname + '.key') }}"

    # ── Users από dict ───────────────────────────
    app_users:
      - name: alice
        role: admin
        groups: [sudo, docker]
      - name: bob
        role: developer
        groups: [docker]

  tasks:

    # ── Deployment info ───────────────────────────
    - name: "📊 Deployment Info"
      ansible.builtin.debug:
        msg:
          - "Version : {{ deploy_version }}"
          - "Commit  : {{ git_commit }}"
          - "Branch  : {{ git_branch }}"
          - "Host    : {{ inventory_hostname }}"

    # ── SSL certs ────────────────────────────────
    - name: "🔒 Deploy SSL certificate"
      ansible.builtin.copy:
        content: "{{ ssl_cert }}"
        dest:    /etc/ssl/certs/app.crt
        mode:    '0644'

    - name: "🔒 Deploy SSL key"
      ansible.builtin.copy:
        content: "{{ ssl_key }}"
        dest:    /etc/ssl/private/app.key
        mode:    '0600'

    # ── Nginx configs ─────────────────────────────
    - name: "⚙️ Deploy nginx configs"
      ansible.builtin.copy:
        src:  "{{ item }}"
        dest: /etc/nginx/conf.d/
        mode: '0644'
      loop: "{{ query('fileglob', 'files/nginx/conf.d/*.conf') }}"
      loop_control:
        label: "{{ item | basename }}"
      notify: Reload nginx

    # ── App config από template ───────────────────
    - name: "⚙️ App config"
      ansible.builtin.copy:
        content: "{{ lookup('template', 'templates/app.env.j2') }}"
        dest:    /opt/myapp/.env
        mode:    '0640'
        owner:   myapp

    # ── Users ────────────────────────────────────
    - name: "👤 Create app users"
      ansible.builtin.user:
        name:   "{{ item.name }}"
        state:  present
      loop: "{{ app_users }}"
      loop_control:
        label: "{{ item.name }}"

    - name: "👥 Add users to groups"
      ansible.builtin.user:
        name:   "{{ item.0.name }}"
        groups: "{{ item.1 }}"
        append: true
      loop: "{{ app_users | subelements('groups') }}"
      loop_control:
        label: "{{ item.0.name }} → {{ item.1 }}"

    # ── Slack notification ────────────────────────
    - name: "📢 Slack notification"
      ansible.builtin.uri:
        url:         "{{ slack_webhook }}"
        method:      POST
        body_format: json
        body:
          text: >
            ✅ Deploy {{ deploy_version }}
            ({{ git_commit }}) σε {{ inventory_hostname }}
      when: slack_webhook != ''
      run_once: true

  handlers:
    - name: Reload nginx
      ansible.builtin.service:
        name:  nginx
        state: reloaded
```

```bash
# Εκτέλεση
APP_VERSION=2.5.0 \
SLACK_WEBHOOK=https://hooks.slack.com/... \
ansible-playbook playbooks/dynamic-config.yml \
    --limit webservers
```

## Σύνοψη 20.6

```
Lookups στο playbook:
│
├── lookup('env', 'VAR')   → CI/CD secrets
├── lookup('pipe', 'cmd')  → git info
├── lookup('password', .)  → auto-generated creds
├── lookup('file', 'path') → local SSL certs
├── query('fileglob', .)   → batch file deploy
├── lookup('template', .)  → dynamic app config
└── subelements            → users + groups
```
