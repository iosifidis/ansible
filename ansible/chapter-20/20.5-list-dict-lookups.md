# 20.5 List & Dict Lookups 📋

## lookup('items') / loop — Λίστες

```yaml
tasks:

  # ── loop (σύγχρονο, προτιμητέο) ─────────────
  - name: Δημιουργία users (loop)
    ansible.builtin.user:
      name:  "{{ item }}"
      state: present
    loop:
      - alice
      - bob
      - charlie

  # ── loop με dict ─────────────────────────────
  - name: Δημιουργία users με UID
    ansible.builtin.user:
      name: "{{ item.name }}"
      uid:  "{{ item.uid }}"
    loop:
      - { name: alice, uid: 1001 }
      - { name: bob,   uid: 1002 }
```

## dict2items — Dictionary iteration

```yaml
vars:
  nginx_config:
    worker_processes:     auto
    keepalive_timeout:    65
    client_max_body_size: "10m"

tasks:

  - name: Εμφάνιση dict
    ansible.builtin.debug:
      msg: "{{ item.key }}: {{ item.value }}"
    loop: "{{ nginx_config | dict2items }}"

  - name: Dict lookup (παλιό)
    ansible.builtin.debug:
      msg: "{{ item.key }} = {{ item.value }}"
    with_dict: "{{ nginx_config }}"
```

## subelements — Nested structures

```yaml
vars:
  users:
    - name: alice
      groups: [sudo, docker, dev]
    - name: bob
      groups: [dev]
    - name: charlie
      groups: [sudo, dev]

tasks:

  - name: Add users to groups
    ansible.builtin.user:
      name:   "{{ item.0.name }}"
      groups: "{{ item.1 }}"
      append: true
    loop: "{{ users | subelements('groups') }}"
    # item.0 = user dict, item.1 = group name
    loop_control:
      label: "{{ item.0.name }} → {{ item.1 }}"
```

## Σύνοψη 20.5

```
List & Dict Lookups
│
├── loop → Iteration λίστας/dict
├── dict2items → dict σε {key, value} list
└── subelements → nested lists
    ├── item.0 = parent
    └── item.1 = child element
```
