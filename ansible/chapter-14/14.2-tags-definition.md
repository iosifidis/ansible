# 14.2 Ορισμός Tags 🏷️

## Task Level Tags

Το πιο συνηθισμένο — tags σε **μεμονωμένα tasks**:

```yaml
tasks:

  # ── Ένα tag ───────────────────────────────
  - name: Install nginx
    ansible.builtin.package:
      name:  nginx
      state: present
    tags: nginx            # ← single tag (string)

  # ── Πολλαπλά tags ─────────────────────────
  - name: Install packages
    ansible.builtin.package:
      name:  "{{ item }}"
      state: present
    loop: "{{ common_packages }}"
    tags:
      - packages           # ← list format (συνιστάται)
      - install
      - common

  # ── Inline list format ────────────────────
  - name: Configure nginx
    ansible.builtin.template:
      src:  templates/nginx.conf.j2
      dest: /etc/nginx/nginx.conf
    tags: [config, nginx]  # ← inline list

  # ── Task χωρίς tags ───────────────────────
  - name: Start nginx
    ansible.builtin.service:
      name:  nginx
      state: started
    # ← χωρίς tags → τρέχει ΠΑΝΤΑ
    #   (εκτός αν --tags οριστεί)
```

## Play Level Tags

Tags σε **ολόκληρο το play** — εφαρμόζονται σε **όλα** τα tasks:

```yaml
---
# ── Play 1 με tags ────────────────────────────
- name: Web Server Setup
  hosts: webservers
  become: true
  tags:
    - webserver
    - setup             # ← εφαρμόζεται σε ΟΛΑ τα tasks!

  tasks:
    - name: Install nginx      # ← κληρονομεί tag webserver, setup
      ansible.builtin.package:
        name:  nginx
        state: present
      tags: nginx              # ← προστίθεται: nginx + webserver + setup

    - name: Configure nginx    # ← κληρονομεί tag webserver, setup
      ansible.builtin.template:
        src:  templates/nginx.conf.j2
        dest: /etc/nginx/nginx.conf
      tags: config             # ← προστίθεται: config + webserver + setup

# ── Play 2 με διαφορετικά tags ────────────────
- name: Database Setup
  hosts: dbservers
  become: true
  tags:
    - database
    - setup

  tasks:
    - name: Install PostgreSQL
      ansible.builtin.package:
        name:  postgresql
        state: present
      tags: postgresql         # ← postgresql + database + setup
```

```bash
# Τρέξε μόνο webserver play
ansible-playbook site.yml --tags webserver

# Τρέξε setup από ΟΛΑ τα plays
ansible-playbook site.yml --tags setup
# → τρέχει και webserver play και database play!
```

## Block Level Tags

Tags σε **block** — εφαρμόζονται σε όλα τα tasks του block:

```yaml
tasks:

  # ── Block με tags ─────────────────────────
  - name: Nginx installation block
    tags:
      - nginx
      - webserver
    block:

      - name: Install nginx
        ansible.builtin.package:
          name:  nginx
          state: present
        # ← κληρονομεί: nginx, webserver

      - name: Configure nginx
        ansible.builtin.template:
          src:  templates/nginx.conf.j2
          dest: /etc/nginx/nginx.conf
        tags: config
        # ← κληρονομεί + config: nginx, webserver, config

      - name: Start nginx
        ansible.builtin.service:
          name:  nginx
          state: started
        # ← κληρονομεί: nginx, webserver

  # ── Block με rescue ───────────────────────
  - name: Risky operation
    tags: deploy
    block:
      - name: Deploy app
        ansible.builtin.command:
          cmd: /usr/bin/deploy.sh
    rescue:
      - name: Rollback
        ansible.builtin.command:
          cmd: /usr/bin/rollback.sh
        tags:
          - deploy
          - rollback
```

## Include/Import Tags

```yaml
tasks:

  # ── include_tasks με tags ─────────────────
  - name: Include nginx tasks
    ansible.builtin.include_tasks:
      file: tasks/nginx.yml
    tags:
      - nginx
      - webserver
    # ⚠️ include_tasks → tags εφαρμόζονται ΔΥΝΑΜΙΚΑ
    #    (κατά την εκτέλεση)

  # ── import_tasks με tags ──────────────────
  - name: Import nginx tasks
    ansible.builtin.import_tasks:
      file: tasks/nginx.yml
    tags:
      - nginx
      - webserver
    # ✅ import_tasks → tags εφαρμόζονται ΣΤΑΤΙΚΑ
    #    (κατά το parsing — προτιμάται για tags!)
```

> 💡 **import vs include για Tags:**
> ```
> import_tasks  → static  → tags δουλεύουν σωστά ✅
> include_tasks → dynamic → tags μπορεί να μην δουλέψουν
>                           όπως περιμένεις ⚠️
> ```

## Tag Inheritance — Κληρονομικότητα

```yaml
---
- name: My Play
  hosts: all
  tags: play_tag          # ← Level 1

  tasks:
    - name: Block
      tags: block_tag     # ← Level 2
      block:

        - name: Task
          ansible.builtin.debug:
            msg: "Hello"
          tags: task_tag  # ← Level 3

# Αυτό το task έχει tags:
# play_tag + block_tag + task_tag
# → --tags play_tag  ΘΑ το τρέξει
# → --tags block_tag ΘΑ το τρέξει
# → --tags task_tag  ΘΑ το τρέξει
# → --tags other     ΔΕΝ θα το τρέξει
```

## Πλήρες παράδειγμα Tag Structure

```yaml
---
# site.yml — με πλήρη tag δομή

- name: Base Server Setup
  hosts: all
  become: true
  gather_facts: true
  tags: base              # ← play tag

  tasks:

    # ── System Update ──────────────────────
    - name: Update (Debian)
      ansible.builtin.apt:
        update_cache: true
        upgrade:      safe
      when: ansible_facts['os_family'] == "Debian"
      tags:
        - update
        - packages

    - name: Update (RedHat)
      ansible.builtin.dnf:
        name:  "*"
        state: latest
      when: ansible_facts['os_family'] == "RedHat"
      tags:
        - update
        - packages

    - name: Update (openSUSE)
      community.general.zypper:
        name:  "*"
        state: latest
      when: ansible_facts['os_family'] == "Suse"
      tags:
        - update
        - packages

    # ── Common Packages ────────────────────
    - name: Install common packages
      tags:
        - packages
        - common
      block:

        - name: Install (Debian)
          ansible.builtin.apt:
            name:  "{{ common_packages }}"
            state: present
          when: ansible_facts['os_family'] == "Debian"

        - name: Install (RedHat)
          ansible.builtin.dnf:
            name:  "{{ common_packages }}"
            state: present
          when: ansible_facts['os_family'] == "RedHat"

        - name: Install (openSUSE)
          community.general.zypper:
            name:  "{{ common_packages }}"
            state: present
          when: ansible_facts['os_family'] == "Suse"

    # ── System Configuration ───────────────
    - name: Configure timezone
      community.general.timezone:
        name: "{{ system_timezone }}"
      tags:
        - config
        - system
        - timezone

    - name: Configure MOTD
      ansible.builtin.template:
        src:  templates/motd.j2
        dest: /etc/motd
      tags:
        - config
        - system
        - motd

    # ── Security ───────────────────────────
    - name: Security block
      tags:
        - security
      block:

        - name: Configure SSH
          ansible.builtin.template:
            src:      templates/sshd_config.j2
            dest:     /etc/ssh/sshd_config
            validate: sshd -t -f %s
          tags: ssh
          notify: Restart SSH

        - name: Configure ferm (Debian)
          ansible.builtin.template:
            src:  templates/ferm.conf.j2
            dest: /etc/ferm/ferm.conf
          when: ansible_facts['os_family'] == "Debian"
          tags:
            - firewall
            - ferm
          notify: Restart ferm

        - name: Configure fail2ban
          ansible.builtin.template:
            src:  templates/fail2ban_jail.j2
            dest: /etc/fail2ban/jail.local
          tags: fail2ban
          notify: Restart fail2ban

    # ── Application ────────────────────────
    - name: Deploy application
      tags:
        - app
        - deploy
      block:

        - name: Create app directories
          ansible.builtin.file:
            path:  "{{ item }}"
            state: directory
            mode:  '0755'
          loop:
            - /opt/myapp
            - /opt/myapp/logs
          tags: directories

        - name: Deploy app config
          ansible.builtin.template:
            src:  templates/app.conf.j2
            dest: /etc/myapp/app.conf
          tags:
            - config
            - app

        - name: Deploy app files
          ansible.builtin.copy:
            src:  files/myapp/
            dest: /opt/myapp/
          tags: deploy

    # ── Monitoring ─────────────────────────
    - name: Setup monitoring
      ansible.builtin.debug:
        msg: "Setting up monitoring..."
      tags:
        - monitoring
        - never          # ← special tag! Δες 14.3

  handlers:

    - name: Restart SSH
      ansible.builtin.service:
        name:  "{{ service_ssh }}"
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"

    - name: Restart ferm
      ansible.builtin.service:
        name:  ferm
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"

    - name: Restart fail2ban
      ansible.builtin.service:
        name:  fail2ban
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"
```

## Σύνοψη 14.2

```
Ορισμός Tags
├── Task level:
│   tags: nginx              ← string
│   tags: [nginx, config]    ← inline list
│   tags:                    ← block list (συνιστάται)
│     - nginx
│     - config
│
├── Play level:
│   → εφαρμόζεται σε ΟΛΑ τα tasks του play
│
├── Block level:
│   → εφαρμόζεται σε ΟΛΑ τα tasks του block
│
├── Import/Include:
│   ├── import_tasks → static  → ✅ για tags
│   └── include_tasks→ dynamic → ⚠️ προσοχή
│
├── Inheritance:
│   play tags + block tags + task tags = όλα κληρονομούνται
│
└── --list-tags → εμφάνιση διαθέσιμων tags
```
