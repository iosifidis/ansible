# 14.3 Εκτέλεση με Tags ▶️

## --tags — Τρέξε συγκεκριμένα Tags

```bash
# ── Ένα tag ───────────────────────────────────
ansible-playbook playbooks/site.yml --tags nginx

# ── Πολλαπλά tags (OR λογική) ─────────────────
ansible-playbook playbooks/site.yml --tags "nginx,config"
# → τρέχει tasks που έχουν nginx ΚΑΙ/Ή config

# ── Με limit ──────────────────────────────────
ansible-playbook playbooks/site.yml \
    --tags nginx \
    --limit nextcloudpi

# ── Με extra vars ─────────────────────────────
ansible-playbook playbooks/site.yml \
    --tags deploy \
    -e "app_version=2.1.4"

# ── Verbose ───────────────────────────────────
ansible-playbook playbooks/site.yml \
    --tags config \
    -v
```

---

## --skip-tags — Παράλειψε συγκεκριμένα Tags

```bash
# ── Skip ένα tag ──────────────────────────────
ansible-playbook playbooks/site.yml \
    --skip-tags monitoring

# ── Skip πολλαπλά tags ────────────────────────
ansible-playbook playbooks/site.yml \
    --skip-tags "update,monitoring"

# ── Συνδυασμός tags + skip-tags ───────────────
ansible-playbook playbooks/site.yml \
    --tags security \
    --skip-tags fail2ban
# → τρέχει security tasks, ΧΩΡΙΣ fail2ban
```

## Special Tags

Η Ansible έχει **4 ειδικά tags** με ξεχωριστή συμπεριφορά:

### always — Τρέχει πάντα
```yaml
tasks:

  - name: Gather facts
    ansible.builtin.setup:
    tags: always    # ← τρέχει ΠΑΝΤΑ, ακόμα κι αν --tags άλλο

  - name: Final report
    ansible.builtin.debug:
      msg: "Deployment complete!"
    tags:
      - always      # ← ακόμα κι αν --skip-tags αυτό δεν παραλείπεται!
      - report
```

```bash
# Ακόμα κι αν τρέξεις:
ansible-playbook site.yml --tags nginx
# → τα tasks με tag "always" ΠΑΝΤΑ εκτελούνται!
```

### never — Ποτέ δεν τρέχει
```yaml
tasks:

  - name: Reset database (ΕΠΙΚΙΝΔΥΝΟ!)
    ansible.builtin.command:
      cmd: psql -c "DROP DATABASE myapp;"
    tags: never     # ← ΔΕΝ τρέχει ποτέ από μόνο του

  - name: Debug verbose info
    ansible.builtin.debug:
      var: hostvars[inventory_hostname]
    tags:
      - never       # ← default: δεν τρέχει
      - debug       # ← τρέχει ΜΟΝΟ αν --tags debug
```

```bash
# Κανονική εκτέλεση → never tasks παραλείπονται
ansible-playbook site.yml

# Εκπληκτική εκτέλεση → ΜΟΝΟ με explicit tag
ansible-playbook site.yml --tags debug
ansible-playbook site.yml --tags never
```

> 💡 **Γιατί never:**
> ```
> ✅ Επικίνδυνες εργασίες (drop db, format disk)
> ✅ Debug tasks (verbose output)
> ✅ One-time setup (μόνο την πρώτη φορά)
> ✅ Manual tasks (τρέχουν μόνο αν το ζητήσεις)
> ```

### tagged — Μόνο Tasks με Tags
```bash
# Τρέξε ΜΟΝΟ tasks που έχουν κάποιο tag
ansible-playbook site.yml --tags tagged
# → παραλείπει tasks χωρίς tags
```

### untagged — Μόνο Tasks χωρίς Tags
```bash
# Τρέξε ΜΟΝΟ tasks που ΔΕΝ έχουν tag
ansible-playbook site.yml --tags untagged
# → παραλείπει tasks με tags
```

## Λογική Εκτέλεσης

```
┌─────────────────────────────────────────────────────────┐
│  --tags tag1,tag2                                       │
│  → OR λογική: task με tag1 ΚΑΙ/Ή tag2                   │
│  → NΑΙ σε: [tag1], [tag2], [tag1,tag2]                  │
│  → ΟΧΙ σε: [tag3], [tag4]                               │
├─────────────────────────────────────────────────────────┤
│  --skip-tags tag1,tag2                                  │
│  → OR λογική: παράλειψε αν έχει tag1 ΚΑΙ/Ή tag2         │
│  → ΟΧΙ σε: [tag1], [tag2], [tag1,tag2]                  │
│  → ΝΑΙ σε: [tag3], [tag4]                               │
├─────────────────────────────────────────────────────────┤
│  --tags tag1 --skip-tags tag2                           │
│  → τρέχει tag1 tasks, ΕΚΤΟΣ αν έχουν tag2               │
└─────────────────────────────────────────────────────────┘
```

## --list-tasks με Tags

```bash
# Δες ποια tasks θα τρέξουν με συγκεκριμένο tag
ansible-playbook playbooks/site.yml \
    --tags nginx \
    --list-tasks

# Output:
# playbook: playbooks/site.yml
#
#   play #1 (all): Base Server Setup
#     tasks:
#       Install nginx    TAGS: [base, nginx, packages]
#       Configure nginx  TAGS: [base, nginx, config]
#       Start nginx      TAGS: [base, nginx]
```

## Πρακτικά σενάρια

```bash
# ── Σενάριο 1: Μόνο security updates ─────────
ansible-playbook playbooks/site.yml \
    --tags security \
    --limit nextcloudpi

# ── Σενάριο 2: Deploy χωρίς system updates ───
ansible-playbook playbooks/site.yml \
    --skip-tags update \
    --tags deploy

# ── Σενάριο 3: Μόνο config changes ───────────
ansible-playbook playbooks/site.yml \
    --tags config

# ── Σενάριο 4: Όλα εκτός monitoring ──────────
ansible-playbook playbooks/site.yml \
    --skip-tags monitoring

# ── Σενάριο 5: Debug mode ─────────────────────
ansible-playbook playbooks/site.yml \
    --tags "always,debug"

# ── Σενάριο 6: Emergency reset (never tag) ────
ansible-playbook playbooks/site.yml \
    --tags never \
    --limit nextcloudpi
# ⚠️ ΠΡΟΣΟΧΗ — τρέχει επικίνδυνες εργασίες!

# ── Σενάριο 7: CI/CD pipeline ────────────────
# Stage 1: packages
ansible-playbook playbooks/site.yml --tags packages
# Stage 2: config
ansible-playbook playbooks/site.yml --tags config
# Stage 3: deploy
ansible-playbook playbooks/site.yml --tags deploy
# Stage 4: verify
ansible-playbook playbooks/site.yml --tags verify
```

## Tags με ansible-playbook --check

```bash
# Dry run μόνο για config tasks
ansible-playbook playbooks/site.yml \
    --tags config \
    --check --diff \
    --limit nextcloudpi

# → Βλέπεις τι θα αλλάξει στα config αρχεία
# → Χωρίς να κάνεις install ή deploy
```

## Σύνοψη 14.3

```
Εκτέλεση με Tags
├── --tags tag1,tag2    → OR: τρέξε αν έχει tag1 ή tag2
├── --skip-tags tag1    → παράλειψε αν έχει tag1
│
├── Special Tags:
│   ├── always   → τρέχει ΠΑΝΤΑ (ακόμα κι αν skip)
│   ├── never    → τρέχει ΜΟΝΟ αν explicit --tags never
│   ├── tagged   → μόνο tasks ΜΕ tags
│   └── untagged → μόνο tasks ΧΩΡΙΣ tags
│
├── --list-tasks --tags → δες τι θα τρέξει
│
└── Συνδυασμοί:
    ├── --tags + --limit       → tasks + servers
    ├── --tags + --skip-tags   → fine-grained control
    └── --tags + --check --diff→ safe preview
```
