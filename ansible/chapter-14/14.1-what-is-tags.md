# 14.1 Τι είναι τα Tags 🏷️

## Ο ορισμός

Τα **Tags** είναι **ετικέτες** που προσθέτεις σε tasks, plays ή blocks για να μπορείς να **εκτελείς επιλεκτικά** μέρη του playbook σου.

> 📝 **Αναλογία:** Σκέψου τα tags σαν **χαρτάκια Post-it** σε ένα βιβλίο:
> ```
> Playbook = βιβλίο με πολλές σελίδες
> Tags     = χαρτάκια που σημαδεύουν συγκεκριμένες σελίδες
>
> Χωρίς tags → διαβάζεις ΟΛΟ το βιβλίο κάθε φορά
> Με tags    → ανοίγεις μόνο τις σελίδες που θέλεις ✅
> ```

---

## Γιατί χρειάζονται τα Tags;

```yaml
# Φαντάσου ένα μεγάλο playbook:
tasks:
  - name: Update apt cache          # ← 5 δευτερόλεπτα
  - name: Install packages          # ← 30 δευτερόλεπτα
  - name: Configure nginx           # ← 2 δευτερόλεπτα
  - name: Configure PHP             # ← 2 δευτερόλεπτα
  - name: Configure database        # ← 2 δευτερόλεπτα
  - name: Deploy application        # ← 10 δευτερόλεπτα
  - name: Configure SSL             # ← 5 δευτερόλεπτα
  - name: Setup monitoring          # ← 10 δευτερόλεπτα
  # Σύνολο: ~66 δευτερόλεπτα

# Αν θέλεις να αλλάξεις ΜΟΝΟ την εφαρμογή:
# Χωρίς tags → τρέχεις ΟΛΑ (66 δευτερόλεπτα) ❌
# Με tags    → τρέχεις μόνο deploy (10 δευτερόλεπτα) ✅
```

---

## Βασική χρήση

### Ορισμός tag:
```yaml
tasks:
  - name: Install nginx
    ansible.builtin.package:
      name:  nginx
      state: present
    tags:
      - install
      - nginx
      - packages
```

### Εκτέλεση με tag:
```bash
# Τρέξε μόνο tasks με tag "nginx"
ansible-playbook playbooks/site.yml --tags nginx

# Τρέξε μόνο tasks με tag "packages"
ansible-playbook playbooks/site.yml --tags packages

# Παράλειψε tasks με tag "install"
ansible-playbook playbooks/site.yml --skip-tags install
```

---

## Τι κάνουν τα Tags στην πράξη

```
Playbook με 8 tasks:
┌─────────────────────────────────────────────────┐
│ Task 1: Update cache    [packages, update]      │
│ Task 2: Install nginx   [packages, nginx]       │
│ Task 3: Configure nginx [config, nginx]         │
│ Task 4: Install PHP     [packages, php]         │
│ Task 5: Configure PHP   [config, php]           │
│ Task 6: Deploy app      [deploy, app]           │
│ Task 7: Configure SSL   [config, ssl]           │
│ Task 8: Setup monitoring[monitoring]            │
└─────────────────────────────────────────────────┘

ansible-playbook site.yml --tags nginx
→ Εκτελεί: Task 2, Task 3

ansible-playbook site.yml --tags packages
→ Εκτελεί: Task 1, Task 2, Task 4

ansible-playbook site.yml --tags config
→ Εκτελεί: Task 3, Task 5, Task 7

ansible-playbook site.yml --skip-tags monitoring
→ Εκτελεί: Task 1-7 (παραλείπει Task 8)
```

## Tags vs Limit — Η διαφορά

```bash
# --limit → επιλογή SERVERS
ansible-playbook site.yml --limit nextcloud
# → τρέχει ΟΛΑ τα tasks, μόνο στο nextcloud

# --tags → επιλογή TASKS
ansible-playbook site.yml --tags nginx
# → τρέχει ΜΟΝΟ τα nginx tasks, σε ΟΛΟΥΣ τους servers

# Συνδυασμός!
ansible-playbook site.yml \
    --limit nextcloud \
    --tags nginx
# → τρέχει nginx tasks, μόνο στο nextcloud ✅
```

## Πότε χρησιμοποιούμε Tags

```
✅ Χρησιμοποίησε tags για:
├── Επιλεκτικό deployment (μόνο app, μόνο config)
├── Ταχύτερη ανάπτυξη (skip βαριά tasks)
├── Debugging (τρέξε μόνο ένα task)
├── Rollback (τρέξε μόνο restore tasks)
└── CI/CD pipelines (διαφορετικά stages)

❌ ΜΗΝ χρησιμοποιείς tags:
├── Σαν υποκατάστατο καλής οργάνωσης playbook
├── Για να κρύψεις πολύπλοκη λογική
└── Αν το playbook έχει 2-3 tasks (δεν αξίζει)
```

## Σύνοψη 14.1

```
Tags
├── Ετικέτες σε tasks/plays/blocks
├── Επιτρέπουν επιλεκτική εκτέλεση
├── Χρήση:
│   ├── --tags tag_name    → τρέξε μόνο αυτά
│   └── --skip-tags name   → παράλειψε αυτά
├── Tags vs Limit:
│   ├── --limit → επιλογή servers
│   └── --tags  → επιλογή tasks
└── Πότε: μεγάλα playbooks, CI/CD, debugging
```
