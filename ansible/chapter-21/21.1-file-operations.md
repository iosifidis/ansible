# 21.1 File Operations 📁

## copy — Αντιγραφή αρχείων

```yaml
tasks:

  # ── Αρχείο από controller ─────────────────
  - name: Copy config file
    ansible.builtin.copy:
      src:   files/nginx/nginx.conf   # ← τοπικό αρχείο
      dest:  /etc/nginx/nginx.conf
      owner: root
      group: root
      mode:  '0644'
      backup: true    # ← κρατά backup του παλιού

  # ── Inline content ────────────────────────
  - name: Create file with content
    ansible.builtin.copy:
      dest:    /etc/myapp/app.conf
      content: |
        [app]
        port = {{ app_port }}
        env  = {{ app_env }}
      mode:    '0640'
      owner:   myapp

  # ── Remote to remote ──────────────────────
  - name: Copy on remote host
    ansible.builtin.copy:
      src:        /opt/myapp/config.bak
      dest:       /opt/myapp/config.conf
      remote_src: true    # ← αντιγραφή στον ίδιο host
```

## fetch — Λήψη αρχείων από managed host

```yaml
tasks:

  # ── Λήψη log ──────────────────────────────
  - name: Fetch error log
    ansible.builtin.fetch:
      src:  /var/log/nginx/error.log
      dest: "logs/{{ inventory_hostname }}/nginx-error.log"
      flat: true    # ← χωρίς υποφάκελο host

  # ── Λήψη config για audit ─────────────────
  - name: Fetch SSH config
    ansible.builtin.fetch:
      src:  /etc/ssh/sshd_config
      dest: "audit/{{ inventory_hostname }}/sshd_config"
      flat: true

  # ── Λήψη από πολλούς hosts ────────────────
  # (τρέχει αυτόματα για κάθε host του play)
  # → logs/host-01/nginx-error.log
  # → logs/host-02/nginx-error.log
```

## synchronize — rsync wrapper

```yaml
tasks:

  # ── Push: controller → host ───────────────
  - name: Sync app files
    ansible.posix.synchronize:
      src:    /opt/myapp/          # ← local
      dest:   /opt/myapp/          # ← remote
      delete: true                 # ← διέγραψε ό,τι δεν υπάρχει τοπικά
      rsync_opts:
        - "--exclude=*.pyc"
        - "--exclude=__pycache__"
        - "--exclude=.git"
        - "--exclude=node_modules"

  # ── Pull: host → controller ───────────────
  - name: Pull backups
    ansible.posix.synchronize:
      src:    /var/backups/    # ← remote (source)
      dest:   backups/         # ← local
      mode:   pull             # ← αντίστροφη κατεύθυνση
```

## archive & unarchive

```yaml
tasks:

  # ── Δημιουργία archive ────────────────────
  - name: Archive app directory
    ansible.builtin.archive:
      path:   /opt/myapp/
      dest:   /tmp/myapp-backup.tar.gz
      format: gz
      exclude_path:
        - /opt/myapp/logs
        - /opt/myapp/.git

  # ── Εξαγωγή archive ──────────────────────
  - name: Unarchive release
    ansible.builtin.unarchive:
      src:  "files/myapp-{{ app_version }}.tar.gz"  # ← τοπικό
      dest: /opt/myapp/
      owner: myapp
      group: myapp
      extra_opts: [--strip-components=1]

  # ── Unarchive από URL ─────────────────────
  - name: Download and extract
    ansible.builtin.unarchive:
      src:        "https://github.com/nginx/nginx/archive/v1.25.0.tar.gz"
      dest:       /opt/nginx-src/
      remote_src: true    # ← download στον host (όχι controller)
```

## Σύνοψη 21.1

```
File Operations
│
├── copy:   τοπικό → host (ή inline content)
├── fetch:  host → τοπικό (logs, audit)
├── synchronize: rsync (push/pull)
└── archive/unarchive: tar.gz operations
```
