# 21.4 System Administration ⚙️

## cron — Cronjobs

```yaml
tasks:

  # ── Απλό cronjob ─────────────────────────
  - name: Daily backup
    ansible.builtin.cron:
      name:   "Daily backup"    # ← μοναδικό όνομα (idempotent key)
      minute: "0"
      hour:   "2"
      job:    "/opt/backup/backup.sh >> /var/log/backup.log 2>&1"
      user:   root

  # ── Πολλά cronjobs με loop ────────────────
  - name: Scheduled tasks
    ansible.builtin.cron:
      name:    "{{ item.name }}"
      minute:  "{{ item.minute }}"
      hour:    "{{ item.hour }}"
      weekday: "{{ item.weekday | default('*') }}"
      job:     "{{ item.job }}"
    loop:
      - name:   "Daily cleanup"
        minute: "0"
        hour:   "3"
        job:    "/opt/scripts/cleanup.sh"
      - name:   "Weekly report"
        minute: "0"
        hour:   "9"
        weekday: "1"    # ← Δευτέρα
        job:    "/opt/scripts/weekly-report.sh"
      - name:   "Hourly health check"
        minute: "*/5"   # ← κάθε 5 λεπτά
        hour:   "*"
        job:    "/opt/scripts/healthcheck.sh"

  # ── Αφαίρεση cronjob ─────────────────────
  - name: Remove old cronjob
    ansible.builtin.cron:
      name:  "Old task"
      state: absent
```

## sysctl — Kernel parameters

```yaml
tasks:

  # ── Single parameter ─────────────────────
  - name: Enable IP forwarding
    ansible.posix.sysctl:
      name:    net.ipv4.ip_forward
      value:   "1"
      state:   present
      reload:  true    # ← εφαρμόζει αμέσως

  # ── Multiple kernel parameters ───────────
  - name: System performance tuning
    ansible.posix.sysctl:
      name:   "{{ item.name }}"
      value:  "{{ item.value }}"
      state:  present
      reload: true
    loop:
      # ── Network ──
      - { name: "net.core.somaxconn",              value: "65535" }
      - { name: "net.ipv4.tcp_max_syn_backlog",    value: "65535" }
      - { name: "net.ipv4.tcp_fin_timeout",        value: "30"    }
      # ── Memory ──
      - { name: "vm.swappiness",                   value: "10"    }
      - { name: "vm.dirty_ratio",                  value: "15"    }
      # ── File descriptors ──
      - { name: "fs.file-max",                     value: "2097152" }
```

## mount — Filesystem mounts

```yaml
tasks:

  # ── NFS mount ────────────────────────────
  - name: Mount NFS share
    ansible.posix.mount:
      src:    "192.168.1.5:/exports/data"
      path:   /mnt/nas
      fstype: nfs
      opts:   "rw,nfsvers=4,hard,intr"
      state:  mounted    # ← mount + /etc/fstab

  # ── tmpfs ────────────────────────────────
  - name: tmpfs για sessions
    ansible.posix.mount:
      src:    tmpfs
      path:   /tmp/sessions
      fstype: tmpfs
      opts:   "size=512m,mode=0777"
      state:  mounted

  # ── Unmount ──────────────────────────────
  - name: Unmount και αφαίρεση από fstab
    ansible.posix.mount:
      path:  /mnt/old
      state: absent
```

## Σύνοψη 21.4

```
System Administration
│
├── cron: → Scheduled tasks
│   ├── name (unique), minute, hour, job
│   └── state: absent → αφαίρεση
│
├── sysctl: → Kernel parameters
│   ├── reload: true → άμεση εφαρμογή
│   └── Χρήση: network tuning, security
│
└── mount: → Filesystem mounts
    ├── state: mounted  → mount + fstab
    ├── state: unmounted → unmount μόνο
    └── state: absent   → unmount + fstab
```
