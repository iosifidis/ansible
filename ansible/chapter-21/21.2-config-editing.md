# 21.2 Config Editing ✏️

## lineinfile — Διαχείριση γραμμών

Το `lineinfile` εξασφαλίζει ότι μια **συγκεκριμένη γραμμή** υπάρχει (ή δεν υπάρχει) σε ένα αρχείο:

```yaml
tasks:

  # ── Προσθήκη γραμμής (αν δεν υπάρχει) ────
  - name: Enable IP forwarding
    ansible.builtin.lineinfile:
      path:   /etc/sysctl.conf
      line:   "net.ipv4.ip_forward = 1"
      state:  present

  # ── Αντικατάσταση με regexp ───────────────
  - name: Set max connections
    ansible.builtin.lineinfile:
      path:   /etc/nginx/nginx.conf
      regexp: "^worker_connections"
      line:   "worker_connections 1024;"
      # ← βρίσκει την γραμμή με regexp → αντικαθιστά με line

  # ── Αφαίρεση γραμμής ─────────────────────
  - name: Remove old setting
    ansible.builtin.lineinfile:
      path:  /etc/ssh/sshd_config
      regexp: "^PermitRootLogin yes"
      state:  absent

  # ── Hardening SSH ─────────────────────────
  - name: Harden SSH config
    ansible.builtin.lineinfile:
      path:        /etc/ssh/sshd_config
      regexp:      "{{ item.regexp }}"
      line:        "{{ item.line }}"
      state:       present
      backup:      true
    loop:
      - { regexp: "^#?PermitRootLogin",    line: "PermitRootLogin no"              }
      - { regexp: "^#?PasswordAuthentication", line: "PasswordAuthentication no"   }
      - { regexp: "^#?X11Forwarding",      line: "X11Forwarding no"               }
      - { regexp: "^#?MaxAuthTries",        line: "MaxAuthTries 3"                 }
    notify: Restart sshd
```

## blockinfile — Διαχείριση blocks

Το `blockinfile` εισάγει **ολόκληρο block** κειμένου:

```yaml
tasks:

  # ── Εισαγωγή block ───────────────────────
  - name: Add nginx server block
    ansible.builtin.blockinfile:
      path:   /etc/nginx/nginx.conf
      marker: "# {mark} ANSIBLE MANAGED — myapp"
      #         ↑ BEGIN/END markers (idempotent!)
      block:  |
        server {
            listen 80;
            server_name {{ app_domain }};
            return 301 https://$host$request_uri;
        }
      insertafter: "http {"

  # ── Ενημέρωση /etc/hosts ──────────────────
  - name: Update /etc/hosts
    ansible.builtin.blockinfile:
      path:   /etc/hosts
      marker: "# {mark} ANSIBLE MANAGED — cluster"
      block: |
        192.168.1.10  nextcloud nextcloud.local
        192.168.1.20  db-01     db-01.local

  # ── Αφαίρεση block ─────────────────────────
  - name: Remove block
    ansible.builtin.blockinfile:
      path:   /etc/nginx/nginx.conf
      marker: "# {mark} ANSIBLE MANAGED — old-app"
      state:  absent
```

> 💡 **Πώς λειτουργεί το marker:**
> ```
> # BEGIN ANSIBLE MANAGED — myapp
> server {
>     listen 80;
>     ...
> }
> # END ANSIBLE MANAGED — myapp
> ```
> Κάθε re-run αντικαθιστά το block μεταξύ `BEGIN` και `END`. Idempotent ✅

## replace — Αντικατάσταση text

```yaml
tasks:

  # ── Αντικατάσταση string ─────────────────
  - name: Update database host
    ansible.builtin.replace:
      path:    /etc/myapp/config.conf
      regexp:  'db_host\s*=\s*.*'
      replace: "db_host = {{ db_host }}"

  # ── Αντικατάσταση με backup ──────────────
  - name: Update version string
    ansible.builtin.replace:
      path:   /opt/myapp/VERSION
      regexp: "^version:.*$"
      replace: "version: {{ app_version }}"
      backup: true
```

## Σύνοψη 21.2

```
Config Editing
│
├── lineinfile:
│   ├── Μια γραμμή τη φορά
│   ├── regexp → βρίσκει, line → αντικαθιστά
│   └── Χρήση: sysctl, SSH config, single params
│
├── blockinfile:
│   ├── Ολόκληρο block κειμένου
│   ├── marker: idempotent {mark} pattern
│   └── Χρήση: nginx server blocks, /etc/hosts
│
└── replace:
    ├── Regex αντικατάσταση
    └── Χρήση: update values in config files
```
