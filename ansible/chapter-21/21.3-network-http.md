# 21.3 Network & HTTP 🌐

## uri — HTTP requests

```yaml
tasks:

  # ── GET request ───────────────────────────
  - name: Health check
    ansible.builtin.uri:
      url:         "http://localhost:8080/health"
      status_code: 200
    register:  health
    retries:   5
    delay:     3
    until:     health.status == 200

  # ── POST με JSON ──────────────────────────
  - name: API call
    ansible.builtin.uri:
      url:         "https://api.example.com/deploy"
      method:      POST
      body_format: json
      body:
        version:    "{{ app_version }}"
        host:       "{{ inventory_hostname }}"
        timestamp:  "{{ ansible_date_time.iso8601 }}"
      headers:
        Authorization: "Bearer {{ vault_api_token }}"
        Content-Type:  "application/json"
      status_code: [200, 201, 202]
      return_content: true
    register:  api_response
    no_log:    true

  - name: API response
    ansible.builtin.debug:
      msg: "Response: {{ api_response.json }}"

  # ── Download αρχείο ───────────────────────
  - name: Download file
    ansible.builtin.uri:
      url:  "https://example.com/data.json"
      dest: /tmp/data.json
      mode: '0644'

  # ── HTTPS με client cert ──────────────────
  - name: Mutual TLS
    ansible.builtin.uri:
      url:          "https://secure.api.example.com/status"
      client_cert:  /etc/ssl/client.crt
      client_key:   /etc/ssl/client.key
      validate_certs: true
```

## get_url — Λήψη αρχείων

```yaml
tasks:

  # ── Download με checksum ─────────────────
  - name: Download release
    ansible.builtin.get_url:
      url:      "https://github.com/nginx/nginx/archive/v1.25.0.tar.gz"
      dest:     /tmp/nginx-1.25.0.tar.gz
      checksum: "sha256:abc123..."
      mode:     '0644'

  # ── Download GPG key ──────────────────────
  - name: Download signing key
    ansible.builtin.get_url:
      url:  "https://nginx.org/keys/nginx_signing.key"
      dest: /etc/apt/keyrings/nginx.gpg
      mode: '0644'
```

## wait_for — Αναμονή συνθηκών

```yaml
tasks:

  # ── Αναμονή για port ──────────────────────
  - name: Wait for nginx to start
    ansible.builtin.wait_for:
      port:    80
      timeout: 30
      state:   started    # ← ή: stopped, absent, drained

  # ── Αναμονή για αρχείο ───────────────────
  - name: Wait for lock file release
    ansible.builtin.wait_for:
      path:    /var/lock/apt/lock
      state:   absent     # ← αναμένει να εξαφανιστεί
      timeout: 120

  # ── Αναμονή για connection ───────────────
  - name: Wait after reboot
    ansible.builtin.wait_for_connection:
      delay:   5      # ← περίμενε 5s πριν αρχίσεις
      timeout: 120    # ← max αναμονή

  # ── TCP socket ───────────────────────────
  - name: Wait for DB
    ansible.builtin.wait_for:
      host:    "{{ db_host }}"
      port:    5432
      timeout: 60
      state:   started
```
