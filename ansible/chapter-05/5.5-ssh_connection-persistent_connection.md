# 5.5 Sections [ssh_connection] & [persistent_connection] 🔌

## Γιατί είναι σημαντά αυτά τα Sections;

Η Ansible επικοινωνεί με τους servers **κυρίως μέσω SSH**. Οι ρυθμίσεις αυτές καθορίζουν **πώς** γίνεται αυτή η επικοινωνία — και μπορούν να κάνουν τεράστια διαφορά στην **ταχύτητα** και **αξιοπιστία**.

---

## [ssh_connection] — Οι ρυθμίσεις

### Ομάδα 1: Pipelining

```ini
[ssh_connection]

# Pipelining → η πιο σημαντική ρύθμιση απόδοσης!
# Default: False
# True → στέλνει πολλές εντολές σε μία SSH σύνδεση
#        αντί να ανοίγει νέα σύνδεση για κάθε task
pipelining = True
```

> 💡 **Τι κάνει το Pipelining:**
> ```
> Χωρίς pipelining (default):
> Task 1 → [ανοίγει SSH] → εκτελεί → [κλείνει SSH]
> Task 2 → [ανοίγει SSH] → εκτελεί → [κλείνει SSH]
> Task 3 → [ανοίγει SSH] → εκτελεί → [κλείνει SSH]
> Αργό! ❌
>
> Με pipelining:
> [ανοίγει SSH μία φορά]
> Task 1 → εκτελεί
> Task 2 → εκτελεί
> Task 3 → εκτελεί
> [κλείνει SSH]
> Γρήγορο! ✅ (έως 10x ταχύτερο!)
> ```

> ⚠️ **Προϋπόθεση για Pipelining:**
> Πρέπει να απενεργοποιήσεις το `requiretty` στο sudoers των managed servers:
```bash
# Στον managed server
sudo visudo
# Βρες και σχολίασε αυτή τη γραμμή (αν υπάρχει):
# Defaults requiretty
# Ή πρόσθεσε:
Defaults !requiretty
```

### Ομάδα 2: SSH Connection Settings

```ini
[ssh_connection]

# Timeout σύνδεσης SSH σε δευτερόλεπτα
# Default: 10
connect_timeout = 30

# Αριθμός προσπαθειών σύνδεσης
# Default: 3
retries = 3

# Extra SSH arguments
# Χρήσιμο για προσθήκη custom SSH options
ssh_args = -C -o ControlMaster=auto -o ControlPersist=60s
#           │              │                   │
#           │              │                   └── Κράτα σύνδεση 60s
#           │              └────────────────────── Reuse connections
#           └───────────────────────────────────── Compression
```

> 📝 **Τι κάνουν τα SSH args:**
> ```
> -C                    → Συμπίεση δεδομένων (χρήσιμο σε αργές συνδέσεις)
> ControlMaster=auto    → Επαναχρησιμοποίηση SSH connections
> ControlPersist=60s    → Κράτα την σύνδεση ανοιχτή 60 δευτερόλεπτα
>                         μετά την ολοκλήρωση (για επόμενες συνδέσεις)
> ```

### Ομάδα 3: Transfer & Execution

```ini
[ssh_connection]

# Μέθοδος μεταφοράς αρχείων
# Default: smart (επιλέγει αυτόματα)
# Επιλογές: smart, sftp, scp, piped
transfer_method = smart

# Χρήση SCP αντί για SFTP
# Default: False (χρησιμοποιεί SFTP)
# True → χρήσιμο αν ο server δεν υποστηρίζει SFTP
scp_if_ssh = smart

# Control path για ControlMaster
# Default: αυτόματο
control_path_dir = ~/.ansible/cp
control_path = %(directory)s/%%h-%%r
```

---

### Ομάδα 4: Host Key Checking

```ini
[ssh_connection]

# Extra SSH args για απενεργοποίηση host key checking
# (εναλλακτικά του host_key_checking στο [defaults])
ssh_args = -o StrictHostKeyChecking=no
```

## Πλήρες παράδειγμα [ssh_connection]

```ini
[ssh_connection]
# ── Performance ───────────────────────────────
pipelining      = True

# ── Connection ────────────────────────────────
connect_timeout = 30
retries         = 3

# ── SSH Arguments ─────────────────────────────
ssh_args        = -C -o ControlMaster=auto -o ControlPersist=60s

# ── Transfer ──────────────────────────────────
transfer_method = smart
```

## [persistent_connection] — Για Network Devices

Αυτή η section αφορά κυρίως **network devices** (routers, switches κλπ) που δεν χρησιμοποιούν κανονικό SSH:

```ini
[persistent_connection]

# Timeout για persistent connections
# Default: 30
connect_timeout = 30

# Timeout για εντολές
# Default: 10
command_timeout = 30

# Timeout για την ίδια τη σύνδεση
# Default: 0 (δεν λήγει ποτέ)
connect_retry_timeout = 15
```

> 📝 **Σημείωση για τον Μαθητή:** Αν δεν διαχειρίζεσαι network devices (Cisco, Juniper κλπ), **δεν χρειάζεσαι** το `[persistent_connection]`. Το αναφέρουμε για πληρότητα.

## Βέλτιστες ρυθμίσεις για Performance

```ini
[defaults]
# Παράλληλες εκτελέσεις
forks = 20

[ssh_connection]
# Pipelining για ταχύτητα
pipelining = True

# SSH connection reuse
ssh_args = -C -o ControlMaster=auto -o ControlPersist=60s

# Retry σε αποτυχία
retries = 3

# Timeout
connect_timeout = 30
```

## Σύνοψη 5.5

```
[ssh_connection]
├── pipelining      → ταχύτητα (έως 10x) ✅
├── connect_timeout → χρόνος αναμονής σύνδεσης
├── retries         → επαναπροσπάθειες σε αποτυχία
├── ssh_args        → ControlMaster, ControlPersist, Compression
└── transfer_method → sftp/scp/smart για αρχεία

[persistent_connection]
└── Μόνο για network devices (routers, switches)
    ├── connect_timeout
    └── command_timeout
```
