# 5.3 Section [defaults] ⚙️

## Το πιο σημαντικό Section

Το `[defaults]` περιέχει τις **πιο συχνά χρησιμοποιούμενες ρυθμίσεις**. Θα τις αναλύσουμε **ομαδοποιημένες** κατά λειτουργία.

---

## Ομάδα 1: Inventory & Hosts

```ini
[defaults]

# Πού βρίσκεται το inventory
# Default: /etc/ansible/hosts
inventory = ./inventory/hosts.ini

# Απενεργοποίηση ελέγχου SSH host key
# Default: True
# ⚠️ Για production: True (ασφάλεια!)
# ✅ Για εκμάθηση:   False (βολικό)
host_key_checking = False

# Πόσοι servers εκτελούνται παράλληλα
# Default: 5
# ↑ forks = γρηγορότερο αλλά περισσότερο φορτίο
forks = 10
```

> ⚠️ **Για το `host_key_checking`:**
> ```
> host_key_checking = True  (production)
> → Η Ansible επαληθεύει το SSH fingerprint κάθε server
> → Προστατεύει από Man-in-the-Middle επιθέσεις
> → Ζητάει επιβεβαίωση για νέους servers
>
> host_key_checking = False (εκμάθηση/testing)
> → Δεν ελέγχει fingerprints
> → Βολικό για lab περιβάλλοντα
> → ΠΟΤΕ σε production!
> ```

## Ομάδα 2: Remote Connection

```ini
[defaults]

# Ο χρήστης με τον οποίο συνδέεται η Ansible
# Default: το τρέχον username του συστήματος
remote_user = ansible

# Το SSH private key για τη σύνδεση
# Default: ~/.ssh/id_rsa
private_key_file = /home/ansible/.ssh/id_ed25519

# Timeout σύνδεσης σε δευτερόλεπτα
# Default: 10
timeout = 30

# Port σύνδεσης
# Default: 22
# (συνήθως ορίζεται στο inventory ανά host)
remote_port = 22
```

---

## Ομάδα 3: Python Interpreter

```ini
[defaults]

# Πώς η Ansible βρίσκει την Python στους remote servers
# Επιλογές:
#   auto         → ψάχνει αυτόματα (με warning)
#   auto_silent  → ψάχνει αυτόματα (χωρίς warning) ✅
#   auto_legacy  → παλιά συμπεριφορά
#   /usr/bin/python3 → συγκεκριμένο path
interpreter_python = auto_silent
```

> 📝 **Γιατί `auto_silent`:**
> Στο Κεφάλαιο 3 είδαμε αυτό το warning:
> ```
> [WARNING]: Host 'nextcloud' is using the discovered
> Python interpreter at '/usr/bin/python3.11'...
> ```
> Το `auto_silent` το εξαλείφει — η Ansible βρίσκει αυτόματα την Python **χωρίς** να παραπονιέται.

## Ομάδα 4: Output & Logging

```ini
[defaults]

# Πώς εμφανίζεται το output
# Επιλογές: default, yaml, json, minimal, oneline
stdout_callback = default

# Μορφή αποτελεσμάτων (για default callback)
# Επιλογές: yaml, json
result_format = yaml

# Αρχείο καταγραφής (logging)
# Default: κενό (δεν καταγράφει)
log_path = /home/ansible/ansible/ansible.log

# Εμφάνιση χρόνου εκτέλεσης ανά task
# Default: False
# (χρειάζεται callback plugin)
callbacks_enabled = timer, profile_tasks
```

### Σύγκριση stdout_callback:

```bash
# default (με result_format=yaml) → ευανάγνωστο ✅
TASK [Install nginx] ***********
changed: [server01] => 
  cache_update_time: 1234567890
  changed: true

# minimal → ελάχιστο output
changed: server01

# json → για machine processing
{"changed": true, "host": "server01"...}

# oneline → μία γραμμή ανά task
server01 | CHANGED => {...}
```

## Ομάδα 5: Warnings & Deprecations

```ini
[defaults]

# Απενεργοποίηση deprecation warnings
# Default: True (εμφανίζει warnings)
deprecation_warnings = False

# Απενεργοποίηση warnings για command/shell modules
# Default: True
command_warnings = False

# Απενεργοποίηση system warnings
# Default: True
system_warnings = False

# Έλεγχος για νέες εκδόσεις Ansible
# Default: True (μπορεί να αργεί)
# ✅ False για ταχύτερη εκτέλεση
network_cli_ssh_type = libssh
```

## Ομάδα 6: Roles & Collections

```ini
[defaults]

# Πού ψάχνει η Ansible για roles
# Default: ./roles:/etc/ansible/roles
roles_path = ./roles:~/.ansible/roles

# Πού ψάχνει η Ansible για collections
# Default: ~/.ansible/collections:/usr/share/ansible/collections
collections_path = ./collections:~/.ansible/collections

# Αυτόματη εγκατάσταση dependencies
# Default: False
# ⚠️ Προσοχή: μπορεί να κατεβάσει κώδικα αυτόματα
```

## Ομάδα 7: Facts & Cache

```ini
[defaults]

# Συλλογή facts στην αρχή κάθε play
# Default: True
# False → ταχύτερη εκτέλεση αν δεν χρειάζεσαι facts
gather_facts = True

# Subset facts που συλλέγουμε
# Default: all
# Επιλογές: all, min, hardware, network, virtual, facter, ohai
gather_subset = min    # ← ταχύτερο! μόνο τα βασικά

# Cache για facts (αποφεύγει επανάληψη)
# Default: memory (χάνεται μετά την εκτέλεση)
fact_caching = memory

# Για persistent cache (αποθηκεύεται σε αρχείο)
# fact_caching = jsonfile
# fact_caching_connection = /tmp/ansible_facts_cache
# fact_caching_timeout = 3600   ← 1 ώρα σε δευτερόλεπτα
```

> 💡 **Πότε να χρησιμοποιήσεις Facts Cache:**
> ```
> Χωρίς cache: κάθε playbook συλλέγει facts → αργό
> Με cache:    facts αποθηκεύονται → γρήγορο ✅
>
> Χρήσιμο όταν:
> ├── Έχεις πολλούς servers (50+)
> ├── Τρέχεις πολλά playbooks διαδοχικά
> └── Τα facts δεν αλλάζουν συχνά
> ```

## Ομάδα 8: Retry & Error Handling

```ini
[defaults]

# Δημιουργία .retry αρχείων όταν αποτύχει playbook
# Default: True
# Το .retry αρχείο περιέχει τους servers που απέτυχαν
retry_files_enabled = True
retry_files_save_path = ~/.ansible-retry

# Συμπεριφορά όταν ένας server αποτύχει
# Default: False (σταματά το play για τον server)
# True → αγνοεί σφάλματα και συνεχίζει
any_errors_fatal = False
```

---

## Ομάδα 9: Performance

```ini
[defaults]

# Αριθμός παράλληλων εκτελέσεων
forks = 10

# Στρατηγική εκτέλεσης
# Default: linear (ένα task σε όλους, μετά το επόμενο)
# free → κάθε server τρέχει ανεξάρτητα
strategy = linear

# Pipelining → ταχύτερη εκτέλεση
# ⚠️ Απαιτεί: requiretty = False στο sudoers
# (ρυθμίζεται στο [ssh_connection])
```

## Πλήρες παράδειγμα [defaults]

```ini
[defaults]
# ── Inventory ────────────────────────────────
inventory            = ./inventory/hosts.ini
host_key_checking    = False

# ── Remote Connection ─────────────────────────
remote_user          = ansible
private_key_file     = /home/ansible/.ssh/id_ed25519
timeout              = 30
forks                = 10

# ── Python ────────────────────────────────────
interpreter_python   = auto_silent

# ── Output & Logging ──────────────────────────
stdout_callback      = default
result_format        = yaml
log_path             = /home/ansible/ansible/ansible.log

# ── Warnings ──────────────────────────────────
deprecation_warnings = False
command_warnings     = False
system_warnings      = False

# ── Roles & Collections ───────────────────────
roles_path           = ./roles:~/.ansible/roles

# ── Facts ─────────────────────────────────────
gather_subset        = min

# ── Performance ───────────────────────────────
strategy             = linear
```
