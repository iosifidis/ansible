# 5.2 Δομή του ansible.cfg 📋

## Η βασική δομή

Το `ansible.cfg` ακολουθεί τη μορφή **INI file** — την ίδια μορφή που χρησιμοποιεί και το inventory:

```ini
[section1]
key1 = value1
key2 = value2

[section2]
key3 = value3
key4 = value4
```

---

## Τα διαθέσιμα Sections

Η Ansible έχει **πολλά sections**, αλλά αυτά που χρησιμοποιούμε συνήθως είναι:

```
ansible.cfg
├── [defaults]              ← οι πιο συχνές ρυθμίσεις
├── [privilege_escalation]  ← sudo ρυθμίσεις
├── [ssh_connection]        ← SSH παράμετροι
├── [persistent_connection] ← timeouts για network devices
├── [inventory]             ← ρυθμίσεις inventory
└── [galaxy]                ← ρυθμίσεις ansible-galaxy
```

---

## Ανατομία μιας ρύθμισης

```ini
[defaults]
#  ↑
#  Section — ομαδοποιεί σχετικές ρυθμίσεις

inventory = ./inventory/hosts.ini
#   ↑              ↑
#   key         value
# (το όνομα    (η τιμή της
#  ρύθμισης)    ρύθμισης)

# Αυτό είναι σχόλιο — αγνοείται από την Ansible
; Αυτό επίσης είναι σχόλιο (με ελληνικό ερωτηματικό)
```

---

## Τύποι τιμών

Το `ansible.cfg` δέχεται διαφορετικούς τύπους τιμών:

```ini
[defaults]

# Boolean (αληθές/ψευδές)
become          = true     # ή: false, yes, no, 1, 0
host_key_checking = False  # ή: True

# Integer (αριθμός)
forks           = 10
timeout         = 30

# String (κείμενο)
remote_user     = ansible
inventory       = ./inventory/hosts.ini

# Path (διαδρομή)
private_key_file = /home/ansible/.ssh/id_ed25519
log_path         = /home/ansible/ansible/ansible.log

# Choice (επιλογή από λίστα)
stdout_callback = default   # ή: yaml, json, minimal
become_method   = sudo      # ή: su, pbrun, pfexec
```

## Σχέση Sections με λειτουργίες

```
┌──────────────────────────────────────────────────────────┐
│ Section                  │ Τι ελέγχει                    │
├──────────────────────────┼───────────────────────────────┤
│ [defaults]               │ Γενικές ρυθμίσεις             │
│                          │ inventory, user, forks,       │
│                          │ callbacks, logging κλπ        │
├──────────────────────────┼───────────────────────────────┤
│ [privilege_escalation]   │ sudo/su ρυθμίσεις             │
│                          │ become, become_method κλπ     │
├──────────────────────────┼───────────────────────────────┤
│ [ssh_connection]         │ SSH παράμετροι                │
│                          │ pipelining, timeouts,         │
│                          │ extra SSH args κλπ            │
├──────────────────────────┼───────────────────────────────┤
│ [persistent_connection]  │ Network device connections    │
│                          │ connect_timeout κλπ           │
├──────────────────────────┼───────────────────────────────┤
│ [inventory]              │ Inventory plugins             │
│                          │ enable_plugins κλπ            │
├──────────────────────────┼───────────────────────────────┤
│ [galaxy]                 │ ansible-galaxy ρυθμίσεις      │
│                          │ server_list, token κλπ        │
└──────────────────────────┴───────────────────────────────┘
```

## Environment Variables vs ansible.cfg

Κάθε ρύθμιση του `ansible.cfg` έχει και αντίστοιχο **environment variable** με υψηλότερη προτεραιότητα:

```bash
# ansible.cfg          →  Environment Variable
# ─────────────────────────────────────────────
# remote_user          →  ANSIBLE_REMOTE_USER
# forks                →  ANSIBLE_FORKS
# host_key_checking    →  ANSIBLE_HOST_KEY_CHECKING
# become               →  ANSIBLE_BECOME
# inventory            →  ANSIBLE_INVENTORY

# Παράδειγμα χρήσης:
export ANSIBLE_FORKS=20
ansible-playbook playbooks/my_playbook.yml
# Θα χρησιμοποιήσει forks=20 ανεξάρτητα από το ansible.cfg!

# Χρήσιμο για:
# ├── CI/CD pipelines
# ├── Temporary overrides
# └── Testing διαφορετικών τιμών
```

> 💡 **Σειρά Προτεραιότητας Τιμών:**
> ```
> Command line flags      (-i, -u, --become κλπ)  ← υψηλότερη
>         ↓
> Environment variables   (ANSIBLE_*)
>         ↓
> ansible.cfg             (./ansible.cfg κλπ)
>         ↓
> Defaults                (built-in τιμές)         ← χαμηλότερη
> ```

## Έλεγχος ρυθμίσεων

```bash
# Δες ΟΛΕΣ τις τρέχουσες ρυθμίσεις
ansible-config dump

# Δες μόνο όσες έχουν αλλάξει από τα defaults
ansible-config dump --only-changed

# Αναμενόμενο output:
# DEFAULT_BECOME(ansible.cfg) = True
# DEFAULT_BECOME_METHOD(ansible.cfg) = sudo
# DEFAULT_FORKS(ansible.cfg) = 10
# DEFAULT_HOST_LIST(ansible.cfg) = ['./inventory/hosts.ini']
# DEFAULT_REMOTE_USER(ansible.cfg) = ansible
# ...

# Πληροφορίες για συγκεκριμένη ρύθμιση
ansible-config list | grep -A10 "FORKS"
```

## Σύνοψη 5.2

```
Δομή ansible.cfg
├── Μορφή INI (sections + key=value)
├── Sections:
│   ├── [defaults]             → γενικές ρυθμίσεις
│   ├── [privilege_escalation] → sudo
│   ├── [ssh_connection]       → SSH
│   ├── [persistent_connection]→ timeouts
│   ├── [inventory]            → inventory plugins
│   └── [galaxy]               → ansible-galaxy
├── Τύποι τιμών: boolean, integer, string, path
└── Override με environment variables (ANSIBLE_*)
```
