# 5.1 Τι είναι το ansible.cfg ⚙️

## Ο ρόλος του ansible.cfg

Το `ansible.cfg` είναι το **κεντρικό αρχείο ρυθμίσεων** της Ansible. Καθορίζει **πώς συμπεριφέρεται** η Ansible σε κάθε εκτέλεση — από το πού βρίσκει τους servers, μέχρι πώς συνδέεται και τι εμφανίζει στην οθόνη.

> 📝 **Αναλογία:** Σκέψου το `ansible.cfg` σαν τις **"Ρυθμίσεις"** του κινητού σου. Δεν το αγγίζεις κάθε μέρα, αλλά καθορίζει τη συμπεριφορά **όλων** των εφαρμογών.

---

## Χωρίς vs με ansible.cfg

```bash
# Χωρίς ansible.cfg → πρέπει να δίνεις τα πάντα κάθε φορά:
ansible-playbook \
    -i /home/ansible/ansible/inventory/hosts.ini \
    -u ansible \
    --private-key /home/ansible/.ssh/id_ed25519 \
    --become \
    --become-method sudo \
    playbooks/my_playbook.yml

# Με ansible.cfg → απλά:
ansible-playbook playbooks/my_playbook.yml
```

> 💡 **Το ansible.cfg διαβάζει τις ρυθμίσεις αυτόματα** — δεν χρειάζεται να τις επαναλαμβάνεις σε κάθε εντολή!

---

## Σειρά προτεραιότητας

Η Ansible ψάχνει για `ansible.cfg` σε **4 τοποθεσίες** με αυτή τη σειρά:

```
┌─────────────────────────────────────────────────────────┐
│  1. ANSIBLE_CONFIG (environment variable)               │
│     export ANSIBLE_CONFIG=/path/to/ansible.cfg          │
│     → Υψηλότερη προτεραιότητα                           │
├─────────────────────────────────────────────────────────┤
│  2. ./ansible.cfg (τρέχων φάκελος)                      │
│     /home/ansible/ansible/ansible.cfg                   │
│     → Αυτό χρησιμοποιούμε εμείς! ✅                     │
├─────────────────────────────────────────────────────────┤
│  3. ~/.ansible.cfg (home directory)                     │
│     /home/ansible/.ansible.cfg                          │
│     → Για personal ρυθμίσεις                            │
├─────────────────────────────────────────────────────────┤
│  4. /etc/ansible/ansible.cfg (system-wide)              │
│     → Χαμηλότερη προτεραιότητα                          │
│     → Για όλους τους χρήστες του συστήματος             │
└─────────────────────────────────────────────────────────┘
```

### Γιατί είναι σημαντική η σειρά;

```bash
# Παράδειγμα: έχεις 2 ansible.cfg
# /etc/ansible/ansible.cfg    → remote_user = root
# ./ansible.cfg               → remote_user = ansible

# Η Ansible θα χρησιμοποιήσει το ./ansible.cfg
# γιατί έχει ΥΨΗΛΟΤΕΡΗ προτεραιότητα!

# Έλεγχος ποιο ansible.cfg χρησιμοποιείται:
ansible --version | grep "config file"
# config file = /home/ansible/ansible/ansible.cfg ✅
```

## Πού να βάλεις το ansible.cfg σου

```
┌─────────────────────────────────────────────────────────┐
│  Σενάριο                  │ Τοποθεσία                   │
├───────────────────────────┼─────────────────────────────┤
│  Ένα project              │ ./ansible.cfg ✅            │
│  Πολλά projects           │ ~/.ansible.cfg              │
│  Πολλοί χρήστες           │ /etc/ansible/ansible.cfg    │
│  CI/CD pipeline           │ ANSIBLE_CONFIG variable     │
└───────────────────────────┴─────────────────────────────┘
```

> ⚠️ **Σημαντικό για ασφάλεια:** Το `ansible.cfg` στον **τρέχοντα φάκελο** (`./ansible.cfg`) έχει προτεραιότητα. Αυτό σημαίνει ότι αν κατεβάσεις κώδικα από το internet που περιέχει `ansible.cfg`, **αυτό θα χρησιμοποιηθεί** αντί για το δικό σου! Πάντα έλεγχε τι κατεβάζεις.

## Επαλήθευση — Ποιο ansible.cfg χρησιμοποιείται

```bash
# Μέθοδος 1: ansible --version
ansible --version | grep "config file"
# config file = /home/ansible/ansible/ansible.cfg

# Μέθοδος 2: ansible --version (πλήρες)
ansible --version
# ansible [core 2.20.4]
#   config file = /home/ansible/ansible/ansible.cfg ← ✅

# Μέθοδος 3: environment variable
echo $ANSIBLE_CONFIG
# (κενό αν δεν έχει οριστεί)

# Μέθοδος 4: verbose mode
ansible-playbook playbooks/my_playbook.yml -v
# Using /home/ansible/ansible/ansible.cfg as config file ← ✅
```

## Δημιουργία ansible.cfg από το μηδέν

```bash
# Η Ansible μπορεί να δημιουργήσει ένα πλήρες
# ansible.cfg με ΟΛΕΣ τις διαθέσιμες ρυθμίσεις
# (σχολιασμένες) ως αναφορά:
ansible-config init --disabled > ansible.cfg.reference

# Δες πόσες ρυθμίσεις υπάρχουν!
wc -l ansible.cfg.reference
# ~600+ γραμμές!

# Χρήσιμο για να ανακαλύψεις νέες ρυθμίσεις
grep -A2 "host_key" ansible.cfg.reference
```

> 💡 **Pro Tip:** Κράτα το `ansible.cfg.reference` ως **"εγχειρίδιο"** για να βλέπεις τι ρυθμίσεις υπάρχουν. Δεν χρειάζεται να τις θυμάσαι όλες!
