# 5.6 Ανάλυση του υπάρχοντος ansible.cfg 🔍

## Το υπάρχον ansible.cfg

```ini
[defaults]
inventory           = ./inventory/hosts.ini
deprecation_warnings = False
interpreter_python   = auto_silent
remote_user         = ansible
private_key_file    = /home/ansible/.ssh/id_ed25519
forks               = 10
host_key_checking   = False
stdout_callback     = default
result_format       = yaml
log_path            = /home/ansible/ansible/ansible.log

[privilege_escalation]
become              = true
become_method       = sudo
become_user         = root
become_ask_pass     = false
```

---

> 💡 **Συνολική εκτίμηση:** Έχεις ένα **πολύ καλό** βασικό `ansible.cfg`. Είναι λειτουργικό και σωστά δομημένο. Ας δούμε τι μπορεί να βελτιωθεί.

---

## Τι να βελτιώσεις ⚠️

### 1. `host_key_checking = False`

```ini
# Τώρα:
host_key_checking = False

# Πρόβλημα:
# Σε production περιβάλλον αυτό είναι ανασφαλές!
# Δεν επαληθεύεται το fingerprint των servers.

# Λύση: Πρόσθεσε τα fingerprints των servers
# και άλλαξε σε True
host_key_checking = True

# Ή κράτα το False ΜΟΝΟ για lab περιβάλλον
# και χρησιμοποίησε environment variable για production:
# export ANSIBLE_HOST_KEY_CHECKING=True
```

### 2. Μορφοποίηση

```ini
# Τώρα — ανομοιόμορφα spaces:
inventory           = ./inventory/hosts.ini
deprecation_warnings = False   ← λιγότερα spaces

# Καλύτερα — ομοιόμορφη στοίχιση:
inventory            = ./inventory/hosts.ini
deprecation_warnings = False
```

## Τι να προσθέσεις 💡

### 1. Σχόλια & Οργάνωση

```ini
[defaults]
# ── Inventory & Hosts ─────────────────────────
inventory            = ./inventory/hosts.ini
host_key_checking    = False

# ── Remote Connection ─────────────────────────
remote_user          = ansible
private_key_file     = /home/ansible/.ssh/id_ed25519
timeout              = 30
forks                = 10

# ── Python ────────────────────────────────────
interpreter_python   = auto_silent

# ── Output & Logging ──────────────────────────
stdout_callback      = default
result_format        = yaml
log_path             = /home/ansible/ansible/ansible.log

# ── Warnings ──────────────────────────────────
deprecation_warnings = False
system_warnings      = False

# ── Roles ─────────────────────────────────────
roles_path           = ./roles:~/.ansible/roles
```

### 2. `timeout`

```ini
# Πρόσθεσε timeout για αργές συνδέσεις
# Default: 10 → μπορεί να αποτύχει σε αργά δίκτυα
timeout = 30
```

### 3. `system_warnings`

```ini
# Απενεργοποίηση system warnings
# (π.χ. warnings για cowsay που μπορεί να είναι εγκατεστημένο!)
system_warnings = False
```

### 4. `roles_path`

```ini
# Πού ψάχνει για roles
# Χρήσιμο όταν αρχίσουμε το Κεφάλαιο 15
roles_path = ./roles:~/.ansible/roles
```

### 5. `[ssh_connection]` Section

```ini
# Αυτή η section ΛΕΙΠΕΙ εντελώς από το ansible.cfg σου!
# Προσθήκη για καλύτερη απόδοση:

[ssh_connection]
# Ταχύτερη εκτέλεση (έως 10x)
pipelining      = True

# SSH connection reuse
ssh_args        = -C -o ControlMaster=auto -o ControlPersist=60s

# Retry σε αποτυχία
retries         = 3

# Timeout
connect_timeout = 30
```

### 6. `[inventory]` Section

```ini
# Επίσης λείπει — χρήσιμο για dynamic inventories αργότερα
[inventory]
# Ποια inventory plugins είναι ενεργά
enable_plugins = host_list, script, auto, yaml, ini, toml
```

## Το βελτιωμένο ansible.cfg σου

Αυτό είναι το **πλήρες, βελτιωμένο** αρχείο:

```ini
# ============================================================
# Ansible Configuration
# Controller: ansible@ansible-controller
# Τελευταία ενημέρωση: 2026
# ============================================================

[defaults]
# ── Inventory & Hosts ─────────────────────────
inventory            = ./inventory/hosts.ini

# Απενεργοποίηση host key checking (βολικό για αρχή)
host_key_checking    = False
# ⚠️ Άλλαξε σε True για production!

# ── Remote Connection ─────────────────────────
# Ο χρήστης σύνδεσης στους remote servers
remote_user          = ansible

# Το SSH private key
private_key_file     = /home/ansible/.ssh/id_ed25519
timeout              = 30

# Πόσοι servers παράλληλα (default: 5)
forks                = 10

# ── Python ────────────────────────────────────
interpreter_python   = auto_silent

# ── Output & Logging ──────────────────────────
stdout_callback      = default
result_format        = yaml
log_path             = /home/ansible/ansible/ansible.log

# ── Warnings ──────────────────────────────────
deprecation_warnings = False
system_warnings      = False

# ── Roles ─────────────────────────────────────
roles_path           = ./roles:~/.ansible/roles

# ══════════════════════════════════════════════
[privilege_escalation]
# ── Sudo ──────────────────────────────────────
become               = true
become_method        = sudo
become_user          = root
become_ask_pass      = false

# ══════════════════════════════════════════════
[ssh_connection]
# ── Performance ───────────────────────────────
pipelining           = True
ssh_args             = -C -o ControlMaster=auto -o ControlPersist=60s
retries              = 3
connect_timeout      = 30

# ══════════════════════════════════════════════
[inventory]
# ── Plugins ───────────────────────────────────
enable_plugins       = host_list, script, auto, yaml, ini, toml

```

## Εφαρμογή των αλλαγών

```bash
# Επεξεργασία του ansible.cfg
nano ~/ansible/ansible.cfg

# Επαλήθευση ότι δεν υπάρχουν λάθη
ansible --version

# Δες τις αλλαγές που έγιναν
ansible-config dump --only-changed

# Test με ping
ansible nextcloudpi -m ansible.builtin.ping
```
