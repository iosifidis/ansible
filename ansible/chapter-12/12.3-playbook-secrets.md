# 12.3 Χρήση Secrets στο Playbook 🔐

## Τρόποι χρήσης Vault σε Playbook

```
┌─────────────────────────────────────────────────────────┐
│  Τρόπος 1: vars_files → ολόκληρο κρυπτογραφημένο αρχείο │
│  Τρόπος 2: group_vars → αυτόματη φόρτωση                │
│  Τρόπος 3: inline     → κρυπτογραφημένη τιμή στο yaml   │
└─────────────────────────────────────────────────────────┘
```

---

## Τρόπος 1: vars_files

```yaml
---
- name: Deploy με secrets
  hosts: all
  become: true

  vars_files:
    - vars/main.yml          # ← plaintext vars
    - vars/secrets.yml       # ← κρυπτογραφημένο αρχείο ✅

  tasks:

    - name: Ρύθμιση database
      ansible.builtin.template:
        src:  templates/db.conf.j2
        dest: /etc/myapp/db.conf
      # db_password διαβάζεται από secrets.yml!
```

```bash
# Εκτέλεση — η Ansible αποκρυπτογραφεί αυτόματα
ansible-playbook playbooks/deploy.yml

# Αν δεν έχεις vault_password_file στο ansible.cfg:
ansible-playbook playbooks/deploy.yml --ask-vault-pass
```

## Τρόπος 2: group_vars (Αυτόματη φόρτωση ✅)

Η πιο **βέλτιστη πρακτική** — χωρίζεις plaintext από secrets:

```
inventory/
└── group_vars/
    └── all/                    ← φάκελος αντί για αρχείο!
        ├── vars.yml            ← plaintext μεταβλητές
        └── vault.yml           ← κρυπτογραφημένα secrets
```

```bash
# Δημιουργία δομής
mkdir -p ~/ansible/inventory/group_vars/all

# Μετακίνηση vars
mv ~/ansible/inventory/group_vars/all.yml \
   ~/ansible/inventory/group_vars/all/vars.yml
```

```yaml
# inventory/group_vars/all/vars.yml — PLAINTEXT
---
system_timezone:  "Europe/Athens"
http_port:        80
ssh_port:         2022

# Reference στα vault vars (convention)
db_password:      "{{ vault_db_password }}"
api_key:          "{{ vault_api_key }}"
smtp_password:    "{{ vault_smtp_password }}"
```

```yaml
# inventory/group_vars/all/vault.yml — ΚΡΥΠΤΟΓΡΑΦΗΜΕΝΟ
---
vault_db_password:   "MyDBPassword123!"
vault_api_key:       "sk-abc123def456xyz789"
vault_smtp_password: "MyEmailPass!"
```

```bash
# Κρυπτογράφηση vault.yml
ansible-vault encrypt \
    inventory/group_vars/all/vault.yml
```

> 💡 **Το Pattern `vault_` prefix:**
> ```
> vars.yml  → db_password: "{{ vault_db_password }}"
> vault.yml → vault_db_password: "MySecret"
>
> Στο playbook χρησιμοποιείς: {{ db_password }}
> Η Ansible αναλύει:           db_password
>                               → vault_db_password
>                               → "MySecret" ✅
>
> Πλεονεκτήματα:
> ✅ Βλέπεις ποιες vars είναι secrets (vault_ prefix)
> ✅ vars.yml παραμένει readable
> ✅ vault.yml είναι μόνο secrets
> ```

## Χρήση Secrets σε Tasks

```yaml
---
- name: Deploy Application με Secrets
  hosts: all
  become: true
  gather_facts: true

  vars_files:
    - vars/secrets.yml

  vars:
    app_name:  myapp
    db_host:   localhost
    db_port:   5432
    db_name:   "{{ app_name }}_db"

  tasks:

    # ── Database config ────────────────────────
    - name: Deploy database config
      ansible.builtin.template:
        src:   templates/db.conf.j2
        dest:  /etc/myapp/db.conf
        mode:  '0600'          # ← restrictive permissions!
        owner: "{{ app_name }}"
        group: "{{ app_name }}"
      # db_password χρησιμοποιείται στο template

    # ── Environment file ──────────────────────
    - name: Deploy .env file
      ansible.builtin.template:
        src:   templates/env.j2
        dest:  /opt/myapp/.env
        mode:  '0600'
        owner: "{{ app_name }}"

    # ── API config ────────────────────────────
    - name: Ρύθμιση API key
      ansible.builtin.lineinfile:
        path:   /etc/myapp/api.conf
        regexp: '^API_KEY='
        line:   "API_KEY={{ api_key }}"
        mode:   '0600'

    # ── Database user ─────────────────────────
    - name: Δημιουργία database user
      community.postgresql.postgresql_user:
        name:     myapp_user
        password: "{{ db_password }}"
        state:    present
      no_log: true    # ← ΜΗΝ εμφανίζεις το password στο output!

    # ── SMTP config ───────────────────────────
    - name: Deploy SMTP config
      ansible.builtin.copy:
        dest:    /etc/myapp/smtp.conf
        mode:    '0600'
        content: |
          host     = {{ smtp_host | default('smtp.gmail.com') }}
          port     = {{ smtp_port | default(587) }}
          username = {{ smtp_user }}
          password = {{ smtp_password }}
      no_log: true
```

## Templates που χρησιμοποιούν Secrets

```jinja
{# templates/db.conf.j2 #}
{# ============================================================
   Database Configuration
   Generated by Ansible — DO NOT EDIT!
   ============================================================ #}

[database]
host     = {{ db_host     | default('localhost') }}
port     = {{ db_port     | default(5432)        }}
name     = {{ db_name                            }}
user     = {{ db_user     | default('appuser')   }}
password = {{ db_password }}

[pool]
min_connections = {{ db_pool_min | default(2)  }}
max_connections = {{ db_pool_max | default(10) }}
```

```jinja
{# templates/env.j2 #}
{# Application Environment File #}
APP_NAME={{ app_name }}
APP_ENV={{ app_env | default('production') }}
APP_DEBUG={{ 'false' if app_env == 'production' else 'true' }}

DB_HOST={{ db_host }}
DB_PORT={{ db_port }}
DB_DATABASE={{ db_name }}
DB_USERNAME={{ db_user | default('appuser') }}
DB_PASSWORD={{ db_password }}

{% if api_key is defined %}
API_KEY={{ api_key }}
{% endif %}

{% if smtp_password is defined %}
MAIL_HOST={{ smtp_host | default('smtp.gmail.com') }}
MAIL_PORT={{ smtp_port | default(587) }}
MAIL_PASSWORD={{ smtp_password }}
{% endif %}
```

## Vault στο CI/CD Pipeline

```yaml
# .github/workflows/deploy.yml (GitHub Actions)
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:

      - name: Checkout
        uses: actions/checkout@v3

      - name: Setup Ansible
        run: pip install ansible

      - name: Create vault password file
        run: |
          echo "${{ secrets.VAULT_PASSWORD }}" > ~/.vault_pass
          chmod 600 ~/.vault_pass
        # ↑ VAULT_PASSWORD αποθηκεύεται στα GitHub Secrets

      - name: Run playbook
        run: |
          ansible-playbook playbooks/deploy.yml \
              --vault-password-file ~/.vault_pass

      - name: Cleanup
        if: always()
        run: rm -f ~/.vault_pass
```

```
Χρήση Secrets στο Playbook
├── Τρόπος 1: vars_files

│
├── Τρόπος 2: group_vars (βέλτιστο ✅)
│   ├── group_vars/all/vars.yml   → plaintext

│       └── vault_db_pass: "MySecret"
│
├── Τρόπος 3: Inline encrypted values
│   └── db_password: !vault | $ANSIBLE_VAULT...
│
├── Templates με secrets:
│   └── {{ db_password }} → χρησιμοποιείται κανονικά
│
├── Permissions:
│   └── mode: '0600' για αρχεία με secrets
│
└── CI/CD:
    └── Vault password από environment secrets
```
