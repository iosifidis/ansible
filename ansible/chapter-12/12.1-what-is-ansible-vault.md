# 12.1 Τι είναι το Ansible Vault 🔐

## Ο ορισμός

Το **Ansible Vault** είναι το ενσωματωμένο σύστημα **κρυπτογράφησης** της Ansible. Επιτρέπει να αποθηκεύεις **ευαίσθητα δεδομένα** (passwords, API keys, certificates) με ασφάλεια μέσα στα αρχεία σου.

> 📝 **Αναλογία:** Σκέψου το Vault σαν ένα **χρηματοκιβώτιο** μέσα στο repository σου:
> ```
> Χωρίς Vault:
> db_password: MySecret123   ← ορατό σε όλους! ❌
>
> Με Vault:
> db_password: !vault |
>   $ANSIBLE_VAULT;1.1;AES256
>   3861346134...              ← κρυπτογραφημένο ✅
> ```

---

## Γιατί χρειάζεται;

### Το πρόβλημα:

```yaml
# ❌ ΕΠΙΚΙΝΔΥΝΟ — plaintext secrets σε Git!
vars:
  db_password:    MySecret123
  api_key:        sk-abc123def456
  ssl_key_pass:   MySSLPassword
  aws_secret_key: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
```

```bash
# Αν ανεβάσεις αυτό στο Git:
git add group_vars/all.yml
git commit -m "Added database config"
git push origin main
# → ΟΛΟΙ βλέπουν τα passwords! ❌
# → GitHub secret scanning alerts! ❌
# → Security breach! ❌
```

### Η λύση:

```yaml
# ✅ ΑΣΦΑΛΕΣ — κρυπτογραφημένο με Vault
vars:
  db_password: !vault |
    $ANSIBLE_VAULT;1.1;AES256
    38613461343865326139396335613939
    36303232303434306232343934326336
    ...
```

```bash
# Τώρα μπορείς να κάνεις push με ασφάλεια!
git add group_vars/all.yml
git commit -m "Added encrypted database config"
git push origin main
# → Κανείς δεν βλέπει τα passwords! ✅
```

## Πώς λειτουργεί

```
┌─────────────────────────────────────────────────────────┐
│  Εσύ γράφεις plaintext:                                 │
│  db_password: MySecret123                               │
│          │                                              │
│          ▼                                              │
│  ansible-vault encrypt                                  │
│  + vault password                                       │
│          │                                              │
│          ▼                                              │
│  $ANSIBLE_VAULT;1.1;AES256                              │
│  38613461343865326...  ← AES-256 κρυπτογράφηση          │
│          │                                              │
│          ▼                                              │
│  Αποθηκεύεται στο αρχείο / Git                          │
│          │                                              │
│          ▼                                              │
│  ansible-playbook --ask-vault-pass                      │
│  + vault password                                       │
│          │                                              │
│          ▼                                              │
│  Ansible αποκρυπτογραφεί → χρησιμοποιεί το secret       │
└─────────────────────────────────────────────────────────┘
```

---

## Τι μπορεί να κρυπτογραφήσει

```
✅ Ολόκληρα αρχεία (vars files, inventory files)
✅ Μεμονωμένες τιμές μεταβλητών (inline encryption)
✅ Οποιοδήποτε αρχείο (SSL keys, config files)
```

```
❌ ΔΕΝ κρυπτογραφεί:
   Playbook tasks (μόνο τα values, όχι τη δομή)
   Inventory hostnames
```

---

## Αλγόριθμος κρυπτογράφησης

```
Ansible Vault χρησιμοποιεί:
├── AES-256-CBC encryption
├── PBKDF2 key derivation
├── SHA256 HMAC authentication
└── Random salt για κάθε encryption
```

> 💡 **Γιατί είναι ασφαλές:** Ακόμα κι αν κάποιος έχει το κρυπτογραφημένο αρχείο, **δεν μπορεί** να το διαβάσει χωρίς το vault password.

---

## Vault Password — Η βάση της ασφάλειας

```
Vault Password
├── Πρέπει να είναι ΔΥΝΑΤΟ (16+ χαρακτήρες)
├── ΠΟΤΕ να μην αποθηκεύεται σε plaintext
├── ΠΟΤΕ να μην μπαίνει στο Git
└── Τρόποι παροχής:
    ├── --ask-vault-pass  → ρωτάει interactively
    ├── --vault-password-file → από αρχείο
    └── ANSIBLE_VAULT_PASSWORD_FILE env var
```

---

## Vault IDs — Πολλαπλά Passwords

Από Ansible 2.4+ μπορείς να έχεις **πολλαπλά vault passwords** για διαφορετικά environments:

```bash
# Κρυπτογράφηση με συγκεκριμένο vault ID
ansible-vault encrypt \
    --vault-id production@prompt \
    vars/production_secrets.yml

ansible-vault encrypt \
    --vault-id staging@prompt \
    vars/staging_secrets.yml

# Εκτέλεση με πολλαπλά vault IDs
ansible-playbook site.yml \
    --vault-id production@~/.vault_prod \
    --vault-id staging@~/.vault_staging
```

> 📝 **Για τον Μαθητή:** Ξεκινάμε με **ένα vault password** — είναι η πιο συνηθισμένη προσέγγιση. Τα Vault IDs είναι για πιο σύνθετα setups.

## Σύνοψη 12.1

```
Ansible Vault
├── Κρυπτογραφεί ευαίσθητα δεδομένα
├── Αλγόριθμος: AES-256-CBC
├── Χρησιμοποιείται για:
│   ├── Passwords, API keys, tokens
│   ├── SSL private keys
│   └── Οποιοδήποτε sensitive αρχείο
├── Δύο επίπεδα:
│   ├── File-level → ολόκληρο αρχείο
│   └── Variable-level → μεμονωμένη τιμή
├── Vault Password → η βάση της ασφάλειας
└── Vault IDs → πολλαπλά passwords ανά environment
```
