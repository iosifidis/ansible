# 12.4 Suppressing Output — no_log 🔇

## Το πρόβλημα

```yaml
# Χωρίς no_log — το password εμφανίζεται στο output! ❌
- name: Δημιουργία database user
  community.postgresql.postgresql_user:
    name:     myapp_user
    password: "MyDBPassword123!"
    state:    present
```

```bash
# Output (ΕΠΙΚΙΝΔΥΝΟ!):
TASK [Δημιουργία database user] ***************
changed: [nextcloud] => {
    "changed": true,
    "user": "myapp_user",
    "password": "MyDBPassword123!",  # ← ΟΡΑΤΟ! ❌
    ...
}
```

---

## Η λύση: no_log

```yaml
# ✅ Με no_log — κανένα sensitive data στο output
- name: Δημιουργία database user
  community.postgresql.postgresql_user:
    name:     myapp_user
    password: "{{ db_password }}"
    state:    present
  no_log: true    # ← αποκρύπτει ΟΛΟ το output!
```

```bash
# Output (ασφαλές):
TASK [Δημιουργία database user] ***************
changed: [nextcloud]
# ↑ Τίποτα ευαίσθητο! ✅
```

---

## Πού εφαρμόζεται το no_log

### Σε Task Level:
```yaml
tasks:

  # ── Password tasks ────────────────────────
  - name: Αλλαγή root password
    ansible.builtin.user:
      name:     root
      password: "{{ root_password | password_hash('sha512') }}"
    no_log: true

  # ── API calls με tokens ───────────────────
  - name: API call με secret token
    ansible.builtin.uri:
      url:     https://api.example.com/deploy
      method:  POST
      headers:
        Authorization: "Bearer {{ api_token }}"
      body:
        app: "{{ app_name }}"
    no_log: true

  # ── Database operations ───────────────────
  - name: Δημιουργία DB με password
    ansible.builtin.command:
      cmd: >
        mysql -u root -p{{ db_root_password }}
        -e "CREATE DATABASE {{ db_name }};"
    no_log: true

  # ── Copy secret files ─────────────────────
  - name: Deploy SSL private key
    ansible.builtin.copy:
      content: "{{ ssl_private_key }}"
      dest:    /etc/ssl/private/myapp.key
      mode:    '0600'
    no_log: true
```

### Σε Play Level:
```yaml
# ΟΛΟ το play χωρίς logging
- name: Secrets deployment
  hosts: all
  become: true
  no_log: true    # ← εφαρμόζεται σε ΟΛΑ τα tasks!

  tasks:
    - name: Task 1  # ← no_log
    - name: Task 2  # ← no_log
    - name: Task 3  # ← no_log
```

> ⚠️ **Προσοχή με Play-level no_log:**
> ```
> ✅ Χρήσιμο αν ΟΛΑ τα tasks έχουν secrets
> ❌ Κάνει debugging δύσκολο — δεν βλέπεις τίποτα!
> → Προτίμησε task-level no_log
> ```

## no_log με Loop

```yaml
tasks:

  # ── Loop με sensitive data ────────────────
  - name: Δημιουργία users με passwords
    ansible.builtin.user:
      name:     "{{ item.name }}"
      password: "{{ item.password | password_hash('sha512') }}"
      state:    present
    loop: "{{ app_users }}"
    loop_control:
      label: "{{ item.name }}"    # ← εμφανίζει μόνο το name
    no_log: true                  # ← αποκρύπτει passwords
```

## no_log με Register

```yaml
tasks:

  - name: API call με secret
    ansible.builtin.uri:
      url:    https://api.example.com/token
      method: POST
      body:
        client_secret: "{{ client_secret }}"
    register: api_response
    no_log: true    # ← αποκρύπτει request & response

  # ⚠️ Το api_response περιέχει sensitive data!
  # Αν κάνεις debug → χρησιμοποίησε no_log εκεί επίσης
  - name: Χρήση response
    ansible.builtin.debug:
      msg: "Token received"    # ← ΜΗΝ εμφανίζεις api_response!
    # no_log: true  ← αν θέλεις να αποκρύψεις και αυτό
```

## Τι αποκρύπτει vs Τι ΔΕΝ αποκρύπτει

```
no_log: true ΑΠΟΚΡΥΠΤΕΙ:
├── Task arguments (input values)
├── Task output (return values)
├── Changed/failed status details
└── Register variables content

no_log: true ΔΕΝ ΑΠΟΚΡΥΠΤΕΙ:
├── Task name (εμφανίζεται πάντα)
├── Host name
├── Task status (ok/changed/failed)
└── Ansible log file entries
    (αν έχεις log_path στο ansible.cfg!)
```

> ⚠️ **Σημαντικό για το Log File:**

```ini
# ansible.cfg
log_path = /home/ansible/ansible/ansible.log
```

> Ακόμα κι αν χρησιμοποιείς `no_log: true`, τα secrets μπορεί να γραφτούν στο log file!

```bash
# Έλεγξε το log file permissions
chmod 600 ~/ansible/ansible.log
# Ή απενεργοποίησε το logging για sensitive playbooks
```

## Συνδυασμός no_log & Vault

```yaml
---
- name: Full Security Demo
  hosts: all
  become: true

  vars_files:
    - vars/secrets.yml    # ← κρυπτογραφημένο με Vault

  tasks:

    # ── Vault + no_log = Maximum Security ─────
    - name: Ρύθμιση database password
      ansible.builtin.lineinfile:
        path:   /etc/myapp/db.conf
        regexp: '^password='
        line:   "password={{ db_password }}"
        mode:   '0600'
      no_log: true         # ← double protection!
      # Vault κρυπτογραφεί στο disk
      # no_log αποκρύπτει από το output

    - name: Δημιουργία admin user
      ansible.builtin.user:
        name:     admin
        password: "{{ admin_password | password_hash('sha512') }}"
      no_log: true

    - name: Deploy API credentials
      ansible.builtin.template:
        src:   templates/api_config.j2
        dest:  /etc/myapp/api.conf
        mode:  '0600'
        owner: myapp
      no_log: true

    # ── Αυτό ΔΕΝ χρειάζεται no_log ───────────
    - name: Εκκίνηση service
      ansible.builtin.service:
        name:  myapp
        state: started
      # ← κανένα sensitive data εδώ
```

## Debugging με no_log

```yaml
# Πρόβλημα: no_log κάνει debugging δύσκολο!
# Λύση: χρησιμοποίησε -e "no_log_override=false"

tasks:
  - name: Sensitive task
    ansible.builtin.user:
      name:     testuser
      password: "{{ test_password | password_hash('sha512') }}"
    no_log: "{{ no_log_override | default(true) }}"
    # ↑ Default: no_log=true (production)
    # Override: -e "no_log_override=false" (debugging)
```

```bash
# Production (no_log ενεργό)
ansible-playbook playbooks/deploy.yml

# Debugging (no_log απενεργοποιημένο)
ansible-playbook playbooks/deploy.yml \
    -e "no_log_override=false"
# ⚠️ ΜΟΝΟ σε development/testing!
```

## Σύνοψη 12.4

```
no_log
├── Χρήση: no_log: true σε task ή play
├── Αποκρύπτει:
│   ├── Task arguments (input)
│   ├── Task output (return values)
│   └── Register content
├── ΔΕΝ αποκρύπτει:
│   ├── Task name
│   ├── Host name
│   └── Task status (ok/changed/failed)
│
├── Πότε ΠΑΝΤΑ:
│   ├── Passwords & hashes
│   ├── API keys & tokens
│   ├── SSL private keys
│   └── Cloud credentials
│
├── Log file:
│   └── chmod 600 ansible.log
│
└── Debugging:
    └── no_log: "{{ no_log_override | default(true) }}"
```
