# 12.2 Ansible-vault Command Line Tool 🛠️

## Οι εντολές

```
ansible-vault
├── encrypt      → κρυπτογράφηση αρχείου
├── decrypt      → αποκρυπτογράφηση αρχείου
├── view         → προβολή χωρίς αποκρυπτογράφηση στο δίσκο
├── edit         → επεξεργασία κρυπτογραφημένου αρχείου
├── rekey        → αλλαγή vault password
└── encrypt_string → κρυπτογράφηση μεμονωμένης τιμής
```

---

## Προετοιμασία — Vault Password File

```bash
# Δημιουργία vault password αρχείου
# (ΜΗΝ το βάλεις στο Git!)
echo "MyStrongVaultPassword123!" > ~/.vault_pass
chmod 600 ~/.vault_pass

# Πρόσθεσε στο .gitignore
cat >> ~/ansible/.gitignore << 'EOF'
# Vault password files
.vault_pass
*.vault_pass
vault_pass*
# Secret files
secrets/
*.secret
EOF

# Ρύθμιση στο ansible.cfg
nano ~/ansible/ansible.cfg
```

```ini
# ansible.cfg
[defaults]
vault_password_file = ~/.vault_pass
# ↑ Δεν χρειάζεται --ask-vault-pass κάθε φορά!
```

## encrypt — Κρυπτογράφηση αρχείου

```bash
# ── Δημιουργία secrets αρχείου ────────────────
mkdir -p ~/ansible/vars
cat > ~/ansible/vars/secrets.yml << 'EOF'
---
# Sensitive variables
db_password:      "MyDBPassword123!"
api_key:          "sk-abc123def456xyz789"
ssl_key_password: "MySSLKeyPass!"
smtp_password:    "MyEmailPass!"
aws_access_key:   "AKIAIOSFODNN7EXAMPLE"
aws_secret_key:   "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY"
EOF

# ── Κρυπτογράφηση ─────────────────────────────
ansible-vault encrypt vars/secrets.yml

# Αν δεν έχεις vault_password_file:
ansible-vault encrypt vars/secrets.yml --ask-vault-pass

# Αναμενόμενο output:
# Encryption successful

# ── Δες το αποτέλεσμα ─────────────────────────
cat ~/ansible/vars/secrets.yml
# $ANSIBLE_VAULT;1.1;AES256
# 38613461343865326139396335613939363032
# 32303434306232343934326336363431333030
# ...
```

```bash
# ── Κρυπτογράφηση νέου αρχείου (δεν υπάρχει ακόμα) ──
ansible-vault create vars/new_secrets.yml
# → ανοίγει editor (vim) για να γράψεις το περιεχόμενο
# → αποθηκεύεται κρυπτογραφημένο!

# ── Κρυπτογράφηση με συγκεκριμένο vault ID ───
ansible-vault encrypt vars/prod_secrets.yml \
    --vault-id production@~/.vault_prod_pass
```

## decrypt — Αποκρυπτογράφηση αρχείου

```bash
# ── Αποκρυπτογράφηση ──────────────────────────
ansible-vault decrypt vars/secrets.yml

# Αναμενόμενο output:
# Decryption successful

# Δες το plaintext
cat ~/ansible/vars/secrets.yml
# ---
# db_password: MyDBPassword123!
# api_key: sk-abc123def456xyz789
# ...

# ⚠️ ΠΡΟΣΟΧΗ: Μετά το decrypt το αρχείο είναι plaintext!
# Ξανακρυπτογράφησέ το αμέσως ή διάγραψέ το!
ansible-vault encrypt vars/secrets.yml
```

> ⚠️ **Βέλτιστη Πρακτική:** Απέφυγε το `decrypt` σε αρχεία που βρίσκονται σε Git repo. Χρησιμοποίησε `view` ή `edit` αντί για αυτό.

## view — Προβολή χωρίς αποκρυπτογράφηση στο δίσκο

```bash
# ── Προβολή κρυπτογραφημένου αρχείου ─────────
ansible-vault view vars/secrets.yml

# Output (plaintext στο terminal, αρχείο παραμένει κρυπτογραφημένο):
# ---
# db_password: MyDBPassword123!
# api_key: sk-abc123def456xyz789
# ssl_key_password: MySSLKeyPass!
# smtp_password: MyEmailPass!
# aws_access_key: AKIAIOSFODNN7EXAMPLE
# aws_secret_key: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

# ✅ Το αρχείο παραμένει κρυπτογραφημένο!
cat vars/secrets.yml    # → $ANSIBLE_VAULT;1.1;AES256...
```

## edit — Επεξεργασία κρυπτογραφημένου αρχείου

```bash
# ── Επεξεργασία ───────────────────────────────
ansible-vault edit vars/secrets.yml
# → αποκρυπτογραφεί ΠΡΟΣΩΡΙΝΑ σε temp file
# → ανοίγει τον editor (vim)
# → αποθηκεύεις → ξανακρυπτογραφεί αυτόματα
# → διαγράφει το temp file

# ── Αλλαγή editor ─────────────────────────────
EDITOR=nano ansible-vault edit vars/secrets.yml

# ── Ή μόνιμα στο .bashrc ──────────────────────
echo "export EDITOR=nano" >> ~/.bashrc
```

> 💡 **Γιατί edit αντί για decrypt → αλλαγή → encrypt:**
> ```
> decrypt → αρχείο plaintext στο δίσκο → κίνδυνος!
> edit    → plaintext μόνο σε temp file → ασφαλές ✅
> ```

## rekey — Αλλαγή Vault Password

```bash
# ── Αλλαγή vault password ─────────────────────
ansible-vault rekey vars/secrets.yml

# Output:
# Vault password: [παλιό password]
# New Vault password: [νέο password]
# Confirm New Vault password: [νέο password]
# Rekey successful

# ── Αλλαγή με αρχεία ──────────────────────────
ansible-vault rekey vars/secrets.yml \
    --vault-password-file ~/.vault_pass \
    --new-vault-password-file ~/.vault_pass_new

# ── Rekey πολλών αρχείων ──────────────────────
ansible-vault rekey \
    vars/secrets.yml \
    vars/db_secrets.yml \
    vars/api_secrets.yml
```

> 💡 **Πότε να κάνεις rekey:**
> ```
> ✅ Τακτικά (κάθε 3-6 μήνες)
> ✅ Αν φύγει κάποιος από την ομάδα
> ✅ Αν υποψιάζεσαι ότι το password εκτέθηκε
> ```

## encrypt_string — Κρυπτογράφηση μεμονωμένης τιμής

Αντί να κρυπτογραφείς ολόκληρο αρχείο, μπορείς να κρυπτογραφείς **μια μεμονωμένη τιμή**:

```bash
# ── Κρυπτογράφηση τιμής ───────────────────────
ansible-vault encrypt_string 'MyDBPassword123!' \
    --name 'db_password'

# Output:
# db_password: !vault |
#           $ANSIBLE_VAULT;1.1;AES256
#           38613461343865326139396335613939
#           36303232303434306232343934326336
#           ...
# Encryption successful

# ── Αντιγραφή output → group_vars/all.yml ─────
```

```bash
# ── Interactive mode ──────────────────────────
ansible-vault encrypt_string \
    --name 'api_key' \
    --stdin-name 'api_key'
# Reading plaintext input from stdin. (ctrl-d to end input)
# sk-abc123def456xyz789   ← πληκτρολόγησε
# ^D                      ← Ctrl+D για τέλος
```

```bash
# ── Πολλαπλές τιμές με script ─────────────────
for secret in db_password api_key smtp_password; do
    echo -n "Enter value for ${secret}: "
    read -s value
    echo
    ansible-vault encrypt_string "${value}" \
        --name "${secret}" >> vars/secrets.yml
    echo "" >> vars/secrets.yml
done
```

## Ολα τα Commands μαζί — Quick Reference

```bash
# ── Αρχείο operations ─────────────────────────
ansible-vault create  vars/secrets.yml    # νέο κρυπτογραφημένο αρχείο
ansible-vault encrypt vars/secrets.yml    # κρυπτογράφηση υπάρχοντος
ansible-vault decrypt vars/secrets.yml    # αποκρυπτογράφηση (⚠️)
ansible-vault view    vars/secrets.yml    # προβολή (ασφαλές)
ansible-vault edit    vars/secrets.yml    # επεξεργασία (ασφαλές)
ansible-vault rekey   vars/secrets.yml    # αλλαγή password

# ── Inline encryption ─────────────────────────
ansible-vault encrypt_string 'value' --name 'var_name'

# ── Password options ──────────────────────────
--ask-vault-pass                          # ρώτα interactively
--vault-password-file ~/.vault_pass       # από αρχείο
--vault-id prod@~/.vault_prod             # με vault ID
```

## Πρακτική άσκηση

```bash
# Βήμα 1: Δημιούργησε vault password
echo "Ansible@Vault#2026!" > ~/.vault_pass
chmod 600 ~/.vault_pass

# Βήμα 2: Πρόσθεσε στο ansible.cfg
grep -q "vault_password_file" ~/ansible/ansible.cfg || \
    echo "vault_password_file = ~/.vault_pass" >> ~/ansible/ansible.cfg

# Βήμα 3: Δημιούργησε secrets αρχείο
mkdir -p ~/ansible/vars
cat > /tmp/secrets_plain.yml << 'EOF'
---
db_root_password:   "RootPass123!"
db_app_password:    "AppPass456!"
api_github_token:   "ghp_abc123def456"
smtp_password:      "EmailPass789!"
EOF

# Βήμα 4: Κρυπτογράφησε
ansible-vault encrypt /tmp/secrets_plain.yml
cp /tmp/secrets_plain.yml ~/ansible/vars/secrets.yml

# Βήμα 5: Επαλήθευση
ansible-vault view ~/ansible/vars/secrets.yml

# Βήμα 6: Έλεγξε ότι είναι κρυπτογραφημένο
cat ~/ansible/vars/secrets.yml
# → $ANSIBLE_VAULT;1.1;AES256... ✅

# Βήμα 7: Edit test
ansible-vault edit ~/ansible/vars/secrets.yml
# → ανοίγει vim, κάνε μια αλλαγή, αποθήκευσε
```

## Σύνοψη 12.2

```
ansible-vault commands
├── create        → νέο κρυπτογραφημένο αρχείο
├── encrypt       → κρυπτογράφηση αρχείου
├── decrypt       → αποκρυπτογράφηση (⚠️ προσοχή)
├── view          → ασφαλής προβολή ✅
├── edit          → ασφαλής επεξεργασία ✅
├── rekey         → αλλαγή vault password
└── encrypt_string→ inline κρυπτογράφηση τιμής

Password options:
├── --ask-vault-pass         → interactive
├── --vault-password-file    → από αρχείο
└── vault_password_file      → στο ansible.cfg

Βέλτιστες πρακτικές:
├── Χρησιμοποίησε view/edit αντί για decrypt
├── vault_password_file στο ansible.cfg
├── .gitignore για vault password files
└── Τακτικό rekey
```
