# 19.3 extra_vars — Override παντός ⚡

## Τι είναι τα extra_vars

Τα `extra_vars` (flag `-e` ή `--extra-vars`) είναι το **υψηλότερο επίπεδο** μεταβλητών — override κάθε άλλης πηγής.

> ⚠️ **Κρίσιμο:** Extra vars override **ακόμα και** τα `vars/main.yml` ενός role. Χρησιμοποίησέ τα με προσοχή.

---

## Σύνταξη extra_vars

```bash
# ── Απλή τιμή ─────────────────────────────────────────
ansible-playbook site.yml -e "app_version=2.5.0"

# ── Πολλαπλές τιμές ───────────────────────────────────
ansible-playbook site.yml \
    -e "app_version=2.5.0" \
    -e "app_env=staging"

# ── JSON format ────────────────────────────────────────
ansible-playbook site.yml \
    -e '{"app_version": "2.5.0", "app_env": "staging"}'

# ── YAML format ────────────────────────────────────────
ansible-playbook site.yml \
    -e "app_version: '2.5.0'\napp_env: staging"

# ── Από αρχείο (@) ─────────────────────────────────────
ansible-playbook site.yml -e "@vars/extra.yml"
ansible-playbook site.yml -e "@vars/extra.json"

# ── Πολλαπλά αρχεία ───────────────────────────────────
ansible-playbook site.yml \
    -e "@vars/common.yml" \
    -e "@vars/production.yml" \
    -e "app_version=2.5.0"
```

## Χρήσεις extra_vars

### Deployment versioning

```bash
# Κάθε deployment με διαφορετική έκδοση
ansible-playbook deploy.yml \
    --limit webservers \
    -e "app_version=2.5.0"

# Rollback σε παλιά έκδοση
ansible-playbook deploy.yml \
    --limit webservers \
    -e "app_version=2.4.1"
```

### Environment override

```bash
# Staging με production playbook
ansible-playbook site.yml \
    --limit staging-servers \
    -e "app_env=staging app_debug=true"

# Force production settings
ansible-playbook site.yml \
    -e "app_env=production backup_enabled=true"
```

### Mandatory variables pattern

```yaml
# playbook.yml
vars:
  # Χωρίς default — ΠΡΕΠΕΙ να δοθεί από -e
  app_version: "{{ new_version | mandatory }}"
  #                              ↑ αποτυχία αν δεν οριστεί!
```

```bash
# Λάθος (αποτυγχάνει):
ansible-playbook deploy.yml
# fatal: Mandatory variable 'new_version' not defined

# Σωστό:
ansible-playbook deploy.yml -e "new_version=2.5.0"
```

## Extra vars από αρχείο

```yaml
# vars/deploy-production.yml
app_version:    "2.5.0"
app_env:        production
deploy_region:  eu-west-1
notification:   true
slack_channel:  "#deployments"
```

```bash
ansible-playbook deploy.yml \
    --limit production \
    -e "@vars/deploy-production.yml"
```

## Σύνοψη 19.3

```
extra_vars (-e)
│
├── Υψηλότερη προτεραιότητα — override ΠΑΝΤΟΣ
│
├── Syntax:
│   ├── -e "key=value"
│   ├── -e '{"key": "value"}'
│   └── -e "@file.yml"
│
├── Χρήσεις:
│   ├── Deployment versioning (app_version)
│   ├── Environment switching
│   ├── Mandatory variables (| mandatory)
│   └── One-off overrides
│
└── Προσοχή:
    ❌ Μην βάζεις secrets ως -e (εμφανίζονται στο ps!)
    ✅ Χρήση @vault-file για secrets
```
