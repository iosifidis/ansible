# 19.4 Registered Variables & set_fact 🔄

## register — Αποθήκευση αποτελεσμάτων

Το `register` αποθηκεύει το αποτέλεσμα ενός task σε μεταβλητή:

```yaml
tasks:

  - name: Εκτέλεση command
    ansible.builtin.command:
      cmd: "cat /etc/os-release"
    register: os_info        # ← αποθήκευση
    changed_when: false

  # Το register object περιέχει:
  # os_info.stdout      → standard output (string)
  # os_info.stdout_lines → stdout ως λίστα γραμμών
  # os_info.stderr      → standard error
  # os_info.rc          → return code (0=OK)
  # os_info.failed      → true/false
  # os_info.changed     → true/false

  - name: Χρήση register
    ansible.builtin.debug:
      msg:
        - "Output : {{ os_info.stdout_lines[0] }}"
        - "RC     : {{ os_info.rc }}"
        - "Failed : {{ os_info.failed }}"
```

## set_fact — Δημιουργία custom variables

Το `set_fact` δημιουργεί νέες μεταβλητές κατά τη διάρκεια εκτέλεσης:

```yaml
tasks:

  # ── Απλό set_fact ─────────────────────────
  - name: Υπολογισμός
    ansible.builtin.set_fact:
      total_ram_gb: "{{ (ansible_facts['memtotal_mb'] / 1024) | round(1) }}"
      is_production: "{{ app_env == 'production' }}"
      deploy_timestamp: "{{ ansible_date_time.iso8601 }}"

  - name: Χρήση computed vars
    ansible.builtin.debug:
      msg:
        - "RAM    : {{ total_ram_gb }}GB"
        - "Prod   : {{ is_production }}"
        - "Deploy : {{ deploy_timestamp }}"

  # ── set_fact από register ──────────────────
  - name: Έλεγχος έκδοσης
    ansible.builtin.command:
      cmd: nginx -v
    register:     nginx_version_raw
    changed_when: false
    ignore_errors: true

  - name: Parse έκδοση
    ansible.builtin.set_fact:
      nginx_version: >-
        {{ nginx_version_raw.stderr
           | regex_search('nginx/([0-9.]+)', '\\1')
           | first | default('not installed') }}

  - name: Nginx version
    ansible.builtin.debug:
      msg: "Nginx: {{ nginx_version }}"
```

## Ζωή μεταβλητής — Πότε ισχύει

```
register / set_fact ζωή:
│
├── Ισχύει: για τον τρέχοντα host, για τo τρέχον play
│
├── Προσβάσιμο: σε επόμενα tasks του ίδιου play
│
├── ΔΕΝ ισχύει: σε επόμενο play (άλλο - name: Play 2)
│   Λύση: cacheable: true (βλέπε παρακάτω)
│
└── Προσβάσιμο από άλλο host: μέσω hostvars
    {{ hostvars['other_host']['my_var'] }}
```

---

## cacheable: true — Persist μεταξύ plays

```yaml
tasks:

  - name: Persist variable για επόμενο play
    ansible.builtin.set_fact:
      db_migration_done: true
      cacheable: true        # ← persist σε όλο το playbook!
```

```yaml
# Επόμενο play — η μεταβλητή ακόμα υπάρχει
- name: Second Play
  hosts: all
  tasks:
    - name: Χρήση persistent var
      ansible.builtin.debug:
        msg: "Migration done: {{ db_migration_done | default(false) }}"
```

## hostvars — Μεταβλητές από άλλους hosts

```yaml
# Play 1: Συλλογή info από db server
- name: Gather DB info
  hosts: databases
  tasks:
    - name: Get DB port
      ansible.builtin.set_fact:
        db_listen_port: "{{ postgres_port | default(5432) }}"

# Play 2: Χρήση σε webservers
- name: Configure webservers
  hosts: webservers
  tasks:
    - name: Χρήση DB port από db server
      ansible.builtin.template:
        src: app.conf.j2
        dest: /etc/myapp/app.conf
      vars:
        database_url: >-
          postgresql://{{ hostvars[groups['databases'][0]]['ansible_host'] }}:
          {{- hostvars[groups['databases'][0]]['db_listen_port'] }}/mydb
          # ↑ Προσβάσιμο cross-host! ✅
```

## Σύνοψη 19.4

```
register & set_fact
│
├── register:
│   ├── Αποθηκεύει αποτέλεσμα task
│   ├── .stdout, .rc, .failed, .changed
│   └── Χρήση: command/shell output processing
│
├── set_fact:
│   ├── Δημιουργεί custom variable
│   ├── cacheable: true → persist σε όλο το playbook
│   └── Χρήση: computed values, transformations
│
└── hostvars:
    ├── {{ hostvars['hostname']['var'] }}
    └── Cross-host variable access
```
