# 19.5 Ειδικές μεταβλητές (Magic Variables) ✨

## Τι είναι οι Magic Variables

Η Ansible παρέχει αυτόματα μια σειρά από **ειδικές μεταβλητές** που δεν χρειάζεται να ορίσεις — είναι πάντα διαθέσιμες.

> 📝 **Σημείωση:** Αυτές είναι διαφορετικές από τα `ansible_facts` (που συλλέγονται από τον host). Οι magic variables αφορούν **τη δομή του inventory και του play**.

---

## inventory_hostname & inventory_hostname_short

```yaml
tasks:

  - name: Χρήση inventory hostname
    ansible.builtin.debug:
      msg:
        - "Inventory name : {{ inventory_hostname }}"
        # → "nextcloud.example.com" (όπως στο inventory)

        - "Short name     : {{ inventory_hostname_short }}"
        # → "nextcloud" (πριν την πρώτη τελεία)

        - "Actual hostname: {{ ansible_facts['hostname'] }}"
        # → "nextcloud" (πραγματικό hostname του συστήματος)
        # ↑ Μπορεί να διαφέρει από inventory_hostname!
```

---

## groups & group_names

```yaml
tasks:

  - name: Ποιες ομάδες υπάρχουν;
    ansible.builtin.debug:
      msg: "Groups: {{ groups.keys() | list }}"
    # → ['all', 'ungrouped', 'webservers', 'databases', ...]

  - name: Hosts ανά group
    ansible.builtin.debug:
      msg:
        - "webservers: {{ groups['webservers'] }}"
        - "databases : {{ groups['databases'] }}"
        - "all hosts : {{ groups['all'] }}"

  - name: Σε ποιες ομάδες ανήκω;
    ansible.builtin.debug:
      msg: "Ομάδες: {{ group_names }}"
    # → ['webservers', 'production'] (για τον τρέχοντα host)

  # ── Conditional βάσει group ───────────────
  - name: Μόνο για production hosts
    ansible.builtin.debug:
      msg: "Production task!"
    when: "'production' in group_names"
```

## ansible_play_hosts & ansible_play_batch

```yaml
tasks:

  - name: Play hosts
    ansible.builtin.debug:
      msg:
        - "Τρέχων host: {{ inventory_hostname }}"
        - "Όλοι στο play: {{ ansible_play_hosts }}"
        # ↑ Αρχικά όλοι, αφαιρούνται αν αποτύχουν

        - "Τρέχον batch: {{ ansible_play_batch }}"
        # ↑ Hosts στο τρέχον serial batch

  # ── Πρώτος / τελευταίος host ──────────────
  - name: Run only on first host
    ansible.builtin.command:
      cmd: /opt/migrate.sh
    when: inventory_hostname == ansible_play_hosts[0]
    changed_when: true
    # ← ισοδύναμο με run_once: true

  - name: Notification μόνο στο τέλος
    ansible.builtin.uri:
      url:    "https://hooks.slack.com/..."
      method: POST
    when: inventory_hostname == ansible_play_hosts[-1]
    # ← τρέχει ΜΟΝΟ στον τελευταίο host
```

## hostvars — Cross-host access

```yaml
tasks:

  # ── Πρόσβαση σε μεταβλητές άλλου host ────
  - name: DB connection string
    ansible.builtin.template:
      src:  app.conf.j2
      dest: /etc/myapp/app.conf
    vars:
      db_host: >-
        {{ hostvars[groups['databases'][0]]['ansible_host']
           | default(groups['databases'][0]) }}
      db_port: >-
        {{ hostvars[groups['databases'][0]]['postgres_port']
           | default(5432) }}

  # ── Iteration πάνω σε άλλα hosts ──────────
  - name: Αναφορά ολόκληρου inventory
    ansible.builtin.debug:
      msg: >-
        {{ item }}: IP={{ hostvars[item]['ansible_host']
                          | default('N/A') }}
    loop: "{{ groups['all'] }}"
    run_once: true
```

## Άλλες χρήσιμες magic variables

```yaml
tasks:

  - name: Πληροφορίες εκτέλεσης
    ansible.builtin.debug:
      msg:
        # Playbook directory
        - "Playbook dir: {{ playbook_dir }}"

        # Role paths (αν είσαι μέσα σε role)
        - "Role path   : {{ role_path | default('N/A') }}"
        - "Role name   : {{ role_name | default('N/A') }}"

        # Ansible version
        - "Ansible ver : {{ ansible_version.full }}"

        # Inventory file
        - "Inventory   : {{ inventory_dir }}"
```

---

## Σύνοψη 19.5

```
Magic Variables
│
├── inventory_hostname      → όνομα στο inventory
├── inventory_hostname_short → πριν την πρώτη τελεία
│
├── groups['name']          → hosts ανά group
├── group_names             → groups του τρέχοντος host
│
├── ansible_play_hosts      → hosts στο play (ενεργά)
├── ansible_play_batch      → hosts στο τρέχον serial batch
│
├── hostvars['host']['var'] → μεταβλητή άλλου host
│
└── playbook_dir, role_path → paths
```
