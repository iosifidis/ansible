# 19.6 Πρακτικό παράδειγμα — Multi-environment Config 🛠️

## Δομή

```
ansible/
├── hosts.ini
├── group_vars/
│   ├── all/
│   │   ├── vars.yml      ← κοινά
│   │   └── vault.yml     ← encrypted secrets
│   ├── webservers/
│   │   └── vars.yml      ← nginx config
│   ├── production/
│   │   ├── vars.yml      ← production settings
│   │   └── vault.yml     ← production secrets
│   └── staging/
│       └── vars.yml      ← staging settings
├── host_vars/
│   └── nextcloud/
│       ├── vars.yml      ← host overrides
│       └── vault.yml     ← host secrets
└── site.yml
```

## Inventory

```ini
# hosts.ini

nextcloud  ansible_host=192.168.1.10

[databases]

[production]
nextcloud

[staging]
staging-01 ansible_host=192.168.1.30
staging-db ansible_host=192.168.1.31
```

## Variables files

```yaml
# group_vars/all/vars.yml
ansible_user: ansible
system_timezone: Europe/Athens
admin_email: admin@example.com
backup_retention_days: 7

# group_vars/webservers/vars.yml
nginx_port:             80
nginx_worker_processes: auto
nginx_keepalive:        65

# group_vars/production/vars.yml
app_env:       production
app_debug:     false
log_level:     warn
backup_enabled: true
nginx_port:    443    # ← override του webservers default!

# group_vars/staging/vars.yml
app_env:       staging
app_debug:     true
log_level:     debug
backup_enabled: false

# host_vars/nextcloud/vars.yml
certbot_domain: nextcloud.example.com
app_memory:     "2G"    # ← αυτός έχει 4GB RAM
```

## Playbook

```yaml
---
# site.yml

- name: Configure Web Servers
  hosts: webservers
  become: true
  gather_facts: true

  vars:
    # Mandatory — πρέπει να δοθεί από -e
    deploy_version: "{{ new_version | mandatory }}"

  tasks:

    - name: "📊 Variable Precedence Demo"
      ansible.builtin.debug:
        msg:
          - "Host      : {{ inventory_hostname }}"
          - "Groups    : {{ group_names | join(', ') }}"
          - "Environment: {{ app_env }}"
          - "nginx_port: {{ nginx_port }}"
          - "Debug     : {{ app_debug }}"
          - "Version   : {{ deploy_version }}"
          - "Memory    : {{ app_memory | default('default') }}"

    - name: Nginx config template
      ansible.builtin.template:
        src:  templates/nginx.conf.j2
        dest: /etc/nginx/nginx.conf
        mode: '0644'
      vars:
        # task-level override (υψηλότερη από play vars)
        nginx_timeout: >-
          {{ 120 if app_env == 'production' else 30 }}
      notify: Reload nginx

    - name: "Backup only in production"
      ansible.builtin.include_tasks: tasks/backup.yml
      when: backup_enabled | default(false)

  handlers:
    - name: Reload nginx
      ansible.builtin.service:
        name:  nginx
        state: reloaded
```

## Εκτέλεση

```bash
# Production deploy
ansible-playbook site.yml \
    --limit production \
    -e "new_version=2.5.0" \
    --ask-vault-pass

# Staging deploy
ansible-playbook site.yml \
    --limit staging \
    -e "new_version=2.5.0-rc1" \
    --ask-vault-pass

# Debug precedence
ansible-playbook site.yml \
    --limit nextcloud \
    -e "new_version=2.5.0 nginx_port=9090" \
    # ↑ nginx_port=9090 override ΟΛΩΝ (production=443, webservers=80)
    --ask-vault-pass -v
```

## Σύνοψη 19.6

```
Multi-environment Config Pattern:
│
├── group_vars/all/    → κοινά (timezone, admin_email)
├── group_vars/role/   → role-specific (nginx_port: 80)
├── group_vars/env/    → env-specific (app_env, log_level)
│   └── production/vars.yml: nginx_port: 443 ← override!
├── host_vars/host/    → host-specific (certbot_domain)
└── -e "..."           → per-execution (version, hotfix)

Προτεραιότητα (αυξητική):
all < webservers < production < host_vars < -e
```
