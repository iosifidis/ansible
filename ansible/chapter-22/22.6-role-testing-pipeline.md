# 22.6 Πρακτικό παράδειγμα — Role Testing Pipeline 🚀

## Πλήρης test setup για nginx role

```
roles/nginx/
├── tasks/main.yml
├── defaults/main.yml
├── handlers/main.yml
└── molecule/
    └── default/
        ├── molecule.yml    ← δύο distros
        ├── converge.yml    ← εκτέλεση role
        └── verify.yml      ← tests
```

### molecule.yml

```yaml
---
dependency:
  name: galaxy

driver:
  name: docker

platforms:
  - name: ubuntu-24
    image: geerlingguy/docker-ubuntu2404-ansible:latest
    pre_build_image: true
    privileged: true

  - name: rocky-9
    image: geerlingguy/docker-rockylinux9-ansible:latest
    pre_build_image: true
    privileged: true

provisioner:
  name: ansible

verifier:
  name: ansible

lint: |
  set -e
  ansible-lint
```

### converge.yml

```yaml
---
- name: Converge
  hosts: all
  become: true
  gather_facts: true

  vars:
    nginx_port:    80
    nginx_enabled: true

  roles:
    - role: nginx
```

### verify.yml

```yaml
---
- name: Verify
  hosts: all
  gather_facts: true

  tasks:

    - name: Service running
      ansible.builtin.service_facts:

    - name: Assert nginx active
      ansible.builtin.assert:
        that:
          - "'nginx' in services"
          - "services['nginx'].state == 'running'"

    - name: Port 80 listening
      ansible.builtin.wait_for:
        port: 80
        timeout: 5

    - name: HTTP 200 OK
      ansible.builtin.uri:
        url:         http://localhost
        status_code: 200
```

## CI/CD Integration — GitHub Actions

```yaml
# .github/workflows/molecule.yml
name: Molecule Tests

on:
  push:
    branches: [main, develop]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        role: [nginx, postgresql, redis]

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: "3.11"

      - name: Install tools
        run: |
          pip install ansible molecule molecule-plugins[docker] ansible-lint

      - name: Run ansible-lint
        run: ansible-lint
        working-directory: roles/${{ matrix.role }}

      - name: Run Molecule
        run: molecule test
        working-directory: roles/${{ matrix.role }}
        env:
          PY_COLORS: "1"
          ANSIBLE_FORCE_COLOR: "1"
```

## Makefile για local testing

```makefile
# Makefile
.PHONY: lint test all

lint:
	ansible-lint

test-role:
	cd roles/$(ROLE) && molecule test

test-all:
	for role in roles/*/; do \
		cd $$role && molecule test && cd ../..; \
	done

converge:
	cd roles/$(ROLE) && molecule converge

verify:
	cd roles/$(ROLE) && molecule verify

destroy:
	cd roles/$(ROLE) && molecule destroy
```

```bash
# Χρήση
make lint
make test-role ROLE=nginx
make test-all
make converge ROLE=nginx   # ← γρήγορο dev loop
```

## Σύνοψη 22.6

```
Role Testing Pipeline:
│
├── molecule.yml     → platforms (multi-distro)
├── converge.yml     → εκτέλεση role
├── verify.yml       → service, port, HTTP tests
│
├── CI/CD:
│   ├── GitHub Actions → matrix per role
│   └── ansible-lint + molecule test
│
└── Local dev loop:
    ├── molecule converge  → γρήγορο
    ├── molecule verify    → test μόνο
    └── molecule test      → ολόκληρο suite
```
