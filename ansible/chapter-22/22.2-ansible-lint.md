# 22.2 ansible-lint 🔍

## Τι είναι το ansible-lint

Το `ansible-lint` ελέγχει playbooks και roles για **style, best practices και potential bugs** — χωρίς να τα εκτελεί.

---

## Εγκατάσταση

```bash
# Εγκατάσταση
pip install ansible-lint

# Ή με pipx (recommended)
pipx install ansible-lint

# Έλεγχος έκδοσης
ansible-lint --version
```

---

## Βασική χρήση

```bash
# Έλεγχος playbook
ansible-lint playbooks/site.yml

# Έλεγχος role
ansible-lint roles/nginx/

# Έλεγχος ολόκληρου project
ansible-lint

# Με συγκεκριμένο profile
ansible-lint --profile production

# Αγνόησε συγκεκριμένους κανόνες
ansible-lint --skip-list yaml[truthy],name[casing]

# Fix αυτόματα (ό,τι μπορεί)
ansible-lint --fix
```

---

## Profiles

```bash
# Διαθέσιμα profiles:
# min      → ελάχιστοι κανόνες
# basic    → βασικοί κανόνες
# moderate → μέτριοι κανόνες
# safety   → ασφάλεια
# shared   → για shared roles
# production → αυστηρότατοι κανόνες

ansible-lint --profile production playbooks/site.yml
```

---

## .ansible-lint — Configuration

```yaml
# .ansible-lint (στο root του project)
profile: production

# Κανόνες που αγνοούνται
skip_list:
  - yaml[truthy]       # true/false αντί yes/no
  - name[casing]       # task names capitalization

# Warnings αντί errors
warn_list:
  - experimental

# Αρχεία που εξαιρούνται
exclude_paths:
  - .git/
  - molecule/
  - vendor/

# Παρουσίαση
offline: false
verbosity: 1
```

## Συνηθισμένα lint errors & fixes

```yaml
# ❌ Λάθος (lint error: fqcn)
- name: Install nginx
  apt:
    name: nginx

# ✅ Σωστό (FQCN)
- name: Install nginx
  ansible.builtin.apt:
    name: nginx

# ❌ Λάθος (lint: no-changed-when)
- name: Check version
  command: nginx -v

# ✅ Σωστό
- name: Check version
  ansible.builtin.command:
    cmd: nginx -v
  changed_when: false

# ❌ Λάθος (lint: yaml[truthy])
become: yes

# ✅ Σωστό
become: true

# ❌ Λάθος (lint: name[missing])
- ansible.builtin.apt:
    name: nginx

# ✅ Σωστό (task πάντα με name)
- name: Install nginx
  ansible.builtin.apt:
    name: nginx
```

## Σύνοψη 22.2

```
ansible-lint
│
├── Εγκατάσταση: pip install ansible-lint
├── Χρήση: ansible-lint [file/dir]
├── Profiles: min → basic → production
├── Config: .ansible-lint
└── Συνηθισμένα issues:
    ├── fqcn (πλήρη module names)
    ├── no-changed-when (command tasks)
    ├── yaml[truthy] (true vs yes)
    └── name[missing] (task χωρίς name)
```
