# 22.3 Εισαγωγή στο Molecule 🧪

## Τι είναι το Molecule

Το **Molecule** είναι το επίσημο framework για **testing Ansible roles**. Δημιουργεί instances (containers ή VMs), τρέχει το role, ελέγχει τα αποτελέσματα και καθαρίζει.

```
Molecule lifecycle:
│
├── dependency  → Εγκατάσταση dependencies
├── lint        → ansible-lint
├── cleanup     → Καθαρισμός από προηγούμενο run
├── destroy     → Διαγραφή instances
├── syntax      → Syntax check
├── create      → Δημιουργία instances (Docker containers)
├── prepare     → Προετοιμασία instances
├── converge    → Εκτέλεση role
├── idempotency → Εκτέλεση role ΞΑΝΑ → changed=0
├── side_effect → Side effects tests
├── verify      → Tests (Ansible tasks)
└── destroy     → Διαγραφή instances
```

---

## Εγκατάσταση

```bash
# Εγκατάσταση
pip install molecule molecule-plugins[docker]

# Ή με pipx
pipx install molecule
pipx inject molecule molecule-plugins

# Έλεγχος
molecule --version
```

## Σχέση Molecule με Roles

```
roles/
└── nginx/               ← Role που θέλεις να test
    ├── tasks/
    │   └── main.yml
    ├── defaults/
    │   └── main.yml
    ├── handlers/
    │   └── main.yml
    └── molecule/        ← Molecule directory (μέσα στο role!)
        └── default/     ← Test scenario "default"
            ├── molecule.yml      ← Ρύθμιση
            ├── converge.yml      ← Το playbook που τρέχει
            └── verify.yml        ← Tests
```

```
Molecule
```
