# 27.5 Πρακτικό παράδειγμα — Self-managing Fleet 🌐

## Η ιδέα

```
Developer → push → GitHub
                        │
              κάθε 30 λεπτά
                        ↓
Host 1 ──► git pull → ansible-playbook local.yml ──► configured ✅
Host 2 ──► git pull → ansible-playbook local.yml ──► configured ✅
Host N ──► git pull → ansible-playbook local.yml ──► configured ✅
```

Κάθε αλλαγή στο Git εφαρμόζεται σε **όλους** τους hosts εντός 30 λεπτών — χωρίς χειροκίνητη παρέμβαση.

---

## Git repository layout

```
ansible-configs/         ← GitHub repo
├── local.yml            ← entry point
├── requirements.yml     ← Galaxy collections
├── group_vars/
│   └── all.yml          ← κοινές μεταβλητές
├── host_vars/
│   ├── nextcloud.yml    ← host-specific
│   └── db-01.yml
└── roles/
    ├── base/            ← SSH, users, firewall
    ├── monitoring/      ← node_exporter
    └── docker/          ← Docker install
```

---

## local.yml

```yaml
---
- name: Self-configure
  hosts: localhost
  connection: local
  become: true
  gather_facts: true

  pre_tasks:
    - name: Galaxy requirements
      ansible.builtin.command:
        cmd: ansible-galaxy install -r requirements.yml --force
      changed_when: false

  roles:
    - role: base
    - role: monitoring
    - role: docker
      when: install_docker | default(false)

  post_tasks:
    - name: Report
      ansible.builtin.debug:
        msg: "✅ {{ ansible_hostname }} at {{ ansible_date_time.iso8601 }}"
```

## Setup (1 φορά, με push)

```bash
# Στήσε το cron σε όλους τους hosts (μια φορά):
ansible-playbook setup-pull.yml --limit all
# Μετά: κάθε host κάνει pull μόνος του!

# Άμεση εκτέλεση σε συγκεκριμένο host (debugging):
ssh nextcloud "ansible-pull \
    --url git@github.com:myorg/ansible-configs.git \
    --key-file /etc/ansible/deploy_key \
    local.yml"
```

## Σύνοψη Κεφ. 24

```
Ansible Pull Mode
│
├── Πότε: large fleets, cloud, bootstrap
├── Convention: local.yml + connection: local
├── Αυτοματοποίηση: cron κάθε 30 λεπτά
├── Bootstrap: cloud-init + πρώτο pull
└── Pattern: Git → hosts pull → self-configure
```
