# 27.3 Αυτοματοποίηση με cron ⏰

## cron για periodic pull

```yaml
# Playbook που εγκαθιστά το ansible-pull cron
# (τρέχει με PUSH μια φορά για setup!)
---
- name: Setup ansible-pull automation
  hosts: all
  become: true
  gather_facts: true

  vars:
    pull_repo:    "https://github.com/myorg/ansible-configs.git"
    pull_branch:  main
    pull_interval: "*/30"    # ← κάθε 30 λεπτά

  tasks:

    - name: Εγκατάσταση ansible
      ansible.builtin.package:
        name:  ansible
        state: present

    - name: Git deploy key
      ansible.builtin.copy:
        src:   files/deploy_key
        dest:  /etc/ansible/deploy_key
        owner: root
        mode:  '0600'

    - name: ansible-pull cron job
      ansible.builtin.cron:
        name:    "ansible-pull"
        minute:  "{{ pull_interval }}"
        hour:    "*"
        job: >
          /usr/bin/ansible-pull
          --url {{ pull_repo }}
          --branch {{ pull_branch }}
          --key-file /etc/ansible/deploy_key
          --only-if-changed
          local.yml
          >> /var/log/ansible-pull.log 2>&1
        user: root

    - name: Log rotation
      ansible.builtin.blockinfile:
        path:   /etc/logrotate.d/ansible-pull
        marker: "# {mark} ANSIBLE MANAGED"
        block:  |
          /var/log/ansible-pull.log {
              daily
              rotate 7
              compress
              missingok
              notifempty
          }
        create: true
        mode:   '0644'
```

---

## Logging & Monitoring

```bash
# Δες το τελευταίο pull
tail -50 /var/log/ansible-pull.log

# Systemd timer (εναλλακτικά):
# /etc/systemd/system/ansible-pull.timer
[Unit]
Description=Ansible Pull Timer

[Timer]
OnBootSec=5min
OnUnitActiveSec=30min

[Install]
WantedBy=timers.target
```

## Σύνοψη 27.3

```
Automated Pull
│
├── Cron: κάθε 30 λεπτά → ansible-pull
├── --only-if-changed: skip αν repo δεν άλλαξε
├── Logging: /var/log/ansible-pull.log
└── Εναλλακτικό: systemd timer
```
