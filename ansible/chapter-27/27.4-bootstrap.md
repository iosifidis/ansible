# 27.4 Bootstrap νέου host 🚀

## cloud-init + ansible-pull

Το πιο ισχυρό pattern: νέος server στο cloud → **μόνος του** εγκαθιστά και ρυθμίζει τα πάντα:

```yaml
# cloud-init user-data (για cloud providers, Proxmox, κ.ά.)
#cloud-config
packages:
  - git
  - ansible

runcmd:
  # 1. Εγκατάσταση git deploy key
  - mkdir -p /etc/ansible
  - echo "{{ deploy_key_base64 }}" | base64 -d > /etc/ansible/deploy_key
  - chmod 600 /etc/ansible/deploy_key

  # 2. Πρώτο ansible-pull (bootstrap)
  - >
    ansible-pull
    --url git@github.com:myorg/ansible-configs.git
    --key-file /etc/ansible/deploy_key
    --inventory localhost,
    local.yml
    >> /var/log/ansible-bootstrap.log 2>&1

  # Μετά το local.yml:
  # → εγκαθιστά cron για periodic pull
  # → ρυθμίζει SSH, firewall, monitoring
  # → εγκαθιστά Docker, app
```

## Proxmox cloud-init integration

```yaml
# Playbook: provision-vm.yml (τρέχει από controller)
tasks:

  - name: Create VM σε Proxmox
    community.general.proxmox_kvm:
      api_host:   "{{ proxmox_host }}"
      api_user:   "{{ proxmox_user }}"
      api_password: "{{ vault_proxmox_pass }}"
      name:       "{{ vm_name }}"
      clone:      ubuntu-24-template
      node:       pve
      cores:      2
      memory:     2048
      ipconfig:
        ipconfig0: "ip={{ vm_ip }}/24,gw={{ vm_gw }}"
      ciuser:     ansible
      cipassword: "!"
      sshkeys:    "{{ lookup('file', '~/.ssh/ansible_ed25519.pub') }}"
      cicustom:   "user=local:snippets/cloud-init.yml"
      state:      present
    no_log: true

  # Μετά → VM boot → cloud-init → ansible-pull → done!
```

# 27.5 Πρακτικό παράδειγμα — Self-managing Fleet

```
Αρχιτεκτονική:

  Developer → push code → GitHub
                               │
                               ▼
  Host 1  ──cron/30min──► git pull → ansible-playbook local.yml
  Host 2  ──cron/30min──► git pull → ansible-playbook local.yml
  Host N  ──cron/30min──► git pull → ansible-playbook local.yml

  Αποτέλεσμα:
  Κάθε αλλαγή στο Git → όλοι οι hosts ενημερώνονται
  εντός 30 λεπτών, χωρίς χειροκίνητη παρέμβαση!
```

```yaml
# local.yml — Full self-configure playbook
---
- name: Self-configure
  hosts: localhost
  connection: local
  become: true
  gather_facts: true

  vars_files:
    - "host_vars/{{ ansible_hostname }}.yml"

  pre_tasks:
    - name: Galaxy requirements
      ansible.builtin.command:
        cmd: ansible-galaxy install -r requirements.yml --force
      changed_when: false

  roles:
    - role: base          # SSH, users, firewall, sysctl
    - role: monitoring    # node_exporter, cAdvisor
    - role: docker        # Docker install
      when: install_docker | default(false)
    - role: myapp
      when: install_myapp | default(false)

  post_tasks:
    - name: Report
      ansible.builtin.debug:
        msg: >
          ✅ {{ ansible_hostname }} configured at
          {{ ansible_date_time.iso8601 }}
```

```bash
# Εγκατάσταση στον πρώτο host (με PUSH):
ansible-playbook setup-pull.yml --limit new-server

# Μετά από αυτό, ο server κάνει pull μόνος του κάθε 30 λεπτά!
```
