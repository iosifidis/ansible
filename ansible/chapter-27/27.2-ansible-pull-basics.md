# 27.2 ansible-pull Βασική Χρήση 🛠️

## Τι κάνει το ansible-pull

```bash
ansible-pull [options] [playbook.yml]

# Βήματα που εκτελεί:
# 1. git clone/pull <repo>
# 2. cd <repo>
# 3. ansible-playbook local.yml
#    (τρέχει ΩΣ localhost!)
```

---

## Git repo setup

```
ansible-pull repo structure:
│
├── local.yml          ← Convention! Αυτό τρέχει
├── group_vars/
│   └── all.yml
├── host_vars/
│   └── {{ inventory_hostname }}.yml
├── roles/
│   ├── base/
│   ├── monitoring/
│   └── docker/
└── requirements.yml   ← Galaxy dependencies
```

```yaml
# local.yml — Entry point για ansible-pull
---
- name: Self-configure host
  hosts: localhost
  connection: local    # ← πάντα local!
  become: true
  gather_facts: true

  pre_tasks:
    - name: Install Galaxy requirements
      ansible.builtin.command:
        cmd: >
          ansible-galaxy install
          -r {{ playbook_dir }}/requirements.yml
          --force
      changed_when: true

  roles:
    - role: base          # ← πάντα
    - role: monitoring    # ← πάντα
    - role: docker
      when: "'docker_hosts' in group_names"
```

## Βασική εκτέλεση

```bash
# Μία φορά (manually):
ansible-pull \
    --url https://github.com/myorg/ansible-configs.git \
    --branch main \
    local.yml

# Με inventory (για group_names):
ansible-pull \
    --url https://github.com/myorg/ansible-configs.git \
    --inventory localhost, \
    local.yml

# Με verbose:
ansible-pull \
    --url https://github.com/myorg/ansible-configs.git \
    local.yml \
    -v

# Private repo (με deploy key):
ansible-pull \
    --url git@github.com:myorg/ansible-configs.git \
    --key-file /etc/ansible/deploy_key \
    local.yml
```

## Σύνοψη 27.2

```
ansible-pull basics
│
├── Εκτελείται: στον ίδιο τον host
├── Convention: local.yml (entry point)
├── Connection: local (localhost)
├── Repo: git clone → ansible-playbook local.yml
└── Pattern: hosts pull their own config
```
