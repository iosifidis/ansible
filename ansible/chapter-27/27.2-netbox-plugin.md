# 27.2 Netbox Plugin 🗃️

## Εγκατάσταση

```bash
# Εγκατάσταση collection
ansible-galaxy collection install netbox.netbox

# ή requirements.yml
# collections:
#   - name: netbox.netbox
```

---

## Βασική ρύθμιση

```yaml
# inventory/netbox.yml
---
plugin: netbox.netbox.nb_inventory
api_endpoint: "{{ lookup('env', 'NETBOX_URL') | default('https://netbox.example.com') }}"
token: "{{ lookup('env', 'NETBOX_TOKEN') }}"

# ── Φίλτρα — ποιοι hosts ──────────────────
query_filters:
  - status: active          # ← μόνο ενεργές συσκευές
  - tenant: mycompany       # ← συγκεκριμένο tenant
  - site: datacenter-01     # ← συγκεκριμένο site

# ── Τύποι — τι να επιστρέψει ──────────────
device_query_filters:
  - has_primary_ip: true    # ← μόνο με IP

# ── Grouping ──────────────────────────────
group_by:
  - device_roles            # ← group ανά role (webserver, db, etc.)
  - platforms               # ← group ανά OS (ubuntu, rocky)
  - sites                   # ← group ανά datacenter
  - tags                    # ← group ανά NetBox tags

# ── Variables ─────────────────────────────
compose:
  # Κύρια IP
  ansible_host: >-
    primary_ip4.address | ansible.utils.ipaddr('address')
  # SSH user από NetBox custom field
  ansible_user: >-
    custom_fields.ansible_user | default('ansible')
  # Ansible port από custom field
  ansible_port: >-
    custom_fields.ssh_port | default(22) | int

# ── Caching ───────────────────────────────
cache:            true
cache_plugin:     jsonfile
cache_timeout:    300       # ← 5 λεπτά
cache_connection: /tmp/ansible_netbox_cache
```

---

## Χρήση

```bash
# Ρύθμιση env
export NETBOX_URL=https://netbox.example.com
export NETBOX_TOKEN=abc123token

# Προβολή inventory
ansible-inventory -i inventory/netbox.yml --list | jq '.webservers'
ansible-inventory -i inventory/netbox.yml --graph

# Εκτέλεση
ansible-playbook site.yml -i inventory/netbox.yml --limit webservers

# Ή με ansible.cfg:
# [defaults]
# inventory = inventory/netbox.yml
```

## NetBox Custom Fields για Ansible

```
NetBox → Customization → Custom Fields:
│
├── ansible_user   (Text)   → default: ansible
├── ssh_port       (Integer) → default: 22
├── ansible_python (Text)   → default: /usr/bin/python3
└── deploy_env     (Text)   → production/staging
```

```yaml
# Αυτόματη χρήση custom fields
compose:
  ansible_user:        "custom_fields.ansible_user | default('ansible')"
  ansible_port:        "custom_fields.ssh_port | default(22) | int"
  ansible_python_interpreter: "custom_fields.ansible_python | default('/usr/bin/python3')"
  deploy_env:          "custom_fields.deploy_env | default('production')"
```
