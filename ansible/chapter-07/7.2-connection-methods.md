# 7.2 Μέθοδοι σύνδεσης 🔌

## Οι διαθέσιμες μέθοδοι

Η Ansible δεν συνδέεται **μόνο** μέσω SSH. Έχει πολλές μεθόδους σύνδεσης ανάλογα με τον στόχο:

```
┌─────────────────────────────────────────────────────────┐
│  Connection Plugins                                     │
├─────────────────┬───────────────────────────────────────┤
│  ssh            │ Default — Linux/Unix servers          │
│  local          │ Τοπική εκτέλεση στον controller       │
│  docker         │ Docker containers                     │
│  winrm          │ Windows servers                       │
│  paramiko       │ Python SSH (fallback)                 │
│  network_cli    │ Network devices (Cisco, Juniper)      │
│  kubectl        │ Kubernetes pods                       │
└─────────────────┴───────────────────────────────────────┘
```

---

## Μέθοδος 1: SSH (Default) 🔑

Η πιο συχνή μέθοδος — αυτή που χρησιμοποιούμε μέχρι τώρα.

```ini
# Στο inventory
[webservers]
nextcloud ansible_connection=ssh   # ← explicit (συνήθως παραλείπεται)
```

```yaml
# Στο playbook
- name: Play με SSH
  hosts: webservers
  vars:
    ansible_connection: ssh          # ← explicit
  tasks:
    - name: Test
      ansible.builtin.ping:
```

```ini
# Στο ansible.cfg
[defaults]
remote_user      = ansible
private_key_file = /home/ansible/.ssh/id_ed25519

[ssh_connection]
pipelining       = True
ssh_args         = -C -o ControlMaster=auto -o ControlPersist=60s
```

### Παράμετροι SSH σύνδεσης:
```ini
# Στο inventory — όλες οι παράμετροι
[webservers]
server01 ansible_host=192.168.1.10      # IP/hostname
         ansible_port=2022              # SSH port
         ansible_user=ansible           # username
         ansible_ssh_private_key_file=/home/ansible/.ssh/id_ed25519
         ansible_ssh_common_args='-o StrictHostKeyChecking=no'
```

## Μέθοδος 2: Local 🖥️

Εκτελεί tasks **τοπικά** στον controller — χωρίς SSH:

```ini
# Στο inventory
[controller]
localhost ansible_connection=local     # ← local connection
```

```yaml
# Χρήσιμο για:
# ├── Tasks που τρέχουν στον controller
# ├── API calls (AWS, GitHub κλπ)
# └── Local file operations

- name: Local tasks
  hosts: localhost
  connection: local                    # ← local connection
  tasks:

    - name: Δημιουργία τοπικού αρχείου
      ansible.builtin.file:
        path: /tmp/test.txt
        state: touch

    - name: API call (παράδειγμα)
      ansible.builtin.uri:
        url: https://api.github.com
        method: GET
      register: github_response

    - name: Εμφάνιση response
      ansible.builtin.debug:
        msg: "GitHub API: {{ github_response.status }}"
```

## Μέθοδος 3: Docker 🐳

Συνδέεται απευθείας σε **Docker containers**:

```ini
# Στο inventory
[containers]
myapp_container ansible_connection=docker
                ansible_host=myapp          # ← container name
mydb_container  ansible_connection=docker
                ansible_host=mydb
```

```yaml
# Playbook για Docker containers
- name: Configure Docker containers
  hosts: containers
  connection: docker
  tasks:

    - name: Εγκατάσταση package σε container
      ansible.builtin.apt:
        name: curl
        state: present

    - name: Αντιγραφή αρχείου σε container
      ansible.builtin.copy:
        src: files/config.yml
        dest: /app/config.yml
```

```bash
# Προαπαίτηση: ο controller πρέπει να έχει Docker
docker ps
# CONTAINER ID  IMAGE   COMMAND  NAMES
# abc123        nginx   ...      myapp
# def456        mysql   ...      mydb

# Test
ansible containers -m ansible.builtin.ping
```

> 💡 **Πότε χρήσιμο:** Όταν θέλεις να διαχειριστείς το **εσωτερικό** ενός container (όχι το Docker daemon). Θα το δούμε εκτενώς στη **Φάση 2 (Docker)**!

## Μέθοδος 4: WinRM (Windows) 🪟

Για **Windows servers** — η Ansible δεν χρησιμοποιεί SSH:

```ini
# Στο inventory
[windows]
win01 ansible_host=192.168.1.50
      ansible_connection=winrm
      ansible_winrm_transport=ntlm
      ansible_user=Administrator
      ansible_password=MyPassword123
      ansible_winrm_server_cert_validation=ignore
```

```yaml
# Playbook για Windows
- name: Windows configuration
  hosts: windows
  tasks:

    - name: Εγκατάσταση Windows feature
      ansible.windows.win_feature:
        name: Web-Server
        state: present

    - name: Δημιουργία directory
      ansible.windows.win_file:
        path: C:\myapp
        state: directory
```

> 📝 **Σημείωση:** Τα Windows modules βρίσκονται στο `ansible.windows` collection και είναι **διαφορετικά** από τα Linux modules. Δεν θα το καλύψουμε εκτενώς στο παρόν course.

## Μέθοδος 5: Paramiko 🐍

Είναι η **Python υλοποίηση** του SSH — χρησιμοποιείται ως fallback:

```ini
# Στο ansible.cfg
[defaults]
# Χρήση paramiko αντί για system SSH
transport = paramiko
```

```yaml
# Ή στο playbook
- name: Play με paramiko
  hosts: webservers
  vars:
    ansible_connection: paramiko
  tasks:
    - name: Test
      ansible.builtin.ping:
```

> ⚠️ **Πότε χρήσιμο:**
> ```
> ✅ Παλιά συστήματα με incompatible SSH
> ✅ Debugging SSH προβλημάτων
> ✅ Windows controller (δεν έχει system SSH)
> ❌ Normal Linux/Unix → χρησιμοποίησε SSH (πιο γρήγορο)
> ```

## Ορισμός Connection — 3 τρόποι

### Τρόπος 1: Στο Inventory (ανά host)
```ini
[servers]
local_server  ansible_connection=local
ssh_server    ansible_connection=ssh    ansible_host=192.168.1.10
docker_app    ansible_connection=docker ansible_host=mycontainer
```

### Τρόπος 2: Στο Playbook (ανά play)
```yaml
- name: Local play
  hosts: localhost
  connection: local          # ← όλο το play
  tasks:
    - ...

- name: SSH play
  hosts: webservers
  connection: ssh            # ← όλο το play
  tasks:
    - ...
```

### Τρόπος 3: Στο ansible.cfg (global)
```ini
[defaults]
# Default connection για όλα
transport = ssh              # ← global default
```

## Σύγκριση μεθόδων

```
┌──────────────┬────────────┬──────────────┬─────────────────┐
│ Μέθοδος      │ Πότε       │ Ταχύτητα     │ Χρήση           │
├──────────────┼────────────┼──────────────┼─────────────────┤
│ ssh          │ Linux/Unix │ ⭐⭐⭐       │ 95% των cases   │
│ local        │ Controller │ ⭐⭐⭐⭐⭐   │ API calls κλπ   │
│ docker       │ Containers │ ⭐⭐⭐⭐     │ Container mgmt  │
│ winrm        │ Windows    │ ⭐⭐         │ Windows servers │
│ paramiko     │ Fallback   │ ⭐⭐         │ Ειδικές περιπτ. │
│ network_cli  │ Routers    │ ⭐⭐⭐       │ Network devices │
└──────────────┴────────────┴──────────────┴─────────────────┘
```

## Πρακτικό παράδειγμα — Mixed Connections

```yaml
---
# mixed-connections.yml
# Χρήση διαφορετικών connections στο ίδιο playbook

- name: Local tasks (API calls)
  hosts: localhost
  connection: local
  tasks:
    - name: Έλεγχος GitHub API
      ansible.builtin.uri:
        url: https://api.github.com/repos/ansible/ansible
        method: GET
      register: repo_info

    - name: Εμφάνιση stars
      ansible.builtin.debug:
        msg: "Ansible GitHub stars: {{ repo_info.json.stargazers_count }}"

- name: Remote tasks (SSH)
  hosts: all_managed
  connection: ssh
  tasks:
    - name: Εγκατάσταση curl
      ansible.builtin.package:
        name: curl
        state: present
```

## Σύνοψη 7.2

```
Μέθοδοι Σύνδεσης
├── ssh        → default, Linux/Unix ✅
├── local      → controller tasks, API calls
├── docker     → container management
├── winrm      → Windows servers
├── paramiko   → Python SSH fallback
└── network_cli→ routers/switches

Ορισμός:
├── Inventory  → ανά host (ansible_connection=)
├── Playbook   → ανά play (connection:)
└── ansible.cfg→ global (transport=)
```
