# 7.6 Troubleshooting συνδέσεων 🔧

## Γιατί χρειάζεται Troubleshooting;

Οι συνδέσεις είναι το **πιο συχνό σημείο αποτυχίας** στην Ansible. Ένα καλό troubleshooting workflow σε γλιτώνει από ώρες debugging.

```
┌─────────────────────────────────────────────────────────┐
│  Τα πιο συχνά προβλήματα:                               │
│  ├── Connection refused    → λάθος port/IP              │
│  ├── Permission denied     → λάθος key/user             │
│  ├── Host key changed      → server reinstall           │
│  ├── Timeout               → firewall/δίκτυο            │
│  └── Python not found      → λείπει Python              │
└─────────────────────────────────────────────────────────┘
```

---

## Εργαλείο 1: Verbose Mode (-v)

Το πιο βασικό εργαλείο debugging:

```bash
# Επίπεδα verbosity
ansible nextcloud -m ping -v      # βασικό output
ansible nextcloud -m ping -vv     # περισσότερες λεπτομέρειες
ansible nextcloud -m ping -vvv    # SSH commands
ansible nextcloud -m ping -vvvv   # maximum (network level)

# Τι βλέπεις με -vvv:
# ESTABLISH SSH CONNECTION FOR USER: ansible
# SSH: EXEC ssh -C -o ControlMaster=auto \
#      -o ControlPersist=60s \
#      -i /home/ansible/.ssh/id_ed25519 \
#      -p 2022 192.212.104.27 \
#      '/bin/sh -c ...'
```

---

## Εργαλείο 2: Απευθείας SSH Test

Πριν ψάξεις πρόβλημα στην Ansible, **δοκίμασε πρώτα το SSH**:

```bash
# Βασική δοκιμή
ssh -i ~/.ssh/id_ed25519 \
    -p 2022 \
    ansible@192.212.104.27

# Με verbose SSH output
ssh -vvv \
    -i ~/.ssh/id_ed25519 \
    -p 2022 \
    ansible@192.212.104.27

# Τι ψάχνεις στο output:
# debug1: Connecting to 192.212.104.27 port 2022  ← σύνδεση
# debug1: Authentication succeeded (publickey)   ← auth OK ✅
# ή
# Permission denied (publickey)                  ← πρόβλημα key ❌
```

## Συνηθισμένα προβλήματα & λύσεις

### Πρόβλημα 1: Connection Refused ❌

```bash
# Μήνυμα:
# fatal: [nextcloud]: UNREACHABLE! => {
#     "msg": "Failed to connect to the host via ssh:
#             ssh: connect to host 192.212.104.27 port 22:
#             Connection refused"
# }

# Αιτίες & Λύσεις:

# 1. Λάθος port
ansible-inventory --host nextcloud | grep port
# Έλεγξε αν είναι 2022 στο host_vars

# 2. SSH service είναι κατεβασμένο
ssh -p 2022 ansible@192.212.104.27
# Αν αποτύχει → ο SSH server δεν τρέχει

# 3. Firewall μπλοκάρει
nc -zv 192.212.104.27 2022
# Connection refused → firewall ή λάθος port
# Connection succeeded → SSH πρόβλημα
```

---

### Πρόβλημα 2: Permission Denied ❌

```bash
# Μήνυμα:
# fatal: [nextcloud]: UNREACHABLE! => {
#     "msg": "Failed to connect to the host via ssh:
#             ansible@192.212.104.27: Permission denied
#             (publickey)"
# }

# Αιτία 1: Λάθος private key
# Λύση:
ansible-inventory --host nextcloud | grep key_file
# Βεβαιώσου ότι το path είναι σωστό

ls -la ~/.ssh/id_ed25519
# Πρέπει να υπάρχει και να έχει 600 permissions

# Αιτία 2: Public key δεν είναι στο authorized_keys
# Λύση:
ssh-copy-id -i ~/.ssh/id_ed25519.pub \
    -p 2022 ansible@192.212.104.27

# Αιτία 3: Λάθος user
ansible-inventory --host nextcloud | grep user
# Βεβαιώσου ότι είναι "ansible"

# Αιτία 4: Λάθος permissions στο .ssh
# Λύση (στον managed server):
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

---

### Πρόβλημα 3: Host Key Changed ❌

```bash
# Μήνυμα:
# WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!
# fatal: [nextcloud]: UNREACHABLE! => {
#     "msg": "Host key verification failed."
# }

# Αιτία: Server reinstall ή MITM attack

# Λύση 1: Αφαίρεση παλιού key (αν ξέρεις ότι είναι OK)
ssh-keygen -R "[192.212.104.27]:2022"

# Λύση 2: Νέο keyscan
ssh-keyscan -p 2022 192.212.104.27 >> ~/.ssh/known_hosts

# Λύση 3: Προσωρινά ignore (ΜΗΝ σε production!)
ansible nextcloud -m ping \
    -e "ansible_ssh_common_args='-o StrictHostKeyChecking=no'"
```

---

### Πρόβλημα 4: Timeout ❌

```bash
# Μήνυμα:
# fatal: [nextcloud]: UNREACHABLE! => {
#     "msg": "timed out waiting for privilege escalation prompt"
# }

# Αιτία 1: Firewall μπλοκάρει
ping -c 3 192.212.104.27          # έλεγχος connectivity
nc -zv 192.212.104.27 2022        # έλεγχος port

# Αιτία 2: Αργό δίκτυο
# Λύση: αύξηση timeout
ansible nextcloud -m ping \
    -e "ansible_timeout=60"

# Ή στο ansible.cfg:
# [defaults]
# timeout = 60

# Αιτία 3: sudo ζητάει password
# Λύση: έλεγχος sudoers
ssh ansible@192.212.104.27 -p 2022
sudo whoami    # αν ζητάει password → πρόβλημα NOPASSWD
```

---

### Πρόβλημα 5: Python Not Found ❌

```bash
# Μήνυμα:
# fatal: [nextcloud]: FAILED! => {
#     "msg": "/usr/bin/python: not found"
# }

# Λύση 1: Εγκατάσταση Python
ansible nextcloud -m ansible.builtin.raw \
    -a "apt install -y python3" \
    --become
# Το raw module δεν χρειάζεται Python! ✅

# Λύση 2: Ορισμός σωστού Python path
# Στο host_vars/nextcloud.yml:
# ansible_python_interpreter: /usr/bin/python3

# Λύση 3: auto_silent στο ansible.cfg
# interpreter_python = auto_silent
```

---

### Πρόβλημα 6: Sudo Failed ❌

```bash
# Μήνυμα:
# fatal: [nextcloud]: FAILED! => {
#     "msg": "Missing sudo password"
# }

# Αιτία: Λείπει NOPASSWD από sudoers

# Έλεγχος (στον managed server):
sudo cat /etc/sudoers.d/ansible
# ansible ALL=(ALL) NOPASSWD: ALL  ← πρέπει να υπάρχει

# Αν λείπει:
echo "ansible ALL=(ALL) NOPASSWD: ALL" | \
    sudo tee /etc/sudoers.d/ansible
sudo chmod 0440 /etc/sudoers.d/ansible

# Ή δώσε password προσωρινά:
ansible nextcloud -m ping --ask-become-pass
```

## Troubleshooting Playbook

```yaml
---
# diagnose-connection.yml
# Πλήρης διάγνωση σύνδεσης

- name: Diagnose Connection Issues
  hosts: "{{ target | default('all') }}"
  gather_facts: false

  tasks:

    - name: Βήμα 1 - Raw ping (χωρίς Python)
      ansible.builtin.raw: echo "raw connection OK"
      register: raw_result
      ignore_errors: true

    - name: Raw αποτέλεσμα
      ansible.builtin.debug:
        msg: "Raw: {{ raw_result.stdout | default('FAILED') }}"

    - name: Βήμα 2 - Python έλεγχος
      ansible.builtin.raw: python3 --version
      register: python_result
      ignore_errors: true

    - name: Python αποτέλεσμα
      ansible.builtin.debug:
        msg: "Python: {{ python_result.stdout | default('NOT FOUND') }}"

    - name: Βήμα 3 - Gathering Facts
      ansible.builtin.setup:
        gather_subset: min
      register: facts_result
      ignore_errors: true

    - name: Facts αποτέλεσμα
      ansible.builtin.debug:
        msg: "Facts: {{ 'OK' if not facts_result.failed else 'FAILED' }}"

    - name: Βήμα 4 - Sudo έλεγχος
      ansible.builtin.command: whoami
      become: true
      register: sudo_result
      ignore_errors: true

    - name: Sudo αποτέλεσμα
      ansible.builtin.debug:
        msg: "Sudo: {{ sudo_result.stdout | default('FAILED') }}"

    - name: Τελική Αναφορά
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host  : {{ inventory_hostname }}"
          - "Raw   : {{ 'OK ✅' if not raw_result.failed
                        else 'FAILED ❌' }}"
          - "Python: {{ 'OK ✅' if not python_result.failed
                        else 'FAILED ❌' }}"
          - "Facts : {{ 'OK ✅' if not facts_result.failed
                        else 'FAILED ❌' }}"
          - "Sudo  : {{ 'OK ✅' if not sudo_result.failed
                        else 'FAILED ❌' }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
```

```bash
# Εκτέλεση
ansible-playbook playbooks/diagnose-connection.yml \
    --limit nextcloud \
    -v
```

## Quick Troubleshooting Checklist

```bash
# 1. Έλεγχος connectivity
ping -c 3 192.212.104.27                  # network OK;
nc -zv 192.212.104.27 2022               # port open;

# 2. Έλεγχος SSH
ssh -vvv -i ~/.ssh/id_ed25519 \
    -p 2022 ansible@192.212.104.27       # SSH OK;

# 3. Έλεγχος inventory
ansible-inventory --host nextcloud    # vars σωστά;

# 4. Έλεγχος Ansible
ansible nextcloud -m ping -vvv        # Ansible OK;

# 5. Έλεγχος sudo
ansible nextcloud \
    -m command -a "whoami" --become     # sudo OK;

# 6. Έλεγχος facts
ansible nextcloud -m setup \
    -a "filter=ansible_distribution*"   # facts OK;
```

```
├── Εργαλεία:
│   ├── -v/-vvv/-vvvv  → verbose output

│
├── Συνηθισμένα Προβλήματα:
│   ├── Connection refused → port/firewall
│   ├── Permission denied  → key/user/permissions
│   ├── Host key changed   → ssh-keygen -R
│   ├── Timeout            → firewall/δίκτυο/sudo
│   ├── Python not found   → raw module install
│   └── Sudo failed        → sudoers NOPASSWD
│
└── Checklist:
    ping → nc → ssh → inventory → ansible → sudo → facts
```
