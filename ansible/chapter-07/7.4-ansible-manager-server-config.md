# 7.4 Ansible Manager Server Configuration ⚙️

## Τι είναι ο "Manager Server";

Ο **Manager Server** (ή Controller) είναι ο server από τον οποίο η Ansible **εκτελεί** τα playbooks — στη δική μας περίπτωση το **Armbian (ansible-controller)**.

```
┌─────────────────────────────────────────────────────────┐
│  Armbian (Manager/Controller)                           │
│  ├── ansible.cfg    → πώς συνδέεται                     │
│  ├── inventory/     → σε ποιους συνδέεται               │
│  ├── ~/.ssh/        → με ποιο key συνδέεται             │
│  └── playbooks/     → τι εκτελεί                        │
└──────────────────────────┬──────────────────────────────┘
                           │ SSH
                    ┌──────┴──────┐
                    ▼             ▼
              [nextcloud]  [future servers]
```

---

## Πλήρης ρύθμιση Manager Server

Ας δούμε **όλες** τις ρυθμίσεις που αφορούν τη σύνδεση — από το `ansible.cfg` μέχρι το inventory.

---

## Μέρος 1: ansible.cfg — Connection Settings

```ini
# ~/ansible/ansible.cfg

[defaults]
# ── Βασική Σύνδεση ────────────────────────────
remote_user          = ansible
private_key_file     = /home/ansible/.ssh/id_ed25519
timeout              = 30

# ── Host Key ──────────────────────────────────
host_key_checking    = False
# ⚠️ True για production!

# ── Python ────────────────────────────────────
interpreter_python   = auto_silent

[ssh_connection]
# ── Performance ───────────────────────────────
pipelining           = True
ssh_args             = -C -o ControlMaster=auto \
                          -o ControlPersist=60s \
                          -o ServerAliveInterval=30 \
                          -o ServerAliveCountMax=3
# ↑ ServerAliveInterval → ping server κάθε 30s
# ↑ ServerAliveCountMax → max 3 αποτυχημένα pings

# ── Reliability ───────────────────────────────
retries              = 3
connect_timeout      = 30

# ── Transfer ──────────────────────────────────
transfer_method      = smart
```

> 💡 **Νέες Παράμετροι:**
> ```
> ServerAliveInterval=30 → στέλνει keepalive κάθε 30s
>                          αποτρέπει disconnect σε αργά tasks
> ServerAliveCountMax=3  → αν 3 keepalives αποτύχουν → disconnect
>                          αποτρέπει "zombie" connections
> ```

## Μέρος 2: Inventory Connection Variables

```ini
# ~/ansible/inventory/hosts.ini

# ── Global Connection Vars ────────────────────
[all:vars]
ansible_user                 = ansible
ansible_ssh_private_key_file = /home/ansible/.ssh/id_ed25519
ansible_become               = true
ansible_become_method        = sudo
ansible_become_user          = root
```

```yaml
# ~/ansible/inventory/group_vars/all.yml
---
# ── Σύνδεση ───────────────────────────────────
ansible_user:                 ansible
ansible_ssh_private_key_file: /home/ansible/.ssh/id_ed25519
ansible_become:               true

```

## Μέρος 3: SSH Config για τον Manager

Δημιουργία `~/.ssh/config` για ευκολότερη διαχείριση:

```bash
cat > ~/.ssh/config << 'EOF'
# ============================================================
# SSH Config — ansible@bananapim4berry
# ============================================================

# ── Default για όλους τους Ansible servers ────
Host *
    ServerAliveInterval 30
    ServerAliveCountMax 3
    IdentityFile ~/.ssh/id_ed25519

# ── Managed Servers ───────────────────────────
Host nextcloud
    HostName 192.212.104.27
    User ansible
    Port 2022
    IdentityFile ~/.ssh/id_ed25519

# ── Future Servers ────────────────────────────
# Host rocky01
#     HostName 192.168.1.X
#     User ansible
#     Port 2022

# Host suse01
#     HostName 192.168.1.X
#     User ansible
#     Port 2022
EOF

# Σωστά permissions
chmod 600 ~/.ssh/config
```

## Μέρος 4: Επαλήθευση ρυθμίσεων

```bash
# Έλεγχος 1: ansible.cfg
ansible --version
# config file = /home/ansible/ansible/ansible.cfg ✅

# Έλεγχος 2: Connection variables
ansible-inventory --host nextcloud
# {
#     "ansible_become": true,
#     "ansible_host": "192.212.104.27",
#     "ansible_port": 2022,
#     "ansible_user": "ansible",
#     ...
# }

# Έλεγχος 3: SSH Config
ssh -G nextcloud | grep -E "hostname|port|user|identity"
# hostname 192.212.104.27
# port 2022
# user ansible
# identityfile ~/.ssh/id_ed25519

# Έλεγχος 4: Ping test
ansible nextcloud -m ansible.builtin.ping

# Έλεγχος 5: Verbose connection
ansible nextcloud -m ansible.builtin.ping -vvv 2>&1 | \
    grep -E "SSH|EXEC|connection"
```

## Μέρος 5: Προσθήκη νέου Managed Server

Η **διαδικασία** για κάθε νέο server:

```bash
# Βήμα 1: Στείλε SSH key
ssh-copy-id -i ~/.ssh/id_ed25519.pub \
    -p 22 \
    debian@NEW_SERVER_IP

# Βήμα 2: Πρόσθεσε στο inventory
nano ~/ansible/inventory/hosts.ini
# Πρόσθεσε κάτω από το σωστό group:
# newserver

# Βήμα 3: Δημιουργία host_vars
cat > ~/ansible/inventory/host_vars/newserver.yml << EOF
---
ansible_host: NEW_SERVER_IP
ansible_port: 22           # θα αλλάξει σε 2022 μετά το security playbook
EOF

# Βήμα 4: Test σύνδεσης
ansible newserver -m ansible.builtin.ping

# Βήμα 5: Τρέξε security bootstrap
ansible-playbook playbooks/security-bootstrap.yml \
    --limit newserver

# Βήμα 6: Ενημέρωση port στο host_vars
nano ~/ansible/inventory/host_vars/newserver.yml
# ansible_port: 2022   ← άλλαξε σε 2022

# Βήμα 7: Τελικό test
ansible newserver -m ansible.builtin.ping
```

## Μέρος 6: Connection Testing Playbook

```yaml
---
# test-connections.yml
# Πλήρης έλεγχος όλων των συνδέσεων

- name: Test All Connections
  hosts: all
  gather_facts: true

  tasks:

    - name: Ping test
      ansible.builtin.ping:

    - name: SSH connection info
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host    : {{ inventory_hostname }}"
          - "IP      : {{ ansible_host }}"
          - "Port    : {{ ansible_port | default(22) }}"
          - "User    : {{ ansible_user }}"
          - "OS      : {{ ansible_facts['distribution'] }} \
                        {{ ansible_facts['distribution_version'] }}"
          - "Python  : {{ ansible_facts['python_version'] }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

    - name: Sudo test
      ansible.builtin.command: whoami
      become: true
      register: sudo_result

    - name: Sudo αποτέλεσμα
      ansible.builtin.debug:
        msg: "Sudo: {{ sudo_result.stdout }} ✅"

    - name: SSH key test
      ansible.builtin.command:
        cmd: "cat ~/.ssh/authorized_keys"
      register: auth_keys

    - name: Authorized keys
      ansible.builtin.debug:
        msg: "Keys: {{ auth_keys.stdout_lines | length }} key(s) installed"
```

```bash
# Εκτέλεση
ansible-playbook playbooks/test-connections.yml

# Μόνο σε συγκεκριμένο host
ansible-playbook playbooks/test-connections.yml \
    --limit nextcloud
```

## Μέρος 7: Χρήσιμες Ad-hoc εντολές

```bash
# Γρήγορος έλεγχος όλων των servers
ansible all -m ansible.builtin.ping

# Δες uptime όλων
ansible all -m ansible.builtin.command -a "uptime"

# Δες free memory
ansible all -m ansible.builtin.command \
    -a "free -h" --become

# Δες disk usage
ansible all -m ansible.builtin.command \
    -a "df -h" --become

# Δες running services
ansible all -m ansible.builtin.service_facts \
    --become | grep -A2 "nginx\|ssh\|fail2ban"

# Δες OS info
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_distribution*"
```

```
│   └── host_vars/*.yml     → per-host connection vars
│
├── ~/.ssh/config
│   └── Per-host SSH settings
│
└── Νέος Server Checklist:
    ├── ssh-copy-id
    ├── hosts.ini entry
    ├── host_vars file
    ├── ping test
    ├── security-bootstrap
    └── port update
```
