# 3.2 Δημιουργία `ansible` User 👤

## Βήμα 1: Δημιουργία του χρήστη

```bash
# Δημιουργία ans_ctrl με home directory και bash shell
sudo useradd -m -s /bin/bash ansible

# Ορισμός password
sudo passwd ansible
# Enter new UNIX password: [δώσε ένα δυνατό password]
# Retype new UNIX password: [επανέλαβε]
```

---

## Βήμα 2: Sudo δικαιώματα

```bash
# Πρόσθεσε τον ansible στο sudo group
sudo usermod -aG sudo ansible

# Επαλήθευση
groups ansible
# ansible : ansible sudo ✅
```

---

## Βήμα 3: Έλεγχος Home Directory

```bash
# Δες ότι δημιουργήθηκε σωστά το home
ls -la /home/ansible/

# Αναμενόμενο output:
# drwxr-xr-x 2 ansible ansible 4096 ... .
# drwxr-xr-x 4 root     root     4096 ... ..
# -rw-r--r-- 1 ansible ansible  220 ... .bash_logout
# -rw-r--r-- 1 ansible ansible 3526 ... .bashrc
# -rw-r--r-- 1 ansible ansible  807 ... .profile
```

---

## Βήμα 4: Δοκίμασε τον χρήστη

```bash
# Γίνε ansible
sudo su - ansible

# Πρέπει να δεις:
# ansible@ansible-controller:~$

# Έλεγχος sudo
sudo whoami
# [sudo] password for ansible: [δώσε το password]
# root ✅

# Επιστροφή στον αρχικό χρήστη σου
exit
```

---

## Βήμα 5: Δημιουργία .ssh Directory

```bash
# Ως ansible
sudo su - ansible

# Δημιουργία .ssh directory με σωστά permissions
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# Επαλήθευση permissions
ls -la ~ | grep .ssh
# drwx------ 2 ansible ansible 4096 ... .ssh
# ↑↑↑
# 700 = μόνο ο ansible έχει πρόσβαση ✅

# Επιστροφή
exit
```

> ⚠️ **Τα permissions είναι ΚΡΙΣΙΜΑ!**
> ```
> ~/.ssh          → 700 (drwx------)
> ~/.ssh/         → μόνο ο ιδιοκτήτης διαβάζει/γράφει/εκτελεί
> ```
> Αν τα permissions είναι λάθος, το SSH **αρνείται** να χρησιμοποιήσει τα keys!
