# 3.6 Προετοιμασία Managed Servers 🖥️

## Τι Εννοούμε "Managed Servers"

Οι **managed servers** είναι οι servers που η Ansible θα **διαχειρίζεται** — δηλαδή εκεί που θα εκτελεί τα playbooks μας.

```
Armbian Controller (ansible user)
        │
        │ SSH
        ├──────────► Managed Server 1 (Debian/Ubuntu)
        ├──────────► Managed Server 2 (Rocky/AlmaLinux)
        └──────────► Managed Server 3 (openSUSE)
```

---

## Τι xρειάζεται ένας Managed Server

Ένας server για να διαχειριστεί από την Ansible χρειάζεται **ελάχιστα πράγματα**:

```
✅ SSH server ενεργό
✅ Python 3 εγκατεστημένο
✅ Χρήστης "ansible" με sudo δικαιώματα
✅ Το public key του controller στο authorized_keys
```

Τίποτα άλλο — θυμήσου, η Ansible είναι **agentless**!

---

## Βήμα 1: Δημιουργία ansible User στον Managed Server

Αυτά τα βήματα τα κάνεις **σε κάθε managed server** που θέλεις να διαχειριστείς.

```bash
# Συνδέσου στον managed server (από το Ubuntu PC σου ή από το Armbian)
ssh χρήστης@IP_managed_server

# Δημιουργία ansible user
sudo useradd -m -s /bin/bash ansible

# Ορισμός password (προσωρινά — μετά δεν θα χρειάζεται)
sudo passwd ansible
```

---

## Βήμα 2: Sudo δικαιώματα χωρίς Password

```bash
# Δημιουργία sudoers αρχείου για τον ansible user
echo "ansible ALL=(ALL) NOPASSWD: ALL" | \
    sudo tee /etc/sudoers.d/ansible

# Σωστά permissions
sudo chmod 0440 /etc/sudoers.d/ansible

# Επαλήθευση — δεν πρέπει να βγει error
sudo visudo -cf /etc/sudoers.d/ansible
# /etc/sudoers.d/ansible: parsed OK ✅
```

---

## Βήμα 3: Δημιουργία .ssh Directory

```bash
# Γίνε ansible user
sudo su - ansible

# Δημιουργία .ssh με σωστά permissions
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# Δημιουργία authorized_keys
touch ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

# Επιστροφή
exit
```

---

## Βήμα 4: Επαλήθευση Python

```bash
# Έλεγχος Python στον managed server
python3 --version
# Python 3.x.x ✅

# Αν δεν υπάρχει:

# Debian/Ubuntu
sudo apt install -y python3

# Rocky/AlmaLinux
sudo dnf install -y python3

# openSUSE
sudo zypper install -y python3
```

---

## Βήμα 5: Έλεγχος SSH Service

```bash
# Debian/Ubuntu/Armbian
sudo systemctl status ssh

# Rocky/AlmaLinux/openSUSE
sudo systemctl status sshd

# Αν δεν τρέχει:
# Debian/Ubuntu
sudo systemctl enable ssh && sudo systemctl start ssh

# Rocky/AlmaLinux/openSUSE
sudo systemctl enable sshd && sudo systemctl start sshd
```

---

## Έλεγχος 3.6

Για **κάθε managed server** πρέπει να έχεις:

```
✅ ansible user δημιουργήθηκε
✅ sudo NOPASSWD ρυθμισμένο
✅ .ssh directory με permissions 700
✅ authorized_keys με permissions 600
✅ Python 3 εγκατεστημένο
✅ SSH service ενεργό
```
