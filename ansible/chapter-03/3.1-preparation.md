# 3.1 Προετοιμασία Armbian 🖥️

## Βήμα 1: Σύνδεση στο Armbian

Από το Ubuntu PC σου:

```bash
# Σύνδεση στο Armbian
ssh iosifidis@192.168.1.250

# (ή όποιο username και IP έχεις στο Armbian)
```

---

## Βήμα 2: Έλεγχος συστήματος

Μόλις συνδεθείς, ας δούμε πού βρισκόμαστε:

```bash
# Ποια έκδοση τρέχουμε;
cat /etc/os-release

# Αναμενόμενο output:
# PRETTY_NAME="Debian GNU/Linux 13 (trixie)"
# NAME="Debian"
# VERSION_ID="13"

# Πόση μνήμη έχουμε;
free -h

# Πόσο χώρο;
df -h

# Ποιος είναι ο επεξεργαστής;
uname -m
# aarch64  ← ARM αρχιτεκτονική (φυσιολογικό για Armbian)
```

---

## Βήμα 3: System Update

Πριν από οτιδήποτε, σιγουρευόμαστε ότι το σύστημα είναι **πλήρως ενημερωμένο**:

```bash
# Update package list + upgrade όλα τα packages
sudo apt update && sudo apt upgrade -y

# Καθαρισμός περιττών packages
sudo apt autoremove -y
sudo apt autoclean
```

---

## Βήμα 4: Εγκατάσταση βασικών εργαλείων

```bash
# Εργαλεία που θα χρειαστούμε
sudo apt install -y \
    curl \
    wget \
    git \
    nano \
    tree \
    net-tools \
    openssh-client \
    python3 \
    python3-pip

# Επαλήθευση Python (η Ansible το χρειάζεται!)
python3 --version
# Python 3.11.x ή νεότερο ✅
```

> 📝 **Γιατί Python;** Η Ansible είναι γραμμένη σε Python και το χρειάζεται για να τρέξει στον controller.

---

## Βήμα 5: Έλεγχος SSH Service

```bash
# Σιγουρέψου ότι ο SSH server τρέχει
sudo systemctl status ssh

# Πρέπει να δεις: Active: active (running) ✅

# Αν δεν τρέχει:
sudo systemctl enable ssh
sudo systemctl start ssh
```

---

## Βήμα 6: Σημείωσε τις πληροφορίες του συστήματος

```bash
# Δες την IP (για επιβεβαίωση)
ip addr show | grep inet

# Δες το hostname
hostname

# Αν θέλεις να αλλάξεις το hostname σε κάτι πιο περιγραφικό:
sudo hostnamectl set-hostname ansible-controller

# Επαλήθευση
hostname
# ansible-controller ✅
```

> 💡 **Συμβουλή:** Ένα καλό hostname όπως `ansible-controller` σε βοηθά να θυμάσαι τον ρόλο του server, ειδικά όταν έχεις πολλά μηχανήματα.
