# 3.7 Αποστολή SSH Key στον Managed Server 🔑

Από το **Armbian controller**, ως **ansible user**:

## Βήμα 1: Αποστολή Public Key

```bash
# Στέλνουμε το public key στον ansible user του VM
# Θα ρωτήσει το password του ansible user
ssh-copy-id -i ~/.ssh/id_ed25519.pub ansible@83.212.104.27

# Αναμενόμενο output:
# /usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s)
# /usr/bin/ssh-copy-id: INFO: 1 key(s) remain to be installed
# ansible@83.212.104.27's password:
# Number of key(s) added: 1
```

---

## Βήμα 2: Δοκίμασε τη σύνδεση

```bash
# Σύνδεση χωρίς password
ssh -i ~/.ssh/id_ed25519 ansible@83.212.104.27

# ΧΩΡΙΣ password! ✅

# Έλεγχος sudo
sudo whoami
# root ✅

# Επιστροφή στον controller
exit
```

---

## Βήμα 3: Ενημέρωση Inventory

```bash
nano ~/ansible/inventory/hosts.ini
```

```ini
# ============================================
# Ansible Inventory
# Controller: ansible@ansible-controller
# ============================================

[controller]
localhost ansible_connection=local

[debian_based]
debian-vm ansible_host=83.212.104.27

[redhat_based]
# server01 ansible_host=192.168.1.X

[opensuse_based]
# server01 ansible_host=192.168.1.X

[all_managed:children]
debian_based
redhat_based
opensuse_based

[all:vars]
ansible_user                 = ansible
ansible_ssh_private_key_file = /home/ansible/.ssh/id_ed25519
ansible_become               = true
ansible_become_method        = sudo
```
