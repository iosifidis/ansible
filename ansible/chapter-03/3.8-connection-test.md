# 3.8 Πρώτο test σύνδεσης με Ansible 🚀

## Βήμα 1: Ping Test

Το **πιο βασικό test** — ελέγχει αν η Ansible μπορεί να συνδεθεί στους servers:

```bash
# Από το Armbian controller, ως ansible user
# στον φάκελο ~/ansible

# Test σε ΟΛΟΥΣ τους servers
ansible all -m ansible.builtin.ping

# Test μόνο στο debian VM
ansible debian_based -m ansible.builtin.ping

# Test μόνο σε συγκεκριμένο host
ansible nextcloud -m ansible.builtin.ping
```

---

## Βήμα 2: Gathering Facts Test

Ελέγχει αν η Ansible μπορεί να **συλλέξει πληροφορίες** από τον server:

```bash
# Συλλογή πληροφοριών από το VM
ansible nextcloud -m ansible.builtin.setup | head -50

# Θα δεις πολλές πληροφορίες όπως:
# "ansible_distribution": "Debian"
# "ansible_os_family": "Debian"
# "ansible_architecture": "x86_64"
# "ansible_memtotal_mb": ...
```

---

## Βήμα 3: Ad-hoc Command Test

```bash
# Εκτέλεση απλής εντολής
ansible nextcloud -m ansible.builtin.command -a "whoami"
# ansible ✅

# Με sudo
ansible nextcloud -m ansible.builtin.command -a "whoami" --become
# root ✅

# Έλεγχος uptime
ansible nextcloud -m ansible.builtin.command -a "uptime"

# Έλεγχος OS
ansible nextcloud -m ansible.builtin.command -a "cat /etc/os-release"
```
