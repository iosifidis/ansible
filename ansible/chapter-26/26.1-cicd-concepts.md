# 26.1 CI/CD Concepts για Ansible 📐

## Το πρόβλημα

```
Χωρίς CI/CD:
  Developer → git push → "λειτουργεί στο laptop μου"
                       → production αποτυχία 😱

Με CI/CD:
  Developer → git push → lint → test → staging → production ✅
```

---

## CI/CD Pipeline για Ansible

```
┌─────────────────────────────────────────────────┐
│  Git Push (main branch)                         │
│          │                                      │
│  Stage 1: Lint (ansible-lint)                   │
│          │ pass/fail                            │
│  Stage 2: Test (molecule)                       │
│          │ pass/fail                            │
│  Stage 3: Deploy to Staging                     │
│          │ approval required                    │
│  Stage 4: Deploy to Production                  │
└─────────────────────────────────────────────────┘
```

---

## Secrets στο CI/CD

```
GitHub Secrets / GitLab Variables:
│
├── ANSIBLE_SSH_PRIVATE_KEY  → SSH private key
├── ANSIBLE_VAULT_PASSWORD   → Vault decryption
├── SLACK_WEBHOOK            → Notifications
└── AWX_TOKEN                → AWX API (optional)

Χρήση:
├── GitHub Actions → ${{ secrets.SECRET_NAME }}
└── GitLab CI      → $SECRET_NAME (από Variables)
```

---

## Σύνοψη 26.1

```
CI/CD Stages:
lint → molecule test → staging deploy → production deploy

Tools:
├── GitHub Actions (.github/workflows/)
├── GitLab CI (.gitlab-ci.yml)
└── Secrets: SSH key + Vault password
```
