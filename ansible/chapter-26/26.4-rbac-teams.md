# 26.4 RBAC & Teams 👥

## Role-Based Access Control

```
AWX RBAC Model:
│
├── Organization
│   ├── Admin     → πλήρης έλεγχος
│   ├── Member    → βλέπει/χρησιμοποιεί
│   └── Auditor   → read-only view
│
├── Teams
│   └── Ομάδα users με κοινά permissions
│
├── Ανά Resource (Inventory, Project, Template):
│   ├── Admin  → manage + execute
│   ├── Use    → execute only
│   └── Read   → view only
│
└── Παράδειγμα:
    ├── Team "Developers":
    │   ├── Use: Inventory "Staging"
    │   └── Execute: Template "Deploy to Staging"
    │   (ΔΕΝ έχουν πρόσβαση σε Production!)
    └── Team "SREs":
        └── Admin: όλα
```

## Ρύθμιση μέσω API

```yaml
tasks:

  # ── Δημιουργία Teams ───────────────────
  - name: Create Teams
    ansible.builtin.uri:
      url:    "{{ awx_host }}/api/v2/teams/"
      method: POST
      user:   "{{ awx_user }}"
      password: "{{ awx_pass }}"
      force_basic_auth: true
      body_format: json
      body:
        name:         "{{ item.name }}"
        organization: "{{ org_id }}"
        description:  "{{ item.description }}"
      status_code: [200, 201]
    loop:
      - { name: Developers, description: "Dev team" }
      - { name: SREs,       description: "SRE team" }
      - { name: Auditors,   description: "Read-only" }
    no_log: true

  # ── Δημιουργία Users ──────────────────
  - name: Create Users
    ansible.builtin.uri:
      url:    "{{ awx_host }}/api/v2/users/"
      method: POST
      user:   "{{ awx_user }}"
      password: "{{ awx_pass }}"
      force_basic_auth: true
      body_format: json
      body:
        username:   "{{ item.username }}"
        email:      "{{ item.email }}"
        password:   "{{ item.password }}"
        first_name: "{{ item.first_name }}"
        last_name:  "{{ item.last_name }}"
      status_code: [200, 201]
    loop: "{{ awx_users }}"
    no_log: true
```

## Σύνοψη 26.4

```
RBAC
│
├── Levels: Organization → Team → User
│
├── Roles per resource:
│   ├── Admin  → full control
│   ├── Use    → execute only
│   └── Read   → view only
│
└── Pattern: Teams (Devs, SREs) + Resource roles
    Devs → staging only
    SREs → everything
```
