# 26.3 Job Templates & Workflows ⚙️

## Ιεραρχία οντοτήτων στο AWX

```
Project (Git repo)
    ↓ χρησιμοποιείται από
Job Template
    ├── + Inventory  (ποιοι hosts)
    ├── + Credentials (SSH key, passwords)
    ├── + Playbook   (ποιο .yml)
    └── + Extra Vars / Survey
```

---

## Δημιουργία μέσω awxkit (Ansible)

```yaml
---
# awx-setup.yml — Ρύθμιση AWX μέσω API
- name: AWX Setup
  hosts: localhost
  gather_facts: false

  vars:
    awx_host:  "http://localhost:80"
    awx_user:  admin
    awx_pass:  "{{ vault_awx_admin_pass }}"

  tasks:

    # ── Organization ───────────────────────
    - name: Create Organization
      ansible.builtin.uri:
        url:    "{{ awx_host }}/api/v2/organizations/"
        method: POST
        user:   "{{ awx_user }}"
        password: "{{ awx_pass }}"
        force_basic_auth: true
        body_format: json
        body:
          name:        MyOrg
          description: "Main organization"
        status_code: [200, 201]
      register: org
      no_log:   true

    # ── Credentials (SSH Key) ───────────────
    - name: Create SSH Credential
      ansible.builtin.uri:
        url:    "{{ awx_host }}/api/v2/credentials/"
        method: POST
        user:   "{{ awx_user }}"
        password: "{{ awx_pass }}"
        force_basic_auth: true
        body_format: json
        body:
          name:             "Ansible SSH Key"
          credential_type:  1             # ← Machine (SSH)
          organization:     "{{ org.json.id }}"
          inputs:
            username:   ansible
            ssh_key_data: "{{ lookup('file', '~/.ssh/ansible_ed25519') }}"
        status_code: [200, 201]
      no_log: true

    # ── Inventory ──────────────────────────
    - name: Create Inventory
      ansible.builtin.uri:
        url:    "{{ awx_host }}/api/v2/inventories/"
        method: POST
        user:   "{{ awx_user }}"
        password: "{{ awx_pass }}"
        force_basic_auth: true
        body_format: json
        body:
          name:         "Production"
          organization: "{{ org.json.id }}"
        status_code: [200, 201]
      register: inventory
      no_log:   true

    # ── Project (Git) ──────────────────────
    - name: Create Project
      ansible.builtin.uri:
        url:    "{{ awx_host }}/api/v2/projects/"
        method: POST
        user:   "{{ awx_user }}"
        password: "{{ awx_pass }}"
        force_basic_auth: true
        body_format: json
        body:
          name:             "MyApp Playbooks"
          organization:     "{{ org.json.id }}"
          scm_type:         git
          scm_url:          "https://github.com/myorg/ansible-playbooks.git"
          scm_branch:       main
          scm_update_on_launch: true
        status_code: [200, 201]
      register: project
      no_log:   true

    # ── Job Template ──────────────────────
    - name: Create Job Template
      ansible.builtin.uri:
        url:    "{{ awx_host }}/api/v2/job_templates/"
        method: POST
        user:   "{{ awx_user }}"
        password: "{{ awx_pass }}"
        force_basic_auth: true
        body_format: json
        body:
          name:        "Deploy MyApp"
          job_type:    run
          inventory:   "{{ inventory.json.id }}"
          project:     "{{ project.json.id }}"
          playbook:    "playbooks/deploy.yml"
          ask_variables_on_launch: true
          survey_enabled: true
        status_code: [200, 201]
      no_log: true
```

## Survey — Input form για χρήστες

```yaml
# Survey spec (JSON)
survey_spec:
  name:        "Deploy Parameters"
  description: "Enter deployment details"
  spec:
    - question_name:        "App Version"
      question_description: "Which version to deploy?"
      variable:             app_version
      type:                 text
      required:             true
      default:              latest

    - question_name:        "Environment"
      question_description: "Target environment"
      variable:             app_env
      type:                 multiplechoice
      choices:              "staging\nproduction"
      required:             true
      default:              staging
```

## Σύνοψη 26.3

```
Job Templates & Workflows
│
├── Job Template = runnable playbook
│   ├── Project (git)
│   ├── Inventory (hosts)
│   ├── Credentials (SSH/passwords)
│   └── Survey (user input form)
│
├── Workflow = chain of Job Templates
│   ├── success/failure paths
│   └── Parallel or sequential
│
└── Setup: awxkit CLI ή REST API
```
