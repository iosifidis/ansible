# 26.4 Secrets στο CI/CD 🔐

## SSH Key — Ρύθμιση

```bash
# 1. Δημιουργία dedicated CI/CD key
ssh-keygen -t ed25519 -C "ci-cd-ansible" -f ~/.ssh/ansible_cicd_ed25519 -N ""

# 2. Προσθήκη public key στους managed hosts
ssh-copy-id -i ~/.ssh/ansible_cicd_ed25519.pub ansible@nextcloud

# 3. Προσθήκη private key στο CI/CD secret:
cat ~/.ssh/ansible_cicd_ed25519
# → Αντίγραφε στο GitHub Secret: ANSIBLE_SSH_PRIVATE_KEY
```

## Vault Password σε CI/CD

```bash
# Επιλογή 1: Password file (απλό)
echo "$ANSIBLE_VAULT_PASSWORD" > .vault_pass
ansible-playbook site.yml --vault-password-file .vault_pass
rm -f .vault_pass    # ← πάντα cleanup!

# Επιλογή 2: Environment variable
export ANSIBLE_VAULT_PASSWORD_FILE=/dev/stdin
echo "$ANSIBLE_VAULT_PASSWORD" | ansible-playbook site.yml \
    --vault-password-file /dev/stdin

# Επιλογή 3: Vault password script
cat > vault_pass.py << 'EOF'
import os, sys
print(os.environ.get('ANSIBLE_VAULT_PASSWORD', ''))
EOF
ansible-playbook site.yml --vault-password-file vault_pass.py
```

## known_hosts management

```bash
# ❌ Μη ασφαλές (skip verification)
# ANSIBLE_HOST_KEY_CHECKING=False

# ✅ Ασφαλές (pre-populate known_hosts)
mkdir -p ~/.ssh
ssh-keyscan -H staging.example.com >> ~/.ssh/known_hosts
ssh-keyscan -H prod.example.com    >> ~/.ssh/known_hosts
# Τα fingerprints είναι public — ασφαλές να είναι hardcoded!
```

## Σύνοψη 26.4

```
CI/CD Secrets Best Practices:
│
├── SSH Key:
│   ├── Dedicated CI/CD key (όχι personal key)
│   └── Stored encrypted ως masked secret
│
├── Vault Password:
│   ├── Masked variable στο CI/CD
│   └── Γράψε σε file → use → rm -f
│
└── known_hosts:
    ├── ssh-keyscan πριν deployment
    └── ΌΧΙ ANSIBLE_HOST_KEY_CHECKING=False!
```
