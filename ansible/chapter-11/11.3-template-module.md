# 11.3 Το template Module 📄

## Βασική χρήση

```yaml
- name: Deploy config από template
  ansible.builtin.template:
    src:  templates/nginx.conf.j2   # ← template στον controller
    dest: /etc/nginx/nginx.conf     # ← destination στον server
```

---

## Όλες οι παράμετροι

```yaml
- name: Deploy config
  ansible.builtin.template:
    # ── Υποχρεωτικές ──────────────────────────
    src:   templates/nginx.conf.j2  # path στον controller
    dest:  /etc/nginx/nginx.conf    # path στον server

    # ── Permissions ───────────────────────────
    owner: root                     # ιδιοκτήτης
    group: root                     # group
    mode:  '0644'                   # permissions

    # ── Backup ────────────────────────────────
    backup: true                    # backup πριν αντικατάσταση
    # → δημιουργεί: nginx.conf.2026-01-01@10:00~

    # ── Validation ────────────────────────────
    validate: nginx -t -c %s        # εκτέλεση πριν deploy
    # ↑ %s = το path του αρχείου
    # αν αποτύχει → ΔΕΝ αντικαθίσταται το αρχείο!

    # ── SELinux (RedHat) ──────────────────────
    setype: httpd_config_t          # SELinux context

    # ── Encoding ──────────────────────────────
    encoding: utf-8                 # default: utf-8

    # ── Force ─────────────────────────────────
    force: true                     # πάντα αντικατάσταση
                                    # ακόμα κι αν ίδιο
```

## Validation — Πολύ σημαντικό!

```yaml
tasks:

  # ── nginx validation ──────────────────────
  - name: Deploy nginx config
    ansible.builtin.template:
      src:      templates/nginx.conf.j2
      dest:     /etc/nginx/nginx.conf
      validate: nginx -t -c %s      # ← έλεγχος σύνταξης
      backup:   true
    notify: Restart nginx

  # ── sshd validation ───────────────────────
  - name: Deploy sshd config
    ansible.builtin.template:
      src:      templates/sshd_config.j2
      dest:     /etc/ssh/sshd_config
      validate: sshd -t -f %s       # ← έλεγχος σύνταξης
      backup:   true
      mode:     '0600'
    notify: Restart SSH

  # ── sudoers validation ────────────────────
  - name: Deploy sudoers
    ansible.builtin.template:
      src:      templates/sudoers.j2
      dest:     /etc/sudoers
      validate: visudo -cf %s       # ← ΚΡΙΣΙΜΟ για sudoers!
      mode:     '0440'

  # ── Apache validation ─────────────────────
  - name: Deploy Apache config
    ansible.builtin.template:
      src:      templates/apache.conf.j2
      dest:     /etc/apache2/apache2.conf
      validate: apache2ctl -t -f %s
      backup:   true
    notify: Restart Apache
```

> ⚠️ **Γιατί Validation:**
> ```
> Χωρίς validate:
> → Λάθος config deploy → service crash → downtime! ❌
>
> Με validate:
> → Έλεγχος config ΠΡΙΝ deploy
> → Αν λάθος → ΔΕΝ αντικαθίσταται → service τρέχει! ✅
> ```

## src Path — Πού ψάχνει η Ansible

```
ansible/
├── playbooks/
│   └── myplaybook.yml
└── templates/
    └── nginx.conf.j2
```

```yaml
# Relative path (από τον φάκελο του playbook)
- name: Template
  ansible.builtin.template:
    src: templates/nginx.conf.j2    # ← σχετικό path ✅
    dest: /etc/nginx/nginx.conf

# Absolute path
- name: Template
  ansible.builtin.template:
    src: /home/ansible/ansible/templates/nginx.conf.j2
    dest: /etc/nginx/nginx.conf

# Μόνο όνομα (ψάχνει στο templates/ directory)
- name: Template
  ansible.builtin.template:
    src: nginx.conf.j2              # ← βρίσκει στο templates/ ✅
    dest: /etc/nginx/nginx.conf
```

## Dynamic dest Path

```yaml
vars:
  app_name: myapp
  app_env:  production

tasks:

  # ── Dynamic filename ──────────────────────
  - name: Deploy app config
    ansible.builtin.template:
      src:  templates/app.conf.j2
      dest: "/etc/{{ app_name }}/{{ app_name }}.conf"
      # → /etc/myapp/myapp.conf

  # ── Per-host config ───────────────────────
  - name: Deploy host-specific config
    ansible.builtin.template:
      src:  templates/host.conf.j2
      dest: "/etc/myapp/{{ inventory_hostname }}.conf"
      # → /etc/myapp/nextcloud.conf

  # ── Per-environment config ────────────────
  - name: Deploy environment config
    ansible.builtin.template:
      src:  "templates/{{ app_env }}.conf.j2"
      # → templates/production.conf.j2
      dest: /etc/myapp/config.conf
```

## Template με Loop

```yaml
vars:
  vhosts:
    - name:   site1
      domain: site1.example.com
      port:   80
    - name:   site2
      domain: site2.example.com
      port:   8080

tasks:

  # ── Deploy πολλά config αρχεία με loop ────
  - name: Deploy vhost configs
    ansible.builtin.template:
      src:  templates/vhost.conf.j2
      dest: "/etc/nginx/sites-available/{{ item.name }}.conf"
      mode: '0644'
    loop: "{{ vhosts }}"
    loop_control:
      label: "{{ item.name }}"
    notify: Reload nginx

  # ── Enable vhosts (symlink) ───────────────
  - name: Enable vhosts
    ansible.builtin.file:
      src:   "/etc/nginx/sites-available/{{ item.name }}.conf"
      dest:  "/etc/nginx/sites-enabled/{{ item.name }}.conf"
      state: link
    loop: "{{ vhosts }}"
    loop_control:
      label: "{{ item.name }}"
    notify: Reload nginx
```

```jinja
{# templates/vhost.conf.j2 #}
server {
    listen      {{ item.port }};
    server_name {{ item.domain }};
    root        /var/www/{{ item.name }};
    index       index.html;

    access_log  /var/log/nginx/{{ item.name }}_access.log;
    error_log   /var/log/nginx/{{ item.name }}_error.log;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

## Έλεγχος αλλαγών — diff Mode

```bash
# Δες τι θα αλλάξει στα templates ΠΡΙΝ deploy
ansible-playbook playbooks/myplaybook.yml \
    --check --diff \
    --limit nextcloud
```

```diff
TASK [Deploy nginx config] **************
--- before: /etc/nginx/nginx.conf
+++ after: /etc/nginx/nginx.conf
@@ -1,5 +1,5 @@
 worker_processes 4;
-listen 80;
+listen 8080;
 server_name nextcloud;
```

> 💡 **Το `--diff` flag** με templates είναι **εξαιρετικά χρήσιμο** — βλέπεις ακριβώς τι θα αλλάξει στο config αρχείο πριν το deploy!

## Πλήρες παράδειγμα

```yaml
---
# template-demo.yml

- name: Template Module Demo
  hosts: debian_based
  become: true
  gather_facts: true

  vars:
    app_name:    mywebapp
    http_port:   80
    https_port:  443
    ssl_enabled: false
    web_root:    "/var/www/{{ app_name }}"
    workers:     "{{ ansible_facts['processor_vcpus'] }}"

    vhosts:
      - name:    mywebapp
        domain:  "{{ inventory_hostname }}"
        port:    "{{ http_port }}"
        root:    "{{ web_root }}"

  tasks:

    # ── Εγκατάσταση nginx ─────────────────────
    - name: Εγκατάσταση nginx
      ansible.builtin.apt:
        name:         nginx
        state:        present
        update_cache: true

    # ── Δημιουργία directories ────────────────
    - name: Δημιουργία web root
      ansible.builtin.file:
        path:  "{{ web_root }}"
        state: directory
        mode:  '0755'
        owner: www-data
        group: www-data

    # ── Deploy templates ──────────────────────
    - name: Deploy nginx.conf
      ansible.builtin.template:
        src:      templates/nginx.conf.j2
        dest:     /etc/nginx/nginx.conf
        owner:    root
        group:    root
        mode:     '0644'
        backup:   true
        validate: nginx -t -c %s
      notify: Restart nginx

    - name: Deploy vhost config
      ansible.builtin.template:
        src:    templates/vhost.conf.j2
        dest:   "/etc/nginx/sites-available/{{ item.name }}.conf"
        mode:   '0644'
        backup: true
      loop: "{{ vhosts }}"
      loop_control:
        label: "{{ item.name }}"
      notify: Reload nginx

    - name: Enable vhosts
      ansible.builtin.file:
        src:   "/etc/nginx/sites-available/{{ item.name }}.conf"
        dest:  "/etc/nginx/sites-enabled/{{ item.name }}.conf"
        state: link
      loop: "{{ vhosts }}"
      loop_control:
        label: "{{ item.name }}"
      notify: Reload nginx

    # ── Deploy index.html ─────────────────────
    - name: Deploy index.html
      ansible.builtin.template:
        src:   templates/index.html.j2
        dest:  "{{ web_root }}/index.html"
        owner: www-data
        group: www-data
        mode:  '0644'

    # ── Flush & verify ────────────────────────
    - name: Flush handlers
      ansible.builtin.meta: flush_handlers

    - name: Έλεγχος nginx
      ansible.builtin.uri:
        url:         "http://localhost:{{ http_port }}"
        status_code: 200
      register: nginx_check

    - name: Αποτέλεσμα
      ansible.builtin.debug:
        msg: "nginx: {{ nginx_check.status }} ✅"

  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"

    - name: Reload nginx
      ansible.builtin.service:
        name:  nginx
        state: reloaded
      ignore_errors: "{{ ansible_check_mode }}"
```

```bash
# Δημιουργία templates
mkdir -p ~/ansible/templates
```

```jinja
{# templates/nginx.conf.j2 #}
{# Generated by Ansible — DO NOT EDIT! #}
user www-data;
worker_processes {{ workers | default(ansible_facts['processor_vcpus']) }};
pid /run/nginx.pid;

events {
    worker_connections 768;
}

http {
    sendfile on;
    tcp_nopush on;
    types_hash_max_size 2048;

    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    access_log /var/log/nginx/access.log;
    error_log  /var/log/nginx/error.log;

    gzip on;

    include /etc/nginx/conf.d/*.conf;
    include /etc/nginx/sites-enabled/*;
}

## Σύνοψη 11.3

```
template Module
├── Παράμετροι:
│   ├── src      → template στον controller (.j2)
│   ├── dest     → destination στον server
│   ├── owner/group/mode → permissions
│   ├── backup   → backup πριν αντικατάσταση ✅
│   └── validate → έλεγχος ΠΡΙΝ deploy ✅✅
│
├── src path:
│   ├── Relative από playbook directory
│   └── templates/ directory (auto-search)
│
├── Dynamic paths:
│   └── dest: "/etc/{{ app_name }}/config.conf"
│
├── Loop + template:
│   └── πολλά config αρχεία από ένα template
│
└── --diff flag:
    └── βλέπεις αλλαγές ΠΡΙΝ deploy
```
