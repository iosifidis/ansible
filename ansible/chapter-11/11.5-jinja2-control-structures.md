# 11.5 Jinja2 Control Structures 🔀

## Τι είναι τα Control Structures;

Είναι οι **δομές ελέγχου** του Jinja2 — if/else και for loops — που κάνουν τα templates **δυναμικά**:

```jinja
{% if condition %}   ← απόφαση
{% for item in list %}  ← επανάληψη
{% set variable = value %}  ← ορισμός μεταβλητής
```

---

## if / elif / else

### Βασική δομή:
```jinja
{% if condition %}
  κείμενο αν true
{% elif other_condition %}
  κείμενο αν other_condition
{% else %}
  κείμενο αν false
{% endif %}
```

### Παραδείγματα:
```jinja
{# ── Απλό if ─────────────────────────────── #}
{% if ssl_enabled %}
ssl_certificate     /etc/ssl/certs/{{ app_name }}.crt;
ssl_certificate_key /etc/ssl/private/{{ app_name }}.key;
{% endif %}

{# ── if/else ─────────────────────────────── #}
{% if app_env == 'production' %}
log_level = error;
debug     = false;
{% else %}
log_level = debug;
debug     = true;
{% endif %}

{# ── if/elif/else ────────────────────────── #}
{% if ansible_facts['os_family'] == 'Debian' %}
package_manager = apt
service_manager = systemd
{% elif ansible_facts['os_family'] == 'RedHat' %}
package_manager = dnf
service_manager = systemd
{% elif ansible_facts['os_family'] == 'Suse' %}
package_manager = zypper
service_manager = systemd
{% else %}
package_manager = unknown
service_manager = unknown
{% endif %}

{# ── Nested if ────────────────────────────── #}
{% if ssl_enabled %}
  {% if ssl_redirect %}
  return 301 https://$host$request_uri;
  {% else %}
  listen 80;
  {% endif %}
{% endif %}
```

## if με Λογικούς Τελεστές

```jinja
{# ── AND ────────────────────────────────── #}
{% if ssl_enabled and ssl_cert is defined %}
ssl_certificate {{ ssl_cert }};
{% endif %}

{# ── OR ─────────────────────────────────── #}
{% if app_env == 'production' or app_env == 'staging' %}
error_reporting = minimal;
{% endif %}

{# ── NOT ────────────────────────────────── #}
{% if not debug_mode %}
access_log off;
{% endif %}

{# ── Σύνθετη συνθήκη ──────────────────────── #}
{% if (ssl_enabled and ssl_cert is defined)
      or (app_env == 'production') %}
strict_transport_security = true;
{% endif %}

{# ── is defined / is not defined ─────────── #}
{% if custom_port is defined %}
listen {{ custom_port }};
{% else %}
listen 80;
{% endif %}

{# ── in operator ─────────────────────────── #}
{% if inventory_hostname in groups['webservers'] %}
role = webserver;
{% endif %}

{# ── Σύγκριση αριθμών ──────────────────── #}
{% if ansible_facts['memtotal_mb'] | int >= 4096 %}
worker_processes {{ ansible_facts['processor_vcpus'] | int * 2 }};
{% else %}
worker_processes {{ ansible_facts['processor_vcpus'] | int }};
{% endif %}
```

## for Loops

### Βασική δομή:
```jinja
{% for item in list %}
  {{ item }}
{% endfor %}
```

### Παραδείγματα:
```jinja
{# ── Απλό loop ───────────────────────────── #}
{% for package in common_packages %}
{{ package }}
{% endfor %}

{# ── Loop με dictionary ───────────────────── #}
{% for vhost in vhosts %}
server {
    listen      {{ vhost.port }};
    server_name {{ vhost.domain }};
    root        {{ vhost.root }};
}
{% endfor %}

{# ── Loop με index ───────────────────────── #}
{% for server in upstream_servers %}
server {{ server.ip }}:{{ server.port }} weight={{ loop.index }};
{% endfor %}

{# ── Loop με if (φιλτράρισμα) ────────────── #}
{% for user in users %}
{% if user.enabled %}
{{ user.name }}:{{ user.password }}:{{ user.uid }}:{{ user.gid }}
{% endif %}
{% endfor %}
```

## Loop Special Variables

Μέσα σε κάθε for loop έχεις πρόσβαση στις **loop variables**:

```jinja
{% for item in my_list %}
  loop.index    = {{ loop.index }}    ← 1,2,3... (1-based)
  loop.index0   = {{ loop.index0 }}   ← 0,1,2... (0-based)
  loop.revindex = {{ loop.revindex }} ← count down (1-based)
  loop.first    = {{ loop.first }}    ← true αν πρώτο
  loop.last     = {{ loop.last }}     ← true αν τελευταίο
  loop.length   = {{ loop.length }}   ← μέγεθος λίστας
  loop.depth    = {{ loop.depth }}    ← βάθος nested loop
{% endfor %}
```

### Πρακτικά:
```jinja
{# ── Comma separated (χωρίς τελευταίο comma) #}
{% for server in servers %}
{{ server.ip }}{{ ',' if not loop.last else '' }}
{% endfor %}
{# → 192.168.1.10,192.168.1.11,192.168.1.12 #}

{# ── Αρίθμηση από 1 ──────────────────────── #}
{% for item in items %}
{{ loop.index }}. {{ item }}
{% endfor %}
{# → 1. nginx
       2. mysql
       3. redis #}

{# ── First/Last special treatment ────────── #}
{% for server in upstream_servers %}
{% if loop.first %}
# Primary server
{% elif loop.last %}
# Backup server
{% else %}
# Secondary server
{% endif %}
server {{ server.ip }}:{{ server.port }};
{% endfor %}
```

## for με else

```jinja
{# else εκτελείται αν η λίστα είναι κενή #}
{% for user in admin_users %}
{{ user.name }} ALL=(ALL) NOPASSWD: ALL
{% else %}
{# Δεν υπάρχουν admin users! #}
# WARNING: No admin users defined!
{% endfor %}
```

## Nested Loops

```jinja
{# ── Nested for loops ────────────────────── #}
{% for host in groups['webservers'] %}
{% for port in [80, 443, 8080] %}
{{ host }}:{{ port }}
{% endfor %}
{% endfor %}

{# ── Vhosts με locations ─────────────────── #}
{% for vhost in vhosts %}
server {
    listen      {{ vhost.port }};
    server_name {{ vhost.domain }};

    {% for location in vhost.locations %}
    location {{ location.path }} {
        proxy_pass {{ location.backend }};
    }
    {% endfor %}
}
{% endfor %}
```

## set — Ορισμός μεταβλητών

```jinja
{# ── Απλός ορισμός ───────────────────────── #}
{% set max_workers = ansible_facts['processor_vcpus'] | int * 2 %}
worker_processes {{ max_workers }};

{# ── Conditional ορισμός ─────────────────── #}
{% set log_level = 'debug' if app_env != 'production' else 'error' %}
log_level = {{ log_level }};

{# ── Υπολογισμός ─────────────────────────── #}
{% set total_ram_gb = (ansible_facts['memtotal_mb'] / 1024) | round(1) %}
{# Available RAM: {{ total_ram_gb }}GB #}

{% set worker_memory = (ansible_facts['memtotal_mb'] * 0.75 / workers) | int %}
worker_memory_limit = {{ worker_memory }}M;

{# ── List ορισμός ─────────────────────────── #}
{% set allowed_ips = ['127.0.0.1', '::1'] %}
{% if admin_ips is defined %}
{% set allowed_ips = allowed_ips + admin_ips %}
{% endif %}
{% for ip in allowed_ips %}
allow {{ ip }};
{% endfor %}
deny all;
```

## Πλήρες παράδειγμα — nginx.conf.j2

```jinja
{# templates/nginx_full.conf.j2 #}
{# ============================================================
   Nginx Configuration
   Generated by Ansible for {{ inventory_hostname }}
   OS: {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}
   ============================================================ #}

{# ── Υπολογισμός workers ──────────────────── #}
{% set cpu_count = ansible_facts['processor_vcpus'] | int %}
{% set ram_mb    = ansible_facts['memtotal_mb']     | int %}
{% set workers   = cpu_count if ram_mb >= 2048 else (cpu_count // 2) | max(1) %}

user www-data;
worker_processes {{ workers }};
pid /run/nginx.pid;

events {
{%- if ram_mb >= 4096 %}
    worker_connections 2048;
{%- elif ram_mb >= 2048 %}
    worker_connections 1024;
{%- else %}
    worker_connections 512;
{%- endif %}
    multi_accept on;
}

http {
    sendfile    on;
    tcp_nopush  on;
    tcp_nodelay on;
    keepalive_timeout {{ keepalive_timeout | default(65) }};

    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    {# ── Logging ──────────────────────────── #}
    {% if app_env == 'production' %}
    access_log /var/log/nginx/access.log;
    error_log  /var/log/nginx/error.log warn;
    {% else %}
    access_log /var/log/nginx/access.log;
    error_log  /var/log/nginx/error.log debug;
    {% endif %}

    {# ── Gzip ────────────────────────────── #}
    gzip on;
    gzip_types text/plain text/css application/json
               application/javascript text/xml;

    {# ── Virtual Hosts ────────────────────── #}
    {% for vhost in vhosts | default([]) %}
    server {
        {# ── Basic settings ───────────────── #}
        server_name {{ vhost.domains | join(' ') }};
        root        {{ vhost.root | default('/var/www/html') }};
        index       index.html index.php;

        {# ── Listen ports ─────────────────── #}
        {% if vhost.ssl | default(false) %}
        listen 443 ssl http2;
        listen [::]:443 ssl http2;

        ssl_certificate     {{ vhost.ssl_cert }};
        ssl_certificate_key {{ vhost.ssl_key  }};
        ssl_protocols       {{ ssl_protocols | default(['TLSv1.2','TLSv1.3']) | join(' ') }};

        {# ── HTTP redirect ────────────────── #}
        {% if vhost.redirect_http | default(true) %}
        if ($scheme != "https") {
            return 301 https://$host$request_uri;
        }
        {% endif %}

        {% else %}
        listen 80;
        listen [::]:80;
        {% endif %}

        {# ── Locations ────────────────────── #}
        {% for location in vhost.locations | default([{'path': '/', 'type': 'static'}]) %}
        location {{ location.path }} {
            {% if location.type == 'proxy' %}
            proxy_pass         {{ location.backend }};
            proxy_set_header   Host $host;
            proxy_set_header   X-Real-IP $remote_addr;
            {% elif location.type == 'php' %}
            fastcgi_pass       unix:/run/php/php8.1-fpm.sock;
            fastcgi_index      index.php;
            include            fastcgi_params;
            {% else %}
            try_files          $uri $uri/ =404;
            {% endif %}
        }
        {% endfor %}

        {# ── Logging per vhost ────────────── #}
        access_log /var/log/nginx/{{ vhost.name }}_access.log;
        error_log  /var/log/nginx/{{ vhost.name }}_error.log;

        {# ── IP restrictions ──────────────── #}
        {% if vhost.allowed_ips is defined and vhost.allowed_ips | length > 0 %}
        {% for ip in vhost.allowed_ips %}
        allow {{ ip }};
        {% endfor %}
        deny all;
        {% endif %}
    }
    {% endfor %}

    include /etc/nginx/conf.d/*.conf;
}
```

### Variables για το template:
```yaml
# vars για το nginx_full.conf.j2
app_env:           production
keepalive_timeout: 65

vhosts:
  - name:    myapp
    domains:
      - myapp.example.com
      - www.myapp.example.com
    root:    /var/www/myapp
    ssl:     false
    locations:
      - path:    /
        type:    static
      - path:    /api
        type:    proxy
        backend: http://localhost:3000

  - name:    admin
    domains:
      - admin.example.com
    root:        /var/www/admin
    ssl:         true
    ssl_cert:    /etc/ssl/certs/admin.crt
    ssl_key:     /etc/ssl/private/admin.key
    allowed_ips:
      - 192.168.1.0/24
      - 10.0.0.1
    locations:
      - path: /
        type: static
```

## Σύνοψη 11.5

```
Jinja2 Control Structures
├── if/elif/else:
│   ├── {% if condition %}...{% endif %}
│   ├── Operators: and, or, not, in, is defined
│   └── Nested if υποστηρίζεται
│
├── for loops:
│   ├── {% for item in list %}...{% endfor %}
│   ├── Loop variables:
│   │   ├── loop.index   → 1-based counter
│   │   ├── loop.index0  → 0-based counter
│   │   ├── loop.first   → πρώτο στοιχείο
│   │   ├── loop.last    → τελευταίο στοιχείο
│   │   └── loop.length  → μέγεθος λίστας
│   ├── for/else → αν λίστα κενή
│   └── Nested loops υποστηρίζονται
│
├── set:
│   └── {% set var = value %}
│
└── Whitespace control:
    └── {%- -%} αφαιρεί περιττά κενά
```
