# 11.2 Jinja2 Βασική σύνταξη 📝

## Τα 3 βασικά Delimiters

```jinja
{{ }}   ← Expressions  — εμφάνιση τιμών/μεταβλητών
{% %}   ← Statements   — λογική (if, for, set)
{# #}   ← Comments     — σχόλια (δεν εμφανίζονται)
```

---

## 1. Expressions `{{ }}`

Χρησιμοποιούνται για **εμφάνιση τιμών**:

```jinja
{# Απλές μεταβλητές #}
{{ http_port }}
{{ app_name }}
{{ inventory_hostname }}

{# Ansible Facts #}
{{ ansible_facts['hostname'] }}
{{ ansible_facts['os_family'] }}
{{ ansible_facts['processor_vcpus'] }}
{{ ansible_facts['memtotal_mb'] }}
{{ ansible_facts['default_ipv4']['address'] }}

{# Dictionary access #}
{{ database.host }}
{{ database['port'] }}

{# List access #}
{{ packages[0] }}
{{ packages[-1] }}       ← τελευταίο στοιχείο

{# Expressions #}
{{ http_port + 1 }}      ← αριθμητική
{{ app_name ~ '_log' }}  ← string concatenation (~)
{{ 2 * workers }}        ← πολλαπλασιασμός
```

---

## 2. Statements `{% %}`

Χρησιμοποιούνται για **λογική**:

```jinja
{# if statement #}
{% if condition %}
  κείμενο
{% endif %}

{# for loop #}
{% for item in list %}
  {{ item }}
{% endfor %}

{# set variable #}
{% set my_var = "value" %}

{# import/include #}
{% include 'other_template.j2' %}
```

---

## 3. Comments `{# #}`

```jinja
{# Αυτό είναι σχόλιο — δεν εμφανίζεται στο output #}

{#
   Πολυγραμμικό σχόλιο
   για μεγαλύτερες επεξηγήσεις
#}

# Αυτό ΔΕΝ είναι Jinja2 σχόλιο — εμφανίζεται στο output!
```

---

## Whitespace Control

Ένα κοινό πρόβλημα με Jinja2 είναι τα **περιττά κενά και νέες γραμμές**:

```jinja
{# Χωρίς whitespace control #}
{% if ssl_enabled %}
ssl_certificate /etc/ssl/cert.pem;
{% endif %}

{# Output (με περιττές κενές γραμμές): #}

ssl_certificate /etc/ssl/cert.pem;


{# ΜΕ whitespace control (παύλα -) #}
{%- if ssl_enabled %}
ssl_certificate /etc/ssl/cert.pem;
{%- endif %}

{# Output (καθαρό): #}
ssl_certificate /etc/ssl/cert.pem;
```

```jinja
{# Παύλα στην αρχή → αφαιρεί whitespace ΠΡΙΝ #}
{%- if condition %}

{# Παύλα στο τέλος → αφαιρεί whitespace ΜΕΤΑ #}
{% if condition -%}

{# Και τα δύο #}
{%- if condition -%}
```

## Default Values

```jinja
{# Αν η μεταβλητή δεν υπάρχει → χρησιμοποίησε default #}
{{ http_port | default(80) }}
{{ app_name  | default('myapp') }}
{{ workers   | default(ansible_facts['processor_vcpus']) }}

{# Default αν είναι undefined ή false #}
{{ my_var | default('fallback', boolean=true) }}

{# Παράδειγμα σε template #}
worker_processes {{ workers | default(ansible_facts['processor_vcpus']) }};
listen {{ http_port | default(80) }};
server_name {{ server_name | default(inventory_hostname) }};
```

## Operators

```jinja
{# ── Σύγκριση ────────────────────────────── #}
{{ x == y }}    ← ίσο
{{ x != y }}    ← διαφορετικό
{{ x > y  }}    ← μεγαλύτερο
{{ x < y  }}    ← μικρότερο
{{ x >= y }}    ← μεγαλύτερο ή ίσο
{{ x <= y }}    ← μικρότερο ή ίσο

{# ── Λογικοί ─────────────────────────────── #}
{{ x and y }}   ← και
{{ x or y  }}   ← ή
{{ not x   }}   ← όχι

{# ── Membership ──────────────────────────── #}
{{ 'nginx' in packages }}     ← υπάρχει στη λίστα
{{ 'web' in inventory_hostname }} ← υπάρχει στο string

{# ── Tests ───────────────────────────────── #}
{{ my_var is defined }}       ← είναι ορισμένο
{{ my_var is not defined }}   ← δεν είναι ορισμένο
{{ my_var is string }}        ← είναι string
{{ my_var is number }}        ← είναι αριθμός
{{ my_var is none }}          ← είναι None
```

---

## Inline Conditionals (Ternary)

```jinja
{# Σύντομη μορφή if/else σε μία γραμμή #}
{{ 'yes' if condition else 'no' }}

{# Παραδείγματα #}
{{ 'enabled' if ssl_enabled else 'disabled' }}
{{ 'production' if app_env == 'production' else 'development' }}
{{ workers if workers is defined else ansible_facts['processor_vcpus'] }}

{# Σε config αρχείο #}
ssl {{ 'on' if ssl_enabled else 'off' }};
debug {{ 'true' if app_env != 'production' else 'false' }};
worker_processes {{ ansible_facts['processor_vcpus'] if workers is not defined else workers }};
```

---

## String Operations

```jinja
{# Concatenation με ~ #}
{{ app_name ~ '.log' }}
{{ '/var/log/' ~ app_name ~ '/error.log' }}

{# Upper/Lower #}
{{ app_name | upper }}
{{ app_name | lower }}

{# Replace #}
{{ inventory_hostname | replace('.', '_') }}

{# Split #}
{{ '192.168.1.10' | split('.') }}
{{ '192.168.1.10' | split('.') | first }}   ← '192'
{{ '192.168.1.10' | split('.') | last  }}   ← '10'

{# Strip #}
{{ '  hello  ' | trim }}    ← 'hello'
```

## Πλήρες παράδειγμα Template

```jinja
{# templates/app.conf.j2 #}
{# ============================================================
   Application Configuration
   Generated by Ansible — DO NOT EDIT MANUALLY!
   Host: {{ inventory_hostname }}
   Date: {{ ansible_date_time.date }}
   ============================================================ #}

[app]
name     = {{ app_name | default('myapp') }}
env      = {{ app_env  | default('production') }}
debug    = {{ 'true' if app_env != 'production' else 'false' }}
version  = {{ app_version | default('latest') }}

[server]
host     = {{ ansible_facts['default_ipv4']['address'] }}
port     = {{ http_port | default(8080) }}
workers  = {{ workers   | default(ansible_facts['processor_vcpus']) }}

[database]
host     = {{ db_config.host     | default('localhost') }}
port     = {{ db_config.port     | default(5432) }}
name     = {{ db_config.name     | default(app_name ~ '_db') }}
user     = {{ db_config.user     | default('appuser') }}

[logging]
level    = {{ 'debug' if app_env != 'production' else 'error' }}
path     = /var/log/{{ app_name }}/app.log
max_size = {{ log_max_size | default('100M') }}
```

## Χρήση σε Playbook Variables

Τα Jinja2 expressions δουλεύουν και **μέσα στα playbooks**, όχι μόνο στα templates:

```yaml
vars:
  # ── Expressions σε variables ──────────────
  log_path:    "/var/log/{{ app_name }}/app.log"
  config_path: "/etc/{{ app_name }}/config.conf"
  db_name:     "{{ app_name }}_{{ app_env }}"

tasks:
  # ── Expressions σε task arguments ─────────
  - name: Δημιουργία log directory
    ansible.builtin.file:
      path:  "{{ log_path }}"
      state: directory

  - name: Εμφάνιση πληροφοριών
    ansible.builtin.debug:
      msg: >
        Server {{ inventory_hostname }}
        τρέχει {{ ansible_facts['distribution'] }}
        με {{ ansible_facts['processor_vcpus'] }} CPUs
        και {{ ansible_facts['memtotal_mb'] }}MB RAM

  # ── Conditionals σε when ──────────────────
  - name: Task μόνο αν enough RAM
    ansible.builtin.debug:
      msg: "Αρκετή RAM!"
    when: ansible_facts['memtotal_mb'] | int >= 1024
```

## Σύνοψη 11.2

```
Jinja2 Βασική Σύνταξη
├── Delimiters:
│   ├── {{ }} → expressions (τιμές/μεταβλητές)
│   ├── {% %} → statements (if, for, set)
│   └── {# #} → comments
│
├── Whitespace control:
│   └── παύλα (-) αφαιρεί περιττά κενά/newlines
│
├── Default values:
│   └── {{ var | default(value) }}
│
├── Operators:
│   ├── Σύγκριση: == != > < >= <=
│   ├── Λογικοί: and, or, not
│   ├── Membership: in, not in
│   └── Tests: is defined, is string, is number
│
├── Inline conditional:
│   └── {{ 'yes' if condition else 'no' }}
│
└── String ops:
    ├── ~ concatenation
    ├── | upper/lower/replace/trim
    └── | split('.') | first/last
```
