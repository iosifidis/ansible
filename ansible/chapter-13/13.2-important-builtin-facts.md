# 13.2 Σημαντικά Built-in Facts 📋

## Κατηγορίες Facts

```
ansible_facts
├── System      → OS, hostname, timezone
├── Hardware    → CPU, RAM, disk
├── Network     → interfaces, IPs, DNS
├── Date/Time   → current date, time
└── Environment → Python, packages
```

---

## System Facts

```yaml
tasks:
  - name: System Facts
    ansible.builtin.debug:
      msg:
        # ── OS Info ───────────────────────────
        - "Distribution    : {{ ansible_facts['distribution'] }}"
        # → Debian, Ubuntu, Rocky, Fedora, openSUSE

        - "Version         : {{ ansible_facts['distribution_version'] }}"
        # → 12.13, 22.04, 9.3 κλπ

        - "Major Version   : {{ ansible_facts['distribution_major_version'] }}"
        # → 12, 22, 9 (μόνο ο κύριος αριθμός)

        - "Release         : {{ ansible_facts['distribution_release'] }}"
        # → bookworm, jammy, plow κλπ

        - "OS Family       : {{ ansible_facts['os_family'] }}"
        # → Debian, RedHat, Suse, Archlinux

        - "OS Type         : {{ ansible_facts['system'] }}"
        # → Linux, FreeBSD, Darwin (macOS)

        # ── Hostname ──────────────────────────
        - "Hostname        : {{ ansible_facts['hostname'] }}"
        # → nextcloud (short)

        - "FQDN            : {{ ansible_facts['fqdn'] }}"
        # → nextcloud.example.com (full)

        - "Nodename        : {{ ansible_facts['nodename'] }}"
        # → nextcloud

        # ── Kernel ────────────────────────────
        - "Kernel          : {{ ansible_facts['kernel'] }}"
        # → 6.1.0-41-amd64

        - "Kernel Version  : {{ ansible_facts['kernel_version'] }}"
        # → #1 SMP PREEMPT_DYNAMIC

        # ── Python ────────────────────────────
        - "Python Version  : {{ ansible_facts['python_version'] }}"
        # → 3.11.2

        - "Python Path     : {{ ansible_facts['python']['executable'] }}"
        # → /usr/bin/python3

        # ── Package Manager ───────────────────
        - "Pkg Manager     : {{ ansible_facts['pkg_mgr'] }}"
        # → apt, dnf, zypper

        # ── Service Manager ───────────────────
        - "Service Manager : {{ ansible_facts['service_mgr'] }}"
        # → systemd, sysvinit
```

## Hardware Facts

```yaml
tasks:
  - name: Hardware Facts
    ansible.builtin.debug:
      msg:
        # ── CPU ───────────────────────────────
        - "Architecture    : {{ ansible_facts['architecture'] }}"
        # → x86_64, aarch64, armv7l

        - "vCPUs           : {{ ansible_facts['processor_vcpus'] }}"
        # → 4 (virtual CPUs)

        - "CPU Count       : {{ ansible_facts['processor_count'] }}"
        # → 1 (physical sockets)

        - "Cores per Socket: {{ ansible_facts['processor_cores'] }}"
        # → 4

        - "CPU Model       : {{ ansible_facts['processor'][0] }}"
        # → Intel(R) Xeon(R) CPU E5-2650 v2

        # ── Memory ────────────────────────────
        - "Total RAM       : {{ ansible_facts['memtotal_mb'] }}MB"
        # → 1976MB

        - "Free RAM        : {{ ansible_facts['memfree_mb'] }}MB"
        # → 386MB

        - "Total Swap      : {{ ansible_facts['swaptotal_mb'] }}MB"
        # → 987MB

        - "Free Swap       : {{ ansible_facts['swapfree_mb'] }}MB"
        # → 986MB

        # ── RAM σε GB (με filter) ─────────────
        - "RAM (GB)        : {{ (ansible_facts['memtotal_mb'] / 1024) | round(1) }}GB"

# ── Disk Facts ────────────────────────────────
  - name: Disk Facts
    ansible.builtin.debug:
      msg: >
        Mount: {{ item.mount }}
        Size : {{ (item.size_total / 1073741824) | round(1) }}GB
        Free : {{ (item.size_available / 1073741824) | round(1) }}GB
        Used%: {{ ((item.size_total - item.size_available)
                   / item.size_total * 100) | round(1) }}%
    loop: "{{ ansible_facts['mounts'] }}"
    when: item.mount == '/'    # ← μόνο root
    loop_control:
      label: "{{ item.mount }}"
```

## Network Facts

```yaml
tasks:
  - name: Network Facts
    ansible.builtin.debug:
      msg:
        # ── Default Interface ─────────────────
        - "Default IP      : {{ ansible_facts['default_ipv4']['address'] }}"
        # → 192.212.104.27

        - "Default GW      : {{ ansible_facts['default_ipv4']['gateway'] }}"
        # → 83.212.104.1

        - "Default IF      : {{ ansible_facts['default_ipv4']['interface'] }}"
        # → eth0, ens3, eth1

        - "MAC Address     : {{ ansible_facts['default_ipv4']['macaddress'] }}"
        # → fa:16:3e:xx:xx:xx

        - "Network         : {{ ansible_facts['default_ipv4']['network'] }}"
        # → 83.212.104.0

        - "Netmask         : {{ ansible_facts['default_ipv4']['netmask'] }}"
        # → 255.255.254.0

        # ── IPv6 ──────────────────────────────
        - "Default IPv6    : {{ ansible_facts['default_ipv6']['address'] | default('N/A') }}"

        # ── DNS ───────────────────────────────
        - "DNS Servers     : {{ ansible_facts['dns']['nameservers'] | join(', ') }}"
        # → 8.8.8.8, 8.8.4.4

        # ── All Interfaces ────────────────────
        - "Interfaces      : {{ ansible_facts['interfaces'] | join(', ') }}"
        # → lo, eth0, eth1

# ── Per Interface Details ─────────────────────
  - name: Interface details
    ansible.builtin.debug:
      msg:
        - "Interface: {{ item }}"
        - "IP: {{ ansible_facts['ansible_' + item]['ipv4']['address']
                  | default('N/A') }}"
        - "MAC: {{ ansible_facts['ansible_' + item]['macaddress']
                   | default('N/A') }}"
    loop: "{{ ansible_facts['interfaces'] }}"
    when:
      - item != 'lo'
      - ansible_facts['ansible_' + item]['ipv4'] is defined
    loop_control:
      label: "{{ item }}"
```

## Date & Time Facts

```yaml
tasks:
  - name: DateTime Facts
    ansible.builtin.debug:
      msg:
        # ── Date ──────────────────────────────
        - "Date            : {{ ansible_facts['date_time']['date'] }}"
        # → 2026-01-15

        - "Time            : {{ ansible_facts['date_time']['time'] }}"
        # → 14:30:25

        - "DateTime        : {{ ansible_facts['date_time']['iso8601'] }}"
        # → 2026-01-15T14:30:25Z

        - "Epoch           : {{ ansible_facts['date_time']['epoch'] }}"
        # → 1736951425

        - "Weekday         : {{ ansible_facts['date_time']['weekday'] }}"
        # → Wednesday

        - "Year            : {{ ansible_facts['date_time']['year'] }}"
        - "Month           : {{ ansible_facts['date_time']['month'] }}"
        - "Day             : {{ ansible_facts['date_time']['day'] }}"
        - "Hour            : {{ ansible_facts['date_time']['hour'] }}"
        - "Minute          : {{ ansible_facts['date_time']['minute'] }}"

        # ── Timezone ──────────────────────────
        - "Timezone        : {{ ansible_facts['date_time']['tz'] }}"
        # → UTC, EET

        - "TZ Offset       : {{ ansible_facts['date_time']['tz_offset'] }}"
        # → +0000, +0200
```

## Environment & Virtualization Facts

```yaml
tasks:
  - name: Environment Facts
    ansible.builtin.debug:
      msg:
        # ── Virtualization ────────────────────
        - "Virt Type       : {{ ansible_facts['virtualization_type'] | default('N/A') }}"
        # → kvm, vmware, virtualbox, docker, xen, N/A (bare metal)

        - "Virt Role       : {{ ansible_facts['virtualization_role'] | default('N/A') }}"
        # → guest, host

        - "Is Virtual      : {{ ansible_facts['virtualization_type'] is defined
                                 and ansible_facts['virtualization_type'] != 'NA' }}"

        # ── Environment Variables ─────────────
        - "HOME            : {{ ansible_facts['env']['HOME'] }}"
        - "PATH            : {{ ansible_facts['env']['PATH'] }}"
        - "USER            : {{ ansible_facts['env']['USER'] }}"

        # ── Selinux (RedHat) ──────────────────
        - "SELinux         : {{ ansible_facts['selinux']['status'] | default('N/A') }}"
        # → enabled, disabled, N/A (non-RedHat)
```

## Χρήσιμα Facts Patterns

```yaml
tasks:

  # ── Conditional βάσει OS ──────────────────
  - name: Debian-only task
    ansible.builtin.apt:
      name: python3-apt
      state: present
    when: ansible_facts['os_family'] == "Debian"

  # ── Conditional βάσει έκδοσης ─────────────
  - name: Debian 12+ only
    ansible.builtin.debug:
      msg: "Debian Bookworm ή νεότερο!"
    when:
      - ansible_facts['distribution'] == "Debian"
      - ansible_facts['distribution_major_version'] | int >= 12

  # ── Conditional βάσει RAM ─────────────────
  - name: High memory config
    ansible.builtin.template:
      src:  templates/high_mem.conf.j2
      dest: /etc/myapp/performance.conf
    when: ansible_facts['memtotal_mb'] | int >= 4096

  # ── Conditional βάσει αρχιτεκτονικής ──────
  - name: ARM-specific task
    ansible.builtin.debug:
      msg: "Running on ARM!"
    when: ansible_facts['architecture'] == "aarch64"

  # ── Dynamic workers βάσει CPU ─────────────
  - name: Set worker count
    ansible.builtin.set_fact:
      nginx_workers: "{{ ansible_facts['processor_vcpus'] | int }}"

  # ── Dynamic memory config ─────────────────
  - name: Set memory limits
    ansible.builtin.set_fact:
      app_memory_limit: >-
        {{ (ansible_facts['memtotal_mb'] * 0.75) | int }}M
```

│             kernel, pkg_mgr, service_mgr

│             memtotal_mb, memfree_mb, mounts

              selinux (RedHat)

├── when: ansible_facts['os_family'] == "Debian"
