# 13.3 Custom Facts 🔧

## Τι είναι τα Custom Facts;

Εκτός από τα **built-in facts** που συλλέγει αυτόματα η Ansible, μπορείς να ορίσεις **δικά σου facts** — πληροφορίες ειδικές για το environment σου που η Ansible δεν ξέρει από μόνη της.

> 📝 **Παραδείγματα Custom Facts:**
> ```
> ├── Ποια έκδοση της εφαρμογής σου είναι εγκατεστημένη
> ├── Αν ένα custom service τρέχει
> ├── Deployment metadata (πότε, ποιος έκανε deploy)
> └── Business-specific πληροφορίες
> ```

---

## Πώς Λειτουργούν τα Custom Facts

```
┌─────────────────────────────────────────────────────────┐
│  Managed Server                                         │
│                                                         │
│  /etc/ansible/facts.d/          ← ειδικός φάκελος       │
│  ├── myapp.fact                 ← INI format            │
│  ├── system_info.fact           ← INI format            │
│  └── deployment.fact            ← JSON format           │
│           │                                             │
│           ▼                                             │
│  Ansible setup module τα διαβάζει αυτόματα!             │
│           │                                             │
│           ▼                                             │
│  ansible_facts['ansible_local']['myapp']                │
│                    ↑                                    │
│                    └── 'ansible_local' namespace        │
└─────────────────────────────────────────────────────────┘
```

## Τύποι Custom Facts Files

```
┌─────────────────────────────────────────────────────────┐
│  Τύπος 1: INI format (.fact αρχείο)                     │
│  Απλό, κατανοητό, στατικό                               │
├─────────────────────────────────────────────────────────┤
│  Τύπος 2: JSON format (.fact αρχείο)                    │
│  Δομημένο, υποστηρίζει nested data                      │
├─────────────────────────────────────────────────────────┤
│  Τύπος 3: Executable script (.fact εκτελέσιμο)          │
│  Δυναμικό, τρέχει κάθε φορά                             │
└─────────────────────────────────────────────────────────┘
```

---

## Τύπος 1: INI Format

```ini
# /etc/ansible/facts.d/myapp.fact
[application]
name    = mywebapp
version = 2.1.4
env     = production
port    = 8080

[deployment]
date    = 2026-01-15
user    = deploy
method  = ansible
```

```yaml
# Πρόσβαση:
ansible_facts['ansible_local']['myapp']['application']['name']
# → mywebapp

ansible_facts['ansible_local']['myapp']['application']['version']
# → 2.1.4

ansible_facts['ansible_local']['myapp']['deployment']['date']
# → 2026-01-15
```

## Τύπος 3: Executable Script

```bash
#!/bin/bash
# /etc/ansible/facts.d/system_status.fact
# ← πρέπει να είναι εκτελέσιμο (chmod +x)
# ← πρέπει να επιστρέφει JSON!

APP_VERSION=$(cat /opt/myapp/VERSION 2>/dev/null || echo "unknown")
APP_STATUS=$(systemctl is-active myapp 2>/dev/null || echo "inactive")
DISK_USAGE=$(df / | tail -1 | awk '{print $5}' | tr -d '%')
LAST_DEPLOY=$(stat -c %Y /opt/myapp 2>/dev/null || echo "0")

cat << EOF
{
  "app_version": "${APP_VERSION}",
  "app_status":  "${APP_STATUS}",
  "disk_usage":  ${DISK_USAGE},
  "last_deploy": ${LAST_DEPLOY}
}
EOF
```

```yaml
# Πρόσβαση:
ansible_facts['ansible_local']['system_status']['app_version']
ansible_facts['ansible_local']['system_status']['app_status']
ansible_facts['ansible_local']['system_status']['disk_usage']
```

> 💡 **Γιατί Executable Facts:**
> ```
> ✅ Δυναμικές πληροφορίες (τρέχουν κάθε φορά)
> ✅ Μπορούν να υπολογίζουν τιμές
> ✅ Μπορούν να ελέγχουν services, files κλπ
> ❌ Πιο αργά (εκτέλεση script)
> ```

## Δημιουργία Custom Facts με Ansible

```yaml
---
# deploy-custom-facts.yml

- name: Deploy Custom Facts
  hosts: all
  become: true
  gather_facts: true

  vars:
    app_name:    mywebapp
    app_version: "2.1.4"
    app_env:     production

  tasks:

    # ── Δημιουργία facts directory ────────────
    - name: Δημιουργία facts.d directory
      ansible.builtin.file:
        path:  /etc/ansible/facts.d
        state: directory
        mode:  '0755'
        owner: root
        group: root

    # ── INI fact αρχείο ───────────────────────
    - name: Deploy application fact (INI)
      ansible.builtin.copy:
        dest:  /etc/ansible/facts.d/application.fact
        mode:  '0644'
        content: |
          [info]
          name    = {{ app_name }}
          version = {{ app_version }}
          env     = {{ app_env }}
          managed = true

          [paths]
          app_dir    = /opt/{{ app_name }}
          config_dir = /etc/{{ app_name }}
          log_dir    = /var/log/{{ app_name }}

          [deployment]
          date   = {{ ansible_facts['date_time']['date'] }}
          time   = {{ ansible_facts['date_time']['time'] }}
          ansible = {{ ansible_version.full }}
      notify: Refresh facts

    # ── JSON fact αρχείο ──────────────────────
    - name: Deploy system fact (JSON)
      ansible.builtin.copy:
        dest:  /etc/ansible/facts.d/system.fact
        mode:  '0644'
        content: |
          {
            "os": {
              "family":       "{{ ansible_facts['os_family'] }}",
              "distribution": "{{ ansible_facts['distribution'] }}",
              "version":      "{{ ansible_facts['distribution_version'] }}"
            },
            "hardware": {
              "cpus":    {{ ansible_facts['processor_vcpus'] }},
              "ram_mb":  {{ ansible_facts['memtotal_mb'] }},
              "arch":    "{{ ansible_facts['architecture'] }}"
            },
            "network": {
              "ip":      "{{ ansible_facts['default_ipv4']['address'] }}",
              "iface":   "{{ ansible_facts['default_ipv4']['interface'] }}"
            }
          }
      notify: Refresh facts

    # ── Executable fact script ─────────────────
    - name: Deploy status fact script
      ansible.builtin.copy:
        dest:  /etc/ansible/facts.d/status.fact
        mode:  '0755'      # ← εκτελέσιμο!
        content: |
          #!/bin/bash
          # Dynamic status fact

          # App version
          APP_VER=$(cat /opt/{{ app_name }}/VERSION \
                    2>/dev/null || echo "not_installed")

          # Service status
          APP_STATUS=$(systemctl is-active {{ app_name }} \
                       2>/dev/null || echo "inactive")

          # Disk usage %
          DISK=$(df / | tail -1 | \
                 awk '{print $5}' | tr -d '%')

          # Uptime seconds
          UPTIME=$(cat /proc/uptime | \
                   awk '{print int($1)}')

          echo "{
            \"app_version\": \"${APP_VER}\",
            \"app_status\":  \"${APP_STATUS}\",
            \"disk_usage\":  ${DISK},
            \"uptime_sec\":  ${UPTIME}
          }"

    # ── Refresh facts ─────────────────────────
    - name: Refresh local facts
      ansible.builtin.setup:
        filter: ansible_local

    # ── Εμφάνιση custom facts ─────────────────
    - name: Εμφάνιση custom facts
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Custom Facts για {{ inventory_hostname }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "App Name   : {{ ansible_facts['ansible_local']['application']['info']['name'] }}"
          - "App Version: {{ ansible_facts['ansible_local']['application']['info']['version'] }}"
          - "Deploy Date: {{ ansible_facts['ansible_local']['application']['deployment']['date'] }}"
          - "OS Family  : {{ ansible_facts['ansible_local']['system']['os']['family'] }}"
          - "RAM MB     : {{ ansible_facts['ansible_local']['system']['hardware']['ram_mb'] }}"
          - "App Status : {{ ansible_facts['ansible_local']['status']['app_status'] | default('N/A') }}"
          - "Disk Usage : {{ ansible_facts['ansible_local']['status']['disk_usage'] | default('N/A') }}%"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

  handlers:

    - name: Refresh facts
      ansible.builtin.setup:
        filter: ansible_local
```

## Χρήση Custom Facts σε Conditionals

```yaml
tasks:

  # ── Conditional βάσει app version ─────────
  - name: Upgrade αν παλιά έκδοση
    ansible.builtin.debug:
      msg: "Χρειάζεται upgrade!"
    when:
      - ansible_facts['ansible_local']['application'] is defined
      - ansible_facts['ansible_local']['application']['info']['version']
        is version('2.0.0', '<')

  # ── Conditional βάσει app status ──────────
  - name: Start app αν δεν τρέχει
    ansible.builtin.service:
      name:  myapp
      state: started
    when:
      - ansible_facts['ansible_local']['status'] is defined
      - ansible_facts['ansible_local']['status']['app_status'] != 'active'

  # ── Conditional βάσει disk usage ──────────
  - name: Προειδοποίηση disk space
    ansible.builtin.debug:
      msg: "⚠️ ΧΑΜΗΛΟΣ ΧΩΡΟΣ ΔΙΣΚΟΥ!"
    when:
      - ansible_facts['ansible_local']['status'] is defined
      - ansible_facts['ansible_local']['status']['disk_usage'] | int > 80
```

## Ανανέωση Facts κατά την εκτέλεση

```yaml
tasks:

  # ── Deploy νέα έκδοση ─────────────────────
  - name: Deploy new app version
    ansible.builtin.copy:
      src:  dist/myapp-2.2.0.tar.gz
      dest: /opt/myapp/myapp-2.2.0.tar.gz

  - name: Update VERSION file
    ansible.builtin.copy:
      content: "2.2.0\n"
      dest:    /opt/myapp/VERSION

  # ── Ανανέωση facts μετά το deploy ─────────
  - name: Refresh custom facts
    ansible.builtin.setup:
      filter: ansible_local
    # ↑ Ξαναδιαβάζει τα .fact αρχεία!

  # ── Τώρα τα facts είναι ενημερωμένα ───────
  - name: Επαλήθευση νέας έκδοσης
    ansible.builtin.debug:
      msg: "New version: {{ ansible_facts['ansible_local']['status']['app_version'] }}"
    # → 2.2.0 ✅
```

## Σύνοψη 13.3

```
Custom Facts
├── Τοποθεσία: /etc/ansible/facts.d/*.fact
├── Namespace: ansible_facts['ansible_local']['filename']
│
├── Τύποι:
│   ├── INI    → [section] key=value (στατικό)
│   ├── JSON   → {"key": "value"} (δομημένο)
│   └── Script → εκτελέσιμο που επιστρέφει JSON
│
├── Δημιουργία:
│   └── ansible.builtin.copy/template → facts.d/
│
├── Ανανέωση:
│   └── ansible.builtin.setup filter=ansible_local
│
└── Χρήση:
    ├── Conditionals βάσει app version/status
    └── Dynamic configuration βάσει custom data
```
