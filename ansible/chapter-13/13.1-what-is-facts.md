# 13.1 Τι είναι τα Facts 📊

## Ο ορισμός

Τα **Facts** είναι **πληροφορίες που συλλέγει αυτόματα η Ansible** από κάθε managed server κατά την εκτέλεση ενός playbook — πριν τρέξει οποιοδήποτε task.

> 📝 **Αναλογία:** Σκέψου τα facts σαν το **"ιατρικό ιστορικό"** ενός server:
> ```
> Γιατρός (Ansible) εξετάζει ασθενή (server) πριν θεραπεία:
> ├── Ηλικία      → ansible_facts['distribution_version']
> ├── Βάρος       → ansible_facts['memtotal_mb']
> ├── Αλλεργίες   → ansible_facts['os_family']
> └── Ομάδα αίματος → ansible_facts['architecture']
> ```

---

## Gathering Facts — Πώς Λειτουργεί

```
┌─────────────────────────────────────────────────────────┐
│  PLAY ξεκινά                                            │
│       │                                                 │
│       ▼                                                 │
│  TASK [Gathering Facts]                                 │
│  → Ansible εκτελεί το setup module                      │
│  → Συνδέεται SSH στον server                            │
│  → Τρέχει Python script                                 │
│  → Συλλέγει ~500+ πληροφορίες                           │
│  → Επιστρέφει JSON                                      │
│       │                                                 │
│       ▼                                                 │
│  Facts αποθηκεύονται στη μνήμη                          │
│  → Διαθέσιμα σε όλα τα tasks του play                   │
│  → Διαθέσιμα μέσω ansible_facts['...']                  │
└─────────────────────────────────────────────────────────┘
```

## Το setup Module

```bash
# Χειροκίνητη εκτέλεση gathering facts
ansible nextcloud -m ansible.builtin.setup

# Output (εκατοντάδες γραμμές!):
# nextcloud | SUCCESS => {
#     "ansible_facts": {
#         "ansible_architecture": "x86_64",
#         "ansible_bios_date": "04/01/2014",
#         "ansible_distribution": "Debian",
#         "ansible_distribution_major_version": "12",
#         ...
#     }
# }

# Φιλτράρισμα — μόνο ό,τι χρειάζεσαι
ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_distribution*"

ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_memory*"

ansible nextcloud -m ansible.builtin.setup \
    -a "filter=ansible_processor*"
```

## gather_facts — Έλεγχος συλλογής

```yaml
# ── Default: gather_facts = true ──────────────
- name: Play με facts (default)
  hosts: all
  # gather_facts: true ← implicit

  tasks:
    - name: Χρησιμοποίησε facts
      ansible.builtin.debug:
        msg: "OS: {{ ansible_facts['distribution'] }}"

# ── Απενεργοποίηση: gather_facts = false ──────
- name: Play χωρίς facts (πιο γρήγορο!)
  hosts: all
  gather_facts: false    # ← παρακάμπτει setup module

  tasks:
    - name: Γρήγορη εντολή
      ansible.builtin.command: uptime
    # ⚠️ Δεν μπορείς να χρησιμοποιήσεις ansible_facts!
```

## gather_subset — Επιλεκτική συλλογή

```yaml
# Συλλογή μόνο συγκεκριμένων facts (πιο γρήγορο)
- name: Selective facts
  hosts: all
  gather_facts: true
  gather_subset:
    - min           # ← ελάχιστα (hardware + network)
    - '!all'        # ← απενεργοποίηση όλων
    - network       # ← μόνο network
    - hardware      # ← μόνο hardware

# Διαθέσιμα subsets:
# all          → όλα (default)
# min          → ελάχιστα
# hardware     → CPU, RAM, disk
# network      → interfaces, IPs
# virtual      → virtualization info
# ohai         → Chef's ohai facts
# facter       → Puppet's facter facts
```

> 💡 **Performance Tip:**
```yaml
 # Αν χρειάζεσαι μόνο OS info:
 gather_subset:
   - '!all'
   - '!min'
   - distribution   # ← μόνο distribution info
 # → πολύ γρηγορότερο!
```

## Πρόσβαση στα Facts

```yaml
tasks:

  # ── Τρόπος 1: ansible_facts dict (συνιστάται) ──
  - name: Modern syntax
    ansible.builtin.debug:
      msg: "{{ ansible_facts['distribution'] }}"

  # ── Τρόπος 2: dot notation ────────────────────
  - name: Dot notation
    ansible.builtin.debug:
      msg: "{{ ansible_facts.distribution }}"

  # ── Τρόπος 3: inject (deprecated!) ───────────
  - name: Old syntax (ΑΠΟΦΥΓΕ!)
    ansible.builtin.debug:
      msg: "{{ ansible_distribution }}"    # ← deprecated!
      # ↑ Αυτό που μας έδινε warnings στο Κεφ. 3!
```

> ⚠️ **Γιατί `ansible_facts['...']` και όχι `ansible_distribution`:**
> ```
> Το ansible_distribution (χωρίς ansible_facts[''])
> είναι deprecated από Ansible 2.10+
> → Θα αφαιρεθεί σε μελλοντική έκδοση
> → Χρησιμοποίησε ΠΑΝΤΑ ansible_facts['distribution']
> ```

## Facts σε Templates

```jinja
{# Χρήση facts μέσα σε Jinja2 template #}

{# ── System info ─────────────────────────── #}
Hostname    : {{ ansible_facts['hostname'] }}
FQDN        : {{ ansible_facts['fqdn'] }}
OS          : {{ ansible_facts['distribution'] }}
Version     : {{ ansible_facts['distribution_version'] }}
Kernel      : {{ ansible_facts['kernel'] }}

{# ── Hardware ────────────────────────────── #}
CPUs        : {{ ansible_facts['processor_vcpus'] }}
RAM         : {{ (ansible_facts['memtotal_mb'] / 1024) | round(1) }}GB
Architecture: {{ ansible_facts['architecture'] }}

{# ── Network ─────────────────────────────── #}
IP Address  : {{ ansible_facts['default_ipv4']['address'] }}
MAC Address : {{ ansible_facts['default_ipv4']['macaddress'] }}
Interface   : {{ ansible_facts['default_ipv4']['interface'] }}
```

## Πότε ΔΕΝ χρειάζονται Facts

```yaml
# ── Χωρίς facts: πιο γρήγορο κατά 2-3 δευτερόλεπτα ──
- name: Quick maintenance tasks
  hosts: all
  gather_facts: false    # ← skip facts

  tasks:

    # Απλές εντολές που δεν χρειάζονται facts
    - name: Restart service
      ansible.builtin.service:
        name:  nginx
        state: restarted

    - name: Check uptime
      ansible.builtin.command: uptime

    - name: Disk usage
      ansible.builtin.command: df -h
```

> 💡 **Κανόνας:**
> ```
> Χρειάζεσαι ansible_facts['os_family'];    → gather_facts: true
> Χρειάζεσαι ansible_facts['distribution']; → gather_facts: true
> Κάνεις απλές εντολές/restarts;            → gather_facts: false
> ```

## Σύνοψη 13.1

```
Ansible Facts
├── Τι είναι: αυτόματες πληροφορίες από servers
├── Πώς: setup module → SSH → Python → JSON
├── Πότε: αρχή κάθε play (Gathering Facts task)
│
├── Έλεγχος:
│   ├── gather_facts: true  → συλλογή (default)
│   ├── gather_facts: false → παράλειψη (γρηγορότερο)
│   └── gather_subset       → επιλεκτική συλλογή
│
├── Πρόσβαση:
│   ├── ansible_facts['key'] → συνιστάται ✅
│   ├── ansible_facts.key    → OK
│   └── ansible_key          → deprecated ❌
│
└── Χρήση:
    ├── Playbook tasks (when, debug, template)
    ├── Jinja2 templates
    └── Inventory variables
```
