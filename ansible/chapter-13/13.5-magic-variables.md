# 13.5 Magic Variables ✨

## Τι είναι τα Magic Variables;

Τα **Magic Variables** είναι ειδικές μεταβλητές που η Ansible **ορίζει αυτόματα** — δεν είναι facts (δεν τα συλλέγει από τον server), αλλά πληροφορίες για το **ίδιο το Ansible environment**:

```
┌─────────────────────────────────────────────────────────┐
│  Facts         → πληροφορίες ΑΠΟ τον server             │
│  Magic Vars    → πληροφορίες ΓΙΑ το Ansible environment │
└─────────────────────────────────────────────────────────┘
```

---

## inventory_hostname

Το όνομα του host **όπως ορίζεται στο inventory**:

```yaml
tasks:

  - name: inventory_hostname demo
    ansible.builtin.debug:
      msg:
        - "inventory_hostname      : {{ inventory_hostname }}"
        # → nextcloud (όπως στο hosts.ini)

        - "inventory_hostname_short: {{ inventory_hostname_short }}"
        # → nextcloud (χωρίς domain)
        # αν ήταν "nextcloud.example.com" → "nextcloud"

# ── Διαφορά με ansible_facts['hostname'] ──────
# inventory_hostname  → από το inventory (εσύ το ορίζεις)
# ansible_facts['hostname'] → από τον server (πραγματικό hostname)
# → Μπορεί να διαφέρουν!
```

```yaml
# Χρήση σε templates & tasks
- name: Δημιουργία config
  ansible.builtin.copy:
    dest:    "/etc/myapp/{{ inventory_hostname }}.conf"
    content: "server_name = {{ inventory_hostname }}"

- name: Log entry
  ansible.builtin.debug:
    msg: "Configuring {{ inventory_hostname }}..."
```

## group_names

Λίστα με τα **groups στα οποία ανήκει** ο τρέχων host:

```yaml
tasks:

  - name: group_names demo
    ansible.builtin.debug:
      msg: "Groups: {{ group_names }}"
    # → ['debian_based', 'all_managed']

  # ── Conditional βάσει group ───────────────
  - name: Task μόνο για webservers group
    ansible.builtin.debug:
      msg: "I'm a web server!"
    when: "'webservers' in group_names"

  - name: Task για debian ή ubuntu group
    ansible.builtin.debug:
      msg: "Debian-based system!"
    when: "'debian_based' in group_names"

  # ── Εμφάνιση όλων των groups ──────────────
  - name: Εμφάνιση membership
    ansible.builtin.debug:
      msg: "{{ inventory_hostname }} ανήκει σε: {{ group_names | join(', ') }}"
```

## groups

Dictionary με **όλα τα groups** και τους hosts τους:

```yaml
tasks:

  - name: groups demo
    ansible.builtin.debug:
      msg:
        # ── Όλα τα groups ─────────────────────
        - "All groups   : {{ groups.keys() | list }}"
        # → ['all', 'ungrouped', 'controller',
        #    'debian_based', 'redhat_based', ...]

        # ── Hosts ενός group ──────────────────
        - "debian_based : {{ groups['debian_based'] }}"
        # → ['nextcloud']

        - "all hosts    : {{ groups['all'] }}"
        # → ['localhost', 'nextcloud']

        # ── Μέγεθος group ─────────────────────
        - "Server count : {{ groups['all_managed'] | length }}"
        # → 1

  # ── Loop πάνω σε group ────────────────────
  - name: Εμφάνιση όλων των debian servers
    ansible.builtin.debug:
      msg: "Debian server: {{ item }}"
    loop: "{{ groups['debian_based'] }}"

  # ── Conditional βάσει group size ──────────
  - name: Μόνο αν υπάρχουν RedHat servers
    ansible.builtin.debug:
      msg: "RedHat servers: {{ groups['redhat_based'] | join(', ') }}"
    when: groups['redhat_based'] | length > 0
```

## hostvars

Dictionary με **όλες τις μεταβλητές** κάθε host — ακόμα κι αν δεν τρέχει task εκεί:

```yaml
tasks:

  - name: hostvars demo
    ansible.builtin.debug:
      msg:
        # ── Facts άλλου host ──────────────────
        - "nextcloud IP : {{ hostvars['nextcloud']['ansible_host'] }}"
        # → 192.212.104.27

        - "nextcloud OS : {{ hostvars['nextcloud']['ansible_facts']['distribution'] | default('N/A') }}"
        # → Debian (αν έχουν συλλεχθεί facts)

        # ── Custom vars άλλου host ────────────
        - "nextcloud role: {{ hostvars['nextcloud']['server_role'] | default('N/A') }}"
        # → managed_server

  # ── Χρήση hostvars σε template ────────────
  # (δες παράδειγμα παρακάτω)

  # ── Loop με hostvars ──────────────────────
  - name: IPs όλων των servers
    ansible.builtin.debug:
      msg: "{{ item }}: {{ hostvars[item]['ansible_host'] | default('N/A') }}"
    loop: "{{ groups['all_managed'] }}"
```

```jinja
{# Template που χρησιμοποιεί hostvars #}
{# /etc/hosts generation #}

127.0.0.1   localhost
::1         localhost

{# Όλοι οι managed servers #}
{% for host in groups['all_managed'] %}
{% if hostvars[host]['ansible_host'] is defined %}
{{ hostvars[host]['ansible_host'] }}   {{ host }}
{% endif %}
{% endfor %}
```

## ansible_play_hosts & ansible_play_batch

```yaml
tasks:

  - name: Play hosts info
    ansible.builtin.debug:
      msg:
        # ── Hosts που τρέχουν ΣΕ ΑΥΤΟ το play ─
        - "Play hosts  : {{ ansible_play_hosts }}"
        # → ['nextcloud'] (active hosts)

        # ── Hosts σε αυτό το batch (serial) ───
        - "Play batch  : {{ ansible_play_batch }}"
        # → ['nextcloud']

        # ── Συνολικοί hosts του play ──────────
        - "All play hosts: {{ ansible_play_hosts_all }}"

  # ── Χρήσιμο για rolling updates ──────────
  - name: Πρώτος server στο play
    ansible.builtin.debug:
      msg: "I'm the first server!"
    when: inventory_hostname == ansible_play_hosts[0]
```

## ansible_version

```yaml
tasks:

  - name: Ansible version info
    ansible.builtin.debug:
      msg:
        - "Full version : {{ ansible_version.full }}"
        # → 2.20.4

        - "Major        : {{ ansible_version.major }}"
        # → 2

        - "Minor        : {{ ansible_version.minor }}"
        # → 20

        - "Revision     : {{ ansible_version.revision }}"
        # → 4

  # ── Conditional βάσει version ─────────────
  - name: Νέο feature (Ansible 2.15+)
    ansible.builtin.debug:
      msg: "Using new feature!"
    when: ansible_version.full is version('2.15.0', '>=')
```

## ansible_check_mode & ansible_diff_mode

```yaml
tasks:

  - name: Check mode awareness
    ansible.builtin.debug:
      msg:
        - "Check mode : {{ ansible_check_mode }}"
        # → true αν --check, false αν κανονικό
        - "Diff mode  : {{ ansible_diff_mode }}"
        # → true αν --diff

  # ── Χρήση για conditional logic ───────────
  - name: Skip σε check mode
    ansible.builtin.command:
      cmd: /usr/bin/dangerous_script.sh
    when: not ansible_check_mode    # ← ΜΗΝ τρέξεις σε dry run!

  # ── handlers με check mode ────────────────
  handlers:
    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted
      ignore_errors: "{{ ansible_check_mode }}"
      # ↑ Το είδαμε στα Handlers!
```

## inventory_dir & inventory_file

```yaml
tasks:

  - name: Inventory info
    ansible.builtin.debug:
      msg:
        - "Inventory dir : {{ inventory_dir }}"
        # → /home/ansible/ansible/inventory

        - "Inventory file: {{ inventory_file }}"
        # → /home/ansible/ansible/inventory/hosts.ini

        - "Playbook dir  : {{ playbook_dir }}"
        # → /home/ansible/ansible/playbooks

        - "Role path     : {{ role_path | default('N/A') }}"
        # → N/A (αν δεν τρέχουμε σε role)
```

## Πλήρης λίστα Magic Variables

```
┌─────────────────────────────────────────────────────────┐
│  HOST INFO                                              │
├─────────────────────────────────────────────────────────┤
│  inventory_hostname       → όνομα από inventory         │
│  inventory_hostname_short → χωρίς domain                │
│  group_names              → groups του host             │
│  ansible_host             → IP/hostname σύνδεσης        │
│  ansible_port             → SSH port                    │
│  ansible_user             → SSH user                    │
├─────────────────────────────────────────────────────────┤
│  INVENTORY INFO                                         │
├─────────────────────────────────────────────────────────┤
│  groups                   → όλα τα groups               │
│  hostvars                 → vars όλων των hosts         │
│  inventory_dir            → directory inventory         │
│  inventory_file           → path inventory file         │
├─────────────────────────────────────────────────────────┤
│  PLAY INFO                                              │
├─────────────────────────────────────────────────────────┤
│  ansible_play_hosts       → active hosts                │
│  ansible_play_hosts_all   → όλοι οι hosts               │
│  ansible_play_batch       → τρέχον batch                │
│  ansible_play_name        → όνομα play                  │
├─────────────────────────────────────────────────────────┤
│  ANSIBLE INFO                                           │
├─────────────────────────────────────────────────────────┤
│  ansible_version          → έκδοση Ansible              │
│  ansible_check_mode       → dry run;                    │
│  ansible_diff_mode        → diff mode;                  │
│  playbook_dir             → directory playbook          │
│  role_path                → directory role              │
└─────────────────────────────────────────────────────────┘
```

## Πρακτικό παράδειγμα — Όλα Μαζί

```yaml
---
# magic-vars-demo.yml

- name: Magic Variables Demo
  hosts: all
  become: true
  gather_facts: true

  tasks:

    # ── Inventory info ────────────────────────
    - name: Host inventory info
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "inventory_hostname: {{ inventory_hostname }}"
          - "Groups            : {{ group_names | join(', ') }}"
          - "SSH host          : {{ ansible_host }}"
          - "SSH port          : {{ ansible_port | default(22) }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

    # ── Play info ─────────────────────────────
    - name: Play info
      ansible.builtin.debug:
        msg:
          - "Play hosts  : {{ ansible_play_hosts | join(', ') }}"
          - "Total hosts : {{ ansible_play_hosts_all | length }}"
          - "Check mode  : {{ ansible_check_mode }}"
          - "Ansible ver : {{ ansible_version.full }}"

    # ── Groups overview ───────────────────────
    - name: Infrastructure overview
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Infrastructure Overview"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "All managed  : {{ groups['all_managed'] | length }} servers"
          - "Debian based : {{ groups['debian_based'] | length }} servers"
          - "RedHat based : {{ groups['redhat_based'] | length }} servers"
          - "openSUSE     : {{ groups['opensuse_based'] | length }} servers"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      run_once: true    # ← εκτελείται ΜΟΝΟ μία φορά!

    # ── hostvars χρήση ────────────────────────
    - name: Deploy /etc/hosts
      ansible.builtin.template:
        src:   templates/hosts.j2
        dest:  /etc/hosts
        mode:  '0644'
        owner: root

    # ── Conditional βάσει group ───────────────
    - name: Web server specific task
      ansible.builtin.debug:
        msg: "Configuring web server features..."
      when: "'webservers' in group_names"

    - name: Primary server task
      ansible.builtin.debug:
        msg: "I'm the primary server!"
      when: inventory_hostname == ansible_play_hosts[0]

    # ── Facts από άλλους hosts ────────────────
    - name: Show all server IPs
      ansible.builtin.debug:
        msg: >
          {{ item }}:
          {{ hostvars[item]['ansible_host'] | default('unknown') }}
      loop: "{{ groups['all_managed'] }}"
      run_once: true
```

## Template με Magic Variables

```jinja
{# templates/hosts.j2 #}
{# /etc/hosts file #}
{# Generated by Ansible — DO NOT EDIT! #}

# Loopback
127.0.0.1   localhost
::1         localhost ip6-localhost

# This host
127.0.1.1   {{ inventory_hostname }}

# ── Managed Servers ───────────────────────────
{% for host in groups['all_managed'] %}
{% if hostvars[host]['ansible_host'] is defined
      and host != inventory_hostname %}
{{ hostvars[host]['ansible_host'] | ljust(20) }}{{ host }}
{% endif %}
{% endfor %}

# ── Controller ────────────────────────────────
{% if hostvars['localhost'] is defined %}
# Ansible Controller: bananapim4berry (192.168.1.55)
{% endif %}
```

## Σύνοψη 13.5

```
Magic Variables
├── HOST:
│   ├── inventory_hostname  → όνομα από inventory
│   ├── inventory_hostname_short → χωρίς domain
│   ├── group_names         → groups του host
│   └── ansible_host/port/user → σύνδεση
│
├── INVENTORY:
│   ├── groups              → όλα τα groups + hosts
│   ├── hostvars            → vars όλων των hosts
│   └── inventory_dir/file  → paths
│
├── PLAY:
│   ├── ansible_play_hosts  → active hosts
│   ├── ansible_play_batch  → τρέχον batch
│   └── ansible_play_name   → όνομα play
│
└── ANSIBLE:
    ├── ansible_version     → έκδοση
    ├── ansible_check_mode  → dry run
    ├── ansible_diff_mode   → diff
    └── playbook_dir        → directory
```
