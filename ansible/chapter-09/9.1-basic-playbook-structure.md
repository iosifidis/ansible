# 9.1 Βασική δομή Playbook 📜

## Η ιεραρχία ενός Playbook

```
Playbook (.yml αρχείο)
└── Play 1
    ├── Metadata (hosts, become, vars κλπ)
    └── Tasks
        ├── Task 1
        │   └── Module + Arguments
        ├── Task 2
        │   └── Module + Arguments
        └── Task 3
            └── Module + Arguments
└── Play 2
    ├── Metadata
    └── Tasks
        └── ...
```

---

## Ανατομία Play — Κάθε Keyword εξηγημένο

```yaml
---
# Η τριπλή παύλα δηλώνει αρχή YAML αρχείου

- name: Περιγραφή του Play           # ← εμφανίζεται στο output
  hosts: webservers                  # ← ποιοι servers
  become: true                       # ← χρησιμοποίησε sudo
  become_user: root                  # ← γίνε αυτός ο user
  remote_user: ansible               # ← σύνδεση ως αυτός
  gather_facts: true                 # ← συλλογή facts
  any_errors_fatal: false            # ← σταμάτα αν αποτύχει
  max_fail_percentage: 30            # ← max % αποτυχίας
  serial: 1                          # ← rolling updates
  order: inventory                   # ← σειρά εκτέλεσης
  ignore_errors: false               # ← αγνόησε σφάλματα

  vars:                              # ← μεταβλητές play
    http_port: 80
    app_name: myapp

  vars_files:                        # ← μεταβλητές από αρχείο
    - vars/main.yml
    - vars/secrets.yml

  pre_tasks:                         # ← tasks ΠΡΙΝ τα roles
    - name: Pre-task example
      ansible.builtin.debug:
        msg: "Ξεκινάει η εγκατάσταση"

  roles:                             # ← roles (Κεφ. 15)
    - nginx
    - php

  tasks:                             # ← οι εργασίες
    - name: Task 1
      ansible.builtin.package:
        name: nginx
        state: present

  post_tasks:                        # ← tasks ΜΕΤΑ τα roles
    - name: Post-task example
      ansible.builtin.debug:
        msg: "Ολοκληρώθηκε!"

  handlers:                          # ← ειδικές εργασίες
    - name: Restart nginx
      ansible.builtin.service:
        name: nginx
        state: restarted
```

> 📝 **Σημείωση:** Δεν χρειάζεσαι **όλα** τα keywords. Τα πιο συχνά είναι: `name`, `hosts`, `become`, `gather_facts`, `vars`, `tasks`.

## Ανατομία Task — Κάθε Keyword εξηγημένο

```yaml
  tasks:

    - name: Εγκατάσταση nginx       # ← περιγραφή task
      ansible.builtin.package:      # ← το module
        name: nginx                 # ← παράμετρος module
        state: present              # ← παράμετρος module
      become: true                  # ← sudo (override play)
      become_user: root             # ← user (override play)
      when: ansible_facts['os_family'] == "Debian"  # ← συνθήκη
      loop: "{{ packages }}"        # ← επανάληψη
      register: install_result      # ← αποθήκευση αποτελέσματος
      ignore_errors: true           # ← αγνόησε σφάλματα
      failed_when:                  # ← πότε θεωρείται αποτυχία
        - install_result.rc != 0
      changed_when: false           # ← ποτέ δεν μετράει ως αλλαγή
      notify: Restart nginx         # ← κάλεσε handler
      tags:                         # ← ετικέτες (Κεφ. 14)
        - packages
        - nginx
      no_log: false                 # ← απόκρυψη output (για passwords)
      timeout: 30                   # ← max χρόνος εκτέλεσης
```

## Ένα πλήρες παράδειγμα

```yaml
---
# ============================================================
# basic-playbook.yml
# Βασικό παράδειγμα playbook
# ============================================================

- name: Ρύθμιση Web Server
  hosts: debian_based
  become: true
  gather_facts: true

  vars:
    web_port: 80
    web_root: /var/www/html

  tasks:

    # ── Εμφάνιση πληροφοριών ──────────────────
    - name: Εμφάνιση server info
      ansible.builtin.debug:
        msg:
          - "Server : {{ inventory_hostname }}"
          - "OS     : {{ ansible_facts['distribution'] }}"
          - "Port   : {{ web_port }}"

    # ── Εγκατάσταση ───────────────────────────
    - name: Εγκατάσταση nginx
      ansible.builtin.apt:
        name: nginx
        state: present
        update_cache: true

    # ── Δημιουργία web root ───────────────────
    - name: Δημιουργία web root directory
      ansible.builtin.file:
        path: "{{ web_root }}"
        state: directory
        mode: '0755'
        owner: www-data
        group: www-data

    # ── Δημιουργία index.html ─────────────────
    - name: Δημιουργία index.html
      ansible.builtin.copy:
        dest: "{{ web_root }}/index.html"
        content: |
          <html>
            <body>
              <h1>Hello from {{ inventory_hostname }}!</h1>
              <p>Managed by Ansible</p>
            </body>
          </html>
        mode: '0644'
        owner: www-data
        group: www-data
      notify: Restart nginx      # ← αν αλλάξει → restart

    # ── Εκκίνηση service ──────────────────────
    - name: Εκκίνηση και ενεργοποίηση nginx
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

    # ── Επαλήθευση ────────────────────────────
    - name: Έλεγχος nginx
      ansible.builtin.uri:
        url: "http://localhost:{{ web_port }}"
        status_code: 200
      register: nginx_check

    - name: Αποτέλεσμα ελέγχου
      ansible.builtin.debug:
        msg: "nginx ανταποκρίνεται: {{ nginx_check.status }} ✅"

  # ── Handlers ────────────────────────────────
  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name: nginx
        state: restarted
```

## Πολλαπλά Plays σε ένα Playbook

```yaml
---
# multi-play.yml
# Διαφορετικές εργασίες σε διαφορετικούς servers

# ── Play 1: Web Servers ───────────────────────
- name: Ρύθμιση Web Servers
  hosts: webservers
  become: true
  tasks:

    - name: Εγκατάσταση nginx
      ansible.builtin.package:
        name: nginx
        state: present

    - name: Εκκίνηση nginx
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

# ── Play 2: Database Servers ──────────────────
- name: Ρύθμιση Database Servers
  hosts: dbservers
  become: true
  tasks:

    - name: Εγκατάσταση postgresql
      ansible.builtin.package:
        name: postgresql
        state: present

    - name: Εκκίνηση postgresql
      ansible.builtin.service:
        name: postgresql
        state: started
        enabled: true

# ── Play 3: Όλοι οι servers ───────────────────
- name: Κοινές ρυθμίσεις
  hosts: all
  become: true
  tasks:

    - name: Εγκατάσταση κοινών packages
      ansible.builtin.package:
        name:
          - curl
          - nano
          - git
        state: present
```

## YAML Σύνταξη — Σημαντικές λεπτομέρειες

```yaml
# ── Strings ───────────────────────────────────
name: nginx                    # χωρίς quotes
name: "nginx"                  # με double quotes
name: 'nginx'                  # με single quotes
name: "Hello {{ variable }}"   # με variable → ΠΑΝΤΑ quotes!

# ── Booleans ──────────────────────────────────
become: true    # ή: yes, True, TRUE
become: false   # ή: no, False, FALSE

# ── Lists ─────────────────────────────────────
packages:              # block style
  - nginx
  - curl
  - nano

packages: [nginx, curl, nano]   # inline style

# ── Dictionaries ──────────────────────────────
user:                  # block style
  name: ansible
  shell: /bin/bash

user: {name: ansible, shell: /bin/bash}   # inline style

# ── Multiline strings ─────────────────────────
content: |             # literal block (διατηρεί newlines)
  line 1
  line 2
  line 3

content: >             # folded block (newlines → spaces)
  αυτό είναι
  μία γραμμή
```

---

> ⚠️ **Συχνά Λάθη YAML:**

```yaml
# ΛΑΘΟΣ — λείπουν τα quotes για variables
msg: Hello {{ name }}

# ΣΩΣΤΟ
msg: "Hello {{ name }}"

# ΛΑΘΟΣ — λανθασμένη indentation
tasks:
- name: Test      ← πρέπει να είναι με 2 spaces

# ΣΩΣΤΟ
tasks:
  - name: Test
```

## Σύνοψη 9.1

```
Βασική Δομή Playbook
├── Playbook → ένα ή περισσότερα plays
├── Play → metadata + tasks + handlers
│   ├── name, hosts, become, gather_facts
│   ├── vars, vars_files
│   ├── pre_tasks, roles, tasks, post_tasks
│   └── handlers
├── Task → name + module + arguments + options
│   ├── when, loop, register
│   ├── ignore_errors, failed_when, changed_when
│   ├── notify, tags, no_log, timeout
│   └── become, become_user (override)
└── YAML: indentation, quotes, lists, dicts
```
