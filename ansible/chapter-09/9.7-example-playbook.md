# 9.7 Πρακτικό Playbook — Full Example 🚀

## Τι θα φτιάξουμε

Ένα **πλήρες, real-world playbook** που συνδυάζει όλα όσα μάθαμε στο Κεφάλαιο 9:

```
base-setup.yml
├── Ενημέρωση συστήματος (και στις 3 distros)
├── Εγκατάσταση κοινών packages
├── Δημιουργία app user & directories
├── Βασική ρύθμιση συστήματος
├── Ρύθμιση timezone
├── Ρύθμιση hostname
└── Επαλήθευση & report
```

> 💡 **Αυτό το playbook** θα το τρέχεις σε κάθε νέο server **αμέσως μετά** το `security-bootstrap.yml` — είναι το "base configuration" playbook.

---

## Το Playbook

```bash
# Δημιουργία
nano ~/ansible/playbooks/base-setup.yml
```

```yaml
---
# ============================================================
# Base Setup Playbook
# Βασική ρύθμιση νέου server
# Εκτέλεση ΜΕΤΑ το security-bootstrap.yml
# Συμβατό με: Debian/Ubuntu, RedHat/Fedora, openSUSE
# ============================================================

- name: Base Server Setup
  hosts: "{{ target | default('all_managed') }}"
  become: true
  gather_facts: true

  # ══════════════════════════════════════════
  # VARIABLES
  # ══════════════════════════════════════════
  vars:

    # ── Σύστημα ───────────────────────────────
    system_timezone:  "Europe/Athens"
    system_locale:    "el_GR.UTF-8"

    # ── App User ──────────────────────────────
    app_user:         appuser
    app_user_shell:   /bin/bash
    app_user_groups:  []

    # ── Directories ───────────────────────────
    app_directories:
      - path:  /opt/myapp
        mode:  '0755'
        owner: root
      - path:  /opt/myapp/logs
        mode:  '0750'
        owner: "{{ app_user }}"
      - path:  /opt/myapp/config
        mode:  '0750'
        owner: "{{ app_user }}"
      - path:  /opt/myapp/data
        mode:  '0750'
        owner: "{{ app_user }}"

    # ── Κοινά Packages ────────────────────────
    common_packages:
      - curl
      - wget
      - vim
      - git
      - htop
      - tree
      - unzip
      - net-tools

    # ── Debian-specific packages ──────────────
    debian_extra_packages:
      - python3-apt
      - apt-transport-https
      - ca-certificates
      - gnupg
      - lsb-release

    # ── RedHat-specific packages ──────────────
    redhat_extra_packages:
      - python3-libselinux
      - dnf-plugins-core

    # ── openSUSE-specific packages ────────────
    suse_extra_packages:
      - python3-zypp

  # ══════════════════════════════════════════
  # TASKS
  # ══════════════════════════════════════════
  tasks:

    # ── ΕΜΦΑΝΙΣΗ ΠΛΗΡΟΦΟΡΙΩΝ ──────────────────
    - name: Εμφάνιση server πληροφοριών
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host        : {{ inventory_hostname }}"
          - "OS Family   : {{ ansible_facts['os_family'] }}"
          - "Distribution: {{ ansible_facts['distribution'] }}"
          - "Version     : {{ ansible_facts['distribution_version'] }}"
          - "Architecture: {{ ansible_facts['architecture'] }}"
          - "RAM         : {{ ansible_facts['memtotal_mb'] }}MB"
          - "CPU cores   : {{ ansible_facts['processor_vcpus'] }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

    # ══════════════════════════════════════════
    # ΕΝΗΜΕΡΩΣΗ ΣΥΣΤΗΜΑΤΟΣ
    # ══════════════════════════════════════════

    - name: Update apt cache (Debian/Ubuntu)
      ansible.builtin.apt:
        update_cache:      true
        cache_valid_time:  3600
      when: ansible_facts['os_family'] == "Debian"

    - name: System upgrade (Debian/Ubuntu)
      ansible.builtin.apt:
        upgrade: safe
      when: ansible_facts['os_family'] == "Debian"
      tags: upgrade

    - name: Update dnf cache (RedHat/Fedora)
      ansible.builtin.dnf:
        update_cache: true
      when: ansible_facts['os_family'] == "RedHat"

    - name: System upgrade (RedHat/Fedora)
      ansible.builtin.dnf:
        name:  "*"
        state: latest
      when: ansible_facts['os_family'] == "RedHat"
      tags: upgrade

    - name: System upgrade (openSUSE)
      community.general.zypper:
        name:  "*"
        state: latest
      when: ansible_facts['os_family'] == "Suse"
      tags: upgrade

    # ══════════════════════════════════════════
    # ΕΓΚΑΤΑΣΤΑΣΗ PACKAGES
    # ══════════════════════════════════════════

    - name: Εγκατάσταση κοινών packages
      ansible.builtin.package:
        name:  "{{ item }}"
        state: present
      loop: "{{ common_packages }}"
      loop_control:
        label: "{{ item }}"
      tags: packages

    - name: Εγκατάσταση Debian-specific packages
      ansible.builtin.apt:
        name:  "{{ item }}"
        state: present
      loop: "{{ debian_extra_packages }}"
      when: ansible_facts['os_family'] == "Debian"
      loop_control:
        label: "{{ item }}"
      tags: packages

    - name: Εγκατάσταση EPEL (Rocky/AlmaLinux)
      ansible.builtin.dnf:
        name:  epel-release
        state: present
      when:
        - ansible_facts['os_family'] == "RedHat"
        - ansible_facts['distribution'] != "Fedora"
      tags: packages

    - name: Εγκατάσταση RedHat-specific packages
      ansible.builtin.dnf:
        name:  "{{ item }}"
        state: present
      loop: "{{ redhat_extra_packages }}"
      when: ansible_facts['os_family'] == "RedHat"
      loop_control:
        label: "{{ item }}"
      tags: packages

    - name: Εγκατάσταση openSUSE-specific packages
      community.general.zypper:
        name:  "{{ item }}"
        state: present
      loop: "{{ suse_extra_packages }}"
      when: ansible_facts['os_family'] == "Suse"
      loop_control:
        label: "{{ item }}"
      tags: packages

    # ══════════════════════════════════════════
    # ΡΥΘΜΙΣΗ TIMEZONE
    # ══════════════════════════════════════════

    - name: Ρύθμιση timezone
      community.general.timezone:
        name: "{{ system_timezone }}"
      notify: Restart cron
      tags: system

    - name: Επαλήθευση timezone
      ansible.builtin.command:
        cmd: timedatectl show --property=Timezone --value
      register: current_timezone
      changed_when: false
      tags: system

    - name: Εμφάνιση timezone
      ansible.builtin.debug:
        msg: "Timezone: {{ current_timezone.stdout }}"
      tags: system

    # ══════════════════════════════════════════
    # ΔΗΜΙΟΥΡΓΙΑ APP USER
    # ══════════════════════════════════════════

    - name: Δημιουργία app user
      ansible.builtin.user:
        name:        "{{ app_user }}"
        shell:       "{{ app_user_shell }}"
        create_home: true
        state:       present
      tags: users

    - name: Δημιουργία .ssh directory για app user
      ansible.builtin.file:
        path:  "/home/{{ app_user }}/.ssh"
        state: directory
        mode:  '0700'
        owner: "{{ app_user }}"
        group: "{{ app_user }}"
      tags: users

    # ══════════════════════════════════════════
    # ΔΗΜΙΟΥΡΓΙΑ DIRECTORIES
    # ══════════════════════════════════════════

    - name: Δημιουργία app directories
      ansible.builtin.file:
        path:  "{{ item.path }}"
        state: directory
        mode:  "{{ item.mode }}"
        owner: "{{ item.owner }}"
        group: "{{ item.owner }}"
      loop: "{{ app_directories }}"
      loop_control:
        label: "{{ item.path }}"
      tags: directories

    # ══════════════════════════════════════════
    # ΒΑΣΙΚΕΣ ΡΥΘΜΙΣΕΙΣ ΣΥΣΤΗΜΑΤΟΣ
    # ══════════════════════════════════════════

    - name: Ρύθμιση /etc/hosts
      ansible.builtin.lineinfile:
        path:   /etc/hosts
        regexp: "^127.0.1.1"
        line:   "127.0.1.1 {{ inventory_hostname }}"
        state:  present
      tags: system

    - name: Ρύθμιση vim ως default editor
      ansible.builtin.lineinfile:
        path:   /etc/environment
        regexp: "^EDITOR="
        line:   "EDITOR=vim"
        state:  present
        create: true
        mode:   '0644'
      tags: system

    - name: Δημιουργία MOTD
      ansible.builtin.copy:
        dest:  /etc/motd
        mode:  '0644'
        content: |
          ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
           Server  : {{ inventory_hostname }}
           OS      : {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}
           Managed : Ansible {{ ansible_version.full }}
           Env     : {{ app_env | default('production') }}
          ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
      tags: system

    # ══════════════════════════════════════════
    # ΒΕΛΤΙΣΤΟΠΟΙΗΣΗ ΣΥΣΤΗΜΑΤΟΣ
    # ══════════════════════════════════════════

    - name: Ρύθμιση sysctl παραμέτρων
      ansible.posix.sysctl:
        name:       "{{ item.name }}"
        value:      "{{ item.value }}"
        state:      present
        reload:     true
        sysctl_set: true
      loop:
        - name:  net.ipv4.tcp_syncookies
          value: "1"
        - name:  net.ipv4.conf.all.rp_filter
          value: "1"
        - name:  net.core.somaxconn
          value: "65535"
        - name:  vm.swappiness
          value: "10"
      loop_control:
        label: "{{ item.name }}"
      tags: system

    # ══════════════════════════════════════════
    # ΚΑΘΑΡΙΣΜΟΣ
    # ══════════════════════════════════════════

    - name: Καθαρισμός Debian
      ansible.builtin.apt:
        autoremove: true
        autoclean:  true
      when: ansible_facts['os_family'] == "Debian"
      tags: cleanup

    - name: Καθαρισμός RedHat
      ansible.builtin.dnf:
        autoremove: true
      when: ansible_facts['os_family'] == "RedHat"
      tags: cleanup

    - name: Καθαρισμός openSUSE
      community.general.zypper:
        name:  "*"
        state: present
        extra_args: "--clean-deps"
      when: ansible_facts['os_family'] == "Suse"
      ignore_errors: true
      tags: cleanup

    # ══════════════════════════════════════════
    # ΕΠΑΛΗΘΕΥΣΗ & REPORT
    # ══════════════════════════════════════════

    - name: Έλεγχος directories
      ansible.builtin.stat:
        path: "{{ item.path }}"
      register: dir_check
      loop: "{{ app_directories }}"
      loop_control:
        label: "{{ item.path }}"
      tags: verify

    - name: Έλεγχος app user
      ansible.builtin.getent:
        database: passwd
        key:      "{{ app_user }}"
      register: user_check
      ignore_errors: true
      tags: verify

    - name: Έλεγχος timezone
      ansible.builtin.command:
        cmd: timedatectl show --property=Timezone --value
      register: tz_check
      changed_when: false
      tags: verify

    - name: Τελικό Report
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "✅ BASE SETUP REPORT"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Host    : {{ inventory_hostname }}"
          - "OS      : {{ ansible_facts['distribution'] }} \
                        {{ ansible_facts['distribution_version'] }}"
          - "Timezone: {{ tz_check.stdout }}"
          - "App user: {{ app_user }} \
                        {{ '✅' if not user_check.failed else '❌' }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "Directories:"
          - "{% for item in dir_check.results %}\
             {{ item.item.path }}: \
             {{ '✅' if item.stat.exists else '❌' }}\
             {% endfor %}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      tags: verify

  # ══════════════════════════════════════════
  # HANDLERS
  # ══════════════════════════════════════════
  handlers:

    - name: Restart cron
      ansible.builtin.service:
        name: "{{ 'cron' if ansible_facts['os_family'] == 'Debian'
                         else 'crond' }}"
        state: restarted
```

## Εκτέλεση

```bash
# 1. Syntax check
ansible-playbook playbooks/base-setup.yml --syntax-check

# 2. List tasks
ansible-playbook playbooks/base-setup.yml --list-tasks

# 3. Dry run
ansible-playbook playbooks/base-setup.yml \
    --check --diff \
    --limit nextcloud

# 4. Εκτέλεση σε nextcloud
ansible-playbook playbooks/base-setup.yml \
    --limit nextcloud \
    -v

# 5. Μόνο packages (με tags)
ansible-playbook playbooks/base-setup.yml \
    --limit nextcloud \
    --tags packages

# 6. Χωρίς upgrade (skip tags)
ansible-playbook playbooks/base-setup.yml \
    --limit nextcloud \
    --skip-tags upgrade

# 7. Custom timezone
ansible-playbook playbooks/base-setup.yml \
    --limit nextcloud \
    -e "system_timezone=Europe/London"
```
