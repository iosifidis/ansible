# 9.3 Variables (Μεταβλητές) 📊

## Γιατί μεταβλητές;

Οι μεταβλητές κάνουν τα playbooks **επαναχρησιμοποιήσιμα** και **παραμετρικά**:

```yaml
# Χωρίς μεταβλητές — hardcoded, δύσκολο να αλλάξεις
- name: Install nginx
  ansible.builtin.apt:
    name: nginx
    state: present

- name: Create web root
  ansible.builtin.file:
    path: /var/www/html          # ← αλλάζει σε κάθε project
    state: directory

# Με μεταβλητές — ευέλικτο, εύκολο να αλλάξεις
- name: Install {{ web_server }}
  ansible.builtin.apt:
    name: "{{ web_server }}"     # ← nginx, apache, lighttpd...
    state: present

- name: Create web root
  ansible.builtin.file:
    path: "{{ web_root }}"       # ← αλλάζεις μόνο τη μεταβλητή
    state: directory
```

## Naming Convention — Κανόνες ονομασίας

```yaml
# ✅ ΣΩΣΤΟ
web_port: 80                    # snake_case
app_name: myapp
db_max_connections: 100
nginx_worker_processes: 4

# ❌ ΛΑΘΟΣ
web-port: 80                    # παύλα (δεν επιτρέπεται)
WebPort: 80                     # CamelCase (αποφύγετε)
web port: 80                    # κενό (δεν επιτρέπεται)
1st_port: 80                    # αρχίζει με αριθμό (λάθος)

# ❌ Reserved words (μην τα χρησιμοποιείς ως ονόματα)
# environment, role, vars, tasks, hosts, become κλπ
```

> 📝 **Κανόνας:** Πάντα **snake_case** (μικρά γράμματα με underscore). Ξεκινάει με γράμμα, όχι αριθμό.

## Τύποι μεταβλητών

```yaml
# String
app_name: "myapp"
app_env: production             # χωρίς quotes (αν δεν έχει spaces)

# Integer
http_port: 80
max_connections: 100

# Boolean
ssl_enabled: true
debug_mode: false

# List
common_packages:
  - curl
  - vim
  - git

# Dictionary
database:
  host: localhost
  port: 5432
  name: mydb
  user: appuser

# Multiline string
nginx_config: |
  server {
    listen 80;
    server_name example.com;
  }
```

## Τρόποι δήλωσης μεταβλητών

### 1. Στο Playbook (vars section):
```yaml
---
- name: Web Server Setup
  hosts: debian_based
  become: true

  vars:
    # ── Απλές μεταβλητές ──────────────────────
    web_server:   nginx
    http_port:    80
    https_port:   443
    web_root:     /var/www/html
    app_env:      production

    # ── List ──────────────────────────────────
    web_packages:
      - nginx
      - curl
      - vim

    # ── Dictionary ────────────────────────────
    ssl_config:
      cert_path: /etc/ssl/certs/myapp.crt
      key_path:  /etc/ssl/private/myapp.key
      protocols: "TLSv1.2 TLSv1.3"

  tasks:
    - name: Εγκατάσταση {{ web_server }}
      ansible.builtin.apt:
        name: "{{ web_server }}"
        state: present
```

### 2. Από αρχείο (vars_files):
```yaml
---
- name: Web Server Setup
  hosts: debian_based
  vars_files:
    - vars/main.yml        # ← πάντα φορτώνεται
    - vars/secrets.yml     # ← κρυπτογραφημένο με Vault
    - "vars/{{ app_env }}.yml"  # ← δυναμικό!
```

```yaml
# vars/main.yml
---
web_server:   nginx
http_port:    80
web_root:     /var/www/html
```

```yaml
# vars/production.yml
---
debug_mode:   false
log_level:    error
replicas:     3
```

```yaml
# vars/staging.yml
---
debug_mode:   true
log_level:    debug
replicas:     1
```

### 3. Από Command Line (-e):
```bash
# Υψηλότερη προτεραιότητα — override όλα!
ansible-playbook playbooks/webserver.yml \
    -e "http_port=8080 app_env=staging"

# Από αρχείο
ansible-playbook playbooks/webserver.yml \
    -e "@vars/override.yml"
```

### 4. Από group_vars / host_vars:
```yaml
# inventory/group_vars/webservers.yml
---
http_port:  80
https_port: 443
web_root:   /var/www/html
```

```yaml
# inventory/host_vars/nextcloud.yml
---
ansible_host: 192.212.104.27
ansible_port: 2022
server_role:  web
```

### 5. Με set_fact (Runtime):
```yaml
tasks:
  - name: Ορισμός μεταβλητής κατά την εκτέλεση
    ansible.builtin.set_fact:
      app_version: "1.2.3"
      deploy_time: "{{ ansible_date_time.iso8601 }}"

  - name: Χρήση της νέας μεταβλητής
    ansible.builtin.debug:
      msg: "Deploying version {{ app_version }}"
```

### 6. Με register (Αποτέλεσμα Task):
```yaml
tasks:
  - name: Έλεγχος nginx version
    ansible.builtin.command: nginx -v
    register: nginx_version       # ← αποθήκευση output
    changed_when: false

  - name: Εμφάνιση version
    ansible.builtin.debug:
      msg: "Nginx: {{ nginx_version.stderr }}"
      # ↑ nginx -v γράφει στο stderr!

  - name: Χρήση return code
    ansible.builtin.debug:
      msg: "Return code: {{ nginx_version.rc }}"
```

## Χρήση μεταβλητών — Jinja2 Syntax

```yaml
tasks:
  # ── Απλή χρήση ────────────────────────────
  - name: Show variable
    ansible.builtin.debug:
      msg: "Port: {{ http_port }}"

  # ── Μέσα σε string ────────────────────────
  - name: Create config
    ansible.builtin.copy:
      dest: /etc/myapp/config.conf
      content: "listen {{ http_port }};"

  # ── Dictionary access ─────────────────────
  - name: SSL cert path
    ansible.builtin.debug:
      msg: "Cert: {{ ssl_config.cert_path }}"
      # ή
      # msg: "Cert: {{ ssl_config['cert_path'] }}"

  # ── List access ───────────────────────────
  - name: First package
    ansible.builtin.debug:
      msg: "First: {{ web_packages[0] }}"

  # ── Default value ─────────────────────────
  - name: With default
    ansible.builtin.debug:
      msg: "Port: {{ http_port | default(80) }}"

  # ── String operations ─────────────────────
  - name: String ops
    ansible.builtin.debug:
      msg:
        - "Upper: {{ app_name | upper }}"
        - "Length: {{ app_name | length }}"
        - "Replace: {{ app_env | replace('production', 'prod') }}"
```

## Register — Σε βάθος

```yaml
tasks:
  - name: Έλεγχος αν υπάρχει αρχείο
    ansible.builtin.stat:
      path: /etc/nginx/nginx.conf
    register: nginx_conf          # ← αποθήκευση

  - name: Εμφάνιση αποτελέσματος
    ansible.builtin.debug:
      msg:
        - "Exists : {{ nginx_conf.stat.exists }}"
        - "Size   : {{ nginx_conf.stat.size | default('N/A') }}"
        - "Mode   : {{ nginx_conf.stat.mode | default('N/A') }}"

  - name: Εγκατάσταση nginx αν δεν υπάρχει config
    ansible.builtin.apt:
      name: nginx
      state: present
    when: not nginx_conf.stat.exists   # ← χρήση register
```

```yaml
  # Τυπικά fields ενός register result:
  # result.stdout      → standard output
  # result.stderr      → standard error
  # result.rc          → return code (0 = επιτυχία)
  # result.changed     → άλλαξε κάτι;
  # result.failed      → απέτυχε;
  # result.skipped     → παραλείφθηκε;
  # result.stdout_lines→ output ως list γραμμών
```

```

        │

4.  group_vars/groupname.yml

6.  playbook vars (vars: section)

        │
        ▼
Χαμηλότερη προτεραιότητα
```

## Πρακτικό παράδειγμα

```yaml
---
# variables-demo.yml

- name: Variables Demo
  hosts: debian_based
  become: true
  gather_facts: true

  vars:
    app_name:     mywebapp
    http_port:    80
    web_root:     "/var/www/{{ app_name }}"
    app_packages:
      - nginx
      - curl
      - vim
    db_config:
      host: localhost
      port: 5432
      name: "{{ app_name }}_db"

  tasks:

    - name: Εμφάνιση όλων των μεταβλητών
      ansible.builtin.debug:
        msg:
          - "App     : {{ app_name }}"
          - "Port    : {{ http_port }}"
          - "Web root: {{ web_root }}"
          - "DB host : {{ db_config.host }}"
          - "DB name : {{ db_config.name }}"
          - "Packages: {{ app_packages | join(', ') }}"

    - name: Δημιουργία web root
      ansible.builtin.file:
        path: "{{ web_root }}"
        state: directory
        mode: '0755'

    - name: Δημιουργία config από μεταβλητές
      ansible.builtin.copy:
        dest: "{{ web_root }}/app.conf"
        content: |
          # {{ app_name }} configuration
          # Generated by Ansible — DO NOT EDIT!

          listen_port={{ http_port }}
          db_host={{ db_config.host }}
          db_port={{ db_config.port }}
          db_name={{ db_config.name }}
        mode: '0644'

    - name: Ανάγνωση config
      ansible.builtin.command:
        cmd: "cat {{ web_root }}/app.conf"
      register: config_content
      changed_when: false

    - name: Εμφάνιση config
      ansible.builtin.debug:
        msg: "{{ config_content.stdout_lines }}"
```

```bash
# Εκτέλεση
ansible-playbook playbooks/variables-demo.yml \
    --limit nextcloud

# Override από command line
ansible-playbook playbooks/variables-demo.yml \
    --limit nextcloud \
    -e "http_port=8080 app_name=testapp"
```

## Σύνοψη 9.3

```
Variables
├── Naming: snake_case, ξεκινά με γράμμα
├── Τύποι: string, integer, boolean, list, dict
├── Δήλωση:
│   ├── vars:        → στο playbook
│   ├── vars_files:  → από αρχείο
│   ├── -e           → command line (υψηλότερη)
│   ├── group_vars/  → ανά group
│   ├── host_vars/   → ανά host
│   ├── set_fact     → runtime
│   └── register     → από task output
├── Χρήση: "{{ variable_name }}"
│   ├── dict: {{ var.key }} ή {{ var['key'] }}
│   ├── list: {{ var[0] }}
│   └── default: {{ var | default(value) }}
└── Προτεραιότητα: -e > set_fact > host_vars
                   > group_vars > playbook vars
```
