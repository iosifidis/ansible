# 9.6 Combining Loops & Conditionals 🔀🔄

## Γιατί τα συνδυάζουμε;

Ο συνδυασμός loops και conditionals μας δίνει τη δυνατότητα να γράφουμε **πλήρως παραμετρικό κώδικα** που προσαρμόζεται αυτόματα:

```yaml
# Χωρίς συνδυασμό — πολύς κώδικας ❌
- name: Install curl on Debian
  ansible.builtin.apt:
    name: curl
    state: present
  when: ansible_facts['os_family'] == "Debian"

- name: Install vim on Debian
  ansible.builtin.apt:
    name: vim
    state: present
  when: ansible_facts['os_family'] == "Debian"

# Με συνδυασμό — καθαρό! ✅
- name: Install packages on Debian
  ansible.builtin.apt:
    name: "{{ item }}"
    state: present
  loop: "{{ common_packages }}"
  when: ansible_facts['os_family'] == "Debian"
```

---

## Βασικός συνδυασμός

```yaml
tasks:

  # ── Loop + when σε απλή λίστα ─────────────
  - name: Εγκατάσταση packages (Debian)
    ansible.builtin.apt:
      name:  "{{ item }}"
      state: present
    loop:
      - nginx
      - curl
      - vim
      - git
    when: ansible_facts['os_family'] == "Debian"

  # ── Loop + when σε dictionary ─────────────
  - name: Δημιουργία users μόνο σε production
    ansible.builtin.user:
      name:  "{{ item.name }}"
      shell: "{{ item.shell }}"
      state: present
    loop:
      - { name: appuser,  shell: /bin/bash  }
      - { name: deploy,   shell: /bin/bash  }
      - { name: monitor,  shell: /bin/false }
    when: app_env == "production"
    loop_control:
      label: "{{ item.name }}"
```

## when μέσα στο Loop — Φιλτράρισμα Items

```yaml
tasks:

  # ── Εγκατάσταση selective packages ────────
  - name: Εγκατάσταση επιλεγμένων packages
    ansible.builtin.package:
      name:  "{{ item.name }}"
      state: present
    loop:
      - { name: nginx,    enabled: true,  distro: all    }
      - { name: apache2,  enabled: false, distro: debian }
      - { name: mysql,    enabled: true,  distro: all    }
      - { name: fail2ban, enabled: true,  distro: all    }
      - { name: selinux,  enabled: true,  distro: redhat }
    when: item.enabled    # ← εγκατάσταση μόνο αν enabled=true
    loop_control:
      label: "{{ item.name }}"

  # ── Φιλτράρισμα βάσει distro ──────────────
  - name: Distro-specific packages
    ansible.builtin.package:
      name:  "{{ item.name }}"
      state: present
    loop:
      - { name: python3-apt,         distro: Debian }
      - { name: apt-transport-https, distro: Debian }
      - { name: epel-release,        distro: RedHat }
      - { name: python3-libselinux,  distro: RedHat }
      - { name: python3-zypp,        distro: Suse   }
    when: item.distro == ansible_facts['os_family']
    loop_control:
      label: "{{ item.name }}"
```

## Loop + Register + Conditional

```yaml
tasks:

  # ── Έλεγχος services & restart αν χρειάζεται
  - name: Έλεγχος κατάστασης services
    ansible.builtin.command:
      cmd: "systemctl is-active {{ item }}"
    register: service_checks
    loop:
      - nginx
      - ssh
      - fail2ban
    ignore_errors: true
    changed_when: false
    loop_control:
      label: "{{ item }}"

  - name: Εκκίνηση services που δεν τρέχουν
    ansible.builtin.service:
      name:  "{{ item.item }}"
      state: started
    loop: "{{ service_checks.results }}"
    when: item.rc != 0           # ← rc != 0 = δεν τρέχει
    loop_control:
      label: "{{ item.item }}"

  # ── Εμφάνιση αποτελεσμάτων ────────────────
  - name: Status report
    ansible.builtin.debug:
      msg: >
        {{ item.item }}:
        {{ '✅ Running' if item.rc == 0 else '❌ Stopped' }}
    loop: "{{ service_checks.results }}"
    loop_control:
      label: "{{ item.item }}"
```

## Σύνθετο παράδειγμα — Multi-distro Package Management

```yaml
tasks:

  # ── Ορισμός packages ανά distro ───────────
  - name: Ορισμός distro-specific packages
    ansible.builtin.set_fact:
      distro_packages: "{{ debian_pkgs }}"
    when: ansible_facts['os_family'] == "Debian"
    vars:
      debian_pkgs:
        - python3-apt
        - apt-transport-https
        - ca-certificates
        - gnupg

  - name: Ορισμός RedHat packages
    ansible.builtin.set_fact:
      distro_packages: "{{ redhat_pkgs }}"
    when: ansible_facts['os_family'] == "RedHat"
    vars:
      redhat_pkgs:
        - epel-release
        - python3-libselinux
        - dnf-plugins-core

  - name: Ορισμός openSUSE packages
    ansible.builtin.set_fact:
      distro_packages: "{{ suse_pkgs }}"
    when: ansible_facts['os_family'] == "Suse"
    vars:
      suse_pkgs:
        - python3-zypp
        - zypper-aptitude

  # ── Εγκατάσταση (universal με loop) ───────
  - name: Εγκατάσταση distro packages
    ansible.builtin.package:
      name:  "{{ item }}"
      state: present
    loop: "{{ distro_packages }}"
    when: distro_packages is defined
    loop_control:
      label: "{{ item }}"
```

## Loop + Conditional + Handler

```yaml
---
- name: Config Management με Loop & Conditional
  hosts: all
  become: true
  gather_facts: true

  vars:
    config_files:
      - src:     files/nginx.conf
        dest:    /etc/nginx/nginx.conf
        service: nginx
        distro:  all
      - src:     files/sshd_config
        dest:    /etc/ssh/sshd_config
        service: "{{ service_ssh }}"
        distro:  all
      - src:     files/fail2ban.conf
        dest:    /etc/fail2ban/jail.local
        service: fail2ban
        distro:  all

  tasks:

    - name: Αντιγραφή config αρχείων
      ansible.builtin.copy:
        src:    "{{ item.src }}"
        dest:   "{{ item.dest }}"
        backup: true
        mode:   '0644'
      loop: "{{ config_files }}"
      when: >
        item.distro == "all" or
        item.distro == ansible_facts['os_family']
      loop_control:
        label: "{{ item.dest }}"
      notify: "Restart {{ item.service }}"

  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted

    - name: "Restart {{ service_ssh }}"
      ansible.builtin.service:
        name:  "{{ service_ssh }}"
        state: restarted

    - name: Restart fail2ban
      ansible.builtin.service:
        name:  fail2ban
        state: restarted
```

## Πλήρες παράδειγμα — Και στις 3 διανομές

```yaml
---
# loops-conditionals-demo.yml

- name: Loops & Conditionals — Full Demo
  hosts: all
  become: true
  gather_facts: true

  vars:
    app_env: production

    # Packages με metadata
    all_packages:
      - name:    nginx
        enabled: true
        distros: [Debian, RedHat, Suse]
      - name:    curl
        enabled: true
        distros: [Debian, RedHat, Suse]
      - name:    vim
        enabled: true
        distros: [Debian, RedHat, Suse]
      - name:    python3-apt
        enabled: true
        distros: [Debian]
      - name:    epel-release
        enabled: true
        distros: [RedHat]
      - name:    python3-zypp
        enabled: true
        distros: [Suse]

    # Users με metadata
    app_users:
      - name:       appuser
        shell:      /bin/bash
        production: true
        staging:    true
      - name:       debuguser
        shell:      /bin/bash
        production: false    # ← μόνο σε staging
        staging:    true
      - name:       monitor
        shell:      /bin/false
        production: true
        staging:    true

    # Directories
    app_dirs:
      - path:       /opt/myapp
        mode:       '0755'
        production: true
        staging:    true
      - path:       /opt/myapp/logs
        mode:       '0750'
        production: true
        staging:    true
      - path:       /opt/myapp/debug
        mode:       '0755'
        production: false    # ← μόνο σε staging
        staging:    true

  tasks:

    # ── Εμφάνιση περιβάλλοντος ────────────────
    - name: Περιβάλλον εκτέλεσης
      ansible.builtin.debug:
        msg:
          - "Host   : {{ inventory_hostname }}"
          - "OS     : {{ ansible_facts['distribution'] }}"
          - "Family : {{ ansible_facts['os_family'] }}"
          - "Env    : {{ app_env }}"

    # ── Εγκατάσταση packages ──────────────────
    # Loop + when για φιλτράρισμα ανά distro
    - name: Εγκατάσταση packages
      ansible.builtin.package:
        name:  "{{ item.name }}"
        state: present
      loop: "{{ all_packages }}"
      when:
        - item.enabled
        - ansible_facts['distribution'] in item.distros or
          ansible_facts['os_family'] in item.distros
      loop_control:
        label: "{{ item.name }}"

    # ── Δημιουργία directories ────────────────
    # Loop + when για φιλτράρισμα ανά environment
    - name: Δημιουργία directories
      ansible.builtin.file:
        path:  "{{ item.path }}"
        mode:  "{{ item.mode }}"
        state: directory
      loop: "{{ app_dirs }}"
      when: >
        (app_env == "production" and item.production) or
        (app_env == "staging" and item.staging)
      loop_control:
        label: "{{ item.path }}"

    # ── Δημιουργία users ──────────────────────
    # Loop + when για φιλτράρισμα ανά environment
    - name: Δημιουργία users
      ansible.builtin.user:
        name:  "{{ item.name }}"
        shell: "{{ item.shell }}"
        state: present
      loop: "{{ app_users }}"
      when: >
        (app_env == "production" and item.production) or
        (app_env == "staging" and item.staging)
      loop_control:
        label: "{{ item.name }}"

    # ── Επαλήθευση directories ────────────────
    - name: Έλεγχος directories
      ansible.builtin.stat:
        path: "{{ item.path }}"
      register: dir_results
      loop: "{{ app_dirs }}"
      loop_control:
        label: "{{ item.path }}"

    - name: Report directories
      ansible.builtin.debug:
        msg: >
          {{ item.item.path }}:
          {{ '✅ EXISTS' if item.stat.exists else '❌ MISSING' }}
      loop: "{{ dir_results.results }}"
      loop_control:
        label: "{{ item.item.path }}"

    # ── Εκκίνηση services ─────────────────────
    - name: Εκκίνηση nginx
      ansible.builtin.service:
        name:    nginx
        state:   started
        enabled: true
```

## Σύνοψη 9.6

```
Loops + Conditionals
├── Βασικός συνδυασμός:
│   loop: [...]
│   when: condition
│   → when εφαρμόζεται σε κάθε iteration
│
├── Φιλτράρισμα items:
│   when: item.enabled
│   when: item.distro == ansible_facts['os_family']
│
├── Loop + Register + Conditional:
│   → .results list με αποτελέσματα
│   → when: item.rc != 0
│
├── set_fact + loop:
│   → δυναμικοί ορισμοί μεταβλητών ανά distro
│
└── Metadata pattern:
    loop:
      - { name: pkg, enabled: true, distros: [...] }
    when: item.enabled and
          ansible_facts['os_family'] in item.distros
```
