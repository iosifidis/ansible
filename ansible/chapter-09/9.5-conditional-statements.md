# 9.5 Conditional Statements — Συνθήκες 🔀

## Γιατί Conditionals;

```yaml
# Χωρίς conditionals — ξεχωριστά playbooks για κάθε distro ❌
# debian-setup.yml, redhat-setup.yml, opensuse-setup.yml

# Με conditionals — ένα playbook για όλες! ✅
- name: Εγκατάσταση nginx
  ansible.builtin.apt:
    name: nginx
    state: present
  when: ansible_facts['os_family'] == "Debian"

- name: Εγκατάσταση nginx
  ansible.builtin.dnf:
    name: nginx
    state: present
  when: ansible_facts['os_family'] == "RedHat"
```

## Βασικό when

```yaml
tasks:

  # ── Απλή συνθήκη ──────────────────────────
  - name: Εκτέλεση μόνο σε Debian
    ansible.builtin.apt:
      name: nginx
      state: present
    when: ansible_facts['os_family'] == "Debian"

  # ── Boolean συνθήκη ───────────────────────
  - name: Εκτέλεση αν ssl_enabled είναι true
    ansible.builtin.debug:
      msg: "SSL is enabled!"
    when: ssl_enabled                    # ← αρκεί χωρίς == true

  - name: Εκτέλεση αν ssl_enabled είναι false
    ansible.builtin.debug:
      msg: "SSL is disabled!"
    when: not ssl_enabled                # ← άρνηση

  # ── Αριθμητική σύγκριση ───────────────────
  - name: Εκτέλεση αν port είναι 80
    ansible.builtin.debug:
      msg: "HTTP port"
    when: http_port == 80

  - name: Εκτέλεση αν port > 1024
    ansible.builtin.debug:
      msg: "Non-privileged port"
    when: http_port > 1024

  # ── String σύγκριση ───────────────────────
  - name: Εκτέλεση σε production
    ansible.builtin.debug:
      msg: "Production environment!"
    when: app_env == "production"

  - name: Εκτέλεση αν ΔΕΝ είναι production
    ansible.builtin.debug:
      msg: "Non-production environment"
    when: app_env != "production"
```

## when με Facts

Τα facts είναι η πιο συχνή χρήση conditionals:

```yaml
tasks:

  # ── OS Family ─────────────────────────────
  - name: Μόνο Debian/Ubuntu
    ansible.builtin.apt:
      name: nginx
      state: present
    when: ansible_facts['os_family'] == "Debian"

  - name: Μόνο RedHat/Fedora
    ansible.builtin.dnf:
      name: nginx
      state: present
    when: ansible_facts['os_family'] == "RedHat"

  - name: Μόνο openSUSE
    community.general.zypper:
      name: nginx
      state: present
    when: ansible_facts['os_family'] == "Suse"

  # ── Συγκεκριμένη Διανομή ──────────────────
  - name: Μόνο Ubuntu
    ansible.builtin.debug:
      msg: "Ubuntu specific task"
    when: ansible_facts['distribution'] == "Ubuntu"

  - name: Μόνο Debian
    ansible.builtin.debug:
      msg: "Debian specific task"
    when: ansible_facts['distribution'] == "Debian"

  - name: Μόνο Fedora
    ansible.builtin.debug:
      msg: "Fedora specific task"
    when: ansible_facts['distribution'] == "Fedora"

  # ── Συγκεκριμένη Έκδοση ───────────────────
  - name: Μόνο Debian 12+
    ansible.builtin.debug:
      msg: "Debian 12 Bookworm or newer"
    when:
      - ansible_facts['distribution'] == "Debian"
      - ansible_facts['distribution_major_version'] | int >= 12

  # ── Αρχιτεκτονική ─────────────────────────
  - name: Μόνο ARM64
    ansible.builtin.debug:
      msg: "ARM64 architecture"
    when: ansible_facts['architecture'] == "aarch64"

  - name: Μόνο x86_64
    ansible.builtin.debug:
      msg: "x86_64 architecture"
    when: ansible_facts['architecture'] == "x86_64"

  # ── Μνήμη ─────────────────────────────────
  - name: Μόνο αν έχει αρκετή RAM
    ansible.builtin.debug:
      msg: "Enough RAM for this task"
    when: ansible_facts['memtotal_mb'] >= 2048
```

## Πολλαπλές συνθήκες

```yaml
tasks:

  # ── AND (και οι δύο πρέπει να ισχύουν) ────
  # Τρόπος 1: λίστα (συνιστάται)
  - name: AND condition
    ansible.builtin.debug:
      msg: "Debian AND production"
    when:
      - ansible_facts['os_family'] == "Debian"
      - app_env == "production"

  # Τρόπος 2: and keyword
  - name: AND condition (inline)
    ansible.builtin.debug:
      msg: "Debian AND production"
    when: ansible_facts['os_family'] == "Debian" and
          app_env == "production"

  # ── OR (τουλάχιστον μία πρέπει να ισχύει) ─
  - name: OR condition
    ansible.builtin.debug:
      msg: "Debian OR Ubuntu"
    when: >
      ansible_facts['distribution'] == "Debian" or
      ansible_facts['distribution'] == "Ubuntu"

  # ── NOT (αντίστροφη συνθήκη) ──────────────
  - name: NOT condition
    ansible.builtin.debug:
      msg: "Not a RedHat system"
    when: ansible_facts['os_family'] != "RedHat"

  # ── Σύνθετη συνθήκη ───────────────────────
  - name: Complex condition
    ansible.builtin.debug:
      msg: "Complex condition met"
    when: >
      (ansible_facts['os_family'] == "Debian" and
       ansible_facts['distribution_major_version'] | int >= 11) or
      (ansible_facts['os_family'] == "RedHat" and
       ansible_facts['distribution_major_version'] | int >= 8)
```

## when με Register

```yaml
tasks:

  # ── Έλεγχος αν υπάρχει αρχείο ────────────
  - name: Έλεγχος nginx config
    ansible.builtin.stat:
      path: /etc/nginx/nginx.conf
    register: nginx_conf

  - name: Backup αν υπάρχει
    ansible.builtin.copy:
      src:  /etc/nginx/nginx.conf
      dest: /etc/nginx/nginx.conf.bak
      remote_src: true
    when: nginx_conf.stat.exists      # ← χρήση register

  - name: Εγκατάσταση αν δεν υπάρχει
    ansible.builtin.apt:
      name: nginx
      state: present
    when: not nginx_conf.stat.exists

  # ── Έλεγχος return code ───────────────────
  - name: Έλεγχος αν nginx τρέχει
    ansible.builtin.command:
      cmd: systemctl is-active nginx
    register: nginx_status
    ignore_errors: true
    changed_when: false

  - name: Restart αν δεν τρέχει
    ansible.builtin.service:
      name: nginx
      state: started
    when: nginx_status.rc != 0       # ← rc != 0 = δεν τρέχει

  # ── Έλεγχος output ────────────────────────
  - name: Έλεγχος disk usage
    ansible.builtin.shell:
      cmd: "df / | tail -1 | awk '{print $5}' | tr -d '%'"
    register: disk_usage
    changed_when: false

  - name: Προειδοποίηση αν disk > 80%
    ansible.builtin.debug:
      msg: "⚠️ ΠΡΟΕΙΔΟΠΟΙΗΣΗ: Disk usage {{ disk_usage.stdout }}%"
    when: disk_usage.stdout | int > 80
```

## when με Variables

```yaml
tasks:

  # ── Έλεγχος αν μεταβλητή υπάρχει ─────────
  - name: Εκτέλεση αν υπάρχει η μεταβλητή
    ansible.builtin.debug:
      msg: "Variable exists: {{ my_var }}"
    when: my_var is defined

  - name: Εκτέλεση αν ΔΕΝ υπάρχει
    ansible.builtin.debug:
      msg: "Variable not defined!"
    when: my_var is not defined

  # ── Έλεγχος αν λίστα περιέχει τιμή ───────
  - name: Εκτέλεση αν nginx στη λίστα
    ansible.builtin.debug:
      msg: "nginx is in the list"
    when: "'nginx' in web_packages"

  # ── Έλεγχος αν string περιέχει ────────────
  - name: Εκτέλεση αν hostname περιέχει "web"
    ansible.builtin.debug:
      msg: "This is a web server"
    when: "'web' in inventory_hostname"

  # ── Έλεγχος τύπου ─────────────────────────
  - name: Εκτέλεση αν είναι string
    ansible.builtin.debug:
      msg: "It's a string"
    when: my_var is string

  - name: Εκτέλεση αν είναι αριθμός
    ansible.builtin.debug:
      msg: "It's a number"
    when: my_var is number
```

## when σε Block

```yaml
tasks:

  # ── Block με when — εφαρμόζεται σε όλα ────
  - name: Debian-specific tasks
    when: ansible_facts['os_family'] == "Debian"
    block:

      - name: Update apt cache
        ansible.builtin.apt:
          update_cache: true

      - name: Εγκατάσταση apt packages
        ansible.builtin.apt:
          name:
            - nginx
            - python3-apt
            - apt-transport-https
          state: present

      - name: Ρύθμιση ufw
        community.general.ufw:
          rule:  allow
          port:  "80"
          proto: tcp

  # ↑ Το when εφαρμόζεται σε ΟΛΑ τα tasks
  # του block — δεν χρειάζεται να το γράψεις
  # σε κάθε task ξεχωριστά! ✅
```

## Πρακτικό παράδειγμα — Multi-distro Conditionals

```yaml
---
# conditionals-demo.yml

- name: Conditionals Demo — Και στις 3 Διανομές
  hosts: all
  become: true
  gather_facts: true

  vars:
    install_nginx: true
    min_ram_mb:    512
    app_env:       production

  tasks:

    # ── Εμφάνιση πληροφοριών ──────────────────
    - name: Server info
      ansible.builtin.debug:
        msg:
          - "OS Family   : {{ ansible_facts['os_family'] }}"
          - "Distribution: {{ ansible_facts['distribution'] }}"
          - "Version     : {{ ansible_facts['distribution_version'] }}"
          - "RAM         : {{ ansible_facts['memtotal_mb'] }}MB"
          - "Architecture: {{ ansible_facts['architecture'] }}"

    # ── Έλεγχος RAM ───────────────────────────
    - name: Έλεγχος αρκετής RAM
      ansible.builtin.debug:
        msg: "✅ Αρκετή RAM: {{ ansible_facts['memtotal_mb'] }}MB"
      when: ansible_facts['memtotal_mb'] >= min_ram_mb

    - name: Προειδοποίηση RAM
      ansible.builtin.debug:
        msg: "⚠️ Λίγη RAM: {{ ansible_facts['memtotal_mb'] }}MB"
      when: ansible_facts['memtotal_mb'] < min_ram_mb

    # ── Εγκατάσταση ανά distro ────────────────
    - name: Εγκατάσταση nginx (Debian)
      when:
        - install_nginx
        - ansible_facts['os_family'] == "Debian"
      block:

        - name: Update apt cache
          ansible.builtin.apt:
            update_cache: true

        - name: Install nginx (Debian)
          ansible.builtin.apt:
            name: nginx
            state: present

    - name: Εγκατάσταση nginx (RedHat)
      when:
        - install_nginx
        - ansible_facts['os_family'] == "RedHat"
      block:

        - name: Install nginx (RedHat)
          ansible.builtin.dnf:
            name: nginx
            state: present

    - name: Εγκατάσταση nginx (openSUSE)
      when:
        - install_nginx
        - ansible_facts['os_family'] == "Suse"
      block:

        - name: Install nginx (openSUSE)
          community.general.zypper:
            name: nginx
            state: present

    # ── Universal tasks ────────────────────────
    - name: Εκκίνηση nginx (παντού)
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true
      when: install_nginx

    # ── Production μόνο ───────────────────────
    - name: Production-only ρυθμίσεις
      ansible.builtin.debug:
        msg: "Εφαρμογή production ρυθμίσεων..."
      when: app_env == "production"
```

```bash
# Εκτέλεση
ansible-playbook playbooks/conditionals-demo.yml \
    --limit nextcloud -v

# Override env
ansible-playbook playbooks/conditionals-demo.yml \
    --limit nextcloud \
    -e "app_env=staging install_nginx=false"
```

## Σύνοψη 9.5

```
Conditional Statements (when)
├── Βασική σύνταξη: when: condition
│
├── Τύποι συνθηκών:
│   ├── Σύγκριση  → == != > < >= <=
│   ├── Boolean   → when: var / when: not var
│   ├── Existence → is defined / is not defined
│   ├── Inclusion → "'value' in list"
│   └── String    → "'text' in string"
│
├── Πολλαπλές συνθήκες:
│   ├── AND → λίστα ή and keyword
│   ├── OR  → or keyword
│   └── NOT → not keyword ή !=
│
├── when με:
│   ├── Facts    → ansible_facts['os_family']
│   ├── Register → result.rc, result.stat.exists
│   └── Variables→ is defined, in list
│
└── Block + when → εφαρμόζεται σε όλα τα tasks
```
