# 9.4 Looping — Επανάληψη 🔄

## Γιατί Loops;

```yaml
# Χωρίς loop — επαναλαμβανόμενος κώδικας ❌
- name: Εγκατάσταση curl
  ansible.builtin.apt:
    name: curl
    state: present

- name: Εγκατάσταση vim
  ansible.builtin.apt:
    name: vim
    state: present

- name: Εγκατάσταση git
  ansible.builtin.apt:
    name: git
    state: present

# Με loop — καθαρό και συντομότερο ✅
- name: Εγκατάσταση packages
  ansible.builtin.apt:
    name: "{{ item }}"
    state: present
  loop:
    - curl
    - vim
    - git
```

## Βασικό Loop

```yaml
tasks:

  # ── Loop με απλή λίστα ────────────────────
  - name: Εγκατάσταση packages
    ansible.builtin.package:
      name: "{{ item }}"      # ← το item είναι η τρέχουσα τιμή
      state: present
    loop:
      - curl
      - vim
      - git
      - htop
      - tree

  # ── Loop με μεταβλητή ─────────────────────
  - name: Εγκατάσταση από μεταβλητή
    ansible.builtin.package:
      name: "{{ item }}"
      state: present
    loop: "{{ common_packages }}"   # ← από vars/group_vars
```

## Loop με Dictionaries

```yaml
tasks:

  # ── Δημιουργία χρηστών ────────────────────
  - name: Δημιουργία users
    ansible.builtin.user:
      name:  "{{ item.name }}"      # ← item.key
      shell: "{{ item.shell }}"
      groups: "{{ item.groups }}"
      state: present
    loop:
      - name:   developer
        shell:  /bin/bash
        groups: sudo
      - name:   deploy
        shell:  /bin/bash
        groups: www-data
      - name:   monitoring
        shell:  /bin/false
        groups: ""

  # ── Δημιουργία directories ────────────────
  - name: Δημιουργία φακέλων
    ansible.builtin.file:
      path:  "{{ item.path }}"
      mode:  "{{ item.mode }}"
      owner: "{{ item.owner }}"
      state: directory
    loop:
      - path:  /var/www/html
        mode:  '0755'
        owner: www-data
      - path:  /var/log/myapp
        mode:  '0750'
        owner: syslog
      - path:  /etc/myapp
        mode:  '0644'
        owner: root

  # ── Copy αρχείων ──────────────────────────
  - name: Αντιγραφή config αρχείων
    ansible.builtin.copy:
      src:  "{{ item.src }}"
      dest: "{{ item.dest }}"
      mode: "{{ item.mode }}"
    loop:
      - src:  files/nginx.conf
        dest: /etc/nginx/nginx.conf
        mode: '0644'
      - src:  files/php.ini
        dest: /etc/php/8.1/fpm/php.ini
        mode: '0644'
      - src:  files/myapp.conf
        dest: /etc/myapp/config.conf
        mode: '0640'
```

## Loop με Index — loop_control

```yaml
tasks:

  # ── Εμφάνιση index ────────────────────────
  - name: Loop με αρίθμηση
    ansible.builtin.debug:
      msg: "{{ loop_index }}. {{ item }}"
    loop:
      - nginx
      - mysql
      - redis
    loop_control:
      index_var: loop_index    # ← μεταβλητή για index (0,1,2...)

  # ── Custom label στο output ───────────────
  - name: Loop με label
    ansible.builtin.user:
      name:  "{{ item.name }}"
      shell: "{{ item.shell }}"
      state: present
    loop:
      - { name: developer, shell: /bin/bash }
      - { name: deploy,    shell: /bin/bash }
    loop_control:
      label: "{{ item.name }}"   # ← εμφανίζει μόνο το name
      # Χωρίς label: εμφανίζει όλο το dictionary (ακατάστατο)
      # Με label:    εμφανίζει μόνο: item.name ✅

  # ── Pause μεταξύ iterations ───────────────
  - name: Loop με pause
    ansible.builtin.debug:
      msg: "Processing {{ item }}"
    loop:
      - server1
      - server2
      - server3
    loop_control:
      pause: 2    # ← 2 δευτερόλεπτα μεταξύ iterations
```

## Loop με Register

```yaml
tasks:

  - name: Έλεγχος services
    ansible.builtin.service_facts:

  - name: Έλεγχος αν τρέχουν τα services
    ansible.builtin.command:
      cmd: "systemctl is-active {{ item }}"
    register: service_status
    loop:
      - nginx
      - ssh
      - fail2ban
    ignore_errors: true
    changed_when: false

  - name: Εμφάνιση αποτελεσμάτων
    ansible.builtin.debug:
      msg: "{{ item.item }}: {{ item.stdout }}"
    loop: "{{ service_status.results }}"
    # ↑ .results → λίστα με αποτελέσματα κάθε iteration
    loop_control:
      label: "{{ item.item }}"
```

## Nested Loops — Loops μέσα σε Loops

```yaml
tasks:

  # ── Δημιουργία directories ανά user ───────
  - name: Δημιουργία user directories
    ansible.builtin.file:
      path: "/home/{{ item[0] }}/{{ item[1] }}"
      state: directory
      mode: '0755'
    loop: "{{ users | product(directories) | list }}"
    vars:
      users:
        - developer
        - deploy
      directories:
        - projects
        - logs
        - backups

  # ↑ Δημιουργεί:
  # /home/developer/projects
  # /home/developer/logs
  # /home/developer/backups
  # /home/deploy/projects
  # /home/deploy/logs
  # /home/deploy/backups
```

## Loop με Conditionals

```yaml
tasks:

  # ── Εγκατάσταση μόνο αν δεν υπάρχει ──────
  - name: Εγκατάσταση selective packages
    ansible.builtin.package:
      name:  "{{ item.name }}"
      state: present
    loop:
      - { name: nginx,    install: true  }
      - { name: apache2,  install: false }
      - { name: mysql,    install: true  }
      - { name: postgres, install: false }
    when: item.install    # ← εγκατάσταση μόνο αν install=true

  # ── Διαφορετική ενέργεια ανά distro ───────
  - name: Εγκατάσταση distro-specific packages
    ansible.builtin.package:
      name:  "{{ item }}"
      state: present
    loop: "{{ debian_packages }}"
    when: ansible_facts['os_family'] == "Debian"
    vars:
      debian_packages:
        - python3-apt
        - apt-transport-https
        - ca-certificates
```

## until Loop — Επανάληψη μέχρι συνθήκη

```yaml
tasks:

  # ── Περίμενε μέχρι service να ξεκινήσει ──
  - name: Αναμονή για nginx
    ansible.builtin.uri:
      url: http://localhost:80
      status_code: 200
    register: nginx_check
    until: nginx_check.status == 200    # ← συνθήκη
    retries: 10                         # ← max προσπάθειες
    delay: 5                            # ← δευτερόλεπτα μεταξύ

  # ── Αναμονή για database ──────────────────
  - name: Αναμονή για PostgreSQL
    ansible.builtin.command:
      cmd: pg_isready -h localhost
    register: pg_check
    until: pg_check.rc == 0
    retries: 12
    delay: 5
    changed_when: false
```

## Πρακτικό παράδειγμα — Multi-distro

```yaml
---
# loops-demo.yml

- name: Loops Demo — Και στις 3 Διανομές
  hosts: all
  become: true
  gather_facts: true

  vars:
    # Κοινά packages (universal)
    common_packages:
      - curl
      - vim
      - git
      - htop

    # Φάκελοι που χρειάζονται παντού
    app_directories:
      - path:  /opt/myapp
        mode:  '0755'
        owner: root
      - path:  /opt/myapp/logs
        mode:  '0750'
        owner: root
      - path:  /opt/myapp/config
        mode:  '0640'
        owner: root

    # Χρήστες που χρειάζονται παντού
    app_users:
      - name:   appuser
        shell:  /bin/bash
        groups: ""
      - name:   monitor
        shell:  /bin/false
        groups: ""

  tasks:

    # ── Εγκατάσταση common packages ───────────
    - name: Εγκατάσταση κοινών packages (Debian)
      ansible.builtin.apt:
        name: "{{ item }}"
        state: present
        update_cache: true
      loop: "{{ common_packages }}"
      when: ansible_facts['os_family'] == "Debian"
      loop_control:
        label: "{{ item }}"

    - name: Εγκατάσταση κοινών packages (RedHat)
      ansible.builtin.dnf:
        name: "{{ item }}"
        state: present
      loop: "{{ common_packages }}"
      when: ansible_facts['os_family'] == "RedHat"
      loop_control:
        label: "{{ item }}"

    - name: Εγκατάσταση κοινών packages (openSUSE)
      community.general.zypper:
        name: "{{ item }}"
        state: present
      loop: "{{ common_packages }}"
      when: ansible_facts['os_family'] == "Suse"
      loop_control:
        label: "{{ item }}"

    # ── Δημιουργία directories (universal) ────
    - name: Δημιουργία app directories
      ansible.builtin.file:
        path:  "{{ item.path }}"
        mode:  "{{ item.mode }}"
        owner: "{{ item.owner }}"
        state: directory
      loop: "{{ app_directories }}"
      loop_control:
        label: "{{ item.path }}"

    # ── Δημιουργία users (universal) ──────────
    - name: Δημιουργία app users
      ansible.builtin.user:
        name:  "{{ item.name }}"
        shell: "{{ item.shell }}"
        state: present
      loop: "{{ app_users }}"
      loop_control:
        label: "{{ item.name }}"

    # ── Επαλήθευση ────────────────────────────
    - name: Έλεγχος directories
      ansible.builtin.stat:
        path: "{{ item.path }}"
      register: dir_check
      loop: "{{ app_directories }}"
      loop_control:
        label: "{{ item.path }}"

    - name: Αποτελέσματα ελέγχου
      ansible.builtin.debug:
        msg: "{{ item.item.path }}: \
              {{ 'EXISTS ✅' if item.stat.exists else 'MISSING ❌' }}"
      loop: "{{ dir_check.results }}"
      loop_control:
        label: "{{ item.item.path }}"
```

## Σύνοψη 9.4

```
Looping
├── Βασικό loop:
│   loop: [item1, item2, item3]
│   → χρήση: "{{ item }}"
│
├── Dictionary loop:
│   loop: [{key: val}, {key: val}]
│   → χρήση: "{{ item.key }}"
│
├── loop_control:
│   ├── index_var → αρίθμηση (0,1,2...)
│   ├── label     → καθαρό output
│   └── pause     → καθυστέρηση
│
├── register + loop:
│   → αποτελέσματα στο .results list
│
├── Nested loops:
│   → product() filter
│
├── Loop + when:
│   → φιλτράρισμα iterations
│
└── until loop:
    ├── retries → max προσπάθειες
    └── delay   → καθυστέρηση μεταξύ
```
