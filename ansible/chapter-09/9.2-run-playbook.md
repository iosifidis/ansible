# 9.2 Εκτέλεση Playbook ▶️

## Η βασική εντολή

```bash
ansible-playbook [options] playbook.yml
```

---

## Flags — Όλες οι επιλογές

### Inventory & Connection:
```bash
# Custom inventory
ansible-playbook -i inventory/hosts.ini playbook.yml
ansible-playbook -i "192.168.1.10," playbook.yml   # ← inline host

# Custom user
ansible-playbook -u deploy playbook.yml

# Custom SSH key
ansible-playbook --private-key ~/.ssh/other_key playbook.yml

# Custom port
ansible-playbook -e "ansible_port=2022" playbook.yml
```

### Targeting — Ποιους Servers:
```bash
# Limit σε συγκεκριμένο host
ansible-playbook playbook.yml --limit nextcloud

# Limit σε group
ansible-playbook playbook.yml --limit debian_based

# Limit σε πολλά
ansible-playbook playbook.yml --limit "web01,web02"

# Limit με wildcard
ansible-playbook playbook.yml --limit "web*"

# Εξαίρεση
ansible-playbook playbook.yml --limit "all,!controller"
```

### Checking & Testing:
```bash
# Syntax check — έλεγχος YAML σύνταξης
ansible-playbook playbook.yml --syntax-check

# Dry run — τι ΘΑ έκανε χωρίς να κάνει τίποτα
ansible-playbook playbook.yml --check

# Dry run + δες τις αλλαγές
ansible-playbook playbook.yml --check --diff

# List tasks — δες ποια tasks θα τρέξουν
ansible-playbook playbook.yml --list-tasks

# List hosts — δες ποιοι servers θα επηρεαστούν
ansible-playbook playbook.yml --list-hosts

# List tags — δες τα διαθέσιμα tags
ansible-playbook playbook.yml --list-tags
```

### Verbosity:
```bash
# Επίπεδα verbosity
ansible-playbook playbook.yml -v      # βασικό
ansible-playbook playbook.yml -vv     # περισσότερο
ansible-playbook playbook.yml -vvv    # SSH commands
ansible-playbook playbook.yml -vvvv   # network level
```

### Variables:
```bash
# Extra variables (override όλα τα άλλα!)
ansible-playbook playbook.yml -e "http_port=8080"
ansible-playbook playbook.yml -e "http_port=8080 app_env=staging"

# Extra variables από αρχείο
ansible-playbook playbook.yml -e "@vars/extra.yml"

# JSON format
ansible-playbook playbook.yml \
    -e '{"http_port": 8080, "app_env": "staging"}'
```

### Tags:
```bash
# Τρέξε μόνο συγκεκριμένα tags
ansible-playbook playbook.yml --tags "packages,config"

# Παράλειψε συγκεκριμένα tags
ansible-playbook playbook.yml --skip-tags "packages"
```

### Privilege Escalation:
```bash
# Ενεργοποίηση sudo
ansible-playbook playbook.yml --become

# Ζήτα sudo password
ansible-playbook playbook.yml --become --ask-become-pass
ansible-playbook playbook.yml -b -K    # ← σύντομη μορφή
```

## Το --diff Flag

Ένα από τα πιο χρήσιμα flags — δείχνει **τι αλλάζει** σε αρχεία:

```bash
ansible-playbook playbook.yml --check --diff
```

```diff
TASK [Ρύθμιση sshd_config] *******************
--- before: /etc/ssh/sshd_config
+++ after: /etc/ssh/sshd_config
@@ -15,7 +15,7 @@
 # Authentication:
-#PermitRootLogin yes
+PermitRootLogin no
 
-#PasswordAuthentication yes
+PasswordAuthentication no
```

> 💡 **Πότε να χρησιμοποιείς `--diff`:**
> ```
> ✅ Πριν εκτελέσεις playbook σε production
> ✅ Όταν δεν θυμάσαι τι αλλάζει το playbook
> ✅ Για code review — δείχνεις τι θα αλλάξει
> ```

## --syntax-check — Πριν από κάθε εκτέλεση

```bash
# ΠΑΝΤΑ κάνε syntax check πριν εκτελέσεις!
ansible-playbook playbooks/security-bootstrap.yml --syntax-check

# Αναμενόμενο (σωστό):
# playbook: playbooks/security-bootstrap.yml ✅

# Αναμενόμενο (λάθος):
# ERROR! We were unable to read either as JSON nor YAML...
# Syntax Error while loading YAML.
#   mapping values are not allowed here
#   line 23, column 15:
#       name: nginx
#                 ^
```

## Η σειρά εκτέλεσης

```bash
# Βέλτιστη πρακτική — πάντα με αυτή τη σειρά:

# Βήμα 1: Syntax check
ansible-playbook playbooks/myplaybook.yml \
    --syntax-check

# Βήμα 2: List tasks (τι θα τρέξει)
ansible-playbook playbooks/myplaybook.yml \
    --list-tasks

# Βήμα 3: List hosts (σε ποιους)
ansible-playbook playbooks/myplaybook.yml \
    --list-hosts

# Βήμα 4: Dry run (τι θα αλλάξει)
ansible-playbook playbooks/myplaybook.yml \
    --check --diff \
    --limit nextcloud

# Βήμα 5: Εκτέλεση σε ένα server πρώτα
ansible-playbook playbooks/myplaybook.yml \
    --limit nextcloud \
    -v

# Βήμα 6: Εκτέλεση σε όλους
ansible-playbook playbooks/myplaybook.yml -v
```

> 📝 **Αυτή η σειρά** σε γλιτώνει από **πολλά λάθη** — ειδικά σε production!

## Start-at-Task — Ξεκίνα από συγκεκριμένο Task

```bash
# Αν κόλλησε σε ένα task → ξεκίνα από εκεί
ansible-playbook playbooks/myplaybook.yml \
    --start-at-task "Ρύθμιση ferm firewall" \
    --limit nextcloud
```

---

## Step Mode — Task-by-Task επιβεβαίωση

```bash
# Ρωτάει πριν από κάθε task
ansible-playbook playbooks/myplaybook.yml --step

# Output:
# TASK [Εγκατάσταση nginx] ****
# Perform task: TASK: Εγκατάσταση nginx (N)o/(y)es/(c)ontinue:
# → y = εκτέλεσε αυτό το task
# → n = παράλειψε
# → c = εκτέλεσε όλα χωρίς ερωτήσεις
```

> 💡 **Χρήσιμο όταν:**
> ```
> ✅ Debugging — θέλεις να δεις κάθε task μία-μία
> ✅ Νέο playbook — πρώτη φορά εκτέλεσης
> ✅ Production — extra προσοχή
> ```

## Retry Files — Επανεκτέλεση σε αποτυχημένους

```bash
# Αν αποτύχει το playbook:
# → δημιουργείται αρχείο myplaybook.retry

# Επανεκτέλεση μόνο στους αποτυχημένους servers
ansible-playbook playbooks/myplaybook.yml \
    --limit @playbooks/myplaybook.retry
```

## Πρακτικό Παράδειγμα — Εκτέλεση basic-playbook.yml

```bash
# 1. Αποθήκευση playbook
cat > ~/ansible/playbooks/basic-playbook.yml << 'EOF'
---
- name: Βασικό Test Playbook
  hosts: debian_based
  become: true
  gather_facts: true

  vars:
    test_message: "Hello from Ansible!"
    test_dir: /tmp/ansible_test

  tasks:

    - name: Εμφάνιση server info
      ansible.builtin.debug:
        msg:
          - "Host: {{ inventory_hostname }}"
          - "OS  : {{ ansible_facts['distribution'] }}"
          - "Msg : {{ test_message }}"

    - name: Δημιουργία test directory
      ansible.builtin.file:
        path: "{{ test_dir }}"
        state: directory
        mode: '0755'

    - name: Δημιουργία test αρχείου
      ansible.builtin.copy:
        dest: "{{ test_dir }}/test.txt"
        content: "{{ test_message }}\n"
        mode: '0644'

    - name: Ανάγνωση test αρχείου
      ansible.builtin.command:
        cmd: "cat {{ test_dir }}/test.txt"
      register: file_content
      changed_when: false

    - name: Εμφάνιση περιεχομένου
      ansible.builtin.debug:
        msg: "Περιεχόμενο: {{ file_content.stdout }}"
EOF

# 2. Syntax check
ansible-playbook playbooks/basic-playbook.yml --syntax-check

# 3. List tasks
ansible-playbook playbooks/basic-playbook.yml --list-tasks

# 4. Dry run
ansible-playbook playbooks/basic-playbook.yml \
    --check --diff --limit nextcloud

# 5. Εκτέλεση
ansible-playbook playbooks/basic-playbook.yml \
    --limit nextcloud -v
```

## Σύνοψη 9.2

```
Εκτέλεση Playbook
├── Βασική εντολή: ansible-playbook [options] playbook.yml
│
├── Σημαντικά flags:
│   ├── --limit        → συγκεκριμένοι hosts
│   ├── --syntax-check → έλεγχος σύνταξης
│   ├── --check        → dry run
│   ├── --diff         → δες τις αλλαγές
│   ├── --list-tasks   → ποια tasks
│   ├── --list-hosts   → ποιοι servers
│   ├── -e             → extra variables
│   ├── --tags         → συγκεκριμένα tags
│   ├── --start-at-task→ ξεκίνα από task
│   └── --step         → task-by-task
│
└── Σειρά εκτέλεσης:
    syntax-check → list-tasks → list-hosts
    → check+diff → limit test → full run
```
