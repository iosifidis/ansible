# 2.5 Inventories — Η λίστα των Servers σου 📋

## Τι είναι το Inventory;

Το Inventory είναι απλά η **απάντηση στο ερώτημα:**

> *«Σε ΠΟΙΟΥΣ servers θέλω να εκτελέσω τις εργασίες μου;»*

Είναι ένα αρχείο (ή φάκελος) που περιέχει:
- Τη **λίστα των servers** σου
- Τις **ομάδες** στις οποίες ανήκουν
- **Μεταβλητές** που αφορούν κάθε server ή ομάδα

---

## Μορφές Inventory

Η Ansible δέχεται **δύο μορφές** αρχείων inventory:

```
┌─────────────────────────────────┐
│         INVENTORY               │
├─────────────────┬───────────────┤
│   INI format    │  YAML format  │
│   (απλό)        │  (πιο δομημένο│
│   hosts.ini     │  hosts.yml)   │
└─────────────────┴───────────────┘
```

---

## Μορφή 1: INI Format (Απλό & Κατανοητό)

```ini
# hosts.ini

# --- Μεμονωμένοι servers (χωρίς ομάδα) ---
192.168.1.10
192.168.1.11

# --- Ομάδα Web Servers ---
[webservers]
web01.example.com
web02.example.com
192.168.1.20

# --- Ομάδα Database Servers ---
[dbservers]
db01.example.com ansible_port=2222    # custom SSH port
db02.example.com

# --- Ομάδα με μεταβλητές ανά host ---
[appservers]
app01 ansible_host=192.168.1.30 ansible_user=ans_ctrl
app02 ansible_host=192.168.1.31 ansible_user=ans_ctrl
```

---

## Μορφή 2: YAML Format (Πιο δομημένο)

```yaml
# hosts.yml
all:
  children:

    webservers:
      hosts:
        web01.example.com:
        web02.example.com:
        192.168.1.20:

    dbservers:
      hosts:
        db01.example.com:
          ansible_port: 2222        # custom SSH port
        db02.example.com:

    appservers:
      hosts:
        app01:
          ansible_host: 192.168.1.30
          ansible_user: ans_ctrl
        app02:
          ansible_host: 192.168.1.31
          ansible_user: ans_ctrl
```

> 💡 **Ποιο να διαλέξω;** Για αρχή το **INI είναι πιο απλό**. Καθώς μεγαλώνει η υποδομή σου, το YAML γίνεται πιο βολικό λόγω δομής.

## Host Groups — Ομαδοποίηση Servers

Η ομαδοποίηση είναι η **δύναμη** του inventory. Μπορείς να εκτελείς tasks σε **ολόκληρες ομάδες** με μία εντολή:

```ini
# hosts.ini — Πραγματικό παράδειγμα

[webservers]
web01 ansible_host=192.168.1.10
web02 ansible_host=192.168.1.11

[dbservers]
db01 ansible_host=192.168.1.20
db02 ansible_host=192.168.1.21

[monitoring]
grafana01 ansible_host=192.168.1.30

# Nested group — ομάδα από ομάδες!
[production:children]
webservers
dbservers
monitoring
```

```yaml
# Χρήση στο playbook:

# Εκτέλεση μόνο σε webservers
- name: Configure web servers
  hosts: webservers    # ← μόνο η ομάδα webservers
  tasks:
    - name: Install nginx
      ansible.builtin.package:
        name: nginx
        state: present

# Εκτέλεση σε ΟΛΟΥΣ
- name: Update all servers
  hosts: all           # ← όλοι οι servers
  tasks:
    - name: Update packages
      ansible.builtin.package:
        name: "*"
        state: latest
```

## Οι ειδικές μεταβλητές του Inventory

Η Ansible έχει **έτοιμες μεταβλητές** για να ρυθμίσεις τη σύνδεση:

```ini
# hosts.ini — με όλες τις σημαντικές μεταβλητές

[servers]
# Βασικές ρυθμίσεις σύνδεσης
server01 ansible_host=192.168.1.10      # IP ή hostname
         ansible_port=22                # SSH port (default: 22)
         ansible_user=ans_ctrl          # χρήστης σύνδεσης
         ansible_ssh_private_key_file=/home/ans_ctrl/.ssh/id_ed25519

# Sudo ρυθμίσεις
server02 ansible_host=192.168.1.11
         ansible_become=true            # χρησιμοποίησε sudo
         ansible_become_method=sudo     # μέθοδος (sudo/su/pbrun)
         ansible_become_user=root       # γίνε αυτός ο χρήστης
```

## Το Default Inventory Location

```bash
# Η Ansible ψάχνει για inventory εδώ (με αυτή τη σειρά):
1. Αυτό που δίνεις με -i flag
2. ./hosts (τρέχων φάκελος)
3. /etc/ansible/hosts (system-wide default)
```

```bash
# Χρήση custom inventory
ansible-playbook -i hosts.ini my_playbook.yml

# Χρήση default inventory (αν έχεις ρυθμίσει ansible.cfg)
ansible-playbook my_playbook.yml
```

## Το Inventory στο δικό μας Setup

Για το δικό σου περιβάλλον, το inventory θα μοιάζει κάπως έτσι:

```ini
# ~/ansible/inventory/hosts.ini
# (στο Armbian controller, ως ans_ctrl)

[controller]
localhost ansible_connection=local     # ο ίδιος ο controller

[debian_based]
armbian01 ansible_host=192.168.1.50
ubuntu01  ansible_host=192.168.1.51

[redhat_based]
rocky01   ansible_host=192.168.1.60
alma01    ansible_host=192.168.1.61

[opensuse_based]
suse01    ansible_host=192.168.1.70

# Όλοι μαζί για global tasks
[all_managed:children]
debian_based
redhat_based
opensuse_based

# Κοινές μεταβλητές για ΟΛΟΥΣ
[all:vars]
ansible_user=ans_ctrl
ansible_ssh_private_key_file=/home/ans_ctrl/.ssh/id_ed25519
ansible_become=true
ansible_become_method=sudo
```

> 📝 **Σημείωση για τον Μαθητή:** Αυτό το inventory θα το φτιάξουμε **πρακτικά** στο Κεφάλαιο 6, όταν έχουμε στήσει πλήρως το περιβάλλον μας. Τώρα απλώς κατανοούμε τη δομή.

```bash

# @all:

#   |  |--web01
#   |  |--web02
#   |--@dbservers:
#   |  |--db01
#   |  |--db02
#   |--@ungrouped:
```

## Σύνοψη 2.5

```
Inventory
├── Είναι η λίστα με τους servers σου
├── Μορφές: INI (απλό) ή YAML (δομημένο)
├── Οργανώνει servers σε groups
├── Περιέχει μεταβλητές σύνδεσης
└── Τύποι:
    ├── Static  → αρχείο που γράφεις εσύ (Κεφ. 6)
    └── Dynamic → plugin που ανακαλύπτει servers (Κεφ. 6)
```
