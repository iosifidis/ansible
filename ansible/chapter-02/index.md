# Κεφάλαιο 2: High-Level View 🏗️

## Επισκόπηση Κεφαλαίου

Για να τρέξεις ένα Ansible project, θα χρειαστείς τα εξής τέσσερα κομμάτια:

1.  **Inventory (Απογραφή):** Είναι ένα απλό αρχείο κειμένου (συνήθως `.ini` ή `.yml`) που λειτουργεί ως "τηλεφωνικός κατάλογος". Εκεί γράφεις τις IP διευθύνσεις ή τα hostnames των servers σου και τους ομαδοποιείς (π.χ. ομάδα `[webservers]`, ομάδα `[databases]`).
2.  **Modules (Ενότητες/Εργαλεία):** Είναι οι "έτοιμες εντολές" που κάνει η Ansible. Υπάρχουν χιλιάδες modules. Υπάρχει module για να αντιγράφεις αρχεία (`copy`), module για εγκατάσταση πακέτων (`apt` ή `yum`), module για να ξεκινάς Docker containers (`docker_container`), κ.λπ.
3.  **Playbooks (Βιβλία Συνταγών):** Είναι αρχεία YAML που περιέχουν μια σειρά από "Tasks" (Εργασίες). Κάθε Task χρησιμοποιεί ένα Module. Το Playbook είναι ουσιαστικά το τελικό script που τρέχεις.
4.  **Roles (Ρόλοι):** Όταν το project σου μεγαλώσει, ένα τεράστιο Playbook γίνεται δυσανάγνωστο. Τα Roles είναι ένας τρόπος να οργανώνεις τα Playbooks σου σε φακέλους (π.χ. ένας ρόλος για το στήσιμο Nginx, ένας για τη βάση δεδομένων), κάνοντας τον κώδικά σου καθαρό και επαναχρησιμοποιήσιμο.
