# 2.1 Η συνολική εικόνα

Πριν βουτήξουμε στις λεπτομέρειες, ας δούμε **ποια είναι τα βασικά «κομμάτια»** που απαρτίζουν την Ansible και πώς συνδέονται μεταξύ τους.

```
                    ┌─────────────────────────────────┐
                    │         Εσύ (User) 👤           │
                    │   γράφεις Playbooks & Inventory │
                    └────────────────┬────────────────┘
                                     │
                                     ▼
                    ┌─────────────────────────────────┐
                    │       Ansible Controller        │
                    │         (Armbian σου)           │
                    │                                 │
                    │  ┌─────────┐   ┌─────────────┐  │
                    │  │Inventory│   │  Playbook   │  │
                    │  │(servers)│   │  (εργασίες) │  │
                    │  └─────────┘   └─────────────┘  │
                    │                                 │
                    │  ┌─────────┐   ┌─────────────┐  │
                    │  │ Modules │   │   Plugins   │  │
                    │  │(εργαλεία│   │ (επεκτάσεις)│  │
                    │  └─────────┘   └─────────────┘  │
                    └────────────────┬────────────────┘
                                     │ SSH
                    ┌────────────────┼────────────────┐
                    ▼                ▼                ▼
             [Rocky Linux]      [Ubuntu]          [openSUSE]
```

Θα αναλύσουμε **ένα-ένα** τα παρακάτω:

1. **Users** — ποιος χρησιμοποιεί την Ansible
2. **Modules** — τα «εργαλεία» της
3. **Plugins** — οι επεκτάσεις
4. **Inventories** — η λίστα servers
5. **Playbooks** — τα «σενάρια»
