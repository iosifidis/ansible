# 2.3 Modules — Τα «εργαλεία» της Ansible 🔧

## Τι είναι ένα Module;

Το module είναι η **βασική μονάδα εργασίας** της Ansible. Κάθε φορά που η Ansible κάνει **κάτι συγκεκριμένο** σε έναν server, χρησιμοποιεί ένα module.

> 📝 **Αναλογία:** Σκέψου την Ansible σαν **εργαλειοθήκη**. Κάθε module είναι ένα **διαφορετικό εργαλείο** μέσα σε αυτή:
> - Θες να εγκαταστήσεις πακέτο; → module `package`
> - Θες να αντιγράψεις αρχείο; → module `copy`
> - Θες να ξεκινήσεις service; → module `service`

---

## Πώς χρησιμοποιούμε ένα Module

Κάθε module έχει την ίδια βασική δομή μέσα σε ένα playbook:
{% raw %}
```yaml
- name: Περιγραφή του τι κάνει αυτό το task
  ansible.builtin.ΟΝΟΜΑmodule:  # ← το module
    παράμετρος1: τιμή1           # ← οι παράμετροί του
    παράμετρος2: τιμή2
```
{% endraw %}
### Παράδειγμα με το module `package`:
{% raw %}
```yaml
- name: Εγκατάσταση nginx
  ansible.builtin.package:
    name: nginx       # ποιο πακέτο
    state: present    # τι κατάσταση θέλουμε
```
{% endraw %}
---

## Η δομή ονομασίας των Modules

Από την Ansible 2.10+, τα modules έχουν **πλήρες όνομα** (FQCN — Fully Qualified Collection Name):

```
ansible.builtin.package
│       │        │
│       │        └── το όνομα του module
│       └─────────── η collection
└─────────────────── το namespace
```

> 💡 **Συμβουλή:** Στα παλιά playbooks θα δεις απλώς `package` χωρίς prefix. Δουλεύει ακόμα, αλλά το **πλήρες όνομα είναι βέλτιστη πρακτική** γιατί αποφεύγει συγκρούσεις ονομάτων.

## Κατηγορίες Modules

Η Ansible έχει **χιλιάδες** modules. Οι πιο σημαντικές κατηγορίες:

### 📦 Package Management
{% raw %}
```yaml
# Εγκατάσταση πακέτου (δουλεύει σε ΟΛΑ τα distros!)
- name: Install nginx
  ansible.builtin.package:
    name: nginx
    state: present    # present=εγκατάσταση, absent=αφαίρεση

# Για RedHat-based (Rocky, AlmaLinux, CentOS)
- name: Install nginx on RedHat
  ansible.builtin.dnf:
    name: nginx
    state: present

# Για Debian-based (Ubuntu, Debian, Armbian)
- name: Install nginx on Debian
  ansible.builtin.apt:
    name: nginx
    state: present
    update_cache: true   # σαν το "apt update" πριν το install

# Για openSUSE
- name: Install nginx on openSUSE
  community.general.zypper:
    name: nginx
    state: present
```
{% endraw %}
### 📁 File Management
{% raw %}
```yaml
# Αντιγραφή αρχείου
- name: Copy config file
  ansible.builtin.copy:
    src: files/nginx.conf    # από τον controller
    dest: /etc/nginx/nginx.conf  # στον remote server
    owner: root
    group: root
    mode: '0644'

# Δημιουργία directory
- name: Create directory
  ansible.builtin.file:
    path: /var/www/myapp
    state: directory
    mode: '0755'
    owner: www-data
    group: www-data

# Δημιουργία symbolic link
- name: Create symlink
  ansible.builtin.file:
    src: /etc/nginx/sites-available/myapp
    dest: /etc/nginx/sites-enabled/myapp
    state: link
```
{% endraw %}
### ⚙️ Service Management
{% raw %}
```yaml
# Εκκίνηση και ενεργοποίηση service
- name: Start and enable nginx
  ansible.builtin.service:
    name: nginx
    state: started    # started, stopped, restarted, reloaded
    enabled: true     # να ξεκινά αυτόματα στο boot
```
{% endraw %}
### 💻 Command Execution
{% raw %}
```yaml
# Εκτέλεση εντολής (idempotent version)
- name: Check if app is initialized
  ansible.builtin.command:
    cmd: /usr/local/bin/myapp --check
    creates: /var/lib/myapp/initialized  # ΜΗΝ τρέξεις αν υπάρχει αυτό το αρχείο

# Shell εντολή (με pipes, redirects κλπ)
- name: Get disk usage
  ansible.builtin.shell:
    cmd: df -h | grep /dev/sda1
```
{% endraw %}
> ⚠️ **Προσοχή:** Τα `command` και `shell` **δεν είναι idempotent** από μόνα τους. Χρησιμοποίησέ τα μόνο όταν δεν υπάρχει κατάλληλο module!

### 👤 User Management
{% raw %}
```yaml
# Δημιουργία χρήστη
- name: Create ans_ctrl user
  ansible.builtin.user:
    name: ans_ctrl
    shell: /bin/bash
    create_home: true
    state: present

# Προσθήκη SSH key σε χρήστη
- name: Add SSH key for ans_ctrl
  ansible.posix.authorized_key:
    user: ans_ctrl
    state: present
    key: "{{ lookup('file', '/home/ans_ctrl/.ssh/id_ed25519.pub') }}"
```
{% endraw %}

## Πώς βρίσκουμε το σωστό Module

```bash
# Αναζήτηση module από command line
ansible-doc -l | grep package

# Διάβασε την τεκμηρίωση ενός module
ansible-doc ansible.builtin.package

# Δες μόνο τα παραδείγματα
ansible-doc -s ansible.builtin.package
```

> 💡 **Συμβουλή:** Η [επίσημη τεκμηρίωση](https://docs.ansible.com/ansible/latest/collections/ansible/builtin/) είναι εξαιρετική. Κάθε module έχει παραδείγματα που μπορείς να αντιγράψεις και να τροποποιήσεις.

## Σύνοψη 2.3

```
Module
├── Είναι η βασική μονάδα εργασίας
├── Κάθε task χρησιμοποιεί ένα module
├── Έχει παραμέτρους (input) και επιστρέφει αποτέλεσμα
├── Είναι (συνήθως) idempotent
└── Κατηγορίες:
    ├── Package management (apt, dnf, zypper, package)
    ├── File management (copy, file, template)
    ├── Service management (service, systemd)
    ├── Command execution (command, shell)
    └── User management (user, authorized_key)
```
