# 2.4 Plugins — Οι επεκτάσεις της Ansible 🔌

## Τι είναι τα Plugins;

Αν τα **modules** είναι τα «εργαλεία» που εκτελούνται **στους remote servers**, τα **plugins** είναι κώδικας που εκτελείται **στον controller** (στο Armbian σου) και **επεκτείνει τη λειτουργικότητα** της Ansible.

> 📝 **Αναλογία:**
> - **Module** = ο εργάτης που πηγαίνει στον remote server και κάνει τη δουλειά
> - **Plugin** = ο «διευθυντής» στον controller που αποφασίζει **πώς** θα γίνει η δουλειά

---

## Οι κυριότερες κατηγορίες Plugins

### 1. 🔗 Connection Plugins
Καθορίζουν **πώς** η Ansible συνδέεται στους servers.

```yaml
# Στο playbook — σύνδεση μέσω SSH (default)
- name: My playbook
  hosts: all
  vars:
    ansible_connection: ssh      # ← το connection plugin

# Άλλες επιλογές:
# ansible_connection: local     → εκτέλεση τοπικά στον controller
# ansible_connection: docker    → σύνδεση σε Docker container
# ansible_connection: winrm     → σύνδεση σε Windows servers
```

```ini
# Στο inventory
[local]
localhost ansible_connection=local   # τρέχει τοπικά, χωρίς SSH

[containers]
mycontainer ansible_connection=docker
```

---

### 2. 📋 Inventory Plugins
Καθορίζουν **από πού** παίρνει η Ansible τη λίστα των servers.

```yaml
# Παράδειγμα: Dynamic inventory από AWS
# aws_ec2.yml
plugin: amazon.aws.aws_ec2
regions:
  - eu-west-1
filters:
  instance-state-name: running
  tag:Environment: production
```

> 💡 **Σημείωση για τον Μαθητή:** Αντί να γράφεις χειροκίνητα τους servers σου σε ένα αρχείο, ένα inventory plugin μπορεί να τους **ανακαλύψει αυτόματα** (π.χ. από AWS, Azure, VMware κλπ). Θα το δούμε αναλυτικά στο Κεφάλαιο 6.

---

### 3. 🔍 Lookup Plugins
Διαβάζουν δεδομένα από **εξωτερικές πηγές** κατά την εκτέλεση του playbook.
{% raw %}
```yaml
- name: Examples of lookup plugins
  hosts: localhost
  tasks:

    # Διάβασε περιεχόμενο αρχείου από τον controller
    - name: Read SSH public key
      ansible.builtin.debug:
        msg: "{{ lookup('file', '/home/ans_ctrl/.ssh/id_ed25519.pub') }}"

    # Διάβασε environment variable
    - name: Get home directory
      ansible.builtin.debug:
        msg: "{{ lookup('env', 'HOME') }}"

    # Διάβασε από password file (δημιουργεί αν δεν υπάρχει)
    - name: Get or create password
      ansible.builtin.debug:
        msg: "{{ lookup('password', '/tmp/mypassword length=16') }}"
```
{% endraw %}
---

### 4. 🎨 Filter Plugins
Μετασχηματίζουν δεδομένα μέσα στα playbooks (Jinja2 filters).
{% raw %}
```yaml
- name: Filter plugin examples
  hosts: localhost
  vars:
    my_list: [3, 1, 4, 1, 5, 9, 2, 6]
    my_string: "hello world"
    my_path: "/etc/nginx/nginx.conf"

  tasks:
    - name: Show filter examples
      ansible.builtin.debug:
        msg:
          # String filters
          - "Κεφαλαία: {{ my_string | upper }}"
          - "Πρώτο γράμμα: {{ my_string | capitalize }}"

          # List filters
          - "Ταξινομημένη: {{ my_list | sort }}"
          - "Μοναδικά: {{ my_list | unique }}"
          - "Μέγιστο: {{ my_list | max }}"

          # Path filters
          - "Directory: {{ my_path | dirname }}"
          - "Filename: {{ my_path | basename }}"

          # Default value (αν η μεταβλητή δεν υπάρχει)
          - "Port: {{ my_port | default(8080) }}"
```
{% endraw %}

### 5. 📢 Callback Plugins
Ελέγχουν **πώς εμφανίζεται** η έξοδος της Ansible και τι γίνεται μετά από κάθε task.

```ini
# ansible.cfg — αλλαγή εμφάνισης output
[defaults]
# Διαφορετικές επιλογές εμφάνισης:
stdout_callback = yaml        # πιο ευανάγνωστο output
# stdout_callback = json      # για machine-readable output
# stdout_callback = minimal   # ελάχιστο output
```

```bash
# Πώς φαίνεται με yaml callback (πολύ πιο καθαρό!):

PLAY [Install nginx] **********

TASK [Install nginx package]
ok: [server1]
changed: [server2]

PLAY RECAP ********************
server1  : ok=1  changed=0  unreachable=0  failed=0
server2  : ok=1  changed=1  unreachable=0  failed=0
```

---

### 6. 🔐 Vars Plugins
Φορτώνουν **μεταβλητές** από διάφορες πηγές αυτόματα.

```
ansible/
├── inventory/
│   └── hosts.ini
├── group_vars/          ← το vars plugin τα φορτώνει αυτόματα!
│   ├── all.yml          # μεταβλητές για ΟΛΟΥΣ τους servers
│   ├── webservers.yml   # μεταβλητές για την ομάδα webservers
│   └── dbservers.yml    # μεταβλητές για την ομάδα dbservers
└── host_vars/           ← και αυτά!
    ├── server1.yml      # μεταβλητές μόνο για τον server1
    └── server2.yml      # μεταβλητές μόνο για τον server2
```

## Modules vs Plugins — Η Διαφορά

```
┌─────────────────────────────────────────────────────┐
│                  ANSIBLE CONTROLLER                 │
│                                                     │
│  Plugins τρέχουν ΕΔΩ:                               │
│  ├── Connection Plugin  → πώς συνδέομαι;            │
│  ├── Inventory Plugin   → ποιοι είναι οι servers;   │
│  ├── Lookup Plugin      → διάβασε αυτό το αρχείο    │
│  ├── Filter Plugin      → μετασχημάτισε τα data     │
│  └── Callback Plugin    → εμφάνισε το αποτέλεσμα    │
│                                                     │
└──────────────────────────┬──────────────────────────┘
                           │ SSH
                           ▼
┌─────────────────────────────────────────────────────┐
│                  REMOTE SERVER                      │
│                                                     │
│  Modules τρέχουν ΕΔΩ:                               │
│  ├── package  → εγκατάσταση nginx                   │
│  ├── copy     → αντιγραφή αρχείου                   │
│  └── service  → εκκίνηση service                    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## Σύνοψη 2.4

```
Plugins
├── Τρέχουν στον CONTROLLER (όχι στους remote servers)
├── Επεκτείνουν τη λειτουργικότητα της Ansible
└── Κατηγορίες:
    ├── Connection  → πώς συνδέομαι (ssh, docker, local)
    ├── Inventory   → ποιοι είναι οι servers
    ├── Lookup      → διαβάζω δεδομένα από εξωτερικές πηγές
    ├── Filter      → μετασχηματισμός δεδομένων
    ├── Callback    → εμφάνιση αποτελεσμάτων
    └── Vars        → φόρτωση μεταβλητών αυτόματα
```

> 💡 **Για τον Αρχάριο:** Μην ανησυχείς αν δεν έχεις καταλάβει τα πάντα για τα plugins τώρα. Θα τα συναντάς **φυσικά** καθώς προχωράμε στα επόμενα κεφάλαια και θα αποκτήσουν νόημα μέσα από τα παραδείγματα!
