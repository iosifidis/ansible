# 2.6 Ansible Playbooks — Το «Σενάριο» της Ansible 📜

## Τι είναι το Playbook;

Το Playbook είναι το **κεντρικό αρχείο** της Ansible. Είναι εκεί που γράφεις **τι θέλεις να γίνει**, **σε ποιους servers** και **με ποια σειρά**.

> 📝 **Αναλογία:** Σκέψου το Playbook σαν μια **συνταγή μαγειρικής**:
> - Η συνταγή λέει **ποια υλικά** χρειάζεσαι (modules)
> - **Σε ποια σειρά** να τα προσθέσεις (tasks)
> - **Για πόσα άτομα** να μαγειρέψεις (hosts/groups)

---

## Η Βασική Δομή ενός Playbook

Ένα playbook είναι ένα **YAML αρχείο** που περιέχει μία ή περισσότερες **plays**:

```
Playbook (αρχείο .yml)
└── Play 1 (σε ποιους servers + τι κάνουμε)
    ├── Task 1 (χρησιμοποιεί ένα module)
    ├── Task 2 (χρησιμοποιεί ένα module)
    └── Task 3 (χρησιμοποιεί ένα module)
└── Play 2 (άλλοι servers, άλλες εργασίες)
    ├── Task 1
    └── Task 2
```

---

## Ανατομία ενός Playbook

```yaml
---
# Η τριπλή παύλα (---) δηλώνει αρχή YAML αρχείου

# ╔══════════════════════════════╗
# ║         PLAY 1               ║
# ╚══════════════════════════════╝
- name: Ρύθμιση Web Servers        # περιγραφή της play
  hosts: webservers                # σε ποιους servers
  become: true                     # χρησιμοποίησε sudo
  vars:                            # μεταβλητές για αυτή την play
    http_port: 80
    app_version: "1.2.3"

  tasks:                           # οι εργασίες που θα εκτελεστούν

    # Task 1
    - name: Εγκατάσταση nginx
      ansible.builtin.package:
        name: nginx
        state: present

    # Task 2
    - name: Αντιγραφή config
      ansible.builtin.copy:
        src: files/nginx.conf
        dest: /etc/nginx/nginx.conf
        mode: '0644'

    # Task 3
    - name: Εκκίνηση nginx
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

# ╔══════════════════════════════╗
# ║         PLAY 2               ║
# ╚══════════════════════════════╝
- name: Ρύθμιση Database Servers
  hosts: dbservers                 # διαφορετικοί servers!
  become: true

  tasks:
    - name: Εγκατάσταση PostgreSQL
      ansible.builtin.package:
        name: postgresql
        state: present
```

## Τα Βασικά Keywords μιας Play

```yaml
- name: Όνομα play          # περιγραφή (εμφανίζεται στο output)
  hosts: webservers          # ποιοι servers (group ή host)
  become: true               # sudo ναι/όχι
  become_user: root          # ποιος χρήστης μέσω sudo
  remote_user: ans_ctrl      # με ποιον χρήστη συνδέομαι
  gather_facts: true         # μάζεψε πληροφορίες για τον server
  vars:                      # μεταβλητές
    my_var: "value"
  vars_files:                # μεταβλητές από αρχείο
    - vars/main.yml
  tasks:                     # οι εργασίες
    - ...
  handlers:                  # ειδικές εργασίες (θα δούμε Κεφ.10)
    - ...
  tags:                      # ετικέτες (θα δούμε Κεφ.14)
    - setup
```

## Ένα Πλήρες Παράδειγμα — Multi-distro Playbook

Αυτό είναι το **πιο σημαντικό pattern** για εμάς — ένα playbook που δουλεύει και στις **3 διανομές**:

```yaml
---
- name: Εγκατάσταση και ρύθμιση nginx σε όλες τις distros
  hosts: all
  become: true
  gather_facts: true    # ← ΚΡΙΣΙΜΟ! Μαζεύει πληροφορίες distro

  tasks:

    # ── RedHat based (Rocky, AlmaLinux, CentOS) ──
    - name: Εγκατάσταση nginx σε RedHat-based
      ansible.builtin.dnf:
        name: nginx
        state: present
      when: ansible_os_family == "RedHat"    # ← εκτελείται ΜΟΝΟ σε RedHat

    # ── Debian based (Ubuntu, Debian, Armbian) ──
    - name: Update apt cache σε Debian-based
      ansible.builtin.apt:
        update_cache: true
      when: ansible_os_family == "Debian"

    - name: Εγκατάσταση nginx σε Debian-based
      ansible.builtin.apt:
        name: nginx
        state: present
      when: ansible_os_family == "Debian"

    # ── openSUSE ──
    - name: Εγκατάσταση nginx σε openSUSE
      community.general.zypper:
        name: nginx
        state: present
      when: ansible_os_family == "Suse"

    # ── Κοινό για ΟΛΕΣ τις distros ──
    - name: Εκκίνηση nginx (παντού το ίδιο!)
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true
```

> 💡 **Το Μαγικό:** Το `ansible_os_family` είναι ένα **fact** που συλλέγει αυτόματα η Ansible από κάθε server. Έτσι το **ίδιο playbook** αποφασίζει μόνο του τι να κάνει σε κάθε distro!

## Εκτέλεση Playbook

```bash
# Βασική εκτέλεση
ansible-playbook -i hosts.ini my_playbook.yml

# Με verbose output (βλέπεις περισσότερες λεπτομέρειες)
ansible-playbook -i hosts.ini my_playbook.yml -v    # verbose
ansible-playbook -i hosts.ini my_playbook.yml -vv   # πιο verbose
ansible-playbook -i hosts.ini my_playbook.yml -vvv  # maximum

# Dry run — δες τι ΘΑ έκανε χωρίς να το κάνει!
ansible-playbook -i hosts.ini my_playbook.yml --check

# Μόνο σε συγκεκριμένο host
ansible-playbook -i hosts.ini my_playbook.yml --limit web01

# Μόνο σε συγκεκριμένη ομάδα
ansible-playbook -i hosts.ini my_playbook.yml --limit webservers
```

## Πώς Φαίνεται το Output

```bash
$ ansible-playbook -i hosts.ini nginx_setup.yml

PLAY [Εγκατάσταση nginx σε όλες τις distros] ******

TASK [Gathering Facts] ****************************
ok: [web01]
ok: [db01]

TASK [Εγκατάσταση nginx σε RedHat-based] **********
changed: [web01]          # ← έκανε αλλαγή!
skipping: [db01]          # ← παρέλειψε (δεν είναι RedHat)

TASK [Εκκίνηση nginx] *****************************
changed: [web01]

PLAY RECAP ****************************************
web01  : ok=2  changed=2  unreachable=0  failed=0
db01   : ok=1  changed=0  unreachable=0  failed=0
```

### Τα Χρώματα του Output:
| Χρώμα            |  Σημασία     
🟢 **ok** (πράσινο): Task εκτελέστηκε, δεν χρειάστηκε αλλαγή   
🟡 **changed** (κίτρινο): Task εκτελέστηκε και έκανε αλλαγή   
🔵 **skipping** (μπλε): Task παραλείφθηκε (π.χ. λόγω `when`)   
🔴 **failed** (κόκκινο): Task απέτυχε   
⚫ **unreachable** (μαύρο): Server μη προσβάσιμος

## Σύνοψη 2.6

```
Playbook
├── Είναι YAML αρχείο (.yml)
├── Περιέχει μία ή περισσότερες Plays
├── Κάθε Play έχει:
│   ├── hosts    → σε ποιους servers
│   ├── become   → sudo ναι/όχι
│   ├── vars     → μεταβλητές
│   └── tasks    → λίστα εργασιών με modules
└── Εκτελείται με: ansible-playbook
```
