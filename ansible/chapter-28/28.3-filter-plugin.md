# 28.3 Custom Filter Plugin 🔧

## Τι είναι Filter Plugin

Τα **filter plugins** επεκτείνουν τους Jinja2 filters με custom Python functions:

```yaml
# Χρήση builtin filter:
{{ "hello" | upper }}       → HELLO

# Χρήση custom filter:
{{ ip_list | ipv4_only }}   → ["192.168.1.1", "10.0.0.1"]
```

---

## Παράδειγμα Custom Filter

```python
# filter_plugins/network_filters.py

def ipv4_only(ip_list):
    """Φιλτράρει μόνο IPv4 addresses από μια λίστα"""
    import ipaddress
    result = []
    for ip in ip_list:
        try:
            addr = ipaddress.ip_address(ip.split('/')[0])
            if isinstance(addr, ipaddress.IPv4Address):
                result.append(ip)
        except ValueError:
            pass
    return result


def to_cidr(ip, mask):
    """Μετατροπή IP + mask σε CIDR notation"""
    import ipaddress
    network = ipaddress.IPv4Network(f'{ip}/{mask}', strict=False)
    return str(network)


def human_duration(seconds):
    """Μετατρέπει δευτερόλεπτα σε human-readable string"""
    seconds = int(seconds)
    if seconds < 60:
        return f"{seconds}s"
    elif seconds < 3600:
        return f"{seconds // 60}m {seconds % 60}s"
    else:
        hours = seconds // 3600
        mins  = (seconds % 3600) // 60
        return f"{hours}h {mins}m"


# ── Ansible filter registration ───────────────────
class FilterModule(object):
    def filters(self):
        return {
            'ipv4_only':       ipv4_only,
            'to_cidr':         to_cidr,
            'human_duration':  human_duration,
        }
```

## Χρήση custom filters

```yaml
vars:
  all_ips:
    - "192.168.1.1"
    - "2001:db8::1"
    - "10.0.0.1"
    - "fe80::1"

tasks:

  - name: Φιλτράρισμα IPv4
    ansible.builtin.debug:
      msg: "{{ all_ips | ipv4_only }}"
    # → ["192.168.1.1", "10.0.0.1"]

  - name: CIDR notation
    ansible.builtin.debug:
      msg: "{{ '192.168.1.0' | to_cidr('255.255.255.0') }}"
    # → "192.168.1.0/24"

  - name: Human duration
    ansible.builtin.debug:
      msg: "Uptime: {{ 7384 | human_duration }}"
    # → "Uptime: 2h 3m"
```
