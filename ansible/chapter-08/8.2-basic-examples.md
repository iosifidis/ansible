# 8.2 Βασικά παραδείγματα ⚡

## Ping — Το πρώτο Test

Το `ping` module **δεν είναι** το κλασικό ICMP ping — είναι ένας έλεγχος ότι η Ansible μπορεί να συνδεθεί και να εκτελέσει Python:

```bash
# Ping σε έναν host
ansible nextcloud -m ansible.builtin.ping

# Ping σε όλους
ansible all -m ansible.builtin.ping

# Ping με verbose (βλέπεις την SSH σύνδεση)
ansible nextcloud -m ansible.builtin.ping -v

# Αναμενόμενο output:
# nextcloud | SUCCESS => {
#     "changed": false,
#     "ping": "pong"     ← ✅
# }
```

> 📝 **Τι ελέγχει το ping:**
> ```
> ✅ SSH σύνδεση → OK
> ✅ Python υπάρχει → OK
> ✅ Ansible module τρέχει → OK
> ❌ ΔΕΝ ελέγχει sudo
> ❌ ΔΕΝ ελέγχει ICMP connectivity
> ```

## Command Module — Εκτέλεση εντολών

Το πιο συχνά χρησιμοποιούμενο module:

```bash
# Βασική εκτέλεση
ansible nextcloud -m ansible.builtin.command -a "uptime"

# Αναμενόμενο:
# nextcloud | CHANGED | rc=0 >>
# 10:30:01 up 99 days, 10:58, 3 users, load average: 1.01, 1.02, 1.00

# Πολλαπλές πληροφορίες
ansible nextcloud -m ansible.builtin.command -a "df -h"
ansible nextcloud -m ansible.builtin.command -a "free -h"
ansible nextcloud -m ansible.builtin.command -a "whoami"

# Με sudo
ansible nextcloud -m ansible.builtin.command \
    -a "cat /etc/shadow" \
    --become

# Σε όλους τους servers
ansible all -m ansible.builtin.command -a "uname -r"
```

### Τι ΔΕΝ μπορεί το command module:
```bash
# Αυτά ΔΕΝ δουλεύουν με command:
ansible nextcloud -m ansible.builtin.command \
    -a "cat /etc/passwd | grep ansible"   # ❌ pipes
ansible nextcloud -m ansible.builtin.command \
    -a "echo $HOME"                       # ❌ variables
ansible nextcloud -m ansible.builtin.command \
    -a "ls > /tmp/output.txt"             # ❌ redirects
```

## Shell Module — Εκτέλεση με Shell Features

Όταν χρειάζεσαι pipes, variables, redirects:

```bash
# Με pipe
ansible nextcloud -m ansible.builtin.shell \
    -a "cat /etc/passwd | grep ansible"

# Με variable
ansible nextcloud -m ansible.builtin.shell \
    -a "echo $HOME"

# Με redirect
ansible nextcloud -m ansible.builtin.shell \
    -a "ls -la /etc > /tmp/etc_list.txt"

# Με &&
ansible nextcloud -m ansible.builtin.shell \
    -a "cd /tmp && ls -la"

# Με sudo
ansible nextcloud -m ansible.builtin.shell \
    -a "systemctl status ssh | head -5" \
    --become
```

## Command vs Shell — Πότε να χρησιμοποιείς τι

```
┌─────────────────────────────────────────────────────────┐
│  ansible.builtin.command                                │
│  ✅ Ασφαλέστερο (δεν περνάει από shell)                 │
│  ✅ Idempotent friendly                                 │
│  ❌ Δεν υποστηρίζει pipes, variables, redirects         │
│  → Χρησιμοποίησε όταν: απλές εντολές                    │
├─────────────────────────────────────────────────────────┤
│  ansible.builtin.shell                                  │
│  ✅ Υποστηρίζει pipes, variables, redirects             │
│  ✅ Πλήρης shell functionality                          │
│  ❌ Λιγότερο ασφαλές (shell injection risk)             │
│  → Χρησιμοποίησε όταν: χρειάζεσαι shell features        │
└─────────────────────────────────────────────────────────┘
```

> ⚠️ **Βέλτιστη πρακτική:**
> ```
> 1. Πρώτα ψάξε αν υπάρχει κατάλληλο module
>    (π.χ. ansible.builtin.copy αντί για shell cp)
> 2. Αν όχι → command (αν δεν χρειάζεσαι shell features)
> 3. Αν χρειάζεσαι shell features → shell
> ```

## Raw Module — Εκτέλεση χωρίς Python

Το `raw` module **δεν χρειάζεται Python** στον remote server:

```bash
# Χρήσιμο για:
# 1. Servers χωρίς Python
ansible nextcloud -m ansible.builtin.raw \
    -a "apt install -y python3"

# 2. Network devices (routers/switches)
ansible myrouter -m ansible.builtin.raw \
    -a "show version"

# 3. Debugging όταν τίποτα άλλο δεν δουλεύει
ansible nextcloud -m ansible.builtin.raw \
    -a "echo 'raw connection works!'"

# Αναμενόμενο:
# nextcloud | CHANGED | rc=0 >>
# raw connection works!
```

> 📝 **Πότε να χρησιμοποιείς raw:**
> ```
> ✅ Εγκατάσταση Python σε νέο server
> ✅ Network devices
> ✅ Πολύ παλιά συστήματα
> ❌ Κανονική χρήση → χρησιμοποίησε command/shell
> ```

## Πρακτικά παραδείγματα

```bash
# ── Πληροφορίες Συστήματος ────────────────────
# Uptime
ansible all -m ansible.builtin.command -a "uptime"

# OS info
ansible all -m ansible.builtin.command \
    -a "cat /etc/os-release"

# Kernel version
ansible all -m ansible.builtin.command \
    -a "uname -r"

# CPU info
ansible all -m ansible.builtin.command \
    -a "nproc"

# Memory
ansible all -m ansible.builtin.command \
    -a "free -h" --become

# Disk
ansible all -m ansible.builtin.command \
    -a "df -h"

# ── Processes & Services ──────────────────────
# Running processes
ansible nextcloud -m ansible.builtin.shell \
    -a "ps aux | grep nginx" --become

# Service status
ansible nextcloud -m ansible.builtin.command \
    -a "systemctl status ssh" --become

# ── Network ───────────────────────────────────
# IP addresses
ansible all -m ansible.builtin.shell \
    -a "ip addr show | grep inet"

# Open ports
ansible nextcloud -m ansible.builtin.shell \
    -a "ss -tlnp" --become

# ── Logs ──────────────────────────────────────
# Τελευταίες 20 γραμμές syslog
ansible nextcloud -m ansible.builtin.shell \
    -a "tail -20 /var/log/syslog" --become

# Auth log (αποτυχημένες συνδέσεις)
ansible nextcloud -m ansible.builtin.shell \
    -a "grep 'Failed password' /var/log/auth.log | tail -10" \
    --become
```

## Register — Αποθήκευση αποτελέσματος

```bash
# Σε ad-hoc δεν μπορείς να χρησιμοποιήσεις register
# αλλά μπορείς να δεις το output με -v

ansible nextcloud \
    -m ansible.builtin.command \
    -a "df -h" \
    -v

# Για να αποθηκεύσεις αποτέλεσμα → χρησιμοποίησε playbook
```

## Σύνοψη 8.2

```
Βασικά Modules για Ad-Hoc:
├── ping    → έλεγχος σύνδεσης & Python
├── command → εκτέλεση εντολών (ασφαλές)
│             ❌ pipes, variables, redirects
├── shell   → εκτέλεση με shell features
│             ✅ pipes, variables, redirects
└── raw     → χωρίς Python
              ✅ εγκατάσταση Python, network devices

Χρήση:
ansible [hosts] -m [module] -a "[εντολή]" [--become]
```
