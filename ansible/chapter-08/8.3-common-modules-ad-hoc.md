# 8.3 Common Modules σε Ad-Hoc 🔧

## Κατηγορίες Modules

Θα δούμε τα πιο χρήσιμα modules **ανά κατηγορία** με πρακτικά παραδείγματα:

```
├── 📦 Package Management  → apt, dnf, zypper, package
├── 📁 File Management     → file, copy, fetch, template
├── ⚙️  Service Management → service, systemd
├── 👤 User Management     → user, group, authorized_key
└── 🌐 Network & System    → uri, sysctl, cron
```

---

## 📦 Package Management

### Universal Package Module:
```bash
# Εγκατάσταση (δουλεύει σε ΟΛΕΣ τις distros)
ansible all -m ansible.builtin.package \
    -a "name=curl state=present" \
    --become

# Αφαίρεση
ansible all -m ansible.builtin.package \
    -a "name=curl state=absent" \
    --become

# Αναβάθμιση
ansible all -m ansible.builtin.package \
    -a "name=curl state=latest" \
    --become
```

### 🔴 Debian/Ubuntu — apt:
```bash
# Update cache
ansible debian_based -m ansible.builtin.apt \
    -a "update_cache=true" \
    --become

# Εγκατάσταση με update
ansible debian_based -m ansible.builtin.apt \
    -a "name=nginx state=present update_cache=true" \
    --become

# Αφαίρεση με autoremove
ansible debian_based -m ansible.builtin.apt \
    -a "name=nginx state=absent autoremove=true" \
    --become

# Full system upgrade
ansible debian_based -m ansible.builtin.apt \
    -a "upgrade=full update_cache=true" \
    --become

# Εγκατάσταση πολλών packages
ansible debian_based -m ansible.builtin.apt \
    -a "name=curl,wget,vim state=present" \
    --become
```

### 🟠 RedHat/Fedora — dnf:
```bash
# Εγκατάσταση
ansible redhat_based -m ansible.builtin.dnf \
    -a "name=nginx state=present" \
    --become

# Αφαίρεση
ansible redhat_based -m ansible.builtin.dnf \
    -a "name=nginx state=absent" \
    --become

# System update
ansible redhat_based -m ansible.builtin.dnf \
    -a "name='*' state=latest" \
    --become

# Εγκατάσταση από EPEL
ansible redhat_based -m ansible.builtin.dnf \
    -a "name=epel-release state=present" \
    --become
```

### 🟢 openSUSE — zypper:
```bash
# Εγκατάσταση
ansible opensuse_based -m community.general.zypper \
    -a "name=nginx state=present" \
    --become

# Αφαίρεση
ansible opensuse_based -m community.general.zypper \
    -a "name=nginx state=absent" \
    --become

# Update όλων
ansible opensuse_based -m community.general.zypper \
    -a "name='*' state=latest" \
    --become
```

## 📁 File Management

### file — Δημιουργία/Διαχείριση αρχείων:
```bash
# Δημιουργία directory
ansible nextcloud -m ansible.builtin.file \
    -a "path=/var/www/myapp state=directory mode=0755 owner=www-data group=www-data" \
    --become

# Δημιουργία αρχείου
ansible nextcloud -m ansible.builtin.file \
    -a "path=/tmp/test.txt state=touch mode=0644" \
    --become

# Δημιουργία symbolic link
ansible nextcloud -m ansible.builtin.file \
    -a "src=/etc/nginx/sites-available/myapp
        dest=/etc/nginx/sites-enabled/myapp
        state=link" \
    --become

# Διαγραφή αρχείου/directory
ansible nextcloud -m ansible.builtin.file \
    -a "path=/tmp/test.txt state=absent" \
    --become

# Αλλαγή permissions
ansible nextcloud -m ansible.builtin.file \
    -a "path=/var/www/myapp mode=0755 recurse=true" \
    --become
```

### copy — Αντιγραφή Αρχείων:
```bash
# Αντιγραφή από controller σε server
ansible nextcloud -m ansible.builtin.copy \
    -a "src=/home/ansible/ansible/files/nginx.conf
        dest=/etc/nginx/nginx.conf
        owner=root group=root mode=0644" \
    --become

# Δημιουργία αρχείου με περιεχόμενο (inline)
ansible nextcloud -m ansible.builtin.copy \
    -a "content='Hello from Ansible!\n'
        dest=/tmp/hello.txt
        mode=0644"

# Αντιγραφή με backup
ansible nextcloud -m ansible.builtin.copy \
    -a "src=files/nginx.conf
        dest=/etc/nginx/nginx.conf
        backup=true" \
    --become
```

### fetch — Κατέβασμα αρχείων από Server:
```bash
# Κατέβασμα αρχείου από server στον controller
ansible nextcloud -m ansible.builtin.fetch \
    -a "src=/var/log/nginx/error.log
        dest=/home/ansible/logs/
        flat=true" \
    --become

# Κατέβασμα με directory structure
ansible nextcloud -m ansible.builtin.fetch \
    -a "src=/etc/nginx/nginx.conf
        dest=/home/ansible/backups/" \
    --become

# Αναμενόμενο:
# /home/ansible/backups/nextcloud/etc/nginx/nginx.conf
```

### lineinfile — Επεξεργασία γραμμών:
```bash
# Προσθήκη/αλλαγή γραμμής σε αρχείο
ansible nextcloud -m ansible.builtin.lineinfile \
    -a "path=/etc/ssh/sshd_config
        regexp='^#?PermitRootLogin'
        line='PermitRootLogin no'
        state=present
        backup=true" \
    --become

# Αφαίρεση γραμμής
ansible nextcloud -m ansible.builtin.lineinfile \
    -a "path=/etc/hosts
        line='192.168.1.10 web01'
        state=absent" \
    --become
```

## ⚙️ Service Management

### service — Διαχείριση Services:
```bash
# Εκκίνηση service
ansible nextcloud -m ansible.builtin.service \
    -a "name=ssh state=started" \
    --become

# Διακοπή service
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx state=stopped" \
    --become

# Επανεκκίνηση
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx state=restarted" \
    --become

# Reload (χωρίς διακοπή)
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx state=reloaded" \
    --become

# Enable (εκκίνηση στο boot)
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx enabled=true" \
    --become

# Start + Enable μαζί
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx state=started enabled=true" \
    --become
```

### systemd — Για Systemd Services:
```bash
# Reload systemd daemon
ansible nextcloud -m ansible.builtin.systemd \
    -a "daemon_reload=true" \
    --become

# Start service με daemon reload
ansible nextcloud -m ansible.builtin.systemd \
    -a "name=nginx state=started daemon_reload=true" \
    --become

# Δες status
ansible nextcloud -m ansible.builtin.service_facts \
    --become
```

## 👤 User Management

### user — Διαχείριση Χρηστών:
```bash
# Δημιουργία χρήστη
ansible nextcloud -m ansible.builtin.user \
    -a "name=developer
        shell=/bin/bash
        create_home=true
        state=present" \
    --become

# Δημιουργία με groups
ansible nextcloud -m ansible.builtin.user \
    -a "name=developer
        groups=sudo,www-data
        append=true
        state=present" \
    --become

# Αλλαγή password
ansible nextcloud -m ansible.builtin.user \
    -a "name=developer
        password={{ 'MyPassword' | password_hash('sha512') }}
        update_password=always" \
    --become

# Διαγραφή χρήστη
ansible nextcloud -m ansible.builtin.user \
    -a "name=developer
        state=absent
        remove=true" \
    --become
```

### authorized_key — SSH Keys:
```bash
# Προσθήκη SSH key
ansible nextcloud -m ansible.posix.authorized_key \
    -a "user=ansible
        state=present
        key='ssh-ed25519 AAAA... user@host'" \
    --become

# Αφαίρεση SSH key
ansible nextcloud -m ansible.posix.authorized_key \
    -a "user=ansible
        state=absent
        key='ssh-ed25519 AAAA... user@host'" \
    --become

# Από αρχείο
ansible nextcloud -m ansible.posix.authorized_key \
    -a "user=ansible
        state=present
        key={{ lookup('file', '/home/ansible/.ssh/id_ed25519.pub') }}" \
    --become
```

### group — Διαχείριση Groups:
```bash
# Δημιουργία group
ansible nextcloud -m ansible.builtin.group \
    -a "name=developers
        state=present" \
    --become

# Διαγραφή group
ansible nextcloud -m ansible.builtin.group \
    -a "name=developers
        state=absent" \
    --become
```

## 🌐 Network & System

### uri — HTTP Requests:
```bash
# GET request
ansible localhost -m ansible.builtin.uri \
    -a "url=https://api.github.com
        method=GET
        return_content=true" \
    -c local

# POST request
ansible localhost -m ansible.builtin.uri \
    -a "url=https://httpbin.org/post
        method=POST
        body_format=json
        body='{\"key\": \"value\"}'" \
    -c local

# Έλεγχος αν web server ανταποκρίνεται
ansible nextcloud -m ansible.builtin.uri \
    -a "url=http://localhost
        status_code=200"
```

### sysctl — Kernel Parameters:
```bash
# Ορισμός kernel parameter
ansible nextcloud -m ansible.posix.sysctl \
    -a "name=net.ipv4.ip_forward
        value=1
        sysctl_set=true
        state=present
        reload=true" \
    --become

# Βελτιστοποίηση network
ansible nextcloud -m ansible.posix.sysctl \
    -a "name=net.core.somaxconn
        value=65535
        state=present" \
    --become
```

### cron — Cron Jobs:
```bash
# Προσθήκη cron job
ansible nextcloud -m ansible.builtin.cron \
    -a "name='Daily backup'
        minute=0
        hour=2
        job='/usr/local/bin/backup.sh'" \
    --become

# Αφαίρεση cron job
ansible nextcloud -m ansible.builtin.cron \
    -a "name='Daily backup'
        state=absent" \
    --become
```

## Σύνοψη 8.3

```
Common Modules σε Ad-Hoc
├── 📦 Package Management
│   ├── package  → universal (όλες distros)
│   ├── apt      → Debian/Ubuntu
│   ├── dnf      → RedHat/Fedora
│   └── zypper   → openSUSE
│
├── 📁 File Management
│   ├── file        → create/delete/permissions
│   ├── copy        → controller → server
│   ├── fetch       → server → controller
│   └── lineinfile  → επεξεργασία γραμμών
│
├── ⚙️  Service Management
│   ├── service  → start/stop/restart/enable
│   └── systemd  → daemon_reload, systemd-specific
│
├── 👤 User Management
│   ├── user           → create/delete users
│   ├── authorized_key → SSH keys
│   └── group          → create/delete groups
│
└── 🌐 Network & System
    ├── uri     → HTTP requests
    ├── sysctl  → kernel parameters
    └── cron    → cron jobs
```
