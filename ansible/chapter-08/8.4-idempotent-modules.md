# 8.4 Idempotent Modules 🔄

## Τι είναι η Idempotency;

**Idempotency** σημαίνει ότι μπορείς να εκτελέσεις την **ίδια εντολή πολλές φορές** και το αποτέλεσμα θα είναι **πάντα το ίδιο** — χωρίς παρενέργειες.

> 📝 **Αναλογία:** Φαντάσου ότι ανοίγεις ένα διακόπτη φωτός:
> ```
> Idempotent:
> → Πατάς "άναψε" → ανάβει ✅
> → Πατάς "άναψε" ξανά → μένει αναμμένο ✅ (δεν σβήνει!)
>
> Non-idempotent:
> → Πατάς "toggle" → ανάβει
> → Πατάς "toggle" ξανά → σβήνει ❌
> ```

---

## Idempotent vs Non-Idempotent

```
┌─────────────────────────────────────────────────────────┐
│  NON-IDEMPOTENT (επικίνδυνο!)                           │
│                                                         │
│  ansible nextcloud -m ansible.builtin.shell \           │
│      -a "echo 'ansible ALL=(ALL) NOPASSWD: ALL' \       │
│             >> /etc/sudoers"                            │
│                                                         │
│  1η εκτέλεση: προσθέτει γραμμή → ✅                     │
│  2η εκτέλεση: προσθέτει ΞΑΝ γραμμή → ❌ duplicates!     │
│  3η εκτέλεση: προσθέτει ΞΑΝ γραμμή → ❌❌               │
├─────────────────────────────────────────────────────────┤
│  IDEMPOTENT (σωστό!)                                    │
│                                                         │
│  ansible nextcloud -m ansible.builtin.lineinfile \      │
│      -a "path=/etc/sudoers                              │
│          line='ansible ALL=(ALL) NOPASSWD: ALL'         │
│          state=present"                                 │
│                                                         │
│  1η εκτέλεση: προσθέτει γραμμή → CHANGED ✅             │
│  2η εκτέλεση: γραμμή υπάρχει → OK (δεν αλλάζει!) ✅     │
│  3η εκτέλεση: γραμμή υπάρχει → OK ✅                    │
└─────────────────────────────────────────────────────────┘
```

---

## Πώς δηλώνει η Ansible την Idempotency

```bash
# 1η εκτέλεση — αλλαγή έγινε
ansible nextcloud -m ansible.builtin.package \
    -a "name=nginx state=present" --become

# Output:
# nextcloud | CHANGED    ← έγινε εγκατάσταση

# 2η εκτέλεση — τίποτα δεν άλλαξε
ansible nextcloud -m ansible.builtin.package \
    -a "name=nginx state=present" --become

# Output:
# nextcloud | SUCCESS    ← ήδη εγκατεστημένο, δεν έκανε τίποτα
```

## Idempotent Modules ✅

### Package Management:
```bash
# state=present → "να υπάρχει" (όχι "εγκατέστησέ το")
ansible all -m ansible.builtin.package \
    -a "name=nginx state=present" --become
# 1η φορά: CHANGED (εγκαθιστά)
# 2η φορά: SUCCESS (ήδη υπάρχει)

# state=absent → "να μην υπάρχει"
ansible all -m ansible.builtin.package \
    -a "name=nginx state=absent" --become
# 1η φορά: CHANGED (αφαιρεί)
# 2η φορά: SUCCESS (ήδη απούσα)
```

### File Management:
```bash
# state=directory → "να υπάρχει ο φάκελος"
ansible nextcloud -m ansible.builtin.file \
    -a "path=/var/www/myapp state=directory mode=0755" \
    --become
# 1η φορά: CHANGED (δημιουργεί)
# 2η φορά: SUCCESS (ήδη υπάρχει)

# copy → αντιγράφει ΜΟΝΟ αν το αρχείο είναι διαφορετικό
ansible nextcloud -m ansible.builtin.copy \
    -a "src=files/nginx.conf dest=/etc/nginx/nginx.conf" \
    --become
# 1η φορά: CHANGED (αντιγράφει)
# 2η φορά: SUCCESS (ίδιο περιεχόμενο → δεν κάνει τίποτα)
# Αν αλλάξεις το αρχείο: CHANGED (ανιχνεύει αλλαγή!)
```

### Service Management:
```bash
# state=started → "να τρέχει"
ansible nextcloud -m ansible.builtin.service \
    -a "name=nginx state=started enabled=true" --become
# 1η φορά (nginx down): CHANGED (ξεκινά)
# 2η φορά (nginx up):   SUCCESS (ήδη τρέχει)
```

### User Management:
```bash
# state=present → "να υπάρχει ο χρήστης"
ansible nextcloud -m ansible.builtin.user \
    -a "name=developer shell=/bin/bash state=present" \
    --become
# 1η φορά: CHANGED (δημιουργεί)
# 2η φορά: SUCCESS (ήδη υπάρχει)
```

### lineinfile:
```bash
# Ελέγχει αν η γραμμή υπάρχει πριν προσθέσει
ansible nextcloud -m ansible.builtin.lineinfile \
    -a "path=/etc/ssh/sshd_config
        regexp='^#?PermitRootLogin'
        line='PermitRootLogin no'" \
    --become
# 1η φορά: CHANGED (αλλάζει)
# 2η φορά: SUCCESS (ήδη σωστό)
```

## Non-Idempotent Modules ⚠️

### command & shell:
```bash
# ⚠️ Πάντα CHANGED — δεν ξέρει αν χρειάζεται να τρέξει
ansible nextcloud -m ansible.builtin.command \
    -a "mkdir /var/www/myapp"
# 1η φορά: CHANGED ✅
# 2η φορά: CHANGED ❌ (και ERROR γιατί υπάρχει ήδη!)

# ✅ Λύση: χρησιμοποίησε file module
ansible nextcloud -m ansible.builtin.file \
    -a "path=/var/www/myapp state=directory"
```

### Πώς να κάνεις idempotent το command:
```bash
# Παράμετρος creates → τρέξε ΜΟΝΟ αν δεν υπάρχει το αρχείο
ansible nextcloud -m ansible.builtin.command \
    -a "cmd='mkdir /var/www/myapp'
        creates=/var/www/myapp" \
    --become
# 1η φορά: CHANGED (δημιουργεί)
# 2η φορά: SKIPPED (υπάρχει ήδη!) ✅

# Παράμετρος removes → τρέξε ΜΟΝΟ αν υπάρχει το αρχείο
ansible nextcloud -m ansible.builtin.command \
    -a "cmd='rm /tmp/tempfile.txt'
        removes=/tmp/tempfile.txt" \
    --become
# 1η φορά: CHANGED (διαγράφει)
# 2η φορά: SKIPPED (δεν υπάρχει!) ✅
```

## Σύγκριση — Non-Idempotent vs Idempotent

```
┌──────────────────────┬───────────────────────────────────┐
│ Non-Idempotent ❌    │ Idempotent ✅                     │
├──────────────────────┼───────────────────────────────────┤
│ shell "mkdir /app"   │ file path=/app state=directory    │
│ shell "useradd user" │ user name=user state=present      │
│ shell "apt install"  │ apt name=pkg state=present        │
│ shell "echo >> file" │ lineinfile path=file line=...     │
│ shell "systemctl     │ service name=svc state=started    │
│        start svc"    │                                   │
└──────────────────────┴───────────────────────────────────┘
```

## Πρακτική επίδειξη

```bash
# Τρέξε 3 φορές και παρατήρησε το output:

# 1η φορά:
ansible nextcloud -m ansible.builtin.file \
    -a "path=/tmp/ansible_test state=directory mode=0755"
# nextcloud | CHANGED ← δημιούργησε

# 2η φορά:
ansible nextcloud -m ansible.builtin.file \
    -a "path=/tmp/ansible_test state=directory mode=0755"
# nextcloud | SUCCESS ← τίποτα δεν άλλαξε ✅

# 3η φορά:
ansible nextcloud -m ansible.builtin.file \
    -a "path=/tmp/ansible_test state=directory mode=0755"
# nextcloud | SUCCESS ← τίποτα δεν άλλαξε ✅
```

## Σύνοψη 8.4

```
Idempotency
├── Ορισμός: ίδιο αποτέλεσμα ανεξάρτητα πόσες φορές τρέχεις
├── Output:
│   ├── CHANGED → έγινε αλλαγή (1η φορά ή νέα κατάσταση)
│   └── SUCCESS → τίποτα δεν άλλαξε (ήδη στη σωστή κατάσταση)
│
├── Idempotent modules ✅:
│   ├── package, apt, dnf, zypper → state=present/absent
│   ├── file                      → state=directory/file/absent
│   ├── copy                      → ελέγχει checksum
│   ├── service                   → state=started/stopped
│   ├── user                      → state=present/absent
│   └── lineinfile                → regexp matching
│
├── Non-idempotent ⚠️:
│   ├── command → πάντα CHANGED
│   └── shell   → πάντα CHANGED
│
└── Λύση για command/shell:
    ├── creates= → skip αν υπάρχει
    └── removes= → skip αν δεν υπάρχει
```
