# 8.1 Τι είναι τα Ad-Hoc Commands ⚡

## Ο ορισμός

Τα **Ad-Hoc commands** είναι εντολές Ansible που εκτελείς **απευθείας από το terminal** — χωρίς να γράψεις playbook. Είναι ιδανικά για **γρήγορες, μεμονωμένες εργασίες**.

> 📝 **Αναλογία:** Αν τα playbooks είναι σαν **συνταγές μαγειρικής** (οργανωμένες, επαναλήψιμες), τα ad-hoc commands είναι σαν να **ρίχνεις αλάτι στο φαγητό** — γρήγορα, χωρίς να ανοίξεις βιβλίο.

---

## Πότε να χρησιμοποιείς Ad-Hoc

```
✅ Χρησιμοποίησε Ad-Hoc όταν:
├── Θέλεις γρήγορο έλεγχο (ping, uptime, df)
├── Εκτελείς κάτι μία φορά μόνο
├── Δοκιμάζεις ένα module πριν το βάλεις σε playbook
├── Emergency fixes (restart service, kill process)
└── Συλλογή πληροφοριών (facts, logs)

❌ ΜΗΝ χρησιμοποιείς Ad-Hoc όταν:
├── Η εργασία επαναλαμβάνεται τακτικά
├── Έχεις πολλά βήματα που εξαρτώνται μεταξύ τους
├── Χρειάζεσαι error handling
└── Θέλεις documentation & history
```

## Η σύνταξη

```bash
ansible [pattern] -m [module] -a "[arguments]" [options]
#         │           │              │              │
#         │           │              │              └── επιπλέον flags
#         │           │              └─────────────── παράμετροι module
#         │           └────────────────────────────── ποιο module
#         └────────────────────────────────────────── ποιοι servers
```

### Ανατομία Παραδείγματος:

```bash
ansible nextcloud -m ansible.builtin.ping
#         │                    │
#         │                    └── module: ping
#         └─────────────────────── host: nextcloud

ansible all -m ansible.builtin.command -a "uptime" --become
#    │               │                      │          │
#    │               │                      │          └── sudo
#    │               │                      └─────────── εντολή
#    │               └────────────────────────────────── module
#    └────────────────────────────────────────────────── όλοι hosts
```

---

## Οι σημαντικότερες επιλογές (Options)

```bash
# ── Σύνδεση ───────────────────────────────────
-i INVENTORY    # custom inventory file
-u USER         # remote user (override ansible.cfg)
-p PORT         # SSH port
--private-key   # SSH private key

# ── Privilege Escalation ──────────────────────
-b / --become           # ενεργοποίηση sudo
-K / --ask-become-pass  # ζήτα sudo password
--become-user USER      # γίνε συγκεκριμένος user

# ── Εκτέλεση ──────────────────────────────────
-f FORKS        # παράλληλες εκτελέσεις (default: 5)
-C / --check    # dry run
-v / -vvv       # verbose output
--limit PATTERN # περιορισμός σε συγκεκριμένους hosts

# ── Module ────────────────────────────────────
-m MODULE       # ποιο module (default: command)
-a ARGS         # παράμετροι module
```

---

## Pattern — Ποιους Servers στοχεύεις

```bash
# Όλοι
ansible all -m ping

# Συγκεκριμένο group
ansible debian_based -m ping

# Συγκεκριμένος host
ansible nextcloud -m ping

# Πολλά groups
ansible webservers,dbservers -m ping

# Wildcard
ansible web* -m ping

# Εξαίρεση
ansible all,!controller -m ping

# Intersection
ansible debian_based:&webservers -m ping
```

---

## Default Module: command

```bash
# Αν δεν ορίσεις module (-m), χρησιμοποιείται το "command"
ansible nextcloud -a "uptime"
# ← ισοδύναμο με:
ansible nextcloud -m ansible.builtin.command -a "uptime"
```

## Το Output των Ad-Hoc Commands

```bash
ansible nextcloud -m ansible.builtin.ping
```

```yaml
# Επιτυχία:
nextcloud | SUCCESS => {
    "changed": false,
    "ping": "pong"
}

# Αλλαγή:
nextcloud | CHANGED | rc=0 >>
nginx is running

# Αποτυχία:
nextcloud | FAILED! => {
    "changed": false,
    "msg": "..."
}

# Μη προσβάσιμος:
nextcloud | UNREACHABLE! => {
    "changed": false,
    "msg": "Failed to connect..."
}
```

### Τα χρώματα:
```
🟢 SUCCESS/ok    → εκτελέστηκε, δεν άλλαξε τίποτα
🟡 CHANGED       → εκτελέστηκε και έκανε αλλαγή
🔴 FAILED        → απέτυχε
⚫ UNREACHABLE   → δεν μπόρεσε να συνδεθεί
```

## Σύνοψη 8.1

```
Ad-Hoc Commands
├── Γρήγορη εκτέλεση χωρίς playbook
├── Σύνταξη:
│   ansible [pattern] -m [module] -a "[args]" [options]
├── Πότε:
│   ✅ Γρήγοροι έλεγχοι, μεμονωμένες εργασίες
│   ❌ Επαναλαμβανόμενες, σύνθετες εργασίες
├── Patterns: all, group, host, wildcard, exclusion
└── Output: SUCCESS, CHANGED, FAILED, UNREACHABLE
```
