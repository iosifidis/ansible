# 8.5 Ad-Hoc με τις 3 διανομές 🐧

## Η στρατηγική μας

Σε real-world περιβάλλον έχεις **mixed infrastructure** — servers με διαφορετικές διανομές. Πρέπει να ξέρεις πώς να τις διαχειριστείς **όλες μαζί** ή **ξεχωριστά**.

```
ansible all → όλοι (αν το module είναι universal)
ansible debian_based  → μόνο Debian/Ubuntu
ansible redhat_based  → μόνο RedHat/Fedora
ansible opensuse_based→ μόνο openSUSE
```

---

## Σενάριο 1: Ενημέρωση συστήματος

### Ξεχωριστά ανά distro:
```bash
# 🔴 Debian/Ubuntu
ansible debian_based -m ansible.builtin.apt \
    -a "upgrade=full update_cache=true" \
    --become

# 🟠 RedHat/Fedora
ansible redhat_based -m ansible.builtin.dnf \
    -a "name='*' state=latest update_cache=true" \
    --become

# 🟢 openSUSE
ansible opensuse_based -m community.general.zypper \
    -a "name='*' state=latest" \
    --become
```

### Universal — Ένα command για όλους:
```bash
# Δουλεύει σε ΟΛΕΣ τις distros!
ansible all -m ansible.builtin.package \
    -a "name='*' state=latest" \
    --become

# ⚠️ Σημείωση: το package module δεν κάνει
# update_cache αυτόματα σε Debian → καλύτερα
# να το κάνεις ξεχωριστά για debian_based
```

---

## Σενάριο 2: Εγκατάσταση κοινών Packages

```bash
# Universal για όλους
ansible all -m ansible.builtin.package \
    -a "name=curl state=present" \
    --become

ansible all -m ansible.builtin.package \
    -a "name=git state=present" \
    --become

ansible all -m ansible.builtin.package \
    -a "name=vim state=present" \
    --become

# Ένα-ένα ή loop σε playbook
# Για ad-hoc: μία εντολή ανά package
```

---

## Σενάριο 3: Εγκατάσταση nginx

Το nginx έχει **διαφορετικό όνομα** σε μερικές distros:

```bash
# 🔴 Debian/Ubuntu — update cache πρώτα
ansible debian_based -m ansible.builtin.apt \
    -a "name=nginx state=present update_cache=true" \
    --become

# 🟠 RedHat/Fedora
ansible redhat_based -m ansible.builtin.dnf \
    -a "name=nginx state=present" \
    --become

# 🟢 openSUSE
ansible opensuse_based -m community.general.zypper \
    -a "name=nginx state=present" \
    --become

# Εκκίνηση παντού (universal)
ansible all -m ansible.builtin.service \
    -a "name=nginx state=started enabled=true" \
    --become
```

## Σενάριο 4: Διαχείριση SSH Service

Θυμάσαι την μεταβλητή `service_ssh` από το Κεφάλαιο 6;

```bash
# 🔴 Debian/Ubuntu → service name: ssh
ansible debian_based -m ansible.builtin.service \
    -a "name=ssh state=restarted" \
    --become

# 🟠 RedHat/Fedora → service name: sshd
ansible redhat_based -m ansible.builtin.service \
    -a "name=sshd state=restarted" \
    --become

# 🟢 openSUSE → service name: sshd
ansible opensuse_based -m ansible.builtin.service \
    -a "name=sshd state=restarted" \
    --become

# Universal — χρησιμοποιώντας τη μεταβλητή μας!
ansible all -m ansible.builtin.service \
    -a "name={{ service_ssh }} state=restarted" \
    --become
# ↑ Διαβάζει service_ssh από group_vars!
# debian_based  → ssh
# redhat_based  → sshd
# opensuse_based→ sshd
```

## Σενάριο 5: Πληροφορίες συστήματος

```bash
# OS family όλων
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_os_family"

# Αναμενόμενο:
# nextcloud | SUCCESS => {
#     "ansible_facts": {
#         "ansible_os_family": "Debian"
#     }
# }
# rocky01 | SUCCESS => {
#     "ansible_facts": {
#         "ansible_os_family": "RedHat"
#     }
# }

# Distribution info
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_distribution*"

# Package manager ανά distro
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_pkg_mgr"

# Αναμενόμενο:
# nextcloud → "ansible_pkg_mgr": "apt"
# rocky01     → "ansible_pkg_mgr": "dnf"
# suse01      → "ansible_pkg_mgr": "zypper"
```

## Σενάριο 6: Firewall Management

```bash
# 🔴 Debian/Ubuntu → ufw
ansible debian_based -m community.general.ufw \
    -a "rule=allow port=80 proto=tcp" \
    --become

ansible debian_based -m community.general.ufw \
    -a "state=enabled" \
    --become

# 🟠 RedHat/Fedora & 🟢 openSUSE → firewalld
ansible redhat_based -m ansible.posix.firewalld \
    -a "service=http permanent=true state=enabled immediate=true" \
    --become

ansible opensuse_based -m ansible.posix.firewalld \
    -a "service=http permanent=true state=enabled immediate=true" \
    --become
```

## Σενάριο 7: Έλεγχος Logs

```bash
# Syslog — διαφορετικό path ανά distro!

# 🔴 Debian/Ubuntu
ansible debian_based -m ansible.builtin.shell \
    -a "tail -20 /var/log/syslog" \
    --become

# 🟠 RedHat/Fedora
ansible redhat_based -m ansible.builtin.shell \
    -a "tail -20 /var/log/messages" \
    --become

# 🟢 openSUSE
ansible opensuse_based -m ansible.builtin.shell \
    -a "tail -20 /var/log/messages" \
    --become

# Universal — journalctl (δουλεύει παντού με systemd)
ansible all -m ansible.builtin.shell \
    -a "journalctl -n 20 --no-pager" \
    --become
```

## Σενάριο 8: System Information Report

```bash
# Συλλογή πληροφοριών από ΟΛΟΥΣ
ansible all -m ansible.builtin.shell \
    -a "echo '=== {{ inventory_hostname }} ===' && \
        uname -r && \
        cat /etc/os-release | grep PRETTY && \
        free -h | grep Mem && \
        df -h / | tail -1" \
    --become
```

## 🔔 Έτοιμος για πρακτική!

Τώρα έχεις μόνο **Debian** (nextcloud). Όταν προσθέσεις **Fedora** ή **openSUSE**, θα δοκιμάσουμε τα παραπάνω πρακτικά.

```bash
# Αυτό μπορείς να τρέξεις ΤΩΡΑ:

# 1. OS info
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_distribution*"

# 2. Package manager
ansible all -m ansible.builtin.setup \
    -a "filter=ansible_pkg_mgr"

# 3. Update cache
ansible debian_based -m ansible.builtin.apt \
    -a "update_cache=true" \
    --become

# 4. Εγκατάσταση curl (αν δεν υπάρχει)
ansible all -m ansible.builtin.package \
    -a "name=curl state=present" \
    --become

# 5. Service status
ansible all -m ansible.builtin.service \
    -a "name={{ service_ssh }} state=started" \
    --become
```

## Σύνοψη 8.5

```
Ad-Hoc με 3 Διανομές
├── Ξεχωριστά ανά group:
│   ├── debian_based   → apt, ufw, service name=ssh
│   ├── redhat_based   → dnf, firewalld, service name=sshd
│   └── opensuse_based → zypper, firewalld, service name=sshd
│
├── Universal (για όλους):
│   ├── package  → εγκατάσταση
│   ├── service  → με {{ service_ssh }} variable
│   ├── file     → file management
│   └── setup    → facts
│
└── Χρήσιμα facts:
    ├── ansible_os_family    → Debian/RedHat/Suse
    ├── ansible_distribution → Debian/Ubuntu/Fedora/openSUSE
    └── ansible_pkg_mgr      → apt/dnf/zypper
```
