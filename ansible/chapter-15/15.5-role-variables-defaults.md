# 15.5 Role Variables & Defaults 📊

## Η ιεραρχία μεταβλητών σε Role

```
┌─────────────────────────────────────────────────────────┐
│  Υψηλότερη Προτεραιότητα                                │
│                                                         │
│  1. -e / --extra-vars (command line)                    │
│  2. task vars (set_fact, register)                      │
│  3. role vars (role/vars/main.yml)     ← ΥΨΗΛΗ          │
│  4. play vars                                           │
│  5. host_vars                                           │
│  6. group_vars                                          │
│  7. role defaults (role/defaults/main.yml) ← ΧΑΜΗΛΗ     │
│                                                         │
│  Χαμηλότερη Προτεραιότητα                               │
└─────────────────────────────────────────────────────────┘
```

---

## defaults/main.yml — User-Configurable

```yaml
# roles/nginx/defaults/main.yml
---
# ============================================================
# Αυτές οι μεταβλητές ΠΡΟΟΡΙΖΟΝΤΑΙ να αλλαχτούν!
# Χαμηλότερη προτεραιότητα → εύκολο override
# ============================================================

# ── Performance ───────────────────────────────
nginx_worker_processes:   "{{ ansible_facts['processor_vcpus'] | default(1) }}"
nginx_worker_connections: 768
nginx_keepalive_timeout:  65
nginx_client_max_body:    "10M"

# ── Features (ο user επιλέγει) ────────────────
nginx_ssl_enabled:    false
nginx_gzip_enabled:   true
nginx_http2_enabled:  false

# ── Paths (μπορούν να αλλάξουν) ───────────────
nginx_web_root:  /var/www/html
nginx_log_dir:   /var/log/nginx
nginx_conf_dir:  /etc/nginx

# ── Virtual Hosts ─────────────────────────────
nginx_vhosts: []    # ← κενό, ο user προσθέτει
```

## vars/main.yml — Internal Constants

```yaml
# roles/nginx/vars/main.yml
---
# ============================================================
# Αυτές οι μεταβλητές ΔΕΝ προορίζονται να αλλαχτούν!
# Υψηλότερη προτεραιότητα → δύσκολο override
# ============================================================

# ── Package names ανά distro ──────────────────
_nginx_packages:
  Debian: nginx
  RedHat: nginx
  Suse:   nginx

# ── Service name ──────────────────────────────
_nginx_service: nginx    # ← underscore prefix = internal!

# ── Validation commands ───────────────────────
_nginx_validate:      "nginx -t -c %s"
_nginx_version_cmd:   "nginx -v"

# ── Config paths ανά distro (internal) ───────
_nginx_sites_available:
  Debian: /etc/nginx/sites-available
  RedHat: /etc/nginx/conf.d
  Suse:   /etc/nginx/conf.d

_nginx_sites_enabled:
  Debian: /etc/nginx/sites-enabled
  RedHat: /etc/nginx/conf.d
  Suse:   /etc/nginx/conf.d
```

> 💡 **Convention: Underscore Prefix**
> ```
> _nginx_service  → internal variable (underscore prefix)
> nginx_ssl_enabled → user-configurable (no underscore)
>
> Αυτό είναι convention, όχι κανόνας.
> Βοηθά να ξεχωρίζεις internal από user vars.
> ```

## Override Hierarchy — Παράδειγμα

```yaml
# roles/nginx/defaults/main.yml
nginx_worker_processes: 1     # ← χαμηλή προτεραιότητα

# inventory/group_vars/webservers.yml
nginx_worker_processes: 4     # ← override defaults ✅

# inventory/host_vars/web01.yml
nginx_worker_processes: 8     # ← override group_vars ✅

# playbook.yml
- role: nginx
  vars:
    nginx_worker_processes: 16  # ← override host_vars ✅

# command line
# ansible-playbook -e "nginx_worker_processes=32"  ← override all ✅
```

```bash
# Αποτέλεσμα για web01:
# nginx_worker_processes = 32  (command line wins!)

# Αποτέλεσμα για web02 (χωρίς host_vars):
# nginx_worker_processes = 16  (role vars wins!)

# Αποτέλεσμα για web03 (χωρίς role vars ή host_vars):
# nginx_worker_processes = 4   (group_vars wins!)
```

## Πρακτικά παραδείγματα Override

### Σενάριο 1: Group-based Override
```yaml
# inventory/group_vars/webservers.yml
---
# Override nginx defaults για webservers
nginx_worker_processes:   "{{ ansible_facts['processor_vcpus'] * 2 }}"
nginx_worker_connections: 2048
nginx_gzip_enabled:       true
nginx_vhosts:
  - name:    default
    domains: ["{{ inventory_hostname }}"]
    port:    80
    root:    /var/www/html
```

### Σενάριο 2: Host-based Override
```yaml
# inventory/host_vars/nextcloud.yml
---
# Override για nextcloud specifically
nginx_worker_processes:   2    # ← λίγα resources
nginx_worker_connections: 512  # ← λίγη RAM
nginx_client_max_body:    "100M"  # ← μεγάλα uploads
nginx_vhosts:
  - name:    nextcloud
    domains: ["cloud.example.com"]
    port:    80
    root:    /var/www/nextcloud
```

### Σενάριο 3: Playbook-based Override
```yaml
- name: High Performance Web Server
  hosts: webservers
  roles:
    - role: nginx
      vars:
        nginx_worker_processes:   16
        nginx_worker_connections: 4096
        nginx_ssl_enabled:        true
        nginx_http2_enabled:      true
        nginx_vhosts:
          - name:    production
            domains: ["prod.example.com"]
            port:    443
            root:    /var/www/production
```

## Conditional Defaults

```yaml
# roles/nginx/defaults/main.yml
---
# ── Smart defaults βάσει system resources ─────

# Workers: αριθμός CPUs (αν υπάρχουν facts)
nginx_worker_processes: >-
  {{ ansible_facts['processor_vcpus'] | default(1) }}

# Connections: βάσει RAM
nginx_worker_connections: >-
  {{ 2048 if ansible_facts['memtotal_mb'] | default(0) | int >= 4096
     else 1024 if ansible_facts['memtotal_mb'] | default(0) | int >= 2048
     else 768 }}

# Buffer size: βάσει RAM
nginx_client_body_buffer: >-
  {{ '256k' if ansible_facts['memtotal_mb'] | default(0) | int >= 4096
     else '128k' }}
```

## vars_prompt — Interactive Variables

```yaml
# Για sensitive vars που δεν θέλεις στο defaults
- name: Nginx SSL Setup
  hosts: webservers
  become: true

  vars_prompt:
    - name:    ssl_cert_password
      prompt:  "Enter SSL certificate password"
      private: true     # ← δεν εμφανίζεται κατά πληκτρολόγηση

  roles:
    - role: nginx
      vars:
        nginx_ssl_enabled:      true
        nginx_ssl_cert_pass:    "{{ ssl_cert_password }}"
```

## Role Variables Validation

```yaml
# roles/nginx/tasks/main.yml
---
# ── Validation πριν εκτέλεση ──────────────────
- name: Validate role variables
  ansible.builtin.assert:
    that:
      # Port πρέπει να είναι αριθμός
      - nginx_default_port | int > 0
      - nginx_default_port | int < 65535

      # Worker connections πρέπει να είναι > 0
      - nginx_worker_connections | int > 0

      # Αν SSL enabled, cert πρέπει να υπάρχει
      - not nginx_ssl_enabled or nginx_ssl_cert is defined

      # Web root πρέπει να ξεκινά με /
      - nginx_web_root | regex_search('^/')

    fail_msg: >
      Invalid nginx role configuration!
      Check your variables in defaults/main.yml
      or your override vars.
    success_msg: "✅ Nginx role variables validated"
  tags: [always, validate]

- name: Include install tasks
  ansible.builtin.import_tasks:
    file: install.yml
```

## Debugging Role Variables

```bash
# Δες όλες τις μεταβλητές ενός host (με roles)
ansible nextcloud -m ansible.builtin.debug \
    -a "var=hostvars[inventory_hostname]"

# Δες συγκεκριμένες role vars
ansible-playbook playbooks/site.yml \
    --limit nextcloud \
    -e "nginx_worker_processes=4" \
    --tags always \
    -v

# Check mode για να δεις τιμές
ansible-playbook playbooks/site.yml \
    --limit nextcloud \
    --check -v
```

## Πλήρες παράδειγμα — Role με Smart Defaults

```yaml
# roles/nginx/defaults/main.yml — Production-ready defaults
---

# ── Auto-detected από system ───────────────────
nginx_worker_processes: >-
  {{ ansible_facts['processor_vcpus'] | default(1) | int }}

nginx_worker_connections: >-
  {{ [768, (ansible_facts['memtotal_mb'] | default(512) | int / 2) | int] | min }}

# ── Configurable με sensible defaults ─────────
nginx_keepalive_timeout:  65
nginx_client_max_body:    "10M"
nginx_server_tokens:      "off"
nginx_ssl_enabled:        false
nginx_gzip_enabled:       true
nginx_http2_enabled:      false
nginx_default_vhost:      true
nginx_default_port:       80
nginx_web_root:           /var/www/html
nginx_log_dir:            /var/log/nginx
nginx_conf_dir:           /etc/nginx

# ── SSL defaults (αν ssl_enabled=true) ────────
nginx_ssl_port:           443
nginx_ssl_protocols:      ["TLSv1.2", "TLSv1.3"]
nginx_ssl_ciphers:        "HIGH:!aNULL:!MD5"
nginx_ssl_cert:           ""    # ← πρέπει να οριστεί!
nginx_ssl_key:            ""    # ← πρέπει να οριστεί!

# ── Virtual hosts ─────────────────────────────
nginx_vhosts:             []
```

## Σύνοψη 15.5

```
Role Variables & Defaults
├── defaults/main.yml → χαμηλή προτεραιότητα
│   ├── User-configurable settings
│   ├── Εύκολο override από παντού
│   └── Smart defaults (βάσει facts)
│
├── vars/main.yml → υψηλή προτεραιότητα
│   ├── Internal role constants
│   ├── Δύσκολο override
│   └── Convention: _ prefix για internal
│
├── Override ιεραρχία (χαμηλή → υψηλή):
│   role defaults → group_vars → host_vars
│   → play vars → role vars → -e flag
│
├── Validation:
│   └── assert module στο tasks/main.yml
│
└── Debugging:
    └── ansible -m debug -a "var=hostvars[...]"
```
