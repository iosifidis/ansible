# 15.6 Role Dependencies 🔗

## Τι είναι οι Role Dependencies;

Οι **Role Dependencies** επιτρέπουν σε ένα role να **ορίζει άλλα roles** που πρέπει να εκτελεστούν **πριν** από αυτό — αυτόματα, χωρίς να χρειάζεται να τα ορίσεις στο playbook.

> 📝 **Αναλογία:**
> ```
> nginx role χρειάζεται:
> ├── common role  (βασική ρύθμιση)
> └── security role (SSH, firewall)
>
> Χωρίς dependencies → πρέπει να θυμάσαι τη σειρά:
> roles: [common, security, nginx]  ← εσύ ορίζεις
>
> Με dependencies → το nginx role το κάνει αυτόματα:
> roles: [nginx]  ← αρκεί! ✅
> ```

---

## meta/main.yml — Dependencies

```yaml
# roles/nginx/meta/main.yml
---
galaxy_info:
  role_name: nginx
  author:    myusername
  # ...

dependencies:
  # ── Απλή dependency ───────────────────────
  - role: common        # ← εκτελείται ΠΡΩΤΑ

  # ── Dependency με vars ────────────────────
  - role: security
    vars:
      ssh_port:           2022
      ssh_allowed_users:  [ansible]
      firewall_enabled:   true

  # ── Dependency με condition ───────────────
  - role: ssl_certs
    when: nginx_ssl_enabled | bool

  # ── Dependency με tags ────────────────────
  - role: monitoring
    tags: monitoring
```

## Σειρά εκτέλεσης Dependencies

```
┌─────────────────────────────────────────────────────────┐
│  roles: [nginx]                                         │
│                                                         │
│  Αυτόματη εκτέλεση:                                     │
│                                                         │
│  1. common role        ← dependency του nginx           │
│  2. security role      ← dependency του nginx           │
│  3. nginx role         ← το κύριο role                  │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│  roles: [nginx, php, mysql]                             │
│                                                         │
│  Αυτόματη εκτέλεση:                                     │
│                                                         │
│  1. common             ← dep του nginx                  │
│  2. security           ← dep του nginx                  │
│  3. nginx                                               │
│  4. common             ← dep του php (skip! ήδη τρέξε)  │
│  5. php                                                 │
│  6. common             ← dep του mysql (skip!)          │
│  7. mysql                                               │
└─────────────────────────────────────────────────────────┘
```

> 💡 **Deduplication:** Η Ansible εκτελεί κάθε dependency role **μόνο μία φορά** — αν πολλά roles έχουν το ίδιο dependency, δεν εκτελείται ξανά!

## Πλήρες παράδειγμα — Role Hierarchy

```
Roles μας:
├── common      ← βασική ρύθμιση (no dependencies)
├── security    ← depends on: common
├── nginx       ← depends on: common, security
└── myapp       ← depends on: common, security, nginx
```

### common role — meta/main.yml:
```yaml
# roles/common/meta/main.yml
---
galaxy_info:
  role_name: common
  description: "Common base configuration"

dependencies: []    # ← κανένα dependency
```

### security role — meta/main.yml:
```yaml
# roles/security/meta/main.yml
---
galaxy_info:
  role_name: security
  description: "Security hardening"

dependencies:
  - role: common    # ← χρειάζεται common πρώτα
```

### nginx role — meta/main.yml:
```yaml
# roles/nginx/meta/main.yml
---
galaxy_info:
  role_name: nginx
  description: "Nginx web server"

dependencies:
  - role: common
  - role: security
    vars:
      ssh_port:         2022
      firewall_enabled: true
```

### myapp role — meta/main.yml:
```yaml
# roles/myapp/meta/main.yml
---
galaxy_info:
  role_name: myapp
  description: "My application"

dependencies:
  - role: common
  - role: security
  - role: nginx
    vars:
      nginx_vhosts:
        - name:    myapp
          domains: ["myapp.example.com"]
          port:    80
          root:    /var/www/myapp
```

### Playbook — απλό!
```yaml
---
- name: Deploy myapp
  hosts: webservers
  become: true

  roles:
    - myapp    # ← αυτόματα τρέχει: common, security, nginx, myapp ✅
```

## allow_duplicates — Επανεκτέλεση Dependencies

```yaml
# roles/nginx/meta/main.yml
---
allow_duplicates: true    # ← επιτρέπει επανεκτέλεση!

dependencies:
  - role: common
```

```yaml
# Playbook
roles:
  - role: nginx
    vars:
      nginx_port: 80
  - role: nginx         # ← κανονικά θα παρακαμφθεί
    vars:
      nginx_port: 8080  # ← με allow_duplicates: true εκτελείται!
```

> 💡 **Πότε χρήσιμο:**
> ```
> ✅ Εγκατάσταση πολλαπλών instances του ίδιου service
> ✅ Testing διαφορετικών configurations
> ❌ Κανονική χρήση → άφησε το default (false)
> ```

## Dependencies με Conditions

```yaml
# roles/nginx/meta/main.yml
---
dependencies:

  # ── Πάντα ─────────────────────────────────
  - role: common

  # ── Μόνο αν SSL enabled ───────────────────
  - role: ssl_certs
    when: nginx_ssl_enabled | bool

  # ── Μόνο σε production ────────────────────
  - role: monitoring
    when: app_env == "production"

  # ── Μόνο σε συγκεκριμένη distro ──────────
  - role: selinux_config
    when: ansible_facts['os_family'] == "RedHat"
```

## Εξωτερικά Dependencies — requirements.yml

```yaml
# requirements.yml — external role dependencies
---
roles:
  # ── Από Ansible Galaxy ────────────────────
  - name:    geerlingguy.nginx
    version: "3.2.0"

  - name:    geerlingguy.php
    version: ">=5.0.0"

  # ── Από GitHub ────────────────────────────
  - name: my_custom_nginx
    src:  https://github.com/myuser/ansible-nginx
    version: main

  # ── Από local path ────────────────────────
  - name: local_common
    src:  file:///home/ansible/roles/common

collections:
  - name:    community.general
    version: ">=7.0.0"
  - name:    ansible.posix
    version: ">=1.5.0"
```

```bash
# Εγκατάσταση dependencies
ansible-galaxy install -r requirements.yml

# Εγκατάσταση σε συγκεκριμένο path
ansible-galaxy install \
    -r requirements.yml \
    -p ~/ansible/roles/

# Update
ansible-galaxy install \
    -r requirements.yml \
    --force    # ← αναβάθμιση αν υπάρχουν ήδη
```

## Πρακτικό παράδειγμα — Full Hierarchy

```bash
# Δημιουργία roles
cd ~/ansible/roles
ansible-galaxy role init common
ansible-galaxy role init security
ansible-galaxy role init nginx
ansible-galaxy role init myapp
```

```yaml
# roles/common/tasks/main.yml
---
- name: Install common packages
  ansible.builtin.package:
    name:  "{{ item }}"
    state: present
  loop:
    - curl
    - vim
    - git
    - htop

- name: Configure timezone
  community.general.timezone:
    name: "{{ system_timezone | default('Europe/Athens') }}"

- name: Deploy MOTD
  ansible.builtin.template:
    src:  motd.j2
    dest: /etc/motd
    mode: '0644'
```

```yaml
# roles/security/meta/main.yml
---
dependencies:
  - role: common

# roles/security/tasks/main.yml
---
- name: Configure SSH
  ansible.builtin.template:
    src:      sshd_config.j2
    dest:     /etc/ssh/sshd_config
    validate: sshd -t -f %s
    backup:   true
  notify: Restart SSH

- name: Configure firewall (Debian)
  ansible.builtin.template:
    src:  ferm.conf.j2
    dest: /etc/ferm/ferm.conf
  when: ansible_facts['os_family'] == "Debian"
  notify: Restart ferm

- name: Configure fail2ban
  ansible.builtin.template:
    src:  fail2ban_jail.j2
    dest: /etc/fail2ban/jail.local
  notify: Restart fail2ban
```

```yaml
# roles/myapp/meta/main.yml
---
dependencies:
  - role: common
  - role: security
    vars:
      ssh_port: 2022
  - role: nginx
    vars:
      nginx_vhosts:
        - name:    myapp
          domains: ["{{ inventory_hostname }}"]
          port:    80
          root:    /var/www/myapp
          locations:
            - path: /
              type: static
            - path: /api
              type: proxy
              backend: "http://localhost:3000"

# roles/myapp/tasks/main.yml
---
- name: Create app directories
  ansible.builtin.file:
    path:  "{{ item }}"
    state: directory
    owner: www-data
    group: www-data
    mode:  '0755'
  loop:
    - /var/www/myapp
    - /var/www/myapp/logs
    - /etc/myapp

- name: Deploy app config
  ansible.builtin.template:
    src:   app.conf.j2
    dest:  /etc/myapp/app.conf
    mode:  '0644'
    owner: www-data

- name: Deploy app files
  ansible.builtin.copy:
    src:   files/myapp/
    dest:  /var/www/myapp/
    owner: www-data
    group: www-data
    mode:  '0644'
  ignore_errors: true
```

```yaml
# playbook.yml — όλα αυτόματα!
---
- name: Deploy myapp
  hosts: "{{ target | default('all_managed') }}"
  become: true
  gather_facts: true

  roles:
    - myapp    # ← τρέχει: common → security → nginx → myapp ✅

  post_tasks:
    - name: Verify deployment
      ansible.builtin.uri:
        url:         "http://{{ ansible_facts['default_ipv4']['address'] }}"
        status_code: 200
      ignore_errors: true
      register: site_check

    - name: Report
      ansible.builtin.debug:
        msg:
          - "✅ Deployment complete!"
          - "Site: {{ '✅ Online' if not site_check.failed else '⚠️ Check manually' }}"
      tags: always
```

```bash
# Εκτέλεση — τόσο απλό!
ansible-playbook playbooks/deploy.yml \
    --limit nextcloudpi \
    --syntax-check

ansible-playbook playbooks/deploy.yml \
    --limit nextcloudpi \
    --check --diff

ansible-playbook playbooks/deploy.yml \
    --limit nextcloudpi \
    -v
```

## Σύνοψη 15.6

```
Role Dependencies
├── Ορισμός: meta/main.yml → dependencies
├── Αυτόματη εκτέλεση ΠΡΙΝ το κύριο role
├── Deduplication: κάθε role ΜΟΝΟ ΜΙΑ ΦΟΡΑ
│
├── Τύποι:
│   ├── Απλή     → - role: common
│   ├── Με vars  → vars: { ssh_port: 2022 }
│   └── Conditional → when: condition
│
├── allow_duplicates: true
│   └── Επιτρέπει επανεκτέλεση
│
├── requirements.yml:
│   ├── Εξωτερικά roles (Galaxy, GitHub)
│   └── ansible-galaxy install -r requirements.yml
│
└── Best practice:
    ├── common ← security ← nginx ← myapp
    └── Playbook: roles: [myapp]  ← αρκεί!
```
