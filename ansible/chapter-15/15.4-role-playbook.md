# 15.4 Χρήση Roles σε Playbook 🎭

## Τρεις τρόποι χρήσης

```
┌─────────────────────────────────────────────────────────┐
│  Τρόπος 1: roles section    → classic, static           │
│  Τρόπος 2: import_role      → static, με conditions     │
│  Τρόπος 3: include_role     → dynamic, runtime          │
└─────────────────────────────────────────────────────────┘
```

---

## Τρόπος 1: roles Section (Classic)

```yaml
---
- name: Web Server Setup
  hosts: webservers
  become: true
  gather_facts: true

  roles:
    - nginx           # ← απλή χρήση

    - role: nginx     # ← με παραμέτρους
      vars:
        nginx_worker_processes: 4
        nginx_ssl_enabled:      true

    - role: security  # ← με tags
      tags: security
```

### Σειρά εκτέλεσης με roles section:
```
┌─────────────────────────────────────────────────────────┐
│  1. pre_tasks                                           │
│  2. roles (με τη σειρά που ορίζονται)                   │
│  3. tasks                                               │
│  4. post_tasks                                          │
└─────────────────────────────────────────────────────────┘
```

```yaml
---
- name: Full Setup
  hosts: all
  become: true

  pre_tasks:
    - name: Pre-task
      ansible.builtin.debug:
        msg: "1. Τρέχω ΠΡΩΤΑ"

  roles:
    - role: common
    - role: nginx
    - role: security

  tasks:
    - name: Extra task
      ansible.builtin.debug:
        msg: "3. Τρέχω ΜΕΤΑ τα roles"

  post_tasks:
    - name: Post-task
      ansible.builtin.debug:
        msg: "4. Τρέχω ΤΕΛΕΥΤΑΙΟΣ"
```

## Τρόπος 2: import_role (Static)

```yaml
tasks:

  # ── Βασική χρήση ──────────────────────────
  - name: Import nginx role
    ansible.builtin.import_role:
      name: nginx

  # ── Με vars ───────────────────────────────
  - name: Import nginx με custom vars
    ansible.builtin.import_role:
      name: nginx
    vars:
      nginx_worker_processes: 8
      nginx_ssl_enabled:      true
      nginx_vhosts:
        - name:    myapp
          domains: ["myapp.example.com"]
          port:    80
          root:    /var/www/myapp

  # ── Με tags ───────────────────────────────
  - name: Import security role
    ansible.builtin.import_role:
      name: security
    tags: security

  # ── Με when ───────────────────────────────
  - name: Import monitoring (production only)
    ansible.builtin.import_role:
      name: monitoring
    when: app_env == "production"
```

> 📝 **import_role είναι static:**
> ```
> ✅ Tags δουλεύουν σωστά
> ✅ Parsing γίνεται πριν εκτέλεση
> ✅ Καλύτερο για tags & syntax check
> ⚠️ when εκτιμάται κατά parsing
> ```

## Τρόπος 3: include_role (Dynamic)

```yaml
tasks:

  # ── Βασική χρήση ──────────────────────────
  - name: Include nginx role
    ansible.builtin.include_role:
      name: nginx

  # ── Δυναμικό role name ────────────────────
  - name: Include role δυναμικά
    ansible.builtin.include_role:
      name: "{{ item }}"
    loop:
      - nginx
      - php
      - redis

  # ── Conditional ───────────────────────────
  - name: Include role με condition
    ansible.builtin.include_role:
      name: "{{ web_server }}"
    when: install_web_server | default(true)

  # ── Με vars ───────────────────────────────
  - name: Include nginx με vars
    ansible.builtin.include_role:
      name: nginx
    vars:
      nginx_ssl_enabled:     true
      nginx_default_port:    443

  # ── Μόνο συγκεκριμένα tasks ───────────────
  - name: Include μόνο install tasks
    ansible.builtin.include_role:
      name:      nginx
      tasks_from: install    # ← τρέχει tasks/install.yml μόνο!
```

> 📝 **include_role είναι dynamic:**
> ```
> ✅ Loop support
> ✅ Dynamic role names ({{ variable }})
> ✅ Runtime decisions
> ⚠️ Tags δεν δουλεύουν καλά
> ⚠️ Parsing γίνεται κατά εκτέλεση
> ```

## import vs include — Πότε το καθένα

```
┌─────────────────────┬──────────────┬──────────────────┐
│ Χαρακτηριστικό      │ import_role  │ include_role     │
├─────────────────────┼──────────────┼──────────────────┤
│ Parsing             │ Static       │ Dynamic          │
│ Tags                │ ✅ Δουλεύουν│ ⚠️ Περιορισμένα   │
│ Loops               │ ❌           │ ✅               │
│ Dynamic names       │ ❌           │ ✅               │
│ tasks_from          │ ✅           │ ✅               │
│ Syntax check        │ ✅ Πλήρης   │ ⚠️ Μερικός        │
│ Performance         │ ✅ Γρήγορο  │ ⚠️ Πιο αργό       │
└─────────────────────┴──────────────┴──────────────────┘

Χρήσιμος κανόνας:
├── Χρειάζεσαι tags    → import_role ✅
├── Χρειάζεσαι loop    → include_role ✅
└── Default            → import_role ✅
```

## tasks_from — Εκτέλεση συγκεκριμένων Tasks

```yaml
tasks:

  # ── Μόνο install ──────────────────────────
  - name: Εγκατάσταση nginx
    ansible.builtin.import_role:
      name:       nginx
      tasks_from: install    # ← tasks/install.yml

  # ── Μόνο configure ────────────────────────
  - name: Ρύθμιση nginx
    ansible.builtin.import_role:
      name:       nginx
      tasks_from: configure  # ← tasks/configure.yml

  # ── Μόνο service ──────────────────────────
  - name: Εκκίνηση nginx
    ansible.builtin.import_role:
      name:       nginx
      tasks_from: service    # ← tasks/service.yml

# ── Χρήσιμο για: ──────────────────────────────
# ✅ Partial role execution
# ✅ Διαφορετικά stages
# ✅ Testing μεμονωμένων τμημάτων
```

## Roles με Variables Override

```yaml
---
# Τρεις τρόποι να δώσεις vars σε role:

- name: Web Setup
  hosts: all
  become: true

  # ── Τρόπος 1: role vars ───────────────────
  roles:
    - role: nginx
      vars:                       # ← υψηλή προτεραιότητα
        nginx_worker_processes: 4
        nginx_ssl_enabled:      true

  # ── Τρόπος 2: play vars ───────────────────
  vars:
    nginx_worker_processes: 2     # ← override defaults

  # ── Τρόπος 3: -e flag (υψηλότερη) ────────
  # ansible-playbook site.yml -e "nginx_ssl_enabled=true"
```

## Πλήρες παράδειγμα Playbook με Roles

```yaml
---
# site.yml — Χρήση πολλαπλών roles

- name: Full Stack Web Server
  hosts: "{{ target | default('all_managed') }}"
  become: true
  gather_facts: true

  # ── Pre-tasks ─────────────────────────────
  pre_tasks:

    - name: Εμφάνιση deployment info
      ansible.builtin.debug:
        msg:
          - "Host: {{ inventory_hostname }}"
          - "OS  : {{ ansible_facts['distribution'] }}"
      tags: always

    - name: Update package cache (Debian)
      ansible.builtin.apt:
        update_cache:     true
        cache_valid_time: 3600
      when: ansible_facts['os_family'] == "Debian"
      tags: [update, packages]

  # ── Roles ─────────────────────────────────
  roles:

    # Common base configuration
    - role: common
      tags: common

    # Web server
    - role: nginx
      tags: nginx
      vars:
        nginx_worker_processes:   "{{ ansible_facts['processor_vcpus'] }}"
        nginx_worker_connections: 1024
        nginx_gzip_enabled:       true
        nginx_vhosts:
          - name:    "{{ app_name | default('myapp') }}"
            domains:
              - "{{ inventory_hostname }}"
              - "www.{{ inventory_hostname }}"
            port:    80
            root:    "/var/www/{{ app_name | default('myapp') }}"
            locations:
              - path: /
                type: static

    # Security
    - role: security
      tags: security
      vars:
        ssh_port:          2022
        ssh_allowed_users: [ansible]

  # ── Tasks ─────────────────────────────────
  tasks:

    - name: Deploy application
      ansible.builtin.copy:
        src:   "files/{{ app_name | default('myapp') }}/"
        dest:  "/var/www/{{ app_name | default('myapp') }}/"
        owner: www-data
        group: www-data
        mode:  '0644'
      tags: deploy
      ignore_errors: true

  # ── Post-tasks ────────────────────────────
  post_tasks:

    - name: Verify deployment
      ansible.builtin.uri:
        url:         "http://{{ ansible_facts['default_ipv4']['address'] }}"
        status_code: 200
      register:      site_check
      ignore_errors: true
      tags: verify

    - name: Deployment report
      ansible.builtin.debug:
        msg:
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
          - "✅ Deployment complete!"
          - "Host : {{ inventory_hostname }}"
          - "Site : {{ '✅ Online' if not site_check.failed else '⚠️ Check manually' }}"
          - "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
      tags: always
```

## Εκτέλεση

```bash
# ── Syntax check ──────────────────────────────
ansible-playbook playbooks/site.yml --syntax-check

# ── List tasks (βλέπεις και τα role tasks) ────
ansible-playbook playbooks/site.yml --list-tasks

# ── Dry run ───────────────────────────────────
ansible-playbook playbooks/site.yml \
    --check --diff \
    --limit nextcloudpi

# ── Full deployment ───────────────────────────
ansible-playbook playbooks/site.yml \
    --limit nextcloudpi -v

# ── Μόνο nginx role ───────────────────────────
ansible-playbook playbooks/site.yml \
    --tags nginx \
    --limit nextcloudpi

# ── Override vars ─────────────────────────────
ansible-playbook playbooks/site.yml \
    --limit nextcloudpi \
    -e "nginx_worker_processes=8 app_name=myapp"
```
