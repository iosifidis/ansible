# 15.2 Role Directory Structure 📁

## Η πλήρης δομή

```
roles/
└── my_role/                    ← root του role
    ├── tasks/
    │   └── main.yml            ← κύριες εργασίες
    ├── handlers/
    │   └── main.yml            ← handlers
    ├── templates/
    │   └── *.j2                ← Jinja2 templates
    ├── files/
    │   └── *                   ← στατικά αρχεία
    ├── vars/
    │   └── main.yml            ← μεταβλητές (υψηλή προτ.)
    ├── defaults/
    │   └── main.yml            ← default μεταβλητές (χαμηλή προτ.)
    ├── meta/
    │   └── main.yml            ← metadata & dependencies
    └── README.md               ← τεκμηρίωση
```

> 📝 **Σημείωση:** Δεν χρειάζονται **όλοι** οι φάκελοι. Η Ansible αγνοεί αυτούς που λείπουν.

---

## tasks/main.yml — Το κέντρο του Role

```yaml
# roles/nginx/tasks/main.yml
---
# Η Ansible εκτελεί αυτόματα το main.yml!

# ── Μπορείς να έχεις όλα εδώ ─────────────────
- name: Install nginx
  ansible.builtin.package:
    name:  nginx
    state: present

# ── Ή να χωρίζεις σε αρχεία ──────────────────
- name: Include install tasks
  ansible.builtin.import_tasks:
    file: install.yml    # ← tasks/install.yml

- name: Include config tasks
  ansible.builtin.import_tasks:
    file: configure.yml  # ← tasks/configure.yml

- name: Include service tasks
  ansible.builtin.import_tasks:
    file: service.yml    # ← tasks/service.yml
```

```yaml
# roles/nginx/tasks/install.yml
---
- name: Install nginx (Debian)
  ansible.builtin.apt:
    name:  nginx
    state: present
  when: ansible_facts['os_family'] == "Debian"

- name: Install nginx (RedHat)
  ansible.builtin.dnf:
    name:  nginx
    state: present
  when: ansible_facts['os_family'] == "RedHat"

- name: Install nginx (openSUSE)
  community.general.zypper:
    name:  nginx
    state: present
  when: ansible_facts['os_family'] == "Suse"
```

## handlers/main.yml

```yaml
# roles/nginx/handlers/main.yml
---
- name: Restart nginx
  ansible.builtin.service:
    name:  nginx
    state: restarted
  ignore_errors: "{{ ansible_check_mode }}"

- name: Reload nginx
  ansible.builtin.service:
    name:  nginx
    state: reloaded
  ignore_errors: "{{ ansible_check_mode }}"

- name: Test nginx config
  ansible.builtin.command:
    cmd: nginx -t
  changed_when: false
  listen: Validate nginx
```

## templates/ — Jinja2 Templates

```
roles/nginx/templates/
├── nginx.conf.j2          ← κύρια ρύθμιση
├── vhost.conf.j2          ← virtual host template
└── ssl.conf.j2            ← SSL ρύθμιση
```

```jinja
{# roles/nginx/templates/nginx.conf.j2 #}
user www-data;
worker_processes {{ nginx_worker_processes | default(ansible_facts['processor_vcpus']) }};
pid /run/nginx.pid;

events {
    worker_connections {{ nginx_worker_connections | default(768) }};
}

http {
    sendfile on;
    keepalive_timeout {{ nginx_keepalive_timeout | default(65) }};
    include /etc/nginx/mime.types;
    include /etc/nginx/sites-enabled/*;
}
```

> 💡 **Σημαντικό:** Μέσα στο role, το `template` module ψάχνει **αυτόματα** στο `templates/` directory του role. Δεν χρειάζεται full path!

## files/ — Στατικά αρχεία

```
roles/nginx/files/
├── index.html          ← default page
├── robots.txt          ← robots file
└── ssl/
    └── dhparam.pem     ← DH parameters
```

```yaml
# Χρήση στο tasks/main.yml
# Η Ansible ψάχνει αυτόματα στο files/ του role!
- name: Copy default page
  ansible.builtin.copy:
    src:  index.html        # ← από roles/nginx/files/
    dest: /var/www/html/index.html
    mode: '0644'

- name: Copy DH params
  ansible.builtin.copy:
    src:  ssl/dhparam.pem   # ← από roles/nginx/files/ssl/
    dest: /etc/nginx/dhparam.pem
    mode: '0600'
```

## defaults/main.yml — Default Variables

```yaml
# roles/nginx/defaults/main.yml
---
# ── Χαμηλότερη προτεραιότητα ──────────────────
# Μπορούν να override-αρούν από ΟΠΟΥΔΗΠΟΤΕ!

# ── Performance ───────────────────────────────
nginx_worker_processes:   "{{ ansible_facts['processor_vcpus'] }}"
nginx_worker_connections: 768
nginx_keepalive_timeout:  65
nginx_client_max_body:    "10M"

# ── Paths ─────────────────────────────────────
nginx_conf_dir:      /etc/nginx
nginx_sites_dir:     /etc/nginx/sites-available
nginx_enabled_dir:   /etc/nginx/sites-enabled
nginx_log_dir:       /var/log/nginx
nginx_web_root:      /var/www/html

# ── Features ──────────────────────────────────
nginx_ssl_enabled:   false
nginx_gzip_enabled:  true
nginx_http2_enabled: true

# ── Virtual Hosts ─────────────────────────────
nginx_vhosts: []    # ← κενό by default

# ── Logging ───────────────────────────────────
nginx_access_log: "{{ nginx_log_dir }}/access.log"
nginx_error_log:  "{{ nginx_log_dir }}/error.log"
```

## vars/main.yml — Role Variables

```yaml
# roles/nginx/vars/main.yml
---
# ── Υψηλότερη προτεραιότητα από defaults ──────
# Δύσκολο να override-αρούν!
# Χρήση για: internal role variables

# ── Service names ανά distro ──────────────────
nginx_service_name: nginx    # ← ίδιο παντού

# ── Package names ─────────────────────────────
nginx_package_debian:  nginx
nginx_package_redhat:  nginx
nginx_package_suse:    nginx

# ── Config validation ─────────────────────────
nginx_validate_cmd: "nginx -t -c %s"
```

> ⚠️ **defaults vs vars:**
> ```
> defaults/main.yml → ΧΑΜΗΛΗ προτεραιότητα
>   ← μπορούν να αλλαχτούν εύκολα από playbook
>   ← χρήση για: user-configurable settings
>
> vars/main.yml → ΥΨΗΛΗ προτεραιότητα
>   ← δύσκολο να αλλαχτούν
>   ← χρήση για: internal role constants
> ```

## meta/main.yml — Metadata & Dependencies

```yaml
# roles/nginx/meta/main.yml
---
galaxy_info:
  role_name:    nginx
  author:       myusername
  description:  "Install and configure nginx web server"
  license:      MIT
  min_ansible_version: "2.15"

  platforms:
    - name: Debian
      versions: [bookworm, trixie]
    - name: Ubuntu
      versions: [22.04, 24.04]
    - name: EL              # RedHat Enterprise Linux
      versions: [8, 9]
    - name: opensuse
      versions: [15.5, 15.6]

  galaxy_tags:
    - web
    - nginx
    - http

# ── Dependencies ──────────────────────────────
dependencies:
  - role: common          # ← εκτελείται ΠΡΩΤΑ!
  - role: security
    vars:
      ssh_port: 2022      # ← με custom vars
```

## Auto-loading — Τι φορτώνεται αυτόματα

```
Όταν χρησιμοποιείς ένα role, η Ansible:

✅ Εκτελεί    → tasks/main.yml
✅ Φορτώνει   → handlers/main.yml
✅ Φορτώνει   → defaults/main.yml
✅ Φορτώνει   → vars/main.yml
✅ Ψάχνει     → templates/ (για template module)
✅ Ψάχνει     → files/ (για copy module)
✅ Διαβάζει   → meta/main.yml (για dependencies)
```

## Σύνοψη 15.2

```
Role Directory Structure
├── tasks/main.yml    → κύριες εργασίες (υποχρεωτικό)
├── handlers/main.yml → handlers
├── templates/        → Jinja2 templates (.j2)
├── files/            → στατικά αρχεία
├── vars/main.yml     → υψηλή προτεραιότητα vars
├── defaults/main.yml → χαμηλή προτεραιότητα vars
│                       (user-configurable)
└── meta/main.yml     → metadata & dependencies

Auto-loading:
├── tasks, handlers, vars, defaults → αυτόματα
└── templates, files → αυτόματο path resolution

defaults vs vars:
├── defaults → χαμηλή προτ., εύκολο override
└── vars     → υψηλή προτ., internal constants
```
