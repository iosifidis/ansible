# 15.3 Δημιουργία Role 🛠️

## ansible-galaxy init

Η Ansible παρέχει εντολή για **αυτόματη δημιουργία** της δομής ενός role:

```bash
# Μετάβαση στον φάκελο roles
cd ~/ansible/roles

# Δημιουργία νέου role
ansible-galaxy role init nginx

# Output:
# - Role nginx was created successfully

# Δες τη δομή που δημιουργήθηκε
tree nginx/
# nginx/
# ├── README.md
# ├── defaults/
# │   └── main.yml
# ├── files/
# ├── handlers/
# │   └── main.yml
# ├── meta/
# │   └── main.yml
# ├── tasks/
# │   └── main.yml
# ├── templates/
# ├── tests/
# │   ├── inventory
# │   └── test.yml
# └── vars/
#     └── main.yml
```

## Δημιουργία nginx Role — Βήμα προς Βήμα

## Βήμα 1: defaults/main.yml

```bash
cat > ~/ansible/roles/nginx/defaults/main.yml << 'EOF'
---
# ============================================================
# Nginx Role — Default Variables
# Όλες οι μεταβλητές μπορούν να override-αρούν!
# ============================================================

# ── Performance ───────────────────────────────
nginx_worker_processes:   "{{ ansible_facts['processor_vcpus'] | default(1) }}"
nginx_worker_connections: 768
nginx_keepalive_timeout:  65
nginx_client_max_body:    "10M"
nginx_server_tokens:      "off"

# ── Paths ─────────────────────────────────────
nginx_conf_dir:    /etc/nginx
nginx_log_dir:     /var/log/nginx
nginx_web_root:    /var/www/html

# ── Features ──────────────────────────────────
nginx_ssl_enabled:   false
nginx_gzip_enabled:  true
nginx_http2_enabled: false

# ── Virtual Hosts ─────────────────────────────
nginx_vhosts: []

# ── Default vhost ─────────────────────────────
nginx_default_vhost: true
nginx_default_port:  80
nginx_default_root:  "{{ nginx_web_root }}"
EOF
```

## Βήμα 2: vars/main.yml

```bash
cat > ~/ansible/roles/nginx/vars/main.yml << 'EOF'
---
# ============================================================
# Nginx Role — Internal Variables
# ============================================================

# ── Package names ─────────────────────────────
nginx_packages:
  Debian: nginx
  RedHat: nginx
  Suse:   nginx

# ── Service name ──────────────────────────────
nginx_service: nginx

# ── Config validation ─────────────────────────
nginx_validate: "nginx -t -c %s"

# ── Distro-specific paths ─────────────────────
nginx_sites_available:
  Debian: /etc/nginx/sites-available
  RedHat: /etc/nginx/conf.d
  Suse:   /etc/nginx/conf.d

nginx_sites_enabled:
  Debian: /etc/nginx/sites-enabled
  RedHat: /etc/nginx/conf.d
  Suse:   /etc/nginx/conf.d
EOF
```

## Βήμα 4: tasks/install.yml

```bash
cat > ~/ansible/roles/nginx/tasks/install.yml << 'EOF'
---
# ============================================================
# Nginx Role — Install Tasks
# ============================================================

# ── Debian/Ubuntu ─────────────────────────────
- name: Update apt cache (Debian)
  ansible.builtin.apt:
    update_cache:     true
    cache_valid_time: 3600
  when: ansible_facts['os_family'] == "Debian"

- name: Install nginx (Debian)
  ansible.builtin.apt:
    name:  "{{ nginx_packages['Debian'] }}"
    state: present
  when: ansible_facts['os_family'] == "Debian"

# ── RedHat/Fedora ─────────────────────────────
- name: Install nginx (RedHat)
  ansible.builtin.dnf:
    name:  "{{ nginx_packages['RedHat'] }}"
    state: present
  when: ansible_facts['os_family'] == "RedHat"

# ── openSUSE ──────────────────────────────────
- name: Install nginx (openSUSE)
  community.general.zypper:
    name:  "{{ nginx_packages['Suse'] }}"
    state: present
  when: ansible_facts['os_family'] == "Suse"

# ── Επαλήθευση ────────────────────────────────
- name: Verify nginx installation
  ansible.builtin.command:
    cmd: nginx -v
  register:     nginx_version_check
  changed_when: false
  failed_when:  nginx_version_check.rc != 0

- name: Show nginx version
  ansible.builtin.debug:
    msg: "Nginx installed: {{ nginx_version_check.stderr }}"
EOF
```

## Βήμα 5: tasks/configure.yml

```bash
cat > ~/ansible/roles/nginx/tasks/configure.yml << 'EOF'
---
# ============================================================
# Nginx Role — Configure Tasks
# ============================================================

# ── Main config ───────────────────────────────
- name: Deploy nginx.conf
  ansible.builtin.template:
    src:      nginx.conf.j2
    dest:     "{{ nginx_conf_dir }}/nginx.conf"
    owner:    root
    group:    root
    mode:     '0644'
    backup:   true
    validate: "{{ nginx_validate }}"
  notify: Restart nginx

# ── Log directory ─────────────────────────────
- name: Ensure log directory exists
  ansible.builtin.file:
    path:  "{{ nginx_log_dir }}"
    state: directory
    owner: www-data
    group: adm
    mode:  '0755'

# ── Web root ──────────────────────────────────
- name: Ensure web root exists
  ansible.builtin.file:
    path:  "{{ nginx_web_root }}"
    state: directory
    owner: www-data
    group: www-data
    mode:  '0755'

# ── Default page ──────────────────────────────
- name: Deploy default index.html
  ansible.builtin.template:
    src:   index.html.j2
    dest:  "{{ nginx_web_root }}/index.html"
    owner: www-data
    group: www-data
    mode:  '0644'
  when: nginx_default_vhost
EOF
```

## Βήμα 6: tasks/vhosts.yml

```bash
cat > ~/ansible/roles/nginx/tasks/vhosts.yml << 'EOF'
---
# ============================================================
# Nginx Role — Virtual Hosts Tasks
# ============================================================

# ── Sites available directory (Debian) ────────
- name: Ensure sites-available exists (Debian)
  ansible.builtin.file:
    path:  "{{ nginx_sites_available['Debian'] }}"
    state: directory
    mode:  '0755'
  when: ansible_facts['os_family'] == "Debian"

# ── Sites enabled directory (Debian) ──────────
- name: Ensure sites-enabled exists (Debian)
  ansible.builtin.file:
    path:  "{{ nginx_sites_enabled['Debian'] }}"
    state: directory
    mode:  '0755'
  when: ansible_facts['os_family'] == "Debian"

# ── Deploy vhost configs ───────────────────────
- name: Deploy vhost configurations
  ansible.builtin.template:
    src:  vhost.conf.j2
    dest: >-
      {{ nginx_sites_available[ansible_facts['os_family']] }}/{{ item.name }}.conf
    owner: root
    group: root
    mode:  '0644'
  loop: "{{ nginx_vhosts }}"
  loop_control:
    label: "{{ item.name }}"
  notify: Reload nginx
  when: nginx_vhosts | length > 0

# ── Enable vhosts (Debian) ────────────────────
- name: Enable vhost (Debian)
  ansible.builtin.file:
    src:   "{{ nginx_sites_available['Debian'] }}/{{ item.name }}.conf"
    dest:  "{{ nginx_sites_enabled['Debian'] }}/{{ item.name }}.conf"
    state: link
  loop: "{{ nginx_vhosts }}"
  loop_control:
    label: "{{ item.name }}"
  notify: Reload nginx
  when:
    - ansible_facts['os_family'] == "Debian"
    - nginx_vhosts | length > 0
EOF
```

## Βήμα 7: tasks/service.yml

```bash
cat > ~/ansible/roles/nginx/tasks/service.yml << 'EOF'
---
# ============================================================
# Nginx Role — Service Tasks
# ============================================================

- name: Enable and start nginx
  ansible.builtin.service:
    name:    "{{ nginx_service }}"
    state:   started
    enabled: true

- name: Verify nginx is running
  ansible.builtin.uri:
    url:         "http://localhost:{{ nginx_default_port }}"
    status_code: 200
  register:      nginx_check
  retries:       3
  delay:         5
  ignore_errors: true

- name: Nginx status
  ansible.builtin.debug:
    msg: >
      Nginx:
      {{ '✅ Running on port ' + nginx_default_port | string
         if not nginx_check.failed
         else '⚠️ Check nginx manually' }}
EOF
```

## Βήμα 8: handlers/main.yml

```bash
cat > ~/ansible/roles/nginx/handlers/main.yml << 'EOF'
---
# ============================================================
# Nginx Role — Handlers
# ============================================================

- name: Restart nginx
  ansible.builtin.service:
    name:  "{{ nginx_service }}"
    state: restarted
  ignore_errors: "{{ ansible_check_mode }}"

- name: Reload nginx
  ansible.builtin.service:
    name:  "{{ nginx_service }}"
    state: reloaded
  ignore_errors: "{{ ansible_check_mode }}"

- name: Test nginx config
  ansible.builtin.command:
    cmd: nginx -t
  changed_when: false
  listen: Validate nginx
EOF
```

## Βήμα 9: templates/nginx.conf.j2

```bash
cat > ~/ansible/roles/nginx/templates/nginx.conf.j2 << 'EOF'
{# Nginx Main Configuration #}
{# Generated by Ansible Role — DO NOT EDIT! #}

user www-data;
worker_processes {{ nginx_worker_processes }};
pid /run/nginx.pid;

events {
    worker_connections {{ nginx_worker_connections }};
    multi_accept on;
}

http {
    sendfile    on;
    tcp_nopush  on;
    tcp_nodelay on;

    keepalive_timeout   {{ nginx_keepalive_timeout }};
    client_max_body_size {{ nginx_client_max_body }};
    server_tokens       {{ nginx_server_tokens }};

    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # ── Logging ──────────────────────────────
    access_log {{ nginx_log_dir }}/access.log;
    error_log  {{ nginx_log_dir }}/error.log;

    # ── Gzip ─────────────────────────────────
    {% if nginx_gzip_enabled %}
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_types text/plain text/css application/json
               application/javascript text/xml
               application/xml+rss text/javascript;
    {% endif %}

    # ── Virtual Hosts ─────────────────────────
    include {{ nginx_conf_dir }}/conf.d/*.conf;
    {% if ansible_facts['os_family'] == 'Debian' %}
    include {{ nginx_conf_dir }}/sites-enabled/*;
    {% endif %}
}
EOF
```

## Βήμα 10: templates/vhost.conf.j2

```bash
cat > ~/ansible/roles/nginx/templates/vhost.conf.j2 << 'EOF'
{# Virtual Host Configuration #}
{# Generated by Ansible Role — DO NOT EDIT! #}

server {
    listen      {{ item.port | default(80) }};
    server_name {{ item.domains | join(' ') }};
    root        {{ item.root | default(nginx_web_root) }};
    index       index.html index.htm;

    access_log  {{ nginx_log_dir }}/{{ item.name }}_access.log;
    error_log   {{ nginx_log_dir }}/{{ item.name }}_error.log;

    {% for location in item.locations | default([{'path': '/', 'type': 'static'}]) %}
    location {{ location.path }} {
        {% if location.type | default('static') == 'proxy' %}
        proxy_pass       {{ location.backend }};
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        {% elif location.type == 'php' %}
        fastcgi_pass     unix:/run/php/php8.1-fpm.sock;
        fastcgi_index    index.php;
        include          fastcgi_params;
        {% else %}
        try_files        $uri $uri/ =404;
        {% endif %}
    }
    {% endfor %}
}
EOF
```

## Βήμα 13: README.md

```bash
cat > ~/ansible/roles/nginx/README.md << 'EOF'
# Nginx Role

Εγκατάσταση και ρύθμιση nginx web server.
Συμβατό με: Debian, Ubuntu, RedHat, Fedora, openSUSE.

## Χρήση

```yaml
- hosts: webservers
  roles:
    - nginx
```

## Variables

| Variable | Default | Description |
|---|---|---|
| nginx_worker_processes | auto | Worker processes |
| nginx_worker_connections | 768 | Max connections |
| nginx_ssl_enabled | false | Enable SSL |
| nginx_vhosts | [] | Virtual hosts |

## Virtual Hosts

```yaml
nginx_vhosts:
  - name:    mysite
    domains: [mysite.example.com]
    port:    80
    root:    /var/www/mysite
```
EOF
```

## Σύνοψη 15.3

```
Δημιουργία Role
├── ansible-galaxy role init <name>
│   → δημιουργεί αυτόματα τη δομή
│
├── Βήματα:
│   ├── defaults/main.yml → user vars
│   ├── vars/main.yml     → internal vars
│   ├── tasks/main.yml    → entry point
│   ├── tasks/*.yml       → sub-tasks
│   ├── handlers/main.yml → handlers
│   ├── templates/*.j2    → templates
│   ├── meta/main.yml     → metadata
│   └── README.md         → docs
│
└── Best practices:
    ├── Χώρισε tasks σε αρχεία (install/config/service)
    ├── defaults για user settings
    ├── vars για internal constants
    └── Πάντα README.md!
```
