# 15.1 Τι είναι τα Roles 🎭

## Ο ορισμός

Τα **Roles** είναι ο τρόπος της Ansible να **οργανώνει και επαναχρησιμοποιεί** κώδικα. Ένα role είναι μια **αυτόνομη μονάδα** που ομαδοποιεί tasks, variables, templates, handlers και files για έναν συγκεκριμένο σκοπό.

> 📝 **Αναλογία:** Σκέψου τα roles σαν **LEGO τουβλάκια**:
> ```
> Playbook χωρίς roles = ένα γιγάντιο τουβλάκι
>                        δύσκολο να επαναχρησιμοποιηθεί ❌
>
> Playbook με roles    = πολλά μικρά τουβλάκια
>                        το καθένα κάνει κάτι συγκεκριμένο
>                        συνδυάζεις όπως θέλεις ✅
> ```

---

## Γιατί χρειάζονται τα Roles;

### Το πρόβλημα χωρίς Roles:

```yaml
# site.yml — 500+ γραμμές, όλα μαζί ❌
- name: Configure everything
  hosts: all
  tasks:
    # nginx tasks (50 γραμμές)
    - name: Install nginx
    - name: Configure nginx
    - name: ...

    # PHP tasks (40 γραμμές)
    - name: Install PHP
    - name: Configure PHP
    - name: ...

    # Database tasks (60 γραμμές)
    - name: Install PostgreSQL
    - name: Configure PostgreSQL
    - name: ...

    # Security tasks (80 γραμμές)
    - name: Configure SSH
    - name: Setup fail2ban
    - name: ...

    # Monitoring tasks (40 γραμμές)
    - name: Install monitoring
    - name: ...
    # → Αδύνατο να επαναχρησιμοποιηθεί
    # → Δύσκολο να συντηρηθεί
    # → Δεν μπορείς να το μοιραστείς
```

### Η λύση με Roles:

```yaml
# site.yml — καθαρό και οργανωμένο ✅
- name: Configure everything
  hosts: all
  roles:
    - nginx        # ← αυτόνομο role
    - php          # ← αυτόνομο role
    - postgresql   # ← αυτόνομο role
    - security     # ← αυτόνομο role
    - monitoring   # ← αυτόνομο role
```

## Τα 5 πλεονεκτήματα των Roles

### 1. Επαναχρησιμοποίηση
```
nginx role → χρησιμοποιείται σε:
  ├── web-server playbook
  ├── load-balancer playbook
  └── dev-environment playbook
```

### 2. Οργάνωση
```
roles/
├── nginx/      ← όλα τα nginx αρχεία εδώ
├── php/        ← όλα τα php αρχεία εδώ
└── security/   ← όλα τα security αρχεία εδώ
```

### 3. Διαμοιρασμός
```bash
# Δημοσίευση στο Ansible Galaxy
ansible-galaxy role publish nginx

# Εγκατάσταση από Galaxy
ansible-galaxy role install geerlingguy.nginx
```

### 4. Testing
```bash
# Test ένα role μεμονωμένα
molecule test -s nginx
```

### 5. Versioning
```yaml
# requirements.yml
roles:
  - name: geerlingguy.nginx
    version: "3.2.0"    # ← συγκεκριμένη έκδοση
```

## Roles vs Playbooks — Η διαφορά

```
┌─────────────────────────────────────────────────────────┐
│  PLAYBOOK                                               │
│  ├── Ορίζει ΤΙ θέλεις να γίνει                          │
│  ├── Ορίζει ΣΕ ΠΟΙΟΥΣ servers                           │
│  └── Συνδυάζει roles μαζί                               │
│                                                         │
│  site.yml:                                              │
│  - hosts: webservers                                    │
│    roles:                                               │
│      - nginx    ← role                                  │
│      - php      ← role                                  │
├─────────────────────────────────────────────────────────┤
│  ROLE                                                   │
│  ├── Αυτόνομη μονάδα λειτουργικότητας                   │
│  ├── ΔΕΝ ορίζει hosts (το κάνει το playbook)            │
│  ├── Περιέχει: tasks, vars, templates, handlers         │
│  └── Επαναχρησιμοποιήσιμο σε πολλά playbooks            │
│                                                         │
│  roles/nginx/                                           │
│  ├── tasks/main.yml     ← τι κάνει                      │
│  ├── templates/         ← config files                  │
│  └── handlers/main.yml  ← restart nginx                 │
└─────────────────────────────────────────────────────────┘
```

## Πότε να φτιάξεις Role

```
✅ Φτιάξε role όταν:
├── Ο κώδικας επαναλαμβάνεται σε >2 playbooks
├── Ένα component έχει >20 tasks
├── Θέλεις να μοιραστείς με άλλους
├── Θέλεις να κάνεις testing μεμονωμένα
└── Ομάδα ανθρώπων δουλεύει στον ίδιο κώδικα

❌ ΜΗΝ φτιάξεις role όταν:
├── Το playbook έχει <10 tasks
├── Χρησιμοποιείται μόνο σε ένα playbook
└── Είναι πολύ specific για ένα project
```

## Σύνοψη 15.1

```
Roles
├── Αυτόνομες μονάδες λειτουργικότητας
├── Οργανώνουν: tasks, vars, templates,
│              handlers, files, meta
├── Πλεονεκτήματα:
│   ├── Επαναχρησιμοποίηση ✅
│   ├── Οργάνωση ✅
│   ├── Διαμοιρασμός (Galaxy) ✅
│   ├── Testing ✅
│   └── Versioning ✅
├── Roles vs Playbooks:
│   ├── Playbook → ΤΙ + ΣΕ ΠΟΙΟΥΣ
│   └── Role    → αυτόνομη λειτουργία
└── Πότε: >2 playbooks, >20 tasks,
          sharing, testing
```
