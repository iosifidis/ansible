# 4.1 Προαπαιτούμενα 📋

## Τι χρειάζεται η Ansible για να εκτελεστεί

Η Ansible έχει **ελάχιστες απαιτήσεις** — αυτό είναι ένα από τα μεγάλα πλεονεκτήματά της:

```
┌─────────────────────────────────────────────────────┐
│              ANSIBLE CONTROLLER                     │
│                                                     │
│  ✅ Linux/macOS (όχι Windows ως controller)         │
│  ✅ Python 3.9+                                     │
│  ✅ pip (Python package manager)                    │
│  ✅ SSH client                                      │
│                                                     │
├─────────────────────────────────────────────────────┤
│              MANAGED SERVERS                        │
│                                                     │
│  ✅ SSH server                                      │
│  ✅ Python 3.x (εγκαθίσταται αυτόματα συνήθως)      │
│  ❌ Τίποτα άλλο! (agentless)                        │
└─────────────────────────────────────────────────────┘
```

> 📝 **Σημείωση για τον Μαθητή:** Η **Python είναι υποχρεωτικό** γιατί η Ansible είναι γραμμένη σε Python. Το **venv** δεν είναι υποχρεωτικό, αλλά είναι **βέλτιστη πρακτική** όπως είδαμε στο Κεφάλαιο 3.

## Python — Έλεγχος έκδοσης

Πριν από οτιδήποτε, ελέγχουμε αν έχουμε Python και ποια έκδοση:

```bash
# Έλεγχος Python
python3 --version

# Έλεγχος pip
pip3 --version

# Έλεγχος venv
python3 -m venv --help | head -3
```

### Ελάχιστες Απαιτούμενες Εκδόσεις:

```
┌─────────────────┬──────────────────────────────────┐
│ Εργαλείο        │ Ελάχιστη Έκδοση                  │

│ pip             │ 21.0+ (συνιστάται latest)        │
│ Ansible Core    │ 2.15+ (συνιστάται 2.17+)         │
└─────────────────┴──────────────────────────────────┘
```

## 🔴 Debian/Ubuntu — Εγκατάσταση προαπαιτούμενων

### Έλεγχος:
```bash
# Έλεγχος αν υπάρχει Python
python3 --version
# Python 3.11.x ή νεότερο ✅

# Έλεγχος αν υπάρχει pip
pip3 --version
# pip 23.x ✅

# Έλεγχος αν υπάρχει venv
python3 -m venv --help | head -3
# usage: venv ... ✅
```

### Εγκατάσταση (αν δεν υπάρχουν):
```bash
# Ενημέρωση package list
sudo apt update

# Εγκατάσταση Python και εργαλείων
sudo apt install -y \
    python3 \
    python3-pip \
    python3-venv \
    python3-full

# Επαλήθευση
python3 --version
pip3 --version
```

> 💡 **Το `python3-full`** εγκαθιστά **όλα** τα standard Python modules. Χωρίς αυτό, μερικά modules μπορεί να λείπουν και να προκαλέσουν προβλήματα αργότερα.

## 🟠 RedHat/Fedora — Εγκατάσταση προαπαιτούμενων

### Έλεγχος:
```bash
# Έλεγχος Python
python3 --version

# Έλεγχος pip
pip3 --version

# Έλεγχος venv
python3 -m venv --help | head -3
```

### Εγκατάσταση σε Fedora:
```bash
# Ενημέρωση συστήματος
sudo dnf update -y

# Εγκατάσταση Python και εργαλείων
sudo dnf install -y \
    python3 \
    python3-pip \
    python3-virtualenv

# Επαλήθευση
python3 --version
pip3 --version
```

### Εγκατάσταση σε Rocky/AlmaLinux:
```bash
# Ενημέρωση συστήματος
sudo dnf update -y

# Ενεργοποίηση EPEL repository (χρειάζεται για extra packages)
sudo dnf install -y epel-release

# Εγκατάσταση Python και εργαλείων
sudo dnf install -y \
    python3 \
    python3-pip \
    python3-virtualenv

# Επαλήθευση
python3 --version
pip3 --version
```

> 📝 **Τι είναι το EPEL;** Το **Extra Packages for Enterprise Linux** είναι ένα επίσημο repository της Fedora που παρέχει επιπλέον packages για RHEL-based διανομές. Πολλά χρήσιμα εργαλεία (όπως το `python3-virtualenv`) βρίσκονται εκεί.

## 🟢 openSUSE — Εγκατάσταση προαπαιτούμενων

### Έλεγχος:
```bash
# Έλεγχος Python
python3 --version

# Έλεγχος pip
pip3 --version

# Έλεγχος venv
python3 -m venv --help | head -3
```

### Εγκατάσταση σε openSUSE Leap/Tumbleweed:
```bash
# Ενημέρωση συστήματος
sudo zypper refresh

# Εγκατάσταση Python και εργαλείων
sudo zypper install -y \
    python3 \
    python3-pip \
    python3-virtualenv

# Επαλήθευση
python3 --version
pip3 --version
```

> ⚠️ **Διαφορά Leap vs Tumbleweed:**
> ```
> openSUSE Leap       → σταθερή έκδοση, παλιότερη Python
> openSUSE Tumbleweed → rolling release, νεότερη Python
> ```
> Αν έχεις Leap και η Python είναι παλιά, μπορείς να προσθέσεις το repository `devel:languages:python3`.

## Σύνοψη 4.1

```

├── Python 3.9+
│   ├── Debian/Ubuntu → apt install python3 python3-pip python3-venv python3-full

│   └── openSUSE      → zypper install python3 python3-pip python3-virtualenv
│
└── SSH Client (συνήθως προεγκατεστημένο)
    └── apt/dnf/zypper install openssh-client
```
