# 4.5 Εγκατάσταση Collections 📦

## Τι είναι τα Collections;

Τα **Collections** είναι πακέτα που περιέχουν:

```
Collection
├── Modules    (π.χ. community.docker.docker_container)
├── Plugins    (connection, lookup, filter κλπ)
├── Roles      (έτοιμα roles)
└── Playbooks  (έτοιμα playbooks)
```

> 📝 **Αναλογία:** Σκέψου τα collections σαν **"app stores"** για την Ansible. Αντί να γράφεις τα πάντα από την αρχή, εγκαθιστάς έτοιμες λειτουργίες από την κοινότητα.

---

## Η δομή ονομασίας

```
community.docker.docker_container
│          │      │
│          │      └── το module/plugin
│          └───────── η collection
└──────────────────── ο namespace
```

```
ansible.builtin.apt
│       │        │
│       │        └── το module
│       └────────── η collection (ενσωματωμένη)
└────────────────── ο namespace (Ansible project)
```

## Εγκατάσταση Collections

### Μία-Μία:
```bash
# Σιγουρέψου ότι είσαι στο venv
# (venv) ansible@ansible-controller:~/ansible$

# ansible.posix → firewalld, authorized_key, sysctl
ansible-galaxy collection install ansible.posix

# community.general → zypper, ufw, snap, και πολλά άλλα
ansible-galaxy collection install community.general

# community.docker → Docker management (θα χρειαστεί αργότερα)
ansible-galaxy collection install community.docker
```

### Όλες μαζί (συνιστάται):
```bash
ansible-galaxy collection install \
    ansible.posix \
    community.general \
    community.docker
```

### Από requirements.yml (βέλτιστη πρακτική):
```bash
# Δημιουργία requirements.yml
cat > ~/ansible/requirements.yml << 'EOF'
---
collections:
  - name: ansible.posix
    version: ">=1.5.0"

  - name: community.general
    version: ">=7.0.0"

  - name: community.docker
    version: ">=3.0.0"
EOF

# Εγκατάσταση από το αρχείο
ansible-galaxy collection install -r requirements.yml

# Αναμενόμενο output:
# Starting galaxy collection install process
# Installing 'ansible.posix:1.5.x' to '~/.ansible/collections'
# Installing 'community.general:7.x.x' to '~/.ansible/collections'
# Installing 'community.docker:3.x.x' to '~/.ansible/collections'
```

> 💡 **Γιατί requirements.yml;**
> - Καταγράφεις **ακριβώς** ποια collections χρειάζεσαι
> - Μπορείς να ορίσεις **ελάχιστη έκδοση**
> - Εύκολη **αναπαραγωγή** του περιβάλλοντος σε νέο controller
> - Είναι **βέλτιστη πρακτική** σε production

## Επαλήθευση Collections

```bash
# Δες όλα τα εγκατεστημένα collections
ansible-galaxy collection list

# Αναμενόμενο output:
# Collection               Version
# ------------------------ -------
# ansible.posix            1.5.x
# community.docker         3.x.x
# community.general        7.x.x

# Πληροφορίες για συγκεκριμένο collection
ansible-galaxy collection list community.docker

# Έλεγχος αν ένα module υπάρχει
ansible-doc community.docker.docker_container | head -20
```

---

## Πού αποθηκεύονται τα Collections

```bash
# Default τοποθεσία
ls ~/.ansible/collections/ansible_collections/

# Θα δεις:
# ansible/    ← ansible.posix
# community/  ← community.general, community.docker
```

```ini
# Μπορείς να αλλάξεις την τοποθεσία στο ansible.cfg
[defaults]
collections_path = /home/ansible/ansible/collections:~/.ansible/collections
```

---

## Αναβάθμιση Collections

```bash
# Αναβάθμιση συγκεκριμένου collection
ansible-galaxy collection install community.docker --upgrade

# Αναβάθμιση όλων από requirements.yml
ansible-galaxy collection install -r requirements.yml --upgrade
```

## Σύνοψη 4.5

```
Collections
├── Πακέτα με modules, plugins, roles
├── Εγκατάσταση με ansible-galaxy
├── Βέλτιστη πρακτική → requirements.yml
├── Αποθηκεύονται στο ~/.ansible/collections
└── Τα βασικά μας:
    ├── ansible.posix     → Linux/POSIX modules
    ├── community.general → Extra modules (zypper κλπ)
    └── community.docker  → Docker management
```
