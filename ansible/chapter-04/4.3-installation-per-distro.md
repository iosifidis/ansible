# 4.3 Εγκατάσταση Ansible ανά διανομή 🐧

## Η στρατηγική μας

Σε κάθε διανομή ακολουθούμε την **ίδια λογική**:

```
1. Αφαίρεση παλιάς έκδοσης (αν υπάρχει)
2. Εγκατάσταση προαπαιτούμενων
3. Δημιουργία venv
4. Εγκατάσταση Ansible μέσω pip
5. Αυτόματη ενεργοποίηση venv
6. Επαλήθευση
```

---

## 🔴 Debian/Ubuntu

### Βήμα 1: Αφαίρεση παλιάς έκδοσης
```bash
# Έλεγχος αν υπάρχει ήδη εγκατεστημένο Ansible
ansible --version 2>/dev/null && echo "ΥΠΑΡΧΕΙ" || echo "ΔΕΝ ΥΠΑΡΧΕΙ"

# Αν υπάρχει, αφαίρεσέ το
sudo apt remove ansible -y
sudo apt autoremove -y

# Επαλήθευση αφαίρεσης
ansible --version
# bash: ansible: command not found ✅
```

### Βήμα 2: Εγκατάσταση προαπαιτούμενων
```bash
sudo apt update
sudo apt install -y \
    python3 \
    python3-pip \
    python3-venv \
    python3-full \
    openssh-client \
    git

# Επαλήθευση
python3 --version
# Python 3.11.x ή νεότερο ✅
```

### Βήμα 3: Δημιουργία δομής φακέλων
```bash
# Ως ansible user
sudo su - ansible

# Δημιουργία δομής
mkdir -p ~/ansible/{inventory/group_vars,playbooks,roles,files,templates}

# Επαλήθευση
tree ~/ansible/
```

### Βήμα 4: Δημιουργία και ενεργοποίηση venv
```bash
# Δημιουργία venv
python3 -m venv ~/ansible/venv

# Ενεργοποίηση
source ~/ansible/venv/bin/activate
# (venv) ansible@hostname:~$ ✅
```

### Βήμα 5: Εγκατάσταση Ansible
```bash
# Αναβάθμιση pip
pip install --upgrade pip

# Εγκατάσταση Ansible
pip install ansible

# Επαλήθευση
ansible --version
# ansible [core 2.x.x]
# executable location = /home/ansible/ansible/venv/bin/ansible ✅
```

### Βήμα 6: Αυτόματη ενεργοποίηση venv
```bash
cat >> ~/.bashrc << 'EOF'

# Ansible venv
source ~/ansible/venv/bin/activate
cd ~/ansible
EOF

source ~/.bashrc
# (venv) ansible@hostname:~/ansible$ ✅
```

## 🟠 RedHat/Fedora

### Βήμα 1: Αφαίρεση παλιάς έκδοσης
```bash
# Έλεγχος αν υπάρχει
ansible --version 2>/dev/null && echo "ΥΠΑΡΧΕΙ" || echo "ΔΕΝ ΥΠΑΡΧΕΙ"

# Αφαίρεση αν υπάρχει
sudo dnf remove ansible -y
sudo dnf autoremove -y

# Επαλήθευση
ansible --version
# bash: ansible: command not found ✅
```

### Βήμα 2: Εγκατάσταση προαπαιτούμενων

#### Fedora:
```bash
sudo dnf update -y
sudo dnf install -y \
    python3 \
    python3-pip \
    python3-virtualenv \
    openssh-clients \
    git

# Επαλήθευση
python3 --version
pip3 --version
```

#### Rocky Linux / AlmaLinux:
```bash
sudo dnf update -y

# EPEL repository (απαραίτητο!)
sudo dnf install -y epel-release

sudo dnf install -y \
    python3 \
    python3-pip \
    python3-virtualenv \
    openssh-clients \
    git

# Επαλήθευση
python3 --version
pip3 --version
```

> 📝 **Διαφορά Fedora vs Rocky/AlmaLinux:**
> ```
> Fedora        → έχει τα πάντα στα default repos
> Rocky/Alma    → χρειάζεται EPEL για extra packages
> ```

### Βήμα 3: Δημιουργία δομής φακέλων
```bash
# Ως ansible user
sudo su - ansible

mkdir -p ~/ansible/{inventory/group_vars,playbooks,roles,files,templates}
```

### Βήμα 4: Δημιουργία και ενεργοποίηση venv

```bash
# Δημιουργία venv
python3 -m venv ~/ansible/venv

# Ενεργοποίηση
source ~/ansible/venv/bin/activate
# (venv) ansible@hostname:~$ ✅
```

### Βήμα 5: Εγκατάσταση Ansible
```bash
# Αναβάθμιση pip
pip install --upgrade pip

# Εγκατάσταση Ansible
pip install ansible

# Επαλήθευση
ansible --version
# ansible [core 2.x.x]
# executable location = /home/ansible/ansible/venv/bin/ansible ✅
```

### Βήμα 6: SELinux ρύθμιση

> ⚠️ **Σημαντικό μόνο για RedHat-based!** Το **SELinux** είναι ένα σύστημα ασφαλείας που είναι ενεργό by default στις RedHat διανομές. Μπορεί να προκαλέσει προβλήματα με την Ansible αν δεν ρυθμιστεί σωστά.

```bash
# Έλεγχος κατάστασης SELinux
sestatus
# SELinux status: enabled
# Current mode:   enforcing  ← ενεργό!

# Εγκατάσταση Python SELinux bindings
# (χωρίς αυτό η Ansible δεν μπορεί να διαχειριστεί SELinux)
pip install selinux

# Ή μέσω dnf
sudo dnf install -y python3-libselinux
```

### Βήμα 7: Αυτόματη ενεργοποίηση venv
```bash
cat >> ~/.bashrc << 'EOF'

# Ansible venv
source ~/ansible/venv/bin/activate
cd ~/ansible
EOF

source ~/.bashrc
# (venv) ansible@hostname:~/ansible$ ✅
```

## 🟢 openSUSE

> 🔔 **Σημείωση:** Και εδώ θα χρειαστείς το **openSUSE VM** σου για πρακτική εξάσκηση.

### Βήμα 1: Αφαίρεση παλιάς έκδοσης
```bash
# Έλεγχος αν υπάρχει
ansible --version 2>/dev/null && echo "ΥΠΑΡΧΕΙ" || echo "ΔΕΝ ΥΠΑΡΧΕΙ"

# Αφαίρεση αν υπάρχει
sudo zypper remove ansible -y

# Επαλήθευση
ansible --version
# bash: ansible: command not found ✅
```

### Βήμα 2: Εγκατάσταση προαπαιτούμενων

#### openSUSE Leap:
```bash
sudo zypper refresh
sudo zypper update -y
sudo zypper install -y \
    python3 \
    python3-pip \
    python3-virtualenv \
    openssh-clients \
    git

# Επαλήθευση
python3 --version
pip3 --version
```

#### openSUSE Tumbleweed:
```bash
sudo zypper refresh
sudo zypper update -y
sudo zypper install -y \
    python3 \
    python3-pip \
    python3-virtualenv \
    openssh-clients \
    git

# Επαλήθευση
python3 --version
pip3 --version
```

> 💡 **Leap vs Tumbleweed:**
> ```
> Leap        → σταθερή έκδοση, ενημερώσεις κάθε χρόνο
> Tumbleweed  → rolling release, καθημερινές ενημερώσεις
>               πάντα η τελευταία έκδοση Python
> ```

### Βήμα 3: Δημιουργία δομής φακέλων
```bash
sudo su - ansible
mkdir -p ~/ansible/{inventory/group_vars,playbooks,roles,files,templates}
```

### Βήμα 4: Δημιουργία και ενεργοποίηση venv
```bash
python3 -m venv ~/ansible/venv
source ~/ansible/venv/bin/activate
# (venv) ansible@hostname:~$ ✅
```

### Βήμα 5: Εγκατάσταση Ansible
```bash
pip install --upgrade pip
pip install ansible

# Επαλήθευση
ansible --version
# ansible [core 2.x.x]
# executable location = /home/ansible/ansible/venv/bin/ansible ✅
```

### Βήμα 6: AppArmor ρύθμιση

> ⚠️ **Σημαντικό μόνο για openSUSE!** Το **AppArmor** είναι το σύστημα ασφαλείας του openSUSE (αντίστοιχο του SELinux). Σπάνια προκαλεί πρόβλημα με την Ansible, αλλά καλό να το γνωρίζεις.

```bash
# Έλεγχος κατάστασης AppArmor
sudo systemctl status apparmor

# Αν χρειαστεί να δεις τα profiles
sudo aa-status
```

### Βήμα 7: Αυτόματη ενεργοποίηση venv
```bash
cat >> ~/.bashrc << 'EOF'

# Ansible venv
source ~/ansible/venv/bin/activate
cd ~/ansible
EOF

source ~/.bashrc
```
