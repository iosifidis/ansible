# 1.4 Τι κάνει η Ansible — Τα 4 Use Cases

## 🏗️ 1. Infrastructure Provisioning
Δημιουργία servers, VMs, cloud instances από το μηδέν.

```yaml
# Παράδειγμα: Δημιουργία VM στο cloud
- name: Create cloud server
  amazon.aws.ec2_instance:
    name: "web-server-01"
    instance_type: t3.micro
    image_id: ami-12345678
```

## ⚙️ 2. Configuration Management
Διασφάλιση ότι οι servers έχουν πάντα τη σωστή διαμόρφωση.

```yaml
# Παράδειγμα: Διαμόρφωση SSH για ασφάλεια
- name: Secure SSH configuration
  ansible.builtin.lineinfile:
    path: /etc/ssh/sshd_config
    regexp: '^PermitRootLogin'
    line: 'PermitRootLogin no'
```

## 🚀 3. Application Deployment
Ανάπτυξη εφαρμογών σε servers.

```yaml
# Παράδειγμα: Deploy web application
- name: Deploy my app
  ansible.builtin.git:
    repo: 'https://github.com/myuser/myapp.git'
    dest: /var/www/myapp
    version: main
```

## 🎭 4. Orchestration
Συντονισμός πολλαπλών servers σε σωστή σειρά.

```yaml
# Παράδειγμα: Rolling update (ένας-ένας server)
- name: Update web servers one by one
  hosts: webservers
  serial: 1        # ← Ένας κάθε φορά!
  tasks:
    - name: Update application
      ansible.builtin.git:
        repo: 'https://github.com/myapp.git'
        dest: /var/www/app
```
