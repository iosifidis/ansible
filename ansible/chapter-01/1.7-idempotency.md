# 1.7 Idempotency — Η Πιο Σημαντική Έννοια

**Idempotency** σημαίνει: μπορείς να τρέξεις το ίδιο playbook **πολλές φορές** και το αποτέλεσμα θα είναι **πάντα το ίδιο** χωρίς παρενέργειες.

```yaml
# Αυτό το task είναι idempotent:
# - 1η φορά: εγκαθιστά το nginx
# - 2η φορά: βλέπει ότι υπάρχει ήδη, δεν κάνει τίποτα ✅
- name: Install nginx
  ansible.builtin.package:
    name: nginx
    state: present   # "present" = να υπάρχει, όχι "να εγκατασταθεί"
```

> ⚠️ **Προσοχή:** Το module `ansible.builtin.command` και `ansible.builtin.shell` **δεν είναι** idempotent by default — θα τα δούμε αναλυτικά στο Κεφάλαιο 8.
