# 1.6 Το μεγάλο πλεονέκτημα: Agentless! 🎯

Σε αντίθεση με άλλα εργαλεία (Chef, Puppet), η Ansible **δεν χρειάζεται** να εγκαταστήσεις τίποτα στους managed servers:

| Εργαλείο | Agent στους servers; |
|---|---|
| **Ansible** | ❌ Δεν χρειάζεται! Μόνο SSH + Python |
| Chef | ✅ Χρειάζεται Chef Client |
| Puppet | ✅ Χρειάζεται Puppet Agent |
| SaltStack | ✅ Χρειάζεται Salt Minion |

> 💡 **Συμβουλή:** Αυτό σημαίνει ότι αν ένας server έχει SSH και Python (που έχουν σχεδόν όλοι οι Linux servers by default), η Ansible μπορεί να τον διαχειριστεί αμέσως!
