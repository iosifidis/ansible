# 1.2 Γιατί χρειαζόμαστε την Ansible;

## Το Πρόβλημα χωρίς Ansible

Φαντάσου ότι έχεις **10 servers** και πρέπει να εγκαταστήσεις το nginx σε όλους:

```bash
# Χωρίς Ansible: επαναλαμβάνεις αυτό 10 φορές χειροκίνητα!
ssh user@server1 "sudo apt install nginx -y"
ssh user@server2 "sudo apt install nginx -y"
ssh user@server3 "sudo apt install nginx -y"
# ... και άλλα 7 ακόμα 😩
```

## Η λύση με Ansible

```yaml
# Με Ansible: ένα αρχείο, εκτελείται σε ΟΛΟΥΣ τους servers!
- name: Εγκατάσταση nginx παντού
  hosts: all
  tasks:
    - name: Install nginx
      ansible.builtin.package:
        name: nginx
        state: present
```

```bash
# Μία μόνο εντολή για όλους!
ansible-playbook install_nginx.yml
```
