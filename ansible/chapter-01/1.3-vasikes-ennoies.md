# 1.3 Βασικές έννοιες — Ο «Χάρτης» της Ansible

```
┌─────────────────────────────────────────────┐
│           ANSIBLE CONTROLLER                │
│         (το Armbian σου) 🖥️                 │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │Inventory │  │Playbooks │  │  Roles   │   │
│  │(ποιοι    │  │(τι να    │  │(οργάνωση │   │
│  │servers)  │  │κάνεις)   │  │κώδικα)   │   │
│  └──────────┘  └──────────┘  └──────────┘   │
└──────────────────┬──────────────────────────┘
                   │ SSH (χωρίς agent!)
        ┌──────────┼──────────┐
        ▼          ▼          ▼
   [Server1]  [Server2]  [Server3]
   Rocky      Ubuntu     openSUSE
```

## Τα 5 βασικά συστατικά

| Έννοια | Τι είναι | Παράδειγμα |
|---|---|---|
| **Controller** | Ο server που τρέχει την Ansible | Το Armbian σου |
| **Inventory** | Η λίστα με τους servers-στόχους | `hosts.ini` |
| **Playbook** | Το «σενάριο» με τις εργασίες | `deploy.yml` |
| **Module** | Έτοιμη λειτουργία της Ansible | `apt`, `copy`, `service` |
| **Role** | Οργανωμένη συλλογή tasks | `nginx_role/` |
