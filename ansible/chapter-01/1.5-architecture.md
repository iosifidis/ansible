# 1.5 Η αρχιτεκτονική — Controller στο Armbian

## Το Setup σου

```
┌──────────────────┐         SSH          ┌──────────────────┐
│   Ubuntu PC σου  │ ──────────────────►  │  Armbian Server  │
│   (local)        │                      │  (Ansible        │
│                  │                      │   Controller)    │
└──────────────────┘                      └────────┬─────────┘
                                                   │
                                    SSH (Ansible)  │
                              ┌────────────────────┤
                              ▼                    ▼
                         [Managed              [Managed
                          Host 1]               Host 2]
```

## Γιατί αυτό είναι σωστή προσέγγιση ✅

- Ο **controller είναι πάντα online** (δεν εξαρτάται από το PC σου)
- **Centralized management** — όλα τρέχουν από ένα σημείο
- Μπορείς να **δουλεύεις από οπουδήποτε** με SSH
