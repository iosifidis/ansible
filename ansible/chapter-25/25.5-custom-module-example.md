# 25.5 Πρακτικό παράδειγμα — Custom API Module 🚀

## Σύνοψη Κεφαλαίου 25

Αυτό το κεφάλαιο κάλυψε την ανάπτυξη custom plugins:

```
Custom Modules & Plugins
│
├── Κεφ. 25.1: Πότε να γράψεις custom module
│   └── Proprietary APIs, complex idempotency
│
├── Κεφ. 25.2: Module anatomy
│   ├── AnsibleModule(argument_spec)
│   ├── module.params
│   ├── supports_check_mode
│   ├── exit_json(changed=bool)
│   └── fail_json(msg='...')
│
├── Κεφ. 25.3: Filter plugins
│   ├── filter_plugins/my_filters.py
│   └── FilterModule.filters() → {name: fn}
│
├── Κεφ. 25.4: Callback plugins
│   ├── callback_plugins/my_callback.py
│   ├── CallbackModule(CallbackBase)
│   └── v2_playbook_on_stats → notifications
│
└── Κεφ. 25.5: Πρακτικό (NetBox module)
    └── Real-world API integration με CMDB
```

## Ιεραρχία plugin directories

```
project/
├── library/           ← Custom modules
├── filter_plugins/    ← Jinja2 filters
├── callback_plugins/  ← Output/notifications
├── lookup_plugins/    ← Custom lookups
└── action_plugins/    ← Complex actions
```

## Testing custom module

```bash
# Direct test (χωρίς Ansible)
python library/my_module.py <<EOF
{
    "ANSIBLE_MODULE_ARGS": {
        "name": "myapp",
        "state": "present",
        "api_url": "https://api.example.com",
        "api_token": "test-token"
    }
}
EOF

# Με playbook (--check):
ansible-playbook test-module.yml --check -v
```
