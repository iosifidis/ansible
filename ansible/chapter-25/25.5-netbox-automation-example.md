# 25.5 Πρακτικό παράδειγμα — NetBox-Driven Automation 🚀

## Η ιδέα

```
NetBox = Single Source of Truth
│
├── Sysadmin προσθέτει VM στο NetBox
│   (IP, OS, role, environment)
│           │
│           ▼
├── Ansible διαβάζει dynamic inventory από NetBox
│           │
│           ▼
└── Playbook εφαρμόζεται αυτόματα στα νέα hosts
```

---

## Πλήρες setup

```yaml
# inventory/netbox.yml
---
plugin: netbox.netbox.nb_inventory
api_endpoint: "https://netbox.example.com"
token:        "{{ lookup('env', 'NETBOX_TOKEN') }}"

query_filters:
  - status: active

group_by:
  - device_roles    # webserver, database, monitor
  - platforms       # ubuntu, rocky, opensuse
  - tags            # docker, monitoring, backup

compose:
  ansible_host: "primary_ip4.address | ansible.utils.ipaddr('address')"
  ansible_user: "custom_fields.ansible_user | default('ansible')"
  ansible_port: "custom_fields.ssh_port | default(22) | int"
  deploy_env:   "custom_fields.environment | default('production')"
  install_docker: "tags | selectattr('name', 'equalto', 'docker') | list | length > 0"

cache: true
cache_plugin: jsonfile
cache_timeout: 300
cache_connection: /tmp/netbox_cache
```

## Site playbook

```yaml
---
# site.yml — Χρησιμοποιεί NetBox inventory

- name: Base configuration
  hosts: all
  become: true
  gather_facts: true

  roles:
    - role: base         # SSH, firewall, sysctl, users

- name: Monitoring exporters
  hosts: all
  become: true

  tasks:
    - name: Node Exporter
      community.docker.docker_container:
        name:           node_exporter
        image:          prom/node-exporter:v1.7.0
        state:          started
        restart_policy: unless-stopped
        network_mode:   host
        pid_mode:       host
        volumes:
          - "/:/host:ro,rslave"
        command:
          - "--path.rootfs=/host"

- name: Docker hosts setup
  hosts: docker    # ← από NetBox tag "docker"!
  become: true

  roles:
    - role: docker_install

- name: Web servers
  hosts: webservers    # ← από NetBox role "webserver"
  become: true

  roles:
    - role: nginx

- name: Databases
  hosts: databases     # ← από NetBox role "database"
  become: true

  roles:
    - role: postgresql
```

## Εκτέλεση

```bash
# Ρύθμιση
export NETBOX_TOKEN=abc123token

# Δες τους hosts (live!)
ansible-inventory -i inventory/netbox.yml --graph
# @all:
#   |--@webservers:
#   |  |--nextcloud
#   |--@databases:
#   |  |--db-01
#   |--@docker:
#   |  |--nextcloud
#   |  |--db-01

# Εκτέλεση
ansible-playbook site.yml -i inventory/netbox.yml -v

# Μόνο webservers
ansible-playbook site.yml \
    -i inventory/netbox.yml \
    --limit webservers

# Refresh cache
ansible-inventory -i inventory/netbox.yml --list --flush-cache
```

## Workflow: Νέος server

```
1. Sysadmin δημιουργεί VM στο Proxmox
2. Προσθέτει στο NetBox (IP, role=webserver, tag=docker)
3. Ansible pull ή CI/CD trigger:
   → ansible-playbook site.yml -i inventory/netbox.yml
4. Νέος host αυτόματα:
   → ✅ Base config (SSH, firewall)
   → ✅ Node Exporter
   → ✅ Docker (γιατί tag=docker)
   → ✅ Nginx (γιατί role=webserver)
5. Prometheus αυτόματα scrape (Jinja2 template από hostvars)
```
