# 25.1 Dynamic Inventory — Θεωρία 📚

## Static vs Dynamic Inventory

```
Static inventory (hosts.ini):
  [webservers]
  nextcloud ansible_host=192.168.1.10
  web-02    ansible_host=192.168.1.11

  Πρόβλημα:
  ├── Cloud servers αλλάζουν IP συχνά
  ├── Auto-scaling: νέοι servers → χειροκίνητη προσθήκη
  └── Δεδομένα διπλά (hosts.ini + CMDB/cloud console)

Dynamic inventory:
  Ansible ──► Plugin/Script ──► Live data (NetBox, AWS, etc.)
                                         ↓
                             [webservers]
                             nextcloud ansible_host=192.168.1.10
                             (φρέσκα, αυτόματα!)
```

---

## Plugin vs Script

```
Inventory Plugin (σύγχρονο, YAML):
  # inventory/netbox.yml
  plugin: netbox.netbox.nb_inventory
  api_endpoint: https://netbox.example.com
  token: abc123

  Πλεονεκτήματα:
  ✅ Native Ansible integration
  ✅ Caching support
  ✅ Easy filtering
  ✅ Πολλά plugins διαθέσιμα (AWS, GCP, Netbox, VMware)

Inventory Script (παλιό):
  # inventory/my_script.py
  #!/usr/bin/python
  import json; print(json.dumps({...}))

  Πότε ακόμα χρησιμοποιείται:
  → Proprietary systems χωρίς plugin
  → Legacy setups
```

## Inventory Plugin format (inventory.yml)

```yaml
# inventory/production.yml
---
plugin: netbox.netbox.nb_inventory
api_endpoint: https://netbox.example.com
token: "{{ lookup('env', 'NETBOX_TOKEN') }}"

# Φίλτρα
query_filters:
  - status: active
  - tenant: mycompany

# Groups από NetBox roles
group_by:
  - device_roles

# Compose variables
compose:
  ansible_host: primary_ip4.address | ipaddr('address')
  ansible_user: "ansible"
```

```bash
# Test dynamic inventory
ansible-inventory -i inventory/production.yml --list
ansible-inventory -i inventory/production.yml --graph

# Χρήση
ansible-playbook site.yml -i inventory/production.yml
```

## Σύνοψη 25.1

```
Dynamic Inventory
│
├── Plugin (YAML config) → Προτιμητέο
│   └── Φρέσκα δεδομένα από source of truth
│
├── Script (Python) → Legacy
│   └── Custom/proprietary systems
│
└── Εκτέλεση:
    ansible-inventory -i inventory/plugin.yml --list
```
