# 10.5 Βέλτιστες πρακτικές Handlers ✅

## 1. Χρησιμοποίησε Handlers μόνο για Services

```yaml
# ✅ ΣΩΣΤΟ — handlers για service management
handlers:
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted

  - name: Reload nginx
    ansible.builtin.service:
      name:  nginx
      state: reloaded

# ❌ ΛΑΘΟΣ — μην βάζεις σύνθετη λογική σε handlers
handlers:
  - name: Complex handler
    ansible.builtin.shell: |
      systemctl restart nginx
      systemctl restart php-fpm
      php artisan cache:clear
      echo "done" > /tmp/restart.log
    # ↑ Αυτό ανήκει σε tasks, όχι handlers!
```

## 2. Ξεχώρισε restart από reload

```yaml
# ✅ ΣΩΣΤΟ — ξεχωριστοί handlers
handlers:

  # Για μεγάλες αλλαγές (port, SSL, workers)
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted

  # Για μικρές αλλαγές (vhosts, locations)
  - name: Reload nginx
    ansible.builtin.service:
      name:  nginx
      state: reloaded

tasks:

  # Αλλαγή port → restart (απαιτεί πλήρες restart)
  - name: Αλλαγή nginx port
    ansible.builtin.lineinfile:
      path:   /etc/nginx/nginx.conf
      regexp: '^listen'
      line:   'listen 8080;'
    notify: Restart nginx      # ← restart

  # Νέο vhost → reload αρκεί (graceful)
  - name: Προσθήκη νέου vhost
    ansible.builtin.copy:
      src:  files/newsite.conf
      dest: /etc/nginx/sites-available/newsite
    notify: Reload nginx        # ← reload
```

## 3. Χρησιμοποίησε listen για ομαδοποίηση

```yaml
# ❌ ΛΑΘΟΣ — πολλά notify, δύσκολο να συντηρηθεί
tasks:
  - name: Config change
    ansible.builtin.copy:
      src:  files/app.conf
      dest: /etc/app/app.conf
    notify:
      - Restart nginx
      - Restart php-fpm
      - Restart redis
      - Clear opcache
      - Send slack alert

# ✅ ΣΩΣΤΟ — listen group
tasks:
  - name: Config change
    ansible.builtin.copy:
      src:  files/app.conf
      dest: /etc/app/app.conf
    notify: app stack restart   # ← ένα notify

handlers:
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    listen: app stack restart

  - name: Restart php-fpm
    ansible.builtin.service:
      name:  php8.1-fpm
      state: restarted
    listen: app stack restart

  - name: Restart redis
    ansible.builtin.service:
      name:  redis
      state: restarted
    listen: app stack restart
```

## 4. Πάντα ignore_errors σε Check Mode

```yaml
# ✅ ΣΩΣΤΟ — handlers που δουλεύουν σε check mode
handlers:

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    ignore_errors: "{{ ansible_check_mode }}"
    # ↑ Σε dry run: service δεν υπάρχει → ignore error
    # ↑ Σε real run: κανονική εκτέλεση

  - name: Restart SSH
    ansible.builtin.service:
      name:  "{{ service_ssh }}"
      state: restarted
    ignore_errors: "{{ ansible_check_mode }}"

  - name: Restart fail2ban
    ansible.builtin.service:
      name:  fail2ban
      state: restarted
    ignore_errors: "{{ ansible_check_mode }}"
```

## 5. flush_handlers πριν από Critical Tasks

```yaml
tasks:

  # ── Config αλλαγές ────────────────────────
  - name: Nginx config
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx

  - name: SSL config
    ansible.builtin.copy:
      src:  files/ssl.conf
      dest: /etc/nginx/ssl.conf
    notify: Restart nginx

  # ── ΚΡΙΣΙΜΟ: flush πριν το test ───────────
  - name: Εφαρμογή handlers
    ansible.builtin.meta: flush_handlers
    # ↑ Εξασφαλίζει ότι nginx έχει restarted
    #   πριν το επόμενο task!

  # ── Test αφού nginx έχει restarted ────────
  - name: Έλεγχος nginx
    ansible.builtin.uri:
      url:         http://localhost
      status_code: 200
    # ✅ Τώρα ο nginx τρέχει με το νέο config!
```

## 6. Σαφή ονόματα Handlers

```yaml
# ❌ ΛΑΘΟΣ — ασαφή ονόματα
handlers:
  - name: handler1
    ansible.builtin.service:
      name: nginx
      state: restarted

  - name: do_thing
    ansible.builtin.service:
      name: fail2ban
      state: restarted

# ✅ ΣΩΣΤΟ — περιγραφικά ονόματα
handlers:
  - name: Restart nginx web server
    ansible.builtin.service:
      name:  nginx
      state: restarted

  - name: Restart fail2ban IPS
    ansible.builtin.service:
      name:  fail2ban
      state: restarted

  - name: Reload nginx configuration
    ansible.builtin.service:
      name:  nginx
      state: reloaded

  - name: Validate and restart SSH
    ansible.builtin.service:
      name:  "{{ service_ssh }}"
      state: restarted
```

## 7. Handlers σε Roles (Preview Κεφ. 15)

```
my_role/
├── tasks/
│   └── main.yml      ← tasks με notify
├── handlers/
│   └── main.yml      ← handlers εδώ!
└── defaults/
    └── main.yml      ← default variables
```

```yaml
# roles/nginx/handlers/main.yml
---
- name: Restart nginx
  ansible.builtin.service:
    name:  nginx
    state: restarted
  ignore_errors: "{{ ansible_check_mode }}"

- name: Reload nginx
  ansible.builtin.service:
    name:  nginx
    state: reloaded
  ignore_errors: "{{ ansible_check_mode }}"

- name: Test nginx config
  ansible.builtin.command:
    cmd: nginx -t
  changed_when: false
  listen: Validate nginx
```

> 💡 **Σημείωση:** Τα roles έχουν **δικό τους handlers directory** — δεν χρειάζεται να τους ορίζεις στο playbook!

## 8. Anti-patterns — Τι να αποφύγεις

```yaml
# ❌ Anti-pattern 1: Handler που πάντα αλλάζει
handlers:
  - name: Update timestamp
    ansible.builtin.shell:
      cmd: "date > /tmp/last_update"
    # ↑ Shell handlers είναι ΠΑΝΤΑ "changed"
    # Χρησιμοποίησε changed_when: false

# ✅ Σωστό:
handlers:
  - name: Update timestamp
    ansible.builtin.shell:
      cmd: "date > /tmp/last_update"
    changed_when: false    # ← δεν μετράει ως αλλαγή

# ────────────────────────────────────────────

# ❌ Anti-pattern 2: Task ως handler
handlers:
  - name: Deploy app
    ansible.builtin.git:
      repo: https://github.com/myapp.git
      dest: /var/www/myapp
    # ↑ Deployment ανήκει σε tasks!
    # Handlers = service management μόνο!

# ────────────────────────────────────────────

# ❌ Anti-pattern 3: notify χωρίς λόγο
tasks:
  - name: Check disk space
    ansible.builtin.command:
      cmd: df -h
    notify: Restart nginx    # ← γιατί???
    changed_when: false
    # ↑ notify δεν εκπέμπεται αν changed_when: false!
    # Αλλά είναι confusing — αφαίρεσέ το

# ────────────────────────────────────────────

# ❌ Anti-pattern 4: Πάρα πολλοί handlers
handlers:
  - name: Restart nginx after config
  - name: Restart nginx after ssl
  - name: Restart nginx after vhost
  - name: Restart nginx after upstream
  # ↑ Όλοι κάνουν το ίδιο πράγμα!
  # Χρησιμοποίησε listen!

# ✅ Σωστό:
handlers:
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    listen: nginx needs restart
```

## Quick Reference — Handlers Checklist

```
Handlers Checklist ✅
├── Χρησιμοποίησε για service restart/reload
├── Ξεχώρισε restart από reload
├── Χρησιμοποίησε listen για ομαδοποίηση
├── Πρόσθεσε ignore_errors: "{{ ansible_check_mode }}"
├── Χρησιμοποίησε flush_handlers πριν critical tasks
├── Δώσε σαφή, περιγραφικά ονόματα
├── Χρησιμοποίησε group_vars για service names
└── Αποφύγετε:
    ├── Σύνθετη λογική σε handlers
    ├── Deployment tasks ως handlers
    └── Πολλαπλοί handlers με ίδια λειτουργία
```
