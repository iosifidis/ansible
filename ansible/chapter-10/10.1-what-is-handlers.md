# 10.1 Τι είναι οι Handlers 🔔

## Ο ορισμός

Οι **Handlers** είναι ειδικά tasks που εκτελούνται **μόνο όταν κληθούν** από άλλο task μέσω του `notify` — και μόνο αν το task που τους κάλεσε **έκανε αλλαγή**.

> 📝 **Αναλογία:** Σκέψου τον handler σαν **συναγερμό**:
> ```
> Task  = η πόρτα
> Handler = ο συναγερμός
>
> Αν η πόρτα ΔΕΝ ανοίξει → συναγερμός ΔΕΝ χτυπάει
> Αν η πόρτα ανοίξει     → συναγερμός χτυπάει
>
> Αν task δεν αλλάξει    → handler ΔΕΝ τρέχει
> Αν task αλλάξει        → handler τρέχει
> ```

---

## Γιατί υπάρχουν οι Handlers;

### Το πρόβλημα χωρίς Handlers:

```yaml
# ❌ Χωρίς handlers — restart ΠΑΝΤΑ, αλλάξει ή όχι
tasks:
  - name: Αντιγραφή nginx config
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted    # ← τρέχει ΠΑΝΤΑ!
                          # ακόμα κι αν το config δεν άλλαξε
                          # → Απαραίτητο downtime!
```

### Η Λύση με Handlers:

```yaml
# ✅ Με handlers — restart ΜΟΝΟ αν άλλαξε το config
tasks:
  - name: Αντιγραφή nginx config
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx    # ← κάλεσε handler ΑΝ άλλαξε

handlers:
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted       # ← τρέχει ΜΟΝΟ αν notify εκπέμφθηκε
```

## Πώς διαφέρουν από Tasks

```
┌─────────────────────────────────────────────────────────┐
│  TASKS                    │  HANDLERS                   │
├───────────────────────────┼─────────────────────────────┤
│ Τρέχουν πάντα             │ Τρέχουν μόνο αν κληθούν     │
│ (εκτός αν when=false)     │ και αν task άλλαξε          │
├───────────────────────────┼─────────────────────────────┤
│ Τρέχουν με τη σειρά       │ Τρέχουν στο ΤΕΛΟΣ του play  │
│ που ορίζονται             │ (όχι αμέσως)                │
├───────────────────────────┼─────────────────────────────┤
│ Στο tasks: section        │ Στο handlers: section       │
├───────────────────────────┼─────────────────────────────┤
│ Εκτελούνται κάθε φορά     │ Εκτελούνται ΜΟΝΟ ΜΙΑ ΦΟΡΑ   │
│                           │ ακόμα κι αν κληθούν πολλές  │
└───────────────────────────┴─────────────────────────────┘
```

## Πότε τρέχουν οι Handlers

```
┌─────────────────────────────────────────────────────────┐
│  PLAY                                                   │
│  ├── Task 1 → notify Handler A     ← 1η κλήση           │
│  ├── Task 2 → (καμία αλλαγή)                            │
│  ├── Task 3 → notify Handler A     ← 2η κλήση           │
│  ├── Task 4 → notify Handler B                          │
│  └── Task 5 → (καμία αλλαγή)                            │
│                                                         │
│  [ΤΕΛΟΣ TASKS]                                          │
│  └── Handlers εκτελούνται ΕΔΩ:                          │
│      ├── Handler A → τρέχει ΜΟΝΟ ΜΙΑ ΦΟΡΑ ✅            │
│      │              (αν και κλήθηκε 2 φορές)            │
│      └── Handler B → τρέχει ✅                          │
└─────────────────────────────────────────────────────────┘
```

> 💡 **Κρίσιμο:** Ακόμα κι αν ο **ίδιος handler** κληθεί από **πολλά tasks**, εκτελείται **μόνο μία φορά** στο τέλος — αυτό αποτρέπει πολλαπλά restarts!

## Το πρόβλημα με τη σειρά εκτέλεσης

```yaml
tasks:
  - name: Task 1 → notify
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx

  - name: Task 2 → χρειάζεται το restart να έχει γίνει!
    ansible.builtin.uri:
      url: http://localhost
    # ↑ ΔΕΝ θα δουλέψει αν το nginx δεν έχει restarted ακόμα!
    # Οι handlers τρέχουν στο ΤΕΛΟΣ, όχι αμέσως!
```

```yaml
# Λύση: χρήση meta για forced flush
tasks:
  - name: Task 1 → notify
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx

  - name: Εκτέλεση handlers τώρα (flush)
    ansible.builtin.meta: flush_handlers
    # ↑ Τρέχει ΑΜΕΣΩΣ τους pending handlers!

  - name: Task 2 → τώρα δουλεύει!
    ansible.builtin.uri:
      url: http://localhost
```

## Σύνοψη 10.1

```
Handlers
├── Είναι ειδικά tasks
├── Τρέχουν ΜΟΝΟ αν:
│   ├── Κληθούν με notify
│   └── Το task που τους κάλεσε έκανε CHANGED
├── Τρέχουν στο ΤΕΛΟΣ του play
├── Τρέχουν ΜΟΝΟ ΜΙΑ ΦΟΡΑ (ακόμα κι αν κληθούν πολλές)
├── Ιδανικοί για: restart services, reload configs
└── flush_handlers → εκτέλεση αμέσως αν χρειάζεται
```
