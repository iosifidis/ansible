## listen — Ομαδοποίηση Handlers

Το `listen` επιτρέπει σε **πολλούς handlers** να ακούνε το **ίδιο notify**:

```yaml
tasks:

  - name: Αλλαγή web config
    ansible.builtin.copy:
      src:  files/web.conf
      dest: /etc/myapp/web.conf
    notify: web config changed    # ← ένα notify

handlers:

  # Και οι τρεις handlers ακούνε το ίδιο event!
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    listen: web config changed    # ← ακούει αυτό

  - name: Restart php-fpm
    ansible.builtin.service:
      name:  php8.1-fpm
      state: restarted
    listen: web config changed    # ← ακούει αυτό

  - name: Clear app cache
    ansible.builtin.command:
      cmd: php /var/www/myapp/artisan cache:clear
    listen: web config changed    # ← ακούει αυτό
```

> 💡 **Γιατί χρήσιμο:**
> ```
> Χωρίς listen:
> notify:
>   - Restart nginx
>   - Restart php-fpm
>   - Clear app cache
>
> Με listen:
> notify: web config changed   ← πολύ πιο καθαρό! ✅
> ```

## listen vs notify — Σύγκριση

```yaml
# ── Τρόπος 1: Πολλαπλά notify ────────────────
tasks:
  - name: Config change
    ansible.builtin.copy:
      src:  files/app.conf
      dest: /etc/app/app.conf
    notify:
      - Restart nginx
      - Restart php-fpm
      - Restart redis
      - Clear cache
      - Send alert

# ── Τρόπος 2: listen (καλύτερο!) ─────────────
tasks:
  - name: Config change
    ansible.builtin.copy:
      src:  files/app.conf
      dest: /etc/app/app.conf
    notify: app config changed    # ← ένα notify

handlers:
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    listen: app config changed

  - name: Restart php-fpm
    ansible.builtin.service:
      name:  php8.1-fpm
      state: restarted
    listen: app config changed

  - name: Restart redis
    ansible.builtin.service:
      name:  redis
      state: restarted
    listen: app config changed

  - name: Clear cache
    ansible.builtin.command:
      cmd: php artisan cache:clear
    listen: app config changed

  - name: Send alert
    ansible.builtin.debug:
      msg: "⚠️ App config άλλαξε!"
    listen: app config changed
```

## Handlers με Conditions (when)

```yaml
handlers:

  # ── Handler μόνο για Debian ───────────────
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    when: ansible_facts['os_family'] == "Debian"

  # ── Handler μόνο για RedHat ───────────────
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    when: ansible_facts['os_family'] == "RedHat"

  # ── Handler με environment check ──────────
  - name: Send production alert
    ansible.builtin.debug:
      msg: "🚨 Production config changed!"
    when: app_env == "production"
```

## Handlers με Variables

```yaml
---
- name: Handlers με Variables
  hosts: all
  become: true
  gather_facts: true

  vars:
    web_service:  nginx
    app_service:  myapp
    cache_service: redis

  tasks:

    - name: Αλλαγή web config
      ansible.builtin.copy:
        src:  files/nginx.conf
        dest: /etc/nginx/nginx.conf
      notify: "Restart {{ web_service }}"   # ← dynamic handler name!

    - name: Αλλαγή app config
      ansible.builtin.copy:
        src:  files/app.conf
        dest: /etc/myapp/app.conf
      notify: "Restart {{ app_service }}"

  handlers:

    - name: "Restart {{ web_service }}"     # ← dynamic name!
      ansible.builtin.service:
        name:  "{{ web_service }}"
        state: restarted

    - name: "Restart {{ app_service }}"
      ansible.builtin.service:
        name:  "{{ app_service }}"
        state: restarted

    - name: "Restart {{ cache_service }}"
      ansible.builtin.service:
        name:  "{{ cache_service }}"
        state: restarted
```

## force_handlers — Εκτέλεση ακόμα κι αν αποτύχει

Κανονικά, αν ένα task αποτύχει, οι handlers **δεν εκτελούνται**. Το `force_handlers` το αλλάζει αυτό:

```yaml
---
- name: Force Handlers Demo
  hosts: all
  become: true
  force_handlers: true      # ← handlers τρέχουν ΠΑΝΤΑ
                            #   ακόμα κι αν αποτύχει task!

  tasks:

    - name: Config αλλαγή
      ansible.builtin.copy:
        src:  files/nginx.conf
        dest: /etc/nginx/nginx.conf
      notify: Restart nginx

    - name: Task που αποτυγχάνει
      ansible.builtin.command:
        cmd: /nonexistent/command
      # ↑ Χωρίς force_handlers → handler ΔΕΝ τρέχει
      # ↑ Με force_handlers    → handler ΤΡΕΧΕΙ ✅

  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted
```

> 💡 **Πότε χρήσιμο:**
> ```
> ✅ Όταν ο handler κάνει cleanup που πρέπει να γίνει
>    ακόμα κι αν το playbook αποτύχει
> ✅ Logging/alerting handlers
> ✅ Rollback handlers
> ❌ Κανονική χρήση — άφησε το default (false)
> ```

## Handler Chains — Handlers που καλούν Handlers

```yaml
tasks:

  - name: Αλλαγή nginx config
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Validate nginx config    # ← 1ο handler

handlers:

  # ── Chain: validate → restart ─────────────
  - name: Validate nginx config
    ansible.builtin.command:
      cmd: nginx -t                  # ← validation
    register: nginx_valid
    notify: Restart nginx            # ← καλεί 2ο handler!
                                     # μόνο αν validation OK

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
    when: nginx_valid.rc == 0        # ← μόνο αν valid
```

> ⚠️ **Σημείωση:** Οι handler chains είναι **advanced** και πρέπει να τις χρησιμοποιείς με προσοχή — μπορεί να δημιουργήσουν πολύπλοκη λογική.

## Πλήρες παράδειγμα — Advanced Handlers
{% raw %}
```yaml
---
# advanced-handlers-demo.yml

- name: Advanced Handlers Demo
  hosts: all
  become: true
  gather_facts: true
  force_handlers: false

  vars:
    app_env:     production
    web_service: nginx

  tasks:

    # ── Εγκατάσταση ───────────────────────────
    - name: Εγκατάσταση nginx (Debian)
      ansible.builtin.apt:
        name:         nginx
        state:        present
        update_cache: true
      when: ansible_facts['os_family'] == "Debian"

    - name: Εγκατάσταση nginx (RedHat)
      ansible.builtin.dnf:
        name:  nginx
        state: present
      when: ansible_facts['os_family'] == "RedHat"

    - name: Εγκατάσταση nginx (openSUSE)
      community.general.zypper:
        name:  nginx
        state: present
      when: ansible_facts['os_family'] == "Suse"

    # ── Config αλλαγές ────────────────────────
    - name: Nginx main config
      ansible.builtin.copy:
        dest:   /etc/nginx/nginx.conf
        mode:   '0644'
        backup: true
        content: |
          user www-data;
          worker_processes auto;
          pid /run/nginx.pid;
          events { worker_connections 768; }
          http {
            sendfile on;
            include /etc/nginx/mime.types;
            include /etc/nginx/sites-enabled/*;
          }
      notify: nginx changed          # ← listen event

    - name: Nginx default site
      ansible.builtin.copy:
        dest:   /etc/nginx/sites-available/default
        mode:   '0644'
        content: |
          server {
            listen 80 default_server;
            root /var/www/html;
            index index.html;
          }
      notify: nginx changed          # ← ίδιο listen event

    - name: Enable default site
      ansible.builtin.file:
        src:   /etc/nginx/sites-available/default
        dest:  /etc/nginx/sites-enabled/default
        state: link
      notify: nginx changed          # ← ίδιο listen event

    # ── Εκτέλεση handlers πριν test ───────────
    - name: Flush handlers
      ansible.builtin.meta: flush_handlers

    # ── Επαλήθευση ────────────────────────────
    - name: Έλεγχος nginx
      ansible.builtin.uri:
        url:         http://localhost
        status_code: 200
      register: nginx_check
      ignore_errors: true

    - name: Αποτέλεσμα
      ansible.builtin.debug:
        msg: >
          nginx:
          {{ '✅ OK' if nginx_check.status == 200
                    else '❌ FAILED' }}

  # ── HANDLERS ────────────────────────────────
  handlers:

    # ── Validation ────────────────────────────
    - name: Validate nginx
      ansible.builtin.command:
        cmd: nginx -t
      register:     nginx_test
      changed_when: false
      listen: nginx changed          # ← ακούει event

    # ── Restart ───────────────────────────────
    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted
      listen: nginx changed          # ← ακούει ίδιο event
      when: >
        nginx_test is defined and
        nginx_test.rc == 0           # ← μόνο αν valid

    # ── Alert ─────────────────────────────────
    - name: Production alert
      ansible.builtin.debug:
        msg: "🚨 nginx config άλλαξε σε production!"
      listen: nginx changed          # ← ακούει ίδιο event
      when: app_env == "production"
```

## Σύνοψη 10.3

```
Advanced Handlers
├── listen:
│   ├── Πολλοί handlers ακούνε ένα event
│   └── Πιο καθαρό από πολλαπλά notify
│
├── when σε handlers:
│   └── Conditionals για selective execution
│
├── Variables σε handlers:
│   └── Dynamic handler names
│
├── force_handlers:
│   ├── Handlers τρέχουν ακόμα κι αν αποτύχει task
│   └── Χρήσιμο για cleanup/alerting
│
└── Handler chains:
    ├── Handler καλεί άλλο handler
    └── Προσοχή στην πολυπλοκότητα!
```
