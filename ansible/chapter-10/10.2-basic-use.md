# 10.2 Βασική χρήση Handlers 🔔

## Η δομή notify + handlers

```yaml
---
- name: My Play
  hosts: all
  become: true

  tasks:
    - name: Κάποιο task
      ansible.builtin.copy:
        src:  files/nginx.conf
        dest: /etc/nginx/nginx.conf
      notify: Restart nginx    # ← όνομα handler

  handlers:
    - name: Restart nginx      # ← ίδιο όνομα!
      ansible.builtin.service:
        name:  nginx
        state: restarted
```

> ⚠️ **Κρίσιμο:** Το όνομα στο `notify` πρέπει να ταιριάζει **ακριβώς** με το `name` του handler — case sensitive!

---

## Πότε εκπέμπεται το notify

```yaml
tasks:

  # ── CHANGED → handler εκτελείται ─────────
  - name: Config αλλάζει → notify
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
      # αν το αρχείο είναι διαφορετικό → CHANGED
    notify: Restart nginx     # ← ΘΑ εκτελεστεί ✅

  # ── OK → handler ΔΕΝ εκτελείται ──────────
  - name: Config ίδιο → no notify
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
      # αν το αρχείο είναι ίδιο → OK (no change)
    notify: Restart nginx     # ← ΔΕΝ εκτελείται ✅

  # ── FAILED → handler ΔΕΝ εκτελείται ──────
  - name: Task αποτυγχάνει → no notify
    ansible.builtin.command:
      cmd: /nonexistent/command
    notify: Restart nginx     # ← ΔΕΝ εκτελείται
    ignore_errors: true
```

## Πολλαπλά notify σε ένα Task

```yaml
tasks:

  - name: Αλλαγή SSL config
    ansible.builtin.copy:
      src:  files/ssl.conf
      dest: /etc/nginx/ssl.conf
    notify:
      - Restart nginx       # ← πολλαπλά notify
      - Restart fail2ban    # ← ως λίστα
      - Send notification

handlers:

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted

  - name: Restart fail2ban
    ansible.builtin.service:
      name:  fail2ban
      state: restarted

  - name: Send notification
    ansible.builtin.debug:
      msg: "⚠️ SSL config άλλαξε — έλεγξε τη σύνδεση!"
```

## Ένας Handler από πολλά Tasks

```yaml
tasks:

  # Και τα τρία notify τον ίδιο handler
  - name: Αλλαγή nginx.conf
    ansible.builtin.copy:
      src:  files/nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx      # ← 1η κλήση

  - name: Αλλαγή sites-available
    ansible.builtin.template:
      src:  templates/mysite.conf.j2
      dest: /etc/nginx/sites-available/mysite
    notify: Restart nginx      # ← 2η κλήση

  - name: Ενεργοποίηση site
    ansible.builtin.file:
      src:   /etc/nginx/sites-available/mysite
      dest:  /etc/nginx/sites-enabled/mysite
      state: link
    notify: Restart nginx      # ← 3η κλήση

  # ↑ Ο handler Restart nginx θα τρέξει
  # ΜΟΝΟ ΜΙΑ ΦΟΡΑ στο τέλος! ✅

handlers:

  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted
```

## Πλήρες παράδειγμα

```yaml
---
# handlers-demo.yml

- name: Handlers Demo
  hosts: debian_based
  become: true
  gather_facts: true

  tasks:

    # ── Εγκατάσταση ───────────────────────────
    - name: Εγκατάσταση nginx
      ansible.builtin.apt:
        name:         nginx
        state:        present
        update_cache: true

    # ── Config files ──────────────────────────
    - name: Αντιγραφή nginx.conf
      ansible.builtin.copy:
        dest:    /etc/nginx/nginx.conf
        mode:    '0644'
        backup:  true
        content: |
          user www-data;
          worker_processes auto;
          pid /run/nginx.pid;

          events {
            worker_connections 768;
          }

          http {
            sendfile on;
            include /etc/nginx/mime.types;
            include /etc/nginx/conf.d/*.conf;
            include /etc/nginx/sites-enabled/*;
          }
      notify: Restart nginx      # ← αν αλλάξει → restart

    - name: Δημιουργία default site
      ansible.builtin.copy:
        dest:   /etc/nginx/sites-available/default
        mode:   '0644'
        content: |
          server {
            listen 80 default_server;
            root /var/www/html;
            index index.html;

            location / {
              try_files $uri $uri/ =404;
            }
          }
      notify: Reload nginx       # ← reload αρκεί εδώ

    - name: Ενεργοποίηση default site
      ansible.builtin.file:
        src:   /etc/nginx/sites-available/default
        dest:  /etc/nginx/sites-enabled/default
        state: link
      notify: Reload nginx

    - name: Δημιουργία index.html
      ansible.builtin.copy:
        dest:    /var/www/html/index.html
        mode:    '0644'
        owner:   www-data
        group:   www-data
        content: |
          <html>
            <body>
              <h1>{{ inventory_hostname }}</h1>
              <p>Managed by Ansible ✅</p>
            </body>
          </html>
      # ↑ δεν χρειάζεται notify — δεν επηρεάζει nginx config

    # ── Service ───────────────────────────────
    - name: Εκκίνηση nginx
      ansible.builtin.service:
        name:    nginx
        state:   started
        enabled: true

    # ── Flush handlers πριν το test ───────────
    - name: Εφαρμογή pending handlers
      ansible.builtin.meta: flush_handlers

    # ── Επαλήθευση ────────────────────────────
    - name: Έλεγχος nginx
      ansible.builtin.uri:
        url:         http://localhost
        status_code: 200
      register: nginx_test

    - name: Αποτέλεσμα
      ansible.builtin.debug:
        msg: "nginx: {{ nginx_test.status }} ✅"

  # ── HANDLERS ────────────────────────────────
  handlers:

    - name: Restart nginx
      ansible.builtin.service:
        name:  nginx
        state: restarted

    - name: Reload nginx
      ansible.builtin.service:
        name:  nginx
        state: reloaded
```

```bash
# 1η εκτέλεση — όλα αλλάζουν
ansible-playbook playbooks/handlers-demo.yml \
    --limit nextcloud -v

# Output:
# TASK [Αντιγραφή nginx.conf] → CHANGED
# TASK [Δημιουργία default site] → CHANGED
# ...
# RUNNING HANDLER [Restart nginx] → CHANGED ✅
# RUNNING HANDLER [Reload nginx] → CHANGED ✅

# 2η εκτέλεση — τίποτα δεν αλλάζει
ansible-playbook playbooks/handlers-demo.yml \
    --limit nextcloud -v

# Output:
# TASK [Αντιγραφή nginx.conf] → OK (no change)
# TASK [Δημιουργία default site] → OK (no change)
# ...
# (κανένας handler δεν τρέχει!) ✅
```

## Restart vs Reload — Πότε το καθένα

```
┌─────────────────────────────────────────────────────────┐
│  state: restarted                                       │
│  ├── Σταματά και ξεκινά ξανά το service                 │
│  ├── Διακόπτει ενεργές συνδέσεις                        │
│  ├── Χρησιμοποίησε για: μεγάλες αλλαγές config          │
│  └── Παράδειγμα: αλλαγή port, SSL, worker processes     │
├─────────────────────────────────────────────────────────┤
│  state: reloaded                                        │
│  ├── Ξαναδιαβάζει το config χωρίς να σταματήσει         │
│  ├── ΔΕΝ διακόπτει ενεργές συνδέσεις                    │
│  ├── Χρησιμοποίησε για: μικρές αλλαγές config           │
│  └── Παράδειγμα: νέο virtual host, νέο location block   │
└─────────────────────────────────────────────────────────┘
```

```yaml
handlers:

  # Για μεγάλες αλλαγές
  - name: Restart nginx
    ansible.builtin.service:
      name:  nginx
      state: restarted

  # Για μικρές αλλαγές (graceful)
  - name: Reload nginx
    ansible.builtin.service:
      name:  nginx
      state: reloaded

  # Για SSH — πάντα restart (όχι reload)
  - name: Restart SSH
    ansible.builtin.service:
      name:  "{{ service_ssh }}"
      state: restarted

  # Για fail2ban
  - name: Restart fail2ban
    ansible.builtin.service:
      name:  fail2ban
      state: restarted
```

## Σύνοψη 10.2

```
Βασική Χρήση Handlers
├── notify: "Handler Name"   → κλήση handler
├── handlers:                → ορισμός section
│     - name: "Handler Name" → ίδιο όνομα!
│       module: ...
│
├── Εκπομπή notify:
│   ├── CHANGED → εκπέμπεται ✅
│   ├── OK      → δεν εκπέμπεται
│   └── FAILED  → δεν εκπέμπεται
│
├── Πολλαπλά notify:
│   notify: [Handler A, Handler B]
│
├── Ένας handler ← πολλά tasks:
│   → εκτελείται ΜΟΝΟ ΜΙΑ ΦΟΡΑ
│
├── flush_handlers:
│   → εκτέλεση αμέσως (όχι στο τέλος)
│
└── restart vs reload:
    ├── restarted → μεγάλες αλλαγές
    └── reloaded  → μικρές αλλαγές (graceful)
```
