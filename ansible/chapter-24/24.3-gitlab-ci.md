# 24.3 GitLab CI 🦊

## .gitlab-ci.yml

```yaml
# .gitlab-ci.yml
image: python:3.11-slim

stages:
  - lint
  - test
  - deploy-staging
  - deploy-production

variables:
  PY_COLORS:             "1"
  ANSIBLE_FORCE_COLOR:   "1"

# ── Reusable setup ────────────────────────────────
.ansible-setup: &ansible-setup
  before_script:
    - pip install ansible ansible-lint molecule molecule-plugins[docker]
    - ansible-galaxy install -r requirements.yml
    - mkdir -p ~/.ssh
    - echo "$ANSIBLE_SSH_PRIVATE_KEY" | tr -d '\r' > ~/.ssh/id_ed25519
    - chmod 600 ~/.ssh/id_ed25519
    - ssh-keyscan -H "$STAGING_HOST" >> ~/.ssh/known_hosts || true
    - ssh-keyscan -H "$PRODUCTION_HOST" >> ~/.ssh/known_hosts || true
    - echo "$ANSIBLE_VAULT_PASSWORD" > .vault_pass

# ── Stage: Lint ───────────────────────────────────
lint:
  stage: lint
  <<: *ansible-setup
  script:
    - ansible-lint
  after_script:
    - rm -f .vault_pass

# ── Stage: Test ───────────────────────────────────
molecule-nginx:
  stage: test
  needs: [lint]
  services:
    - docker:dind
  variables:
    DOCKER_HOST: tcp://docker:2375
  script:
    - cd roles/nginx && molecule test

molecule-docker:
  stage: test
  needs: [lint]
  services:
    - docker:dind
  variables:
    DOCKER_HOST: tcp://docker:2375
  script:
    - cd roles/docker && molecule test

# ── Stage: Deploy Staging ─────────────────────────
deploy-staging:
  stage: deploy-staging
  needs: [molecule-nginx, molecule-docker]
  <<: *ansible-setup
  script:
    - >
      ansible-playbook playbooks/deploy.yml
      --limit staging
      --vault-password-file .vault_pass
      -e "app_version=$CI_COMMIT_SHORT_SHA"
      -v
  after_script:
    - rm -f .vault_pass ~/.ssh/id_ed25519
  environment:
    name: staging
    url:  https://staging.example.com
  only:
    - develop

# ── Stage: Deploy Production ──────────────────────
deploy-production:
  stage: deploy-production
  needs: [deploy-staging]
  <<: *ansible-setup
  script:
    - >
      ansible-playbook playbooks/deploy.yml
      --limit production
      --vault-password-file .vault_pass
      -e "app_version=$CI_COMMIT_SHORT_SHA"
      -v
  after_script:
    - rm -f .vault_pass ~/.ssh/id_ed25519
  environment:
    name: production
    url:  https://example.com
  when: manual        # ← Manual approval required!
  only:
    - main
```

---

## GitLab Variables Setup

```
GitLab → Settings → CI/CD → Variables:

ANSIBLE_SSH_PRIVATE_KEY   → File type, masked
ANSIBLE_VAULT_PASSWORD    → Variable, masked
STAGING_HOST              → Variable
PRODUCTION_HOST           → Variable
SLACK_WEBHOOK             → Variable, masked
```

---

## Σύνοψη 24.3

```
GitLab CI:
│
├── stages: lint → test → deploy-staging → deploy-production
├── YAML anchors: &ansible-setup → DRY setup
├── needs: → dependency ordering
├── when: manual → manual approval για production
├── environment: → tracking deployments
└── Variables: masked + file types για secrets
```
