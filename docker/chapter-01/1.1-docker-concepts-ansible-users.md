## Docker Concepts — Γρήγορη επανάληψη

### Image vs Container
```
Image    = "συνταγή" — αμετάβλητο template
Container = "φαγητό" — running instance από image

Ansible analogy:
Image     ≈ Role (template για κάτι)
Container ≈ Εφαρμογή που τρέχει από το role
```

### Βασικές εντολές Docker:
```bash
# Images
docker pull nginx:latest          # κατέβασε image
docker images                     # λίστα images
docker rmi nginx:latest           # διέγραψε image
docker build -t myapp:1.0 .       # φτιάξε image

# Containers
docker run -d -p 80:80 nginx      # τρέξε container
docker ps                         # running containers
docker ps -a                      # όλα τα containers
docker stop mycontainer           # σταμάτα
docker rm mycontainer             # διέγραψε
docker logs mycontainer           # δες logs
docker exec -it mycontainer bash  # μπες μέσα
```

## Real-World Workflow

```bash
# Χωρίς Ansible + Docker (χειροκίνητα):
ssh server1
apt install docker.io
docker pull nginx
docker run -d -p 80:80 nginx
# → 4 εντολές, μόνο σε 1 server

# Με Ansible + Docker:
ansible-playbook deploy.yml
# → αυτόματα σε 50 servers! ✅
```

```yaml
# deploy.yml — απλό παράδειγμα
- name: Deploy nginx container
  hosts: all
  become: true
  tasks:
    - name: Pull & run nginx
      community.docker.docker_container:
        name:  web
        image: nginx:latest
        state: started
        ports:
          - "80:80"
```

## Τα 4 Patterns Ansible + Docker

### Pattern 1: Ansible εγκαθιστά Docker
```yaml
# Ansible ρυθμίζει το host για Docker
- name: Install Docker
  ansible.builtin.apt:
    name: docker.io
    state: present
```

### Pattern 2: Ansible διαχειρίζεται Containers
```yaml
# Ansible χειρίζεται containers ως resources
- name: Run application container
  community.docker.docker_container:
    name:    myapp
    image:   myapp:1.0
    state:   started
    restart_policy: always
```

### Pattern 3: Ansible deploy Docker Compose
```yaml
# Ansible deploy ολόκληρα stacks
- name: Deploy stack
  community.docker.docker_compose_v2:
    project_src: /opt/myapp
    state:       present
```

### Pattern 4: Ansible builds Images
```yaml
# Ansible χτίζει custom images
- name: Build application image
  community.docker.docker_image:
    name:   myapp
    tag:    "{{ app_version }}"
    source: build
    build:
      path: /opt/myapp/docker
```

## Docker Networking για Ansible Users

```
Docker Networks ≈ Ansible Inventory Groups

[webservers]              docker network: frontend
  web01                     nginx container
  web02                     app container

[dbservers]               docker network: backend
  db01                      postgres container
                            redis container

# Containers στο ίδιο network μιλάνε μεταξύ τους
# με το container name (όχι IP!)
```

```yaml
# Δημιουργία Docker networks με Ansible
- name: Create Docker networks
  community.docker.docker_network:
    name:  "{{ item }}"
    state: present
  loop:
    - frontend
    - backend
```

## Docker Volumes για Ansible Users

```
Docker Volumes ≈ Persistent storage

Χωρίς volume:  container data χάνεται όταν σταματήσει
Με volume:     data παραμένει ✅
```

```yaml
# Δημιουργία volumes με Ansible
- name: Create data volume
  community.docker.docker_volume:
    name:  postgres_data
    state: present

# Χρήση volume σε container
- name: Run PostgreSQL
  community.docker.docker_container:
    name:  postgres
    image: postgres:15
    volumes:
      - postgres_data:/var/lib/postgresql/data
```

## Environment Variables vs Ansible Vars

```yaml
# Ansible vars → Docker ENV
vars:
  db_password: "{{ vault_db_password }}"
  db_name:     myapp
  app_port:    8080

tasks:
  - name: Run app container
    community.docker.docker_container:
      name:  myapp
      image: myapp:latest
      env:                          # ← Docker ENV variables
        DATABASE_URL: "postgresql://user:{{ db_password }}@db/{{ db_name }}"
        PORT:         "{{ app_port }}"
        NODE_ENV:     production
      no_log: true                  # ← κρύψε passwords!
```

## Idempotency στο Docker

```yaml
# community.docker modules είναι IDEMPOTENT ✅

- name: Run nginx container
  community.docker.docker_container:
    name:  nginx
    image: nginx:latest
    state: started

# 1η εκτέλεση: CHANGED (δημιουργεί container)
# 2η εκτέλεση: SUCCESS (container ήδη τρέχει)
# 3η εκτέλεση: SUCCESS (τίποτα δεν άλλαξε)

# Αν αλλάξεις το image:
# → CHANGED (recreates container με νέο image) ✅
```
